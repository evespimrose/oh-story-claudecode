## 추천 메커니즘

### 起点 추천 프로세스

```
출고 -> 시범 기간(7일) -> 육성 기간(21-42일) -> 삼강 추천/상가
```

**테스트 기간**: 동시 출시된 신간이 동일한 트래픽 풀에서 경쟁하며, 7일 총 트래픽은 고정됨.

**육성 기간**: 4개 등급: 방출 패키지++ > 방출 패키지+ > 방출 패키지 > 지원 패키지(위로상). 1-2일마다 1개 트래픽 패키지씩 총 21개 배분. 다음 트래픽 패키지 규모는 이전 성과(계속 읽음+유지율)에 따라 결정. 화제성은 강하지만 유지율이 떨어지면 악순환 발생.

**핵심 데이터**:
- 출고 시 300의 가짜 팔로우로 테스트 기간과 무결절 연결 가능
- 삼강 랭킹 진입 시 최소 500의 가짜 팔로우 필요
- 1000 이상이면 아래 전부 빈곤 구제 패키지, 2000 이상이면 물량 방출+

### 기점 신작 차트 규칙

상위 등재 조건(셋 중 하나 선택하면 하위 등재): 20만 자 이상 / 계약 30일 이상 / 3일 이상 미연재

**차트에 더 오래 머물기 기법**: 내부 투고 통과 후 편집자와 상담하여, 먼저 3만 자 정도까지 발행한 후 계약 절차를 완료하면 4~5일을 더 머물 수 있습니다.

### 토마토 추천 메커니즘

- 추천 노드, 테스트 글자 수, 트래픽 패키지 규칙이 자주 변경되므로 실행 전에 반드시 공식 백엔드, 편집 기준 또는 최신 작가 공지사항으로 재검토하세요
- 토마토 샘플 분석 시 기록: 검증 기간 글자 수, 읽는 중인 수, 완독률/연재 추적, 도서명 태그, 소개 훅
- 현재 scan에서 AI 동질화 샘플이 밀집되어 있으면 동질화 위험과 차별화 검토를 출력하고, 과거 할당 수치를 직접 그대로 사용하지 마세요
- 데이터를 관찰할 때 프로젝트 실제 글자 수 노드와 플랫폼 최신 규칙에 따라 검토 포인트를 설정하고, 고정 글자 수를 하드 규칙으로 사용하지 마세요

### 도서명 소개의 중요성

기점의 새로운 추천 메커니즘에서는 책 제목과 개요가 첫 번째 필터링 단계입니다:
- 책 제목이 주제를 명확히 하면 하한선을 유지할 수 있습니다
- 책 제목 개요 조회수 >> 추적 읽음 >> 완독률/서재 비율
- 문예적 책 제목은 새로운 메커니즘 하에서 육성 기간이 길어집니다

## 데이터 지표 해석

### 번토마토 핵심 데이터

**추적 독자 수** = 최근 7일 업데이트 장편을 읽은 유효 독자 수입니다. 이 지표는 같은 주제, 같은 글자 수 구간, 같은 추천 단계의 샘플과만 횡단 비교가 가능합니다.

| 지표 | 용법 |
|------|------|
| 추적 독자 수 | 최근 독자 유지율과 업데이트 기대도를 판단하며, 통계 주기를 반드시 표기해야 합니다 |
| 읽는 중인 수 | 트래픽 규모를 판단하며, 책의 나이와 추천 단계를 함께 고려해야 합니다 |
| 완독률 | 챕터 연결이 끊기는지 판단; 획득할 수 없는 경우 보고서에 누락으로 표시 |
| 서재/수집 | 유입 후 유지 여부 판단, 책 제목/소개와 함께 분석 필요 |

히스토리 추적 구간은 표본 주석으로만 사용 가능; 현재 플랫폼의 동일 단계 데이터 지원이 없는 한 고정 초기 노출량 예측을 출력하지 않음.

### Qidian 핵심 데이터

- **수집:초판 비율**: 수집과 초판의 비율, 전환 효율을 반영
- **24시간 실시간 추적**：VIP 독자의 실시간 추적, 상위 추천 시 이 데이터를 봅니다
- **첫 구독 데이터 참고**：출시 첫 구독이 100 미만이면 중상 수준입니다

### 범용 데이터 로직

- 완독률 높음 = 콘텐츠 품질 우수, 추적 높음 = 기대감 충분
- 서재 비율은 좋지만 완독 낮음 = 중간 콘텐츠에 문제 발생
- 수익은 누적 조회수/연재 중 등의 지표와 관련이 있지만, 구체적인 수익은 플랫폼 규칙, 계약 및 추천 단계에 따라 달라지므로 반드시 별도로 확인해야 합니다
- 데이터가 좋지 않을 때 우선 확인 사항: 시작 부분 클릭 유도력, 에피소드 유지율, 기대감 단절

## 소개 작성법

핵심 구조: 주인공의 처지 -> 금수저 능력의 기능 -> 첫 번째 통쾌함 미리보기. 설정 설명서처럼 쓰지 말고 광고처럼 작성하세요. 장점은 구체적으로 설명하세요.

**흔한 실수**: 이것저것 단편적으로 서술하며 핵심 주제 부재 | 창의적인 이름이지만 실제로는 보통의 포인트 적립식 시스템 | "주인공이 어떻게 어떻게 할지 살펴보자"는 공허한 상투표현 | "난" 등 너무 어울리지 않는 표현 사용

**간단한 설명 구조 추출**: 삼강 추천(qidian.com/sanjiang/) 또는 베스트셀러 차트의 같은 장르 히트작 간단한 설명 구조를 참고하여, 기능 위치만 추출하세요: 문제, 이익 포인트, 재미 예고, 안정감, 서스펜스. 구체적인 스토리와 표현 복제는 금지합니다.
