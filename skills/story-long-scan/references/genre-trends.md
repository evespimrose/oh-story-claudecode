# 웹소설 소재 트렌드 및 장르 참고
소재 선택, 장르별 집필 핵심, 랭킹 분석 기법을 담은 퀵 레퍼런스 매뉴얼.

---

## 기발한 설정의 소설(아이디어물) 창작

### 영감에서 집필까지

1. 아이디어 얻기 (치트의 원형/장면/진입점)
2. 잠재력 평가 (순수 창작인가? 시장의 기반이 있는가?)
3. 소재 매칭 (익숙한 장르에 대입해 효과 확인)
4. 핵심 셀링 포인트 추출 (감정적 결핍이나 기대감으로 전환 가능한가)
5. 스토리 원형 정리 (프레임워크/치트/진입점)
6. 집필을 통한 검증

### 치트(특전)의 혁신

기초 = 조건 충족 → 피드백 획득. 변형: 다중 조건 단일 피드백 / 단계별 피드백 / 확률형 피드백 / 중첩 가능 피드백

### 장기 연재 방법

1. 핵심 셀링 포인트에서 다양한 각도를 찾아내고, 서로 다른 갈등 패턴을 정리하여 각 패턴당 1~2권 분량 집필
2. 프레임워크 중첩: 다각도의 교차 순환으로 수백만 자의 분량 확보
3. 프레임워크 + 에피소드 순환: 대목표 → 중목표 → 소목표 → 상세 시놉시스

### 트렌드 편승 = 리스킨(Reskin)

핵심 설정을 그대로 가져오되 익숙한 소재로 교체한다. 치트물은 모든 소재와 호환되며, 동일 소재의 트렌드를 따를 때는 기저의 감정선은 유지하고 각도만 바꾼다.

## 소재 선택

85%의 익숙함 + 15%의 참신함. 데이터가 충분하고 완성도 높은 세계관을 구축할 수 있는 카테고리를 선택한다.

## 경계감 3단계 서클

| 서클 | 예시 | 규칙 |
|------|------|------|
| 장르 서클 | 현대물, 현환, 선협 | 대분류 |
| 유파 서클 | 극도물, 범인물, 영지물 | 세분화 |
| 핵심 소재 서클 | 구체적인 셀링 포인트/치트/감정 포인트 | 내용이 이 서클을 벗어나서는 안 됨 |

| 오류 | 결과 |
|------|------|
| 고무 소설에서 관계 묘사 | 경계를 침범함 |
| 영지물에서 심도 있는 상전 묘사 | 고유의 맛이 변질됨 |
| 미스터리물에서 서스펜스 제거 | 핵심 셀링 포인트 소멸 |

## 차트 분석

### 3단계 분류

| 등급 | 빈도 | 요점 |
|------|------|------|
| 신규 소재 | 극히 드묾 | 여러 차트나 여러 작가에게서 중복 샘플이 나타날 때만 트렌드로 표기하며, 그 외에는 관찰 항목으로 분류 |
| 신규 치트 | 적음, 주로 리모델링 | 저비용 검증 포인트로 적합하나, 반드시 소재의 외피와 감정 유발 방식을 바꿔야 함 |
| 신규 기믹 | 흔함 | 높은 동질화 위험이 있으며, 차별화 기제가 없을 경우 우선순위를 낮춤 |

### 플랫폼별 방법

**치뎬**: 싼장 → 첫 구독 차트 → 계약 신간 차트 상위 15위 → 정품에서 만딩 사이의 작품 분석
**판치에**: 신간 차트 끝까지 확인 → 읽는 중인 독자 30만 명 이상을 기준으로 설정

### 치뎬 인기 소재

| 소재 | 요점 |
|------|------|
| 현대물 | 회귀/농사(종천)/연예; 회귀는 어떤 요소와도 융합 가능 |
| 현환 | 극도류, 스탯 투자 및 압도적 전개 등 피드백이 강한 샘플 우선; 전통 현환은 최근 샘플이 부족할 경우 고위험으로 표시 |
| 선협 | 기발한 설정(뇌동) 융합 루트의 최근 샘플 우선 확인; 순수 전통 루트는 추가적인 타겟층 검증 필요 |
| 역사 | 진/당/명/송/삼국; 2차 창작(동인) 스타일의 서술 방식 |
| 제천무한 | 오리지널 에피소드를 쓰지 말고, 2차 창작(동인) 활용 |
| SF | 아포칼립스류(기발한 설정/농사/게임 설정 포함) |

## 장르별 집필 요점

| 장르 | 핵심 요점 |
|------|----------|
| 극도류 | 치트키(금손가락) 속성 포인트 투자, 압도적인 전개; 경계가 명확하고 검증 비용이 낮아 저복잡도 후보로 적합 |
| 범인류 | 소시민의 성장 + 치밀한 계산; 전투력 수치화 + 수명 기반 전개 |
| 위저드류 | 지식 체계 + 실험 및 탐색을 통한 레벨업, 진입 장벽이 높음 |
| 농사(종천)류 | 식당/서점/어장 경영 등; 복잡도가 낮고 차원 이동과 결합 가능하지만, 여전히 샘플 검증 필요 |
| 현대 고무 | 빈출: 무관+학교 투트랙/절친과의 대비/사저의 유혹/모의고사 허세; 《무성》 앞 3장이 황금 템플릿 |
| 동인물 | 사용자가 대상 IP를 명시하고 플랫폼이 허용하며 최근 샘플이 유효할 때만 사용; 기본적으로 '기존 세계관 + 새로운 변수 + 명장면 각색' 구조만 추출 |
| 랭킹물 | 난이도가 낮으며 적절한 진입점 확보가 관건 |
| 시뮬레이션물 | 시뮬레이션으로 감정적 결핍 유도 → 보상 획득 → 현실에서의 만족 |
| 차원 이동 | 표준 템플릿: 치트키 + 역사적 인물 경악 + 운명 개척 |
| 역사물 | 진/당/명/송/삼국 주류; 위기감 + 밑바닥부터 성장 + 명확한 메인 스토리 필요; 송나라 이후는 심의 리스크가 높음 |

## 현대 회귀물

| 차원 | 요점 |
|------|------|
| 일과 사랑의 비중 | 5:5 비중이 잠재력은 가장 높지만 난이도가 매우 높음. 로맨스가 약하면 8:2, 로맨스가 강하면 2:8부터 시작 |
| 기대감 | 성장 서사가 없다면 기대감을 지속적으로 유지해야 함. 미스터리나 반전은 절제하고, 2만 자 단위 기획의 연속성을 유지할 것 |
| 숏폼 콘텐츠화 | 매 장마다 웃음 포인트 배치. 긍정적인 피드백의 인물 관계망을 구축하여 지속적인 밈(Meme) 활용. 같은 밈이 반복되어도 독자가 지루해하지 않게 구성 |
| 동질화 | 한 끗 차이의 참신한 도입부 + 탄탄한 내용 = 충분히 훌륭한 작품. 부족한 것은 콘텐츠가 아니라 트래픽임 |

## 라이트 노벨

핵심 = 드라마틱한 캐릭터성(특히 미소녀 캐릭터) 어필.

- 메인 서사: 미소녀의 현재 곤경 + 타인과의 은원 관계
- 로맨스 라인: 드라마틱한 전개 + 캐릭터 조합으로 발생하는 사건
- 핵심 경쟁력: 캐릭터 디자인 + 부러움을 자아내는 상호작용 상태

---

## 코미디/병맛물

클리셰: 함정에 빠짐 + 역효과 / 지능이 낮아진 악당 / 오해와 엇갈림, 조합 가능.
기저 원리: 독자의 캐릭터 호감도에 따라, 캐릭터가 두려워하는 요소에 스토리가 공격성을 띠게 함.

## 패도총재물(여성향)

| 구분 | 전통적 | 현대적 |
|------|------|------|
| 여주인공 | 캔디형(순진무구) | 독립적인 커리어 우먼 |
| 만남의 논리 | 선행을 통한 우연한 만남 | 업무적 접점 + 독보적인 가치 |
| 남주인공의 조력 | 전방위적인 케어 | 정서적 가치 + 금상첨화 |
| 기저 논리 | 능력 있는 남자와 결혼해 편히 살기 | 나 자신의 강함 + 강자의 마음을 정복 |

연적 악당은 전형적인 '녹차(여우짓)' 스타일을 지양할 것.
