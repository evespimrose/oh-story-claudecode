## 1. 공통 점검

### 장(장) 구성
- [ ] 시작에 훅이 있다 (날씨/풍경/일상으로 시동을 걸지 않음)
- [ ] 중반에 전개가 있다 (빠른 전개 작품은 가시적인 사건; 느리게 달라붙는 작품은 상태 변화로도 가능)
- [ ] 국면에 변화가 있다 (이 장을 읽고 난 뒤 세계가 이전과 달라졌어야 함)
- [ ] 결말은 변화 위에 놓인다 (요약형으로 마무리하지 않음)

### 도입 점검(앞 300–500자)
- [ ] 훅이 있어 독자의 주의를 끌 수 있다
- [ ] 날씨/풍경/일상으로 시작하지 않는다
- [ ] 주인공이 빠르게 등장한다
- [ ] 흥밋거리나 위기가 드러난다

### 장 전진(전진)
- [ ] 이 장은 최소한 목표/위험/정보/관계/자원/정체성/감정 태도 중 하나의 상태를 바꾼다; 빠른 전개(판타오/쾌감물)는 가시적 사건이나 쾌감 포인트가 있어야 하고, 느린 전개/감정물은 낮은 강도의 작은 변화로도 충족 가능하며 매 장 클라이맥스를 강제하지 않음
- [ ] 글자가 늘어났을 뿐인가? (이 장을 삭제하면 어떤 상태 변화가 사라지는가? 답할 수 없으면 압축 필요)
- [ ] 임무/카드 지점이 유용한가: 막힘이 위에서 말한 상태 변화를 가져오는가?
- [ ] 전진의 강약이 작품이 설정한 장르, 약속된 페이스, 비교 대상에 부합하는가; 단순히 정해진 글자 수 틀을 따르는 것이 아닌가

### 정보 전달
- [ ] 긴 분량의 설정 설명문이 없다
- [ ] 정보는 갈등을 따라 전해진다 (사건을 통해 설정을 전달)
- [ ] 설정량은 조절된다 (한 장에 새 개념 3개 초과 금지)

### 장면(씬) 점검
- [ ] 장면에 목표가 있다 (인물이 무엇을 원하는가)
- [ ] 장면에 장애가 있다 (무엇이 막는가)
- [ ] 장면에 변화가 있다 (끝난 뒤 이전과 달라졌는가)
- [ ] 인물은 느끼기만 하지 않고 행동하고 있다
- [ ] 삭제 가능한 단락이 없다

### 장말
- [ ] 결말이 변화 위에 놓여 있다
- [ ] 위기/결정/발견/반전 중 최소 하나가 있다
- [ ] 요약형 결말이 아니다
- [ ] 독자를 다음 장으로 이끈다

### 문장(언어)
- [ ] 공허한 서정 단락이 없다
- [ ] 동일한 감정의 연속 단락이 없다
- [ ] 대화는 인물의 신분에 맞는다 (사람마다 말투가 달라야 함)
- [ ] 감정은 동작으로 구현된다 ("그가 매우 슬펐다"라고 직접 쓰지 않음)
- [ ] 제목 줄을 제외하고는 장·작성 메타 정보가 없어야 함: 다음과 같은 단어는 금지됨 `第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者` ; 앞글과 이어야 할 때는 인물이 인지할 수 있는 사건 앵커나 상대적 시간으로 바꿀 것; 이야기 내에서 실제로 '제X장'을 읽거나 토론하는 맥락의 리얼한 독자 정체성은 예외

### 연재 연속성
- [ ] 이전에 약속한 내용/복선이 잊히지 않았다
- [ ] 갑자기 대량의 새 설정이 끼워들어오지 않았다
- [ ] 복선이 전진하고 있다
- [ ] 이야기 엔진이 계속 돌아가고 있다

### 허수(filler) 탐지
다음 신호가 보이면 = 필러일 가능성:
- 한 장 전체가 대화인데 새 정보가 전혀 없음
- 동일한 감정을 3단락 이상 반복
- 장면 묘사가 500자 넘는데도 줄거리를 진전시키지 않음
- 인물이 과거 일을 회상만 하고 새로운 시각을 주지 않음
- 연속으로 2장 이상 갈등이 없음
- 삭제해도 무방한 흐름 상세/임무 카드 지점 = 필러; 압축하거나 삭제

## 2. 장편 전용

### 황금 3장 점검
- [ ] 1장 앞 500자에 훅이 있는가?
- [ ] 주인공이 1장에 바로 등장하는가?
- [ ] 1장에 사건이 있는가(단순 깔아두기 아님)?
- [ ] 2장에 업그레이드가 있는가(갈등 심화)?
- [ ] 3장에 계속 읽을 이유가 있는가(다음을 보게 만드는 동기 제공)?
- [ ] 앞 3장에 최소 2개의 쾌감 포인트가 있는가?
- [ ] 세계관에 긴 설정 설명문이 있지 않은가?
- [ ] 각 장의 끝에 다음을 읽게 하는 이유가 있는가? (저압/과도 장은 약한 훅이나 단계 목표로도 괜찮음; 강한 서스펜스 강제하지 않음)

### 리듬(페이스) 점검
- [ ] 최근 5장에 명확한 진전이 있었는가?
- [ ] 쾌감 포인트 간격이 5000자 초과인가? (장 구분 기준: 고압/전진 장은 간격을 따지고, 저압/관계/정보 정리 장은 제외)
- [ ] 연속으로 2장 이상 갈등이 없는가? (호흡 장은 정상; 레드라인은 연속 두 장 압력 레벨 ≤1 또는 인접 장 감정 성향이 동일한 경우)
- [ ] 한 권 내에 장의 고저(고압·저압) 배치가 있는가, 전편 동일 강도인가? 저압+과도 비율은 절제되어 있는가(총합 약 15% 초과 금지)?

### 인물 점검
- [ ] 주인공의 행동은 인물성에 부합하는가?
- [ ] 조연이 존재감을 가지는가?
- [ ] 악역의 위상(카리스마)은 현재 단계에 맞는가?

### 다섯 차원 평가 기준

각 차원 0–100점. 점수 결과에 따라 정교 수선 전략을 선택.

### 차원 1: 핵심 일관성
점검 항목: 주요 갈등, 핵심 행동, 인물 동기가 앞뒤로 일관되는가.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 인물 동기가 갑자기 근거 없이 바뀜 | 치명적 | 동기 전환을 촉발한 사건을 추가 |
| 핵심 갈등이 전후 불일치 | 높음 | 갈등 설정을 소급 수정 |
| 핵심 행동이 인물 성격과 모순 | 높음 | 행동을 조정하거나 설명을 보충 |
| 부차적 갈등을 잊음 | 보통 | 회수하거나 약화시킴 |

### 차원 2: 표층 재작성 정도
점검 항목: 문장·어법이 충분히 독창적인가, 진부한 표현을 피했는가.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 원문 문장을 그대로 가져와 어투가 부자연스럽다 | 보통 | AI 어투가 명백할 때만 고치고, 정상 문장은 유지 |
| AI 표식어 다량 사용 | 높음 | 구체적 묘사로 대체 |
| 동일 문형 반복 | 보통 | 표현을 다양화 |
| 묘사가 지나치게 문어적(수사 과다, 문어체, 은유 연속) | 보통 | 구어체/동작 중심으로 바꿀 것; 동작 중심으로 바꾼다고 해서 문장을 모든 걸 짧게 끊어내는 것이 아님, 쉼표 중심의 중문장을 유지하되 서술을 다듬음 |

### 차원 3: 형식 일관성
점검 항목: 단락이 연극적 단위/카메라 컷처럼 자연스럽게 끊기는가, 주어/인물 이름의 리듬이 자연스러운가, 앞뒤 형식 통일성은 있는가.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 글자 수에 기계적으로 따라 단락 나눔 또는 주어 과밀 | 보통 | 극적 단위에 따라 단락 재배치, 단락 시작에 인명 표기, 단중에는 대명사·생략, 중요한 전환에서 다시 인물 지칭 |
| 장 글자 수가 목표에서 크게 이탈 | **높음** | 글·구상 수선 시 먼저 세부 개요로 돌아가 필요한 사건을 채운 뒤 전개; 이미 존재하는 본문에서 AI 냄새를 제거할 때는 새 플롯 추가 금지 |
| 형식 혼란(대화/묘사 형식 불일치) | 낮음 | 형식 통일 |

### 차원 4: 가독성
점검 항목: 장황함, AI 어투, 공허한 요약, 진부한 수사 표현이 있는가.

| AI 어투 특징 | 어떻게 식별 | 어떻게 수정 |
|-----------|----------|----------|
| 공허한 요약 | "그는 마침내 깨달았다" "모든 것이 말하지 않아도 전해졌다" | 삭제하고 행동으로 대체 |
| 진부한 수사 | "운명은 마치 그를 놀리는 것 같았다" | 삭제하거나 구체적 묘사로 교체 |
| 은유 연쇄 | 연속적 다수의 "같다/마치/듯" 사용, 각 장면을 은유로만 설명 | 서사 기능이 큰 몇 개만 남기고 나머지는 동작·사물·소리·결과 중심으로 바꿈 |
| 감정 태그 | "그는 한참 슬펐다" | 행동 묘사로 전환 |
| 심리 묘사 공회전 | 내면 독백이 새 정보가 없거나 같은 감정의 반복 | 공회전 부분만 압축; 새로운 정보·결단·감정 전환이 있는 독백은 분량 규제로 보지 않음 |

### 차원 5: 논리 연속성
점검 항목: 문장 간/단락 간 흐름이 매끄러운가, 설정 충돌은 없는가.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 설정 전후 모순 | 치명적 | 설정을 찾아 통일 |
| 시간선 오류 | 높음 | 타임라인을 표기하고 수정 |
| 인물 정보 불일치 | 높음 | 인물 파일을 만들어 대조 |
| 인과 사슬 단절 | 보통 | 전이를 보충 |

### 정교 수선 전략

다섯 차원 점수 결과에 따라 수선 전략 선택:

| 주요 문제 | 전략 | 설명 |
|----------|------|------|
| 핵심 일관성 저하 | rewrite | 핵심 갈등을 중심으로 관련 단락을 다시 씀 |
| 글자 수 초과 | compress | 플롯을 밀어내지 않는 내용을 삭제・축약 |
| 의미 없는 카드 지점 | compress | 변화를 만들어내는 지점은 살리고, 과정은 압축 |
| AI 어투 심함 | de_ai | 금지어 교체, 문장 구조 재작성 |
| 잔문제 다수 | polish | 언어 디테일 다듬기 |

### 독자 계약과 결말 예비(종국 비축) 상호 심사

참조 `reader-contract-and-progression.md`. 먼저 "위험 요소(무해)인가?"를 묻고, 다음으로 "재미있는가?"를 묻는다: 무해한 것이 곧 재밌다는 뜻은 아니다. 계약 위반이 없다는 것은 치명적 오류가 없다는 의미일 뿐, 감정의 실현력(감정적 보상)이 충분한지도 확인해야 함.

- [ ] 독자 계약: 이 장/이 권이 초반에 내건 약속을 이행하고 있는가, 아니면 핵심 흥미를 기관·조연·우연에 떠넘기고 있는가? 위험 표기: 계약 안전 / 보강 필요 / 계약 파괴.
- [ ] 주인공 대리권: 표면적 등장 시간으로 판단하지 말고 인과적 권한 + 결산 권한으로 심사; "핵심 노드 4문"으로 결정·대체 불가능성·결과·핵심 결산을 점검. 조연은 부분적 행동을 실행할 수 있으나 독자의 기대권을 조용히 빼앗아가면 안 됨.
- [ ] 기대 부채: 약속이 갚혔는가, 연기되면서 이자(대체 보상)를 지급했는가, 아니면 설명/절차/설정으로 소화해버렸는가?
- [ ] 결말 예비(종국 비축): 이 단위에서 이 단계에서 열어서는 안 되는 결말용 카드를 사용했는가(숙적/진상/정체/금손의 상한)? 어떤 성장선이 천장에 가까워진 것은 아닌가, 이후에 연결할 계단이 남아 있는가? 두 질문 모두 '아니오'이면 통과 — 단일 장에서 다수의 이득(다선 동시 상승)은 좋은 설계로 과속으로 보지 않음.
- [ ] 결산 귀속: 기대권의 귀속이 약속대로 결산되는가; 자발적 양도는 "장기 순이익이 음수이고 + 통제/인과권이 하락"할 때 빨간불, 전략적 양도는 더 큰 통제/미래 이익/권력·정보 교환이 보여야 함.
- [ ] 리듬 연속: 클라이맥스/결산 후 짧은 저압과 작은 가시적 보상/보상이 허용되는가, 기계적으로 즉시 위기를 더하지 않는가? 새 요소는 교체(갈아타기) 빚을 지불했는가, 오래된 약속을 회피하지 않았는가?
- [ ] 장르 특수 리스크: 쾌감물/능력 판타지 계열에서 주인공이 반복적으로 바보 같은 또는 피할 수 있는 무능으로 재난을 만들고 타인이 해결하는 방식으로 인과권·결산 신뢰를 해치고 있지는 않은가?
- [ ] 역검증: "안전한 설명"을 지우면 감정은 더 강해지는가? 위험 장면을 남겨두면 더 강한 기대·대가·쾌감이 발생하는가?

- [ ] 종합선: 계약, 주인공 대리권, 기대 부채, 결말 예비가 서로를 지지하는가, 단지 '무해'한 수준에 그치고 있지 않은가.

### 단위(유닛) 감정 인과의 반증 가능성 점검

- [ ] 목표가 단지 "열혈/슬픔" 같은 감정 라벨에 그치고, 이전 상태→트리거→이후 상태의 감정 인과 고리가 없는가?
- [ ] 문제를 해결하기를 기다리는 도구적 역할의 인물(오브젝트)만 존재하지 않는가?
