# 장르 집필 공식

> **용도**：21개 장르의 구조 뼈대、감정 박자、필수 장면、핵심 규칙。장르별로 분류했으며 바로 적용할 수 있다。
> **문체**：지시형——각 공식은 바로 적용할 수 있는 구조 뼈대다。
> **연계**: 현재 skill 내부의 범용 기법 reference를 우선 사용한다. story-setup 배포 후에는 프로젝트 로컬 agent reference bundle의 집필 기법·구조 형식·장르 스타일 모듈 사본을 사용한다.
> **적용 범위**: 이 문서의 리듬 매개변수(회당 500~800자, 짧은 문장과 백묘사 등)는 단편과 사이다물 회차에만 적용한다. 장편 본문은 쉼표를 활용한 긴 문장을 기본으로 하며, 단편 회차의 문법을 장편에 가져오지 않는다.

## 공식 1: 현대 복수·사이다 단편(6장)

| 장 | 단계 | 요점 |
|----|------|------|
| 1 | 공개적인 배신 | 주인공은 그 자리에서 침착하게 반격해 일단 승리한다 |
| 2 | 침착한 처리 | 권력을 동결·회수하고 배경을 설명한다 |
| 3 | 상대의 반격 | 악역이 찾아오면 증거로 사이다를 준다 |
| 4 | 진실 공개 | 감시 영상·증거로 악역의 본모습을 드러낸다 |
| 5 | 상대의 애원 | 더 많은 증거를 보여 주고 철저히 압도한다 |
| 6 | 최종 즉위 | 새로운 질서+숨겨진 진실 공개 |

**감정**：분노 → 쾌감 → 긴장 → 더 큰 쾌감 → 극도의 쾌감 → 여운+충격
**필수 장면**: 공개적인 모욕으로 시작한다, 소름 끼칠 만큼 침착한 반격, 상징적인 행동, 증거의 단계별 공개, 악역의 자백과 무너짐
**규칙**: 주인공은 절대 평정심을 잃지 않는다. 감정 대신 행동을 사용하고, 상대가 히스테릭할수록 주인공은 더 침착해진다. 먼저 악역이 이겼다고 믿게 한 뒤 반격한다.

## 공식 2: 고대 가문 암투·신분 반전(8회)

| 회차 | 단계 | 요점 |
|----|------|------|
| 1 | 버림받고 회귀 | 친부모가 공개적으로 모욕하지만 주인공은 냉정하게 지켜본다 |
| 2 | 후원 공방 | 여동생의 모함으로 맞고, 숨은 선이 움직인다 |
| 3 | 신분이 처음 드러남 | 핵심 인물이 주목하고 신표를 보여 준다 |
| 4 | 연금됨 | 여동생이 밀고해 절체절명에 빠진다 |
| 5 | 신분 공개 | 성지가 도착하고 모두가 충격에 빠진다 |
| 6 | 반격 추진 | 장부를 조사하고 권세가들이 편에 선다 |
| 7 | 상대의 반격 | 소문과 연합 압박 |
| 8 | 최종 압도 | 황제를 알현하고 진실이 밝혀지며 상대가 몰락한다 |

**감정**: 억압×3 → 해방 → 해방 → 짧은 재억압 → 최종 해방
**필수 장면**: 회귀 후 모욕, 누명을 쓰고 맞는 장면, 신표 공개, 신분 공개의 명장면, 여동생의 악행이 단계적으로 심해지는 과정
**규칙**: 신분은 단계적으로 공개하고, 3회 억압 뒤 1회 해방한다. 부모는 「나쁜 사람」이 아니라 「편애」로 묘사한다. 여동생의 악행은 빈정거림 → 모함 → 살해 시도로 높인다.

## 공식 3: 피폐 로맨스 복수·영혼 시점(7회)

| 회차 | 단계 | 요점 |
|----|------|------|
| 1 | 죽음의 회귀 | 3년 전 바람둥이 남자에게 살해당하고 영혼 시점이 열린다 |
| 2 | 학대 현장 | 바람둥이 남자가 가족을 위협하고 경호원이 폭력을 휘두른다 |
| 3 | 불륜 상대의 위선 | 불륜 상대가 가련한 척하며 사망 증명서를 찢는다 |
| 4 | 관을 열고 진실을 확인한다 | 아이가 「저건 엄마야」라고 말하고 혈서와 예약 파일이 공개된다 |
| 5 | 여론 반전 | 실시간 검색어+주가 폭락+불륜 상대가 버림받음 |
| 6 | 붕괴 현장 | 불륜 상대의 목을 조르고 가족에게 책임을 묻는다 |
| 7 | 마무리 | 오빠의 포석, 바람둥이 남자의 마지막 말 |

**감정**：질식할 듯함 → 격노 → 냉정함 → 가슴 아픔 → 쾌감 → 후련함 → 쓸쓸함
**필수 장면**: 작은아이를 살리고 산모는 살리지 않는 선택, 가족이 맞는 장면과 바람둥이 남자가 불륜 상대에게 선물을 사 주는 대비
**규칙**: 영혼이 허공에 떠 있는 시점으로 쓴다. 「막고 싶지만 무력하다」는 감각을 유지하고, 현재와 3년 전의 회상을 교차한다. 바람둥이 남자는 자신의 악행을 합리화하고, 불륜 상대의 말은 모두 독이 된다.

## 공식 4：도시 시스템·역전 장편（앞 3장）

| 장 | 단계 | 요점 |
|----|------|------|
| 1 | 이혼+시스템 활성화 | 함정 사건의 반전 → 이혼 → 시스템 활성화 |
| 2 | 시스템 패널+초보자 보상 | 「폐기 직전」이라는 투덜거림 → 초보자 패키지 → 이혼 |
| 3 | 이혼 후+새 장비 | 오토바이 등장→전처의 후회 복선→부자 관계 |

**필수 장면**: 중년의 위기가 충분히 처절해야 한다. 시스템 패널의 풍자적 수치, 초보자 패키지의 즉시 효과, 전처의 후회 복선, 숨겨진 장비, 자녀 관계를 포함한다.
**규칙**: 시스템 평가와 주인공의 투덜거림이 핵심 웃음 포인트다. 매회 결말에는 시스템 보상이 있어야 한다. 대비가 쾌감의 원천이며, 생활 디테일로 현실감을 만든다.

## 공식 6: 현환 선협·회귀 역전(19장)

```
도입: 전생의 피살 전모 → 핵심 단계로 회귀 → 일부러 전생과 다르게 행동 → 상대가 스스로 의심하고 혼란에 빠짐 → 주변 사람들은 이해하지 못함 → 상대가 점점 더 깊이 빠짐 → 핵심 인물이 돕는다 → 악역을 차례로 무너뜨림 → 최종 결전 → 열린 결말의 해피엔딩
→ 주변 사람들은 이해하지 못함 → 상대가 점점 더 깊이 빠짐 → 핵심 인물이 도움 → 악역을 차례로 무너뜨림 → 최종 결전 → 열린 결말의 해피엔딩
```

**감정**: 억울함 → 쾌감 → 미스터리 → 더 큰 쾌감 → 긴장 → 따뜻함
**필수 장면**: 전생의 죽음이 잔혹하게 단계적으로 심해진다. 회귀 후 첫 행동은 이상해야 한다. 상대의 자기 의심이 핵심 쾌감이며, 배신은 단계적으로 높이고 큰 감정은 절제된 묘사로 보여 준다.
**규칙**: 전생과 같은 일을 하지 않는 것이 가장 큰 치트키다. 이상 행동으로 정보 격차를 만들고, 선협 설정은 감정선을 위해 봉사하게 하며 설정을 과도하게 쌓지 않는다.

## 공식 7: 시대 회귀·이중 복수(19장)

```
도입: 전생의 피살 전모 → 핵심 단계로 회귀 → 일부러 전생과 다르게 행동 → 상대가 스스로 의심하고 혼란에 빠짐 → 주변 사람들은 이해하지 못함 → 상대가 점점 더 깊이 빠짐 → 핵심 인물이 돕는다 → 악역을 차례로 무너뜨림 → 최종 결전 → 열린 결말의 해피엔딩
→ 바람둥이 남자의 전생 죄행 폭로 → 바람둥이 남자는 이겼다고 믿음 → 더 많은 증거 공개 → 바람둥이 남자 붕괴
→ 남주인공의 진짜 신분 공개 → 화려한 사이다 → 남주인공의 후회와 비극적 결말
```

**감정**: 분노 → 후련함 → 달콤함 → 긴장 → 극도의 쾌감 → 여운
**필수 장면**: 전생의 헌신을 도입부에서 분명히 설명하고, 이중 회귀의 공방과 시대 디테일(인조견, 대단결, 맨발 의사)을 보여 준다. 남주인공은 결함이 있어 보이지만 실제로는 완벽하고, 붕괴 장면을 충분히 쓴다.
**규칙**: 시대감은 실제 역사 디테일로 만든다. 「희생양」은 「바람을 피웠다」보다 충격적일 수 있다. 이중 회귀는 이중의 인과를 만들고, 배신은 단계적으로 높인다.

## 공식 8: 궁중 암투·여제 역전(19장)

```
가족이 피해를 입음 → 강제로 혼인 교환 → 겉으로 순종하고 은밀히 포석을 깐다 → 모든 자원을 챙겨 떠남 → 새로운 세력에서 힘을 모음 → 더 큰 음모를 발견 → 동맹과 연합 → 수도 반격 → 구세력 붕괴 → 황제가 되어 개혁하고 해피엔딩
→ 새로운 세력에서 힘을 모음 → 더 큰 음모를 발견 → 동맹과 연합 → 수도 반격 → 구세력 붕괴 → 즉위+개혁+해피엔딩
```

**감정**: 비통한 분노 → 인내 → 의문 → 쾌감 → 극도의 쾌감 → 충족
**필수 장면**: 가족의 피해가 충분히 처절해야 한다. 혼인 교환에서 지혜를 보여 주고, 「가산을 챙겨 떠나는 것」을 전환점으로 삼는다. 각 포석에는 합리적인 동기가 있어야 하며, 반격의 명장면과 즉위 후 개혁으로 주인공의 그릇을 보여 준다.
**규칙**: 주인공은 계획을 설명하지 않고 독자가 추측하게 한다. 고대풍 대화에는 옛스러운 맛을 주되 지나치게 문언체로 쓰지 않는다. 포석은 나중에 돌아보면 깨닫게 되는 효과를 만들어야 하며, 악역은 「이익에 이끌리는 냉정함」을 보인다.

## 공식 9: 현대 미스터리·초자연 시점(18장)

```
설정[귀신이 인간으로 위장함] → 판에 속아 들어감 → 원한이 성장할 수 있음을 발견 → 흐름을 타고 움직임 → 범죄 네트워크 폭로 → 귀신 능력 성장 → 잔챙이 상대 → 배후 조종자 찾기 → 전생의 사인 폭로 → 최종 대결 → 법적·초자연적 이중 처벌
→ 범죄 네트워크 폭로 → 귀신 능력 성장 → 잔챙이 상대 → 배후 조종자 찾기
→ 전생의 사인 폭로 → 최종 대결 → 법적·초자연적 이중 처벌
```

**감정**: 호기심 → 쾌감(경쟁자의 자멸) → 더 큰 쾌감(주인공은 태연함) → 충격(결말의 반전)
**필수 장면**: 설정을 한 문장으로 설명하고, 속은 뒤 「당황하지 않고 오히려 기뻐하는」 반응을 보여 준다. 귀신 시점의 독특한 정보 격차를 활용하고, 능력이 성장할 때마다 새로운 정보를 공개한다.
**규칙**: 귀신 시점이 독특한 매력이다. 「귀신은 악인을 두려워하지 않고 악인이 귀신을 두려워한다」를 활용한다. 미스터리선과 복수선을 엮고, 매회 결말에는 반전이나 새로운 발견을 둔다.

## 공식 10: 가상 역사·성별 반전(19장)

```
가정폭력·오해 → 배우자가 타인을 편애함 → 실망 끝에 포기 → 떠나기로 결심 → 배우자는 대수롭지 않게 여김 → 떠난 뒤 주인공이 좋아짐 → 배우자가 후회함 → 미친 듯이 속죄함 → 주인공은 용서하지 않음 → 비극·열린 결말
→ 배우자는 대수롭지 않게 여김 → 떠난 뒤 주인공이 좋아짐 → 배우자가 후회함 → 미친 듯이 속죄함 → 주인공은 용서하지 않음 → 비극·열린 결말
```

**감정**: 억울함 → 쾌감 → 미스터리 → 더 큰 쾌감 → 긴장 → 따뜻함
**필수 장면**: 도입부의 이상 행동, 경쟁자의 자멸 세 단계(꾀병 → 실언 → 살인), 매번의 양보가 다음 포석이 되게 한다.

```
6 그물을 거둔다(상대에게 양다리 욕심의 선택지를 주고 스스로 무덤을 파게 한다)
7 화려한 퇴장(모든 진실을 공개하고 이민을 떠나며 머리도 돌리지 않는다)
```

**감정**: 깨달음 → 쾌감 → 더 큰 쾌감 → 극도의 쾌감 → 후련함 → 달관
**필수 장면**: 「너에게 줄게」라는 순간, 백월광의 세 번 연속 떠보기(애교 → 울기 → 협박), 바람둥이 남자의 양다리 욕심이 드러나는 장면
**규칙**: 「너에게 주는 것이 최고의 벌이다」를 중심으로 한다. 전생의 기억은 매회 짧게 삽입하고, 주인공의 감정은 「쓸쓸한 웃음」으로 표현한다.

## 공식 21: 공개 심판형 사이다

### 핵심 장면 설계
```
1. 「경기장」을 설정한다(주주총회·가문 연회·회사 로비) — 반드시 공개된 장소여야 한다.
2. 악역이 먼저 「승리」하게 한다(공개 승리 선언, 주인공 모욕).
3. 주인공의 상징적인 침착함(물컵을 들기·정장을 정리하기·미소 짓기).
4. 증거를 한 장씩 던지며 층층이 공개한다.
5. 악역이 득의 → 당황 → 절망 → 붕괴 순서로 무너진다.
6. 상징적인 추방 대사를 사용한다.
7. 모두가 침묵한 가운데 주인공이 머리도 돌리지 않고 떠난다.
```

### 상징적인 행동 모음

| 행동 | 효과 |
|------|------|
| 물컵을 들어 한 모금 마신다 | 소름 끼칠 만큼 침착하다 |
| 차 열쇠를 돌리며 느긋하게 걸어 들어간다 | 승리자의 여유 |
| 샴페인 잔을 자연스럽게 집어 든다 | 전장에서의 우아함 |
| 천천히 몸을 낮춰 그녀와 눈높이를 맞춘다 | 내려다보는 자의 자비 |

### 추방 대사 모음

| 대사 | 장면 |
|------|------|
| 「개와 함께, 다시는 들어오지 마라」 | 회사에서 내쫓는 장면 |
| 「오늘부터 이 건물의 문턱도 다시 밟지 마라」 | 영구 추방 |

행동 모음과 대사 모음은 「침착한 대비+권력 선언」의 방향만 보여 주며, 원문을 그대로 베껴서는 안 된다.

## 단편 장르 창작 핵심 요점표

### 세정물·사이다물
- 사이다 밀도: 3~5회마다 한 번, 악역의 오만함은 단계적으로 높인다.
- 모욕을 당한 뒤 2~3회 안에 반드시 반격한다.
- 주인공은 직접 포석을 깔거나 단호하게 반격한다. 매번 「참고 넘기자」는 선택이 쌓이지 않게 한다.
- 악역에게 자기완결적인 악행의 논리를 부여한다.
- 사이다 뒤에는 질질 끌지 않고 절연·회수·신고를 단호하게 처리한다. 직업적 우위를 보여 준다.
- 사이다물은 회당 500~800자로 쓸 수 있으며, 감각 디테일은 행동 박자에 녹이고 별도 문장으로 분리하지 않는다.

### 감정물·피폐물
- 앞 3분의 1에 구체적인 물건·숫자·습관으로 관계의 질감을 만든다.
- 먼저 따뜻하게 보여 준 뒤 잔혹한 진실로 깨뜨리고, 악역의 오만함을 단계적으로 높인다.
- 결말은 긴 독백이 아니라 조용한 디테일로 쓴다.
- 떠남에는 분명한 촉발 사건이 있어야 한다. 이혼할 때는 돈과 권리를 깔끔하게 요구한다.
- 떠난 뒤에는 새로운 삶의 질감을 보여 주고, 이상한 행동을 암시해 의문을 만든다.

### 고대 배경·복수
- 인물 관계는 한두 줄로 명확히 하고 복잡한 세계관을 만들지 않는다.
- 사이다 장면은 직접적이고 단호하게 쓴다. 질질 끌지 않으며 관청 디테일은 행동 박자에 녹인다.
- 가장 큰 비장의 패는 마지막 4분의 1에 공개한다.
- 신분과 실력은 타고난 비장의 패로 활용한다. 떠날 때는 머리도 돌리지 않는다.
- 악인의 결말은 악행과 대응되어야 한다. 통쾌함에서 후련함과 달관으로 넘어간다.

### 미스터리·추리
- 정보 격차를 배치한다(독자는 알고 캐릭터는 모르거나, 그 반대).
- 배제법 구조로 표면적인 설명을 하나씩 제거한다.
- 동기는 먼저 무엇을 했는지 밝힌 뒤 왜 했는지 밝힌다.
- 회귀·타임슬립은 정보 격차 도구로 사용하며 설정 설명을 길게 늘이지 않는다.
- 반전마다 진실의 일부를 드러내 더 큰 의문을 끌어낸다.

### 시대극·가족애
- 양쪽의 고통을 보여 주고 어느 편도 쉽게 들지 않는다.
- 시대 특유의 물건과 풍습으로 질감을 만든다.
- 서둘러 화해시키지 말고 양쪽이 충분히 상처 입게 한다.
- 절연에는 반복과 갈등이 있어야 한다.
- 관계가 끊어진 뒤에는 새로운 관계로 빈자리를 채운다.

### 후킹 밀도 등급

| 장르 | 밀도 | 선호 요소 |
|------|------|------|
| 복수·사이다물 | 매우 높음: 2회마다 | 사이다, 비장의 패, 대가 |
| 미스터리 | 높음: 2~3회마다 | 정보 격차, 카운트다운, 반전 |
| 감정물·피폐물 | 중상: 3회마다 | 감정, 대비, 여운 |
| 고대 배경·궁중 암투 | 중상: 2~3회마다 | 비장의 패, 사이다, 대가 |
| 시대극·가족애 | 중간: 3~4회마다 | 감정, 대비, 여운 |
