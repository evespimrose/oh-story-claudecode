# 심층 구조 설계

> 1·2급 구조, 3막·5막·6막 구조, 인과 사슬, 플롯 중심과 인물 중심의 선택, 5단계 개요 확장법, 지도 전환, 다중 플롯 장기화 기법을 다룬다. 개요 구조를 설계할 때 참고한다.

## 1급 구조와 2급 구조

### 1급 구조 = 단막극의 연결

하나의 이야기선이 서로 독립된 여러 단막극으로 구성되고, 주인공이 끈처럼 모든 단막극을 꿴다.

- 장점: 사이다 포인트가 촘촘하고 구조가 단순해 오류가 적다.
- 단점: 장편 분량을 지탱하기 어렵고 기대감이 단조로우며 상한선이 낮다.

### 2급 구조 = 단막극을 겹쳐 차원을 높이기

1급 구조의 ‘단막극’을 한 권 전체로 늘려 각 권을 하나의 완결된 이야기로 만든다. 핵심 문제는 한 권 20만~30만 자에서 하나의 이야기만 펼치면 포석이 너무 길어진다는 점이다.

**해결책 = 겹겹이 쌓기**: 큰 이야기의 각 구조 부분 자체가 작은 이야기이도록 한다. 작은 이야기에도 사이다 포인트가 있고, 동시에 큰 이야기를 은밀하게 포석한다. 층층이 진행하다가 절정에서 한꺼번에 연결해 폭발시킨다.

### 3급 구조

권과 권이 더 이상 고립되지 않고 하나의 이야기 구조 아래 통합되며, 모든 사건이 서로 연결되고 상호작용한다. 플롯을 촘촘하게 엮는 능력이 매우 많이 요구된다.

### 장편에 관한 특수한 인식

- 최소 충돌 단위 = 비트(하나의 행동에 하나의 반응이 대응).
- 전환 장의 문제는 대개 정보 포석이 너무 많고 충돌이 너무 적다는 데 있다.
- 극작 이론이 그대로 적용되지 않는 두 지점: ① 인물 아크 — 수백만 자 장편이라면 주인공은 이미 성숙했어야 하므로 주인공을 기능적 도구로 활용할 수 있다. ② 세부 다듬기 — 장편 독자는 잠재의미를 깊게 분석하지 않는다.

## 이야기 기본 구조(주인공 -> 장애물 -> 목표)

**핵심 모델**: 주인공 -> 장애물 -> 목표

기본 구조를 좋은 이야기로 끌어올리는 3단계:
1. **굴곡 추가**: 장애물이 여러 개 있어야 이야기가 된다.
2. **난이도 상승**: 난이도가 같으면 단조롭고, 낮아지면 지루하다. 반드시 점점 어려워져야 한다.
3. **예상 밖의 전개**: 주인공이 목표에 도달하기 직전에 뜻밖의 일을 준다 — 계획이 실패한다. 해결법은 순간적인 발상(즉석에서 떠올린 방법)이나 의미심장한 미소(오래 숨겨 둔 수)를 활용하는 것이다.

### 서브 플롯과 메인 플롯의 양방향 접속법

서브 플롯과 메인 플롯 양쪽에서 동시에 파고들고 마지막에 서로 맞물리게 한다 -> 앞뒤가 모두 자연스럽게 수습된다. 서브 플롯이 ‘고립된 사례’가 되지 않도록 한다. 큰 정책이 단계적으로 전파되고, 주인공의 경험은 거대한 현상의 한 단면이어야 한다.

### 단편에서 장편으로 연결하기

장편 = 여러 단편의 연결, 연결 장치 = 훅. 단편이 끝나기 전에 아직 처리되지 않은 일을 반드시 남긴다. 훅에는 독자의 시선을 다음 장면으로 이끄는 방향성이 있다.

## 3막과 5막

### 이야기의 본질: 사실 -> 사건 -> 이야기

- **사실**: 정적인 제시이며 이야기 자체는 아니다.
- **사건**: 변화한 사실(X에서 Y로의 변화).
- **이야기**: 사건을 선택하고 배열해 인과관계로 엮은 결과물.
- **인과가 의미를 만든다**: 인과 논리를 더하면 독자는 ‘왜?’라고 묻고, 의미가 자연스럽게 생긴다.

### 인과 사슬 구축 수단

| 수단 | 설명 |
|------|------|
| 배열 | 시간 순서를 뒤섞어 인과관계를 만든다. |
| 포석 | 사건 b 이전에 사건 a 곁에 원인을 심는다. |
| 복선 | 사건 a와 사건 h의 원인을 심고 여러 사건이 지난 뒤 드러낸다. |
| 훅 | 사건 d 곁에 사건 e의 원인을 심어 긴장과 궁금증을 만든다. |

### 5막 구조: 인과 사슬을 가장 효과적으로 굽히는 템플릿

| 막 | 규칙 | 인과 사슬 상태 |
|----|------|-----------|
| 1막: 시작 | 원인을 반드시 심는다. | 씨앗 |
| 2막: 전개 | 결과 + 원인, 다음 막의 원인으로 발전한다. | 성장 |
| 3막: 전환 | 결과 + 원인, 다음 막의 원인으로 질적 변화를 일으킨다. | 전환 |
| 4막: 행동 | 결과 + 원인, 가장 뜨거운 국면으로 치닫는다. | 질주 |
| 5막: 결말 | 결과를 회수하고 마무리한다. | 완성 |

**5막 규정**: 인과 사슬은 반드시 5개의 고리를 가져야 한다. 각 고리에는 고정된 기능이 있으며, 단계를 건너뛰거나 순서를 바꿀 수 없다.

### 3막·기승전결·5막의 관계

- **3막**(충돌 시작 -> 대립 -> 해결): 세계의 충돌 자체가 충분히 강해 주인공이 밀어붙이지 않아도 성립할 때 사용한다(종말, 천재지변).
- **4막·기승전결**: 외부의 힘이 주인공을 떠밀어 주인공이 저항할 틈 없이 수동적으로 감당할 때 사용한다(후회물 초반, 숙명에 휘말린 이야기).
- **5막**: 주인공이 벼랑 끝에 몰린 뒤 능동적으로 반격할 때 사용한다(사이다물, 복수극).

**전환의 본질**: 충돌의 성질이 질적으로 변하는 것 — 충돌은 더 심각해지고 주인공의 처지는 더 나빠진다. 전환을 일으킬 원인은 미리 은밀하게 심어야 한다.

### 웹소설 6막: 여파(과시의 심층 논리)

과시의 **본질적 충돌**은 ‘주인공과 사회적 인식의 충돌’이지, 주인공과 악역의 충돌이 아니다.

주인공의 실력에는 두 차원이 있다.
- **표면선**: 전투력 체계에서의 승급.
- **암선**: 사회가 주인공을 어떻게 규정하는가.

표면선이 암선보다 앞서면 충돌이 발생하고 -> 과시가 일어나며 -> 암선이 표면선과 같은 수준으로 올라온다. 불균형이 작으면 작은 과시가, 크면 큰 과시가 발생한다.

올바른 과시 방식은 주인공이 ‘내가 강하다’고 직접 증명하게 하는 것이 아니다. 환경·타인·시간이 사회에 ‘정말 강해졌구나’라고 알려 주게 해야 한다.

### 八股文套路化写作六大模块

1. **定调**（黄金三章本质）：回应读者期待。核心公式：令人不安的处境 + 急待提升的地位 + 充满希望的外挂 + 能被展望的美好未来
2. **金手指设计**：信息挂（最优，不易失控）> 加速升级挂 > 物品调用挂（容易失控）。核心：简单，功能与升级规则清晰
3. **脸谱化角色**：给角色贴标签，一看到特征就想起角色
4. **升级流节奏**：目标->行动->完成->奖励循环，周期要短
5. **密集爽点轰炸**：不爽->移除不爽=爽
6. **套路化冲突**：冲突本身越简单越好理解，悬念构建越复杂越好吸引人

## 5단계 개요 확장법

| 단계 | 설명 |
|------|------|
| 1단계 | 전체를 통괄하고 한 문장으로 책 전체를 요약한다. |
| 2단계 | 하나의 이야기 사건 = 하나의 2단계 메인 플롯. |
| 3단계 | 구체적인 플롯. |
| 4단계 | 더 세밀한 플롯 추론. 예: 사촌 형과의 충돌 -> 모욕 -> 분발 -> 금손가락 -> 상대를 완전히 쓰러뜨림. |
| 5단계 | 가장 구체적인 과정, 금손가락을 얻는 세부 과정까지 포함한다. |

**하위 단계는 상위 단계를 지원한다.** 3단계면 장편을 지탱하기 충분하고, 5단계는 혼란을 일으키기 쉽다. 위에서 아래로 확장하면 집필이 막히지 않지만, 아래에서 위로 올리면 막히기 쉽고 메인 플롯에서 벗어나기 쉽다.

### 암선 설계

- 암선 = 독자가 쉽게 알아차리지 못하는 선, 예상 밖의 결과를 만드는 선.
- 암선은 처음부터 끝까지 전체를 통괄하되 직접 설명하지 않고 복선을 남긴다.
- **천 리를 가는 하나의 복선** = 답은 시작부터 주어졌지만 독자는 마지막에야 알아차린다.
- 미스터리에서 흔히 쓰는 구조: 여러 복선을 동시에 진행 -> 한곳에 모음 -> 다른 복선과 다시 결합 -> 마지막에 전체를 통합한다.

### 8개 플롯선 배치

3~4개의 선이면 충분하다 — 메인 플롯(목표 추진) + 감정선 + 1~2개의 서브 플롯·암선(복선 심기). 하위 선은 상위 선을 지원해야 한다.

## 大纲结构选择：重剧情型 vs 重人设型

### 强主线（二级结构）

典型：升级文、悬疑文。重剧情轻人物，配角是工具人。

核心特征：
- 每卷有完整三幕式，每幕又有小三幕式（嵌套）
- 只有一条主线，所有支线推动主线

**大钩子设计**：主线拆成大支线，每个最终目标 = 大钩子。
- 大钩子必须不间断，一个断了马上接另一个
- 更换大钩子关键是铺垫，不能突兀

### 弱主线（一级结构）

典型：无敌文、日常文。轻剧情重人设。

核心特征：
- 单元剧模式，各有完整三幕式
- 公式：核心爽点 + 讨喜人设 + 单元剧舞台
- 不需要明确主线，主角串联一切
- 人设的新颖是重点

### 过渡型

开局弱主线（单元剧日常），后期逐渐过渡为强主线。

### 支线设计原则

支线必须与主线有关，否则是废线。支线人物身份设定自然服务于主线。

## 传统文框架与四大留存手段

### 권별 프레임 설계(목적 + 절정 결말)

프레임 = 뼈대, 플롯 = 겉모습이다. 매 권에서 두 가지를 확실히 한다. ① 새 장소에 온 목적은 무엇인가. ② 큰 절정으로 어떻게 끝낼 것인가.

### 4대 독자 유지 수단

1. **승급**: 전투력뿐 아니라 지위와 재산도 포함한다.
2. **자원 곤경**: 수련에는 자원이 필요하며, 자원을 확보하는 과정은 독자를 붙잡는 좋은 수단이다.
3. **목표 설정**: 큰 목표 + 작은 목표 + 가짜 목표(반드시 이룰 필요는 없으며 기대를 끌어올리는 데 사용).
4. **수수께끼 해제**: 빙산의 일각을 보임 -> 단계적으로 해제 -> 안개를 계속 걷어 냄.

## 지도 전환과 지도 구조

### 지도 전환의 3가지 발전 방식

| 세대 | 핵심 | 문제점 |
|------|------|------|
| 1.0 승천형 | 인간계 -> 선계 -> 신계 | 기존 인간관계를 모두 버림 |
| 2.0 연꽃 지도법 | 연꽃 심장부의 핵심 지도 + 꽃잎 같은 분기 | 공간에 한계가 있음 |
| 3.0 새 방식 | 가문물·시뮬레이터·버전 반복 | 중반부터 포석해야 함 |

### 지도 전환 3법

1. **천 갈래 만 갈래법**: 두 대형 지도 사이에 끊임없이 실마리를 잇는다.
2. **대형 지도를 바꾸지 않는 법**: 작은 지도만 바꾸고 하나의 대형 지도 안에서 움직인다.
3. **연꽃 지도법**: 지도가 연꽃처럼 층층이 펼쳐진다.

### 최상위 프레임법(붕괴 방지)

집필 전 지도 전체의 최상위 세력을 ‘기둥’으로 먼저 세운다. 최상위에서 아래로 확장한다. 지역 -> 소가문 -> 소문파 -> 공법·보물. 등장인물 모두가 어떤 최상위 세력과 연결되도록 한다.

**눈금자 사고**: 최상위 실력의 표현력을 미리 기준점으로 설계한다. 초반 보스=5, 중반=50, 후반에야 100을 쓴다.

### 인간관계 선행법

다음 지도로 가기 전에 먼저 인간관계를 펼쳐 둔다. 핵심은 인간관계가 움직인 뒤 -> 주인공이 움직이는 것이다.

### 지도 전환의 핵심 인식

- 대형 지도를 바꾸면 추가 구독자의 3분의 1을 잃을 수 있다.
- 잃은 독자가 항상 돌아오는 것은 아니다.
- 이후 전개가 좋으면 추가 구독이 다시 오를 수 있다.

## 다중 플롯으로 장편 쓰기

### 다중선 병행과 떡밥 회수

시작부터 메인 플롯에 복선을 심어 서브 플롯을 연다. 메인 플롯 + 두 개 이상의 서브 플롯을 동시에 전개하고, 메인 플롯이 잠시 멈추면 -> 서브 플롯이 이어받는다. 계속 떡밥을 던지고 회수하는 것 = 플롯을 끊임없이 확장하는 일이다.

### 다중선으로 피로감 완화하기

긴 플롯 중간에 조연 시점의 부수적 사건을 반 장가량 넣어 잠시 숨을 돌리게 한다. 전환은 자연스러워야 한다. 메인 플롯에 서브 플롯의 복선을 심기 -> 적절히 전개하기 -> 메인 플롯으로 돌아가기.

## 서양 판타지 창작 요점

**소재 선정**: DND형, 마법사물, 영지 경영물, 영주물 같은 스테디셀러를 선택한다. 고무력물과 일본식 판타지는 피한다.

**세계관**: 인물의 대화와 행동으로 보여 주고 긴 설정 독백은 피한다.

**인물**: 독자의 진입 장벽을 낮추는 음차 번역명을 사용한다. 먼저 금손가락의 특성을 설계하고 인물 성격을 그 특성 주위로 전개한다. 도덕적 사이다는 가장 높은 단계의 사이다 포인트다.

## 1급 구조 = 비교 작품의 플롯 단위(리듬 비교의 축)

1급 구조는 하나의 완결된 단막극이다. 하나의 갈등이 시작부터 폭발과 수습까지 이어지며, 약 1.5만~3만 자 또는 여러 장으로 구성된다. 비교 작품을 분석해 얻은 ‘플롯 단위·장 요약·사이다 순환’이 곧 1급 구조의 연속이고, 내 작품의 권 개요에 있는 ‘플롯 단위’도 1급 구조다. 따라서 ‘1급 구조’는 이론적 명칭이고 산출물에서는 **플롯 단위**로 구현된다(비교 측=분석해 뽑은 플롯 단위, 내 작품 측=권 개요의 플롯 단위 카드). 비교 작품의 리듬을 이식한다는 것은 새 구조를 만드는 일이 아니라, 비교 작품 1급 구조의 연속에서 감정과 기능은 남기고 소재를 바꿔 내 권 개요에 옮기는 일이다.

### 핵심 지점법(모든 규모를 통일하는 리듬 앵커)

모든 규모(작품 전체·권·1급 구조·서브 플롯·장)에는 시작, 1/4, 중점, 3/4, 결말의 다섯 핵심 지점이 있다. 그중 1/4·중점·3/4는 핵심 장면을 배치하는 자리다. 핵심 장면은 세 종류다.

| 유형 | 의미 |
|------|------|
| 플롯 역전 | 전개는 독자의 예상 안에 있지만, 주인공의 해결 방식이 감탄을 부른다(망신 주기, 위기에서 구하기). |
| 플롯 전환 | 예상 밖의 변화(신분 반전, 적이 친구가 됨, 국면의 급변). |
| 촉발 장면 | 작품 전체 또는 한 권에서 처음으로 핵심 메인 플롯과 직접 연결되는 운명 변화의 순간. |

모든 규모에서 세 자리를 전부 채울 필요는 없지만, 한 권 안에는 최소한 1/4·중점·3/4에 각각 하나의 핵심 장면을 배치해 처음부터 끝까지 한 가지 강도만 유지하지 않도록 한다.

### 비교 리듬 이식(권 개요 확정 전 1회 수행, 비교 작품이 없으면 건너뜀)

1. **구간 선택(플롯 단위 기준)**: 주 비교 작품에서 이번 권이 비교할 1급 구조의 연속을 고른다. 선택 단위는 분석 산출물의 플롯 단위(`剧情/{剧情标题}.md`)다. 먼저 주 비교 작품의 `剧情/README.md` ‘플롯 단위 목록’을 읽는다. 목록이 있으면 작품당 파일 하나씩에서 ‘유형·장면 태그’로 같은 유형을 바로 찾는다. 목록이 없으면 `剧情/*.md`에서 ‘유형’ 행(첫 번째 키·필수 열거값) + ‘장면 태그·클리셰 프레임 위치’ 행(두 번째 키)으로 같은 유형을 고른다. 그래도 없으면 장 범위로 되돌아가 구간을 고르며 이 과정에서 멈추지 않는다. 비교 작품이 여러 개면 `cross-book-recall.md`의 개요 예산에 따라 보조 비교 작품에서 같은 유형 항목을 보충한다. 반드시 `剧情/节奏.md`(폭발 밀도·사이다 순환)를 읽으며, 없으면 요약으로 리듬을 추측하지 말고 먼저 복구하거나 분석 Stage 3을 다시 실행한다. 이번 권에서 비교하는 1급 구조 수는 대략 이번 권 글자 수 ÷ 1.5만~3만이다.
2. **핵심 지점 표시**: 비교한 1급 구조가 1/4·중점·3/4에 어떤 핵심 장면을 두었는지 보고 역전·전환·촉발로 판정한다. 요약의 ‘유형=전환점’인 사건점과 기조의 급변(예: 따뜻함→억압감)은 감각에 기대지 않는 확실한 앵커다. 플롯 단위의 ‘구조 분포’(포석·전개·절정·수습기)와 ‘사건점 인덱스’도 같은 역할을 한다.
3. **소재 교체**: 비교 작품의 감정 사슬과 기능 위치는 남기되 대상·장면·사건은 모두 내 작품 것으로 바꾼다. 구체적인 장면을 베끼지 않는다. 기능 위치 목록은 필수 권위 파일 `剧情/情绪模块.md`의 교체 가능한 항목에서 가져오며, 파일이 없으면 대체 목록을 만들지 말고 먼저 복구한다.
4. **약점 보정**: 소재를 바꾸기 전에 `拆文报告.md`의 ‘모방 비권장’을 대조한다. 비교 작품이 특정 핵심 지점에서 약하게 처리했다면(느린 도입의 여백, 주인공의 장기 관망 등 이미 알려진 약점), 이식할 때 그 자리에 빠진 핵심 장면을 보충하거나 뒤의 핵심 장면을 앞당긴다. 비교 작품의 약한 처리를 함께 베끼지 않는다.
5. **장 배치 + 권 개요 반영**: 교체·보정한 핵심 장면을 이번 권의 같은 상대 위치에 둔다. 여기서 1/4·중점·3/4는 **권 단위**다(1/4≈전체 장 수×0.25, 중점×0.5, 3/4×0.75). 권 안에 1급 구조가 여러 개면 각 1급 구조 내부에도 포석→역전→수습이 따로 있으므로 권 단위 핵심 지점과 혼동하지 않는다. 핵심 지점 사이에는 일반 추진 장을 넣고, 각 핵심 지점 뒤에는 필요에 따라 호흡 장·관계 장을 넣는다. 권 개요의 ‘비교 구조 좌표’와 감정선의 장 위치 열에 기록하고, 세부 개요를 이어 쓸 때 각 장에 장 위치를 표시한다. 선택한 플롯 단위는 `{书名}《剧情标题》` 형식으로 플롯 단위 카드의 ‘비교 플롯 참조’에 기록한다.

가까운 곳은 세밀하게, 먼 곳은 거칠게: 현재 권만 세밀하게 배치하고 이후 권은 거친 좌표만 잡으면 된다. 시작부터 책 전체를 확정할 필요는 없다.

一个最小例子（demo《让你管账号，你高燃混剪炸全网》）：对标结构的 1/4 是“小人物拿出粗糙作品，无人看好”，中点是“作品爆火，体制内外同时关注”，3/4 是“专业力量进场替代，反而证明主角不可复制”。换到江晨这条军宣线后，1/4 落成他用手机拍《诸君，且听龙吟》、画质粗糙却先把军魂拍出来；中点落成视频引爆全网和参军热潮；3/4 落成专业团队高清重拍，却被周薄森当场指出“缺了灵魂”，张耀祖最终拍板继续用手机原版。保留的是“轻视→市场验证→权威替代失败→价值坐实”的情绪链，素材、场景和角色关系都来自本书。

### 플롯 단위별 세부 개요 작성(세부 개요 배치 경계)

세부 개요 한 배치 = 권 개요의 플롯 단위 하나(약 5~15장)다. 규모 환산: 플롯 단위 글자 수 ÷ 장당 목표 글자 수 -> 장 수. 장당 목표 글자 수는 해당 작품의 기존 세부 개요 관례를 따르며, 관례가 없으면 장르 리듬에 따른 기본값을 쓴다(빠른 리듬·짧고 빠른 전개 약 2,000자, 균형형 약 3,000자). 플롯 단위가 1.5만 자를 넘고 비트에 독립 절정이 둘 이상 있으면 여러 플롯 단위로 나누고, 그렇지 않으면 하나의 플롯 단위로 둔다. 플롯 단위가 10장을 넘으면 두 배치로 나누어 개요를 만들고 두 배치는 같은 한 번의 리콜을 공유한다. 첫 배치는 앞 10장을 상한으로 하며 단위를 넘을 수 있다. 넘어간 플롯 단위는 카드를 만들 때 한 번 리콜하고, 남은 장은 이후의 순환 배치가 플롯 단위 카드 결론을 공유한다. 정박 규칙은 바뀌지 않는다(참조: [Phase 3: 개요 구축](workflow-setup.md#phase-3大纲搭建)).

建卡时做一次**剧情批召回**：读剧情单元卡「对标剧情参照」指向的剧情单元（≤3 个文件）的「结构分布」「情节点索引」，回查该书 `剧情/节奏.md` 同章节区间的爽点循环 / 触动点与被引情绪模块卡，提炼 5-8 拍共性节拍写入剧情单元卡「单元节拍/章功能分配」，单元情绪引擎字段对照主对标 `剧情/情绪模块.md` 的可复现模块校准。若主产物存在但被引的单个情绪模块卡未命中，只跳过该卡；`剧情/情绪模块.md` 或 `剧情/节奏.md` 文件缺失仍按上方 fail-fast 规则先修复。换素材与修硬伤纪律同上方迁移步骤 3/4——保留情绪链和功能位，对象、场景、事件全换，对标弱处理就地修正。结论固化进剧情单元卡后，逐章细纲只消费剧情单元卡，不重读剧情单元。

매일 연재하는 중 권 개요에 ‘비교 플롯 참조’ 등 현재 프로토콜의 필수 필드가 빠진 것을 발견하면, 먼저 권 개요를 보충한 뒤 세부 개요를 만든다. 잠긴 권 개요에는 자동으로 되써서는 안 되며, 개요 보충 경계에서 멈춰야 한다. 비트 분석 과정은 추적 파일에 쓰지 않고, 미래의 연속성에 영향을 주는 최종 제약이나 다음 장의 약속만 이번 장 추적 트랜잭션에 넣는다.

## 장 위치와 강약 조절(‘매 장이 단편처럼 보이는’ 문제 해소)

한 권 안의 장은 원래 압박의 높낮이가 있어야 한다. 여기서 압박 등급은 **폭발·충돌의 강도**를 뜻한다(서스펜스 척도 1 미세 / 2 소 / 3 중 / 4 대 / 5 극 재사용). 감정 강도와는 다르다. 관계를 회수하거나 눈물 나는 장은 압박이 낮아도(폭발이 작아도) 감정 강도는 최고일 수 있으며, 감정 강도는 권 개요 감정선의 ‘감정 기조 + 강도’가 담당한다. 장 위치는 ‘이 장이 속한 1급 구조 안에서의 위치’에서 자연스럽게 나오며 독립 태그를 따로 붙이는 것이 아니다. 1급 구조의 첫 장은 대개 포석·공감, 중간은 역전, 마무리는 폭발과 수습을 담당한다. 황금 도입부, 절정 결산 + 온기 같은 장은 ‘고압 + 관계’처럼 복합 표기를 하거나 비워 둘 수 있다.

| 장 위치 | 기능 | 압박 등급 | 권 내 비중(균형형·장편 기준선, 강제 할당 아님) | 훅 요구 |
|------|------|--------|--------------------------|----------|
| 고압 장 | 망신 주기·신분 폭로·반전·절정, 핵심 지점의 핵심 장면 착지 | 4~5 | 약 15~20% | 장 끝 강한 훅, 역전·전환 담당 |
| 일반 추진 장 | 메인 플롯 추진, 충돌 상승, 단막극 중반 | 2~3 | 약 40~50% | 장 끝 중간 훅, 최소 하나의 작은 사이다 또는 기대 상승 |
| 수련·시행착오 장 | 실력·자원 축적, 능력 포석, 실패와 재시도 | 2 | 약 5~10% | 진행 훅(조금 부족함·곧 돌파), 반전은 없어도 됨 |
| 관계 회수 장 | 감정선 실현, 관계 전환, 주변 인물의 일상 | 2~3 | 약 5~10% | 감정 훅, 밀고 당김도 메인 플롯과 연결 |
| 저압 일상 장 | 절정 뒤 휴식, 관계 온도 상승, 강약 조절 | 1~2 | 약 10% 이하 | 약한 훅 또는 감정 훅만 허용, 반전·사이다 강요 안 함 |
| 정보 정리 장 | 장면 전환, 설정 전달, 시간 연결 | 1 | 약 5% 이하. 합칠 수 있으면 합치고 단독 장은 최소화 | 뚜렷한 사이다는 없어도 됨. 정보를 ‘연기’로 전달하고 끝에는 다음 구간의 목표 제시 |

두 가지 하한선:

- **기대를 끊지 않고 폭발을 분산한다.** 저압 장에 사이다나 반전이 없어도 되지만, 모든 장에는 다음을 읽게 하는 이유(작은 호기심·단계 목표·미묘한 기대)가 있어야 한다. 낮추는 것은 폭발 강도이지 앞으로 나아가는 힘이 아니다.
- **같은 감정 모티프의 밀집 금지.** ‘매 장이 단편처럼 보이는’ 문제보다 더 은밀한 피로 원인은 여러 장에 같은 감정 모티프가 고강도로 연속되는 것이다(예: 다섯 장 연속 국가·가족애 또는 눈물). 권 개요의 감정선을 배치할 때 인접한 3~4장의 감정 기조를 줄마다 보고, 같은 모티프가 2~3장을 넘겨 이어지지 않게 한다. 훅을 자르는 대신 감정·훅 방식·다중 플롯의 교차로 차별화한다.

장르별 등급(위의 비중은 균형형·장편 기준선이며 장르별로 나눈다): 판치에의 짧고 빠른 전개·남성향 일선은 고압 장이 30%를 넘고 호흡 장이 5% 안팎까지 줄어도 정상이다. 기준선을 이유로 ‘호흡을 보충하고 고압을 자르면’ 오히려 추가 구독이 떨어질 수 있다. 여성향·세태물·후회물은 인물 설정과 관계의 수용량이 커서 관계·저압 장이 더 많을 수 있지만, 여전히 감정의 꺾은선은 유지해야 하며 매 장에 세 번의 반전이 필요한 것은 아니다. 저압·관계 장의 위치는 볼거리이지 채우기용이 아니다.

글자 수 예산과의 연결: 장 위치는 밀도·희소 비율의 하한만 바꾸며 Σ 계약은 바꾸지 않는다. 고압 장은 많은 밀도점으로 Σ∈[장 목표, ×1.1]에 도달한다. 저압 일상·정보 정리·순수 전환 장은 포석(120~150)과 희소점(≈40)으로 분량을 채우며 밀도점 0개도 허용한다. 단, 관계 회수 장은 최소 하나의 감정 밀도점(≈250)을 유지해야 관계가 무너지지 않는다. 집필 뒤 글자 수가 목표의 90% 미만이라 위치상의 빚이 생기면, 고압·추진 장은 밀도점을 보충해 다시 쓰고 저압·전환 장은 포석·상호작용·연기 비트를 보충한다. 사이다 밀도점을 억지로 넣지 않는다. 낮은 밀도점은 설계이지 빚이 아니다.
