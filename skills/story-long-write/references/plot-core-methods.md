## 소개요4단계법

세부 대강과 본문 비율은 **1:2.5 ~ 1:3** 사이로 유지한다.

다음 네 단계로 진행한다:

1. **분단 판단** — 대강을 플롯 노드별로 분단한다
2. **목적과 효과 표기** — 각 단락에 목적과 기대 효과를 표기하되 사건을 풀어쓰지 마라
3. **상세/간략 표기** — 어떤 단락을 상세히 쓸지, 어떤 단락을 간단히 처리할지 명확히 한다
4. **빠른 위치 파악** — 이후 글쓰기 때 해당 단락이 전달해야 할 목적과 효과를 빠르게 찾을 수 있게 한다

기억하라: 세부 대강은 목적과 효과만 신경 쓰고 사건 전개는 쓰지 않는다.

## 클라이맥스역추적법과AB 초안

### 핵심 사고

클라이맥스에서 뒤로 역추적하여 필요한 인물과 사건을 깔고, AB 교차법으로 채워 넣는다.

### AB 초안법

| 기호 | 의미 | 방법 |
|------|------|------|
| A | 감정 압박/포석/복선 | 어려움 배치, 강력한 적 등장, 미스터리의 실마리 심기 |
| B | 감정 끌어올림/희망 제공/작은 성취 | 작은 반전, 작은 진전, 독자가 잠깐 쾌감을 느끼게 함 |

작업 흐름: 클라이맥스 확정 → 필요한 포석 역추적 → A B A B A B로 배치 → 집필 시에는 현재 AB 구간만 집중해서 쓸 것.

적용 장면: 템포가 빠르고 명확한 클라이맥스 포인트가 있는 플롯에 적합.

## 클라이맥스구축공식

### 5단계 공식

순서대로 실행: **에너지 축적 → 가짜 승리 → 붕괴 → 교차 사투 → 미완으로 마무리**

1. **에너지 축적**:희생 + 초조함을 바닥으로 깔아 독자를 '구경꾼'에서 '참여자'로 끌어들인다
2. **가짜 승리**:먼저 희망을 주고 그것을 산산이 부순다(감정 격차 = 반전의 충격력)
3. **붕괴**:모든 복선 한 번에 터짐 + 주인공을 단독 절망으로 밀어넣음(도움 전부 소실)
4. **교차 사투**:대항 라인과 절망 라인을 번갈아 전환(전환할 때마다 긴장감 상승)
5. **미완 마무리**:여운은 남기되 승패는 즉시 공개하지 않음

핵심 조작: 가짜 승리는 흔히 쓰는 클라이맥스 기술이다. 강한 반전, 강한 압박 또는 대형 클라이맥스에 적합하다; 저압의 장, 보상형 장, 일상/관계 회수 장은 가짜 승리가 필요 없다. 가짜 승리가 없을 때는 다른 방식으로 감정 격차나 명확한 성취를 제공해야 한다.

## 훅분류과오프닝 흐름

### 세 가지 훅 유형

| 훅 유형 | 특징 | 쓰는 법 포인트 |
|--------|------|----------------|
| 사건훅(사건 훅) | 초반에 집중, 약 5장 | 바로 사건으로 개시, 환생/금손 같은 배경 설명을 길게 하지 않음 |
| 금손훅(금손 훅) | 전편에 분포, 초반 많고 후반 적음 | 주인공과 곤경을 먼저 쓰고 금손을 끌어들임 |
| 캐릭터 설정훅(캐릭터 훅) | 캐릭터가 직접 플롯을 만들어냄 | 캐릭터 자체가 지속적으로 드라마를 생성할 수 있을 때만 사용 |

규칙: 사건형 훅과 금손형 훅은 혼용하면 안 된다.

### 두 가지 표준 오프닝 흐름

**사건형 오프닝**:사건 개입(약 5장) → 주선(메인 라인) 연결 → 목표 분할 → 단계별 쾌감 루프

**메인라인 오프닝**:주인공 현황 묘사 → 몰입감 조성 → 사회 환경 묘사 → 주인공 목표 설정 → 목표 분할(문턱 설정) → 금손 바인딩 → 첫 상승 획득 → 감정적 흔들기 2–3회 → 완료 → 다음 목표 도출

### 훅으로 유입 끌어오는 전략

| 전략 | 방식 |
|------|------|
| 훅 연장형 | 도입 훅을 핵심으로 삼아 이후 비슷한 훅들을 계속 구성 |
| 훅 유입+일반형 | 도입 훅은 단지 유입 담당, 이후에는 일반 장르 내용 전개 |

도입 훅의 기능은 클릭과 연재 약속을 만드는 것이다. 목적 달성 후 반드시 메인라인에 매달아야 한다.

작가가 책을 시작하기 전에 평가: 훅이 이후 더 많은 분량을 끌어낼 수 있는가? 끌어내기 어렵다면 "훅 유입+일반형" 전략을 사용하라.

## 주선의 올바른 정의

**메인라인은 곧 '업'이 아니다(메인라인 ≠ 레벨업)**. 메인라인은 '한 가지 일'이며, 레벨업은 주인공이 목표를 달성하기 위해 하는 행동이다.

| 개념 | 정의 | 예시 |
|------|------|------|
| 목표(주선) | 주인공이 완수해야 하는 한 가지 일 | 투파창궁: 운람종에 복수하러 가는 것 |
| 행동 | 주인공이 목표 달성을 위해 하는 행동들 | 열심히 수련하고 계속 실력을 끌어올리는 것 |

메인라인이 다음 특징을 만족하는지 점검하라:
- 메인라인은 '한 가지 일'이어야 하며, 요소의 나열이 되어서는 안 된다
- 메인라인이 완료되면, 후속 메인라인을 포석으로 열거나 작품이 종결되어야 한다
- 중심점(앵커)이 잘못되면 이후 모든 플롯이 틀어진다

## 글막힘대응법과플롯순환설계

### 핵심 공식

장르 + 금손 + 주인공 정체 = 순환 패턴. 이 세 요소는 일치해야 한다.

### 6가지 고전적 순환 패턴

| 유형 | 순환 구조 | 순환 동력 |
|------|---------|---------|
| 사건 연쇄 순환 | 사건 → 추리 → 부분 진실 → 더 큰 미스터리 → 새 사건 | 정보 격차 + 추리 |
| 약한 척 강자를 제압하는 순환 | 은근히 성장 → 도발 → 압도 → 충격 → 계속 성장 | 독자-인물 정보 격차 |
| 자원 축적 순환 | 자원 → 스킬 → 실력 → 신규 맵 → 신규 자원 | 나선형 상승 |
| 극적 반전 순환 | 손해 → 반전으로 더 벌기 → 더 큰 베팅 → 또 벌기 | 수치 팽창에 의존하지 않음 |
| 조직 허브 순환 | 각자 모험 → 정보 집결 → 파생 플롯 | 정보 교환 + 다중 라인 |
| 로드무비 순환 | 한 구간 가기 → 사람 만남 → 또 가기 → 또 만남 | 캐릭터 빌드업 능력 |

### 지도 네 세력 프레임

초보 마을(시작 맵)은 네 가지 세력이 포함되어 자원 폐쇄 루프를 형성해야 한다 — 이것이 전체 프레임이다; 이후 지도 변경 시 단순화 가능(아래 '지도 변경의지도그림상세·간략설계' 참조) 하지만 현금화/자원 폐쇄 루트는 놓치지 말 것:

1. **학교/무관** — 스킬 학습, 실력 향상
2. **상인/약방** — 수확을 팔고 자원 획득
3. **산적/적** — 배운 것을 보여줄 대상
4. **관청/관리 기관** — 더 높은 상승 통로

### 지위-환경 동기화 원칙

지위가 올라가면 환경의 위험도도 올라가야 한다. 둘이 동기화되지 않으면 독자는 지루해한다.

### 지도 전환 세 전략

1. **구신지도 연동**(새 세력이 구 세력의 상위)
2. **사람을 데려가기**(중요 인물을 새 지도에 데려감)
3. **사전 포석으로 매력 만들기**(독자가 새 지도로 가고 싶게 만드는 포석)

### 특수 유형 처리

- **천재류**:레벨 개수를 크게 늘려 수치가 몇십 장 만에 붕괴하지 않게 한다
- **무적류**:순환 핵심을 정보 격차로 전환(한 번 깬다 → 또 깸, 매번 인식 갱신)

## 일상물개요 프레임법

### 창작 경로

다음 단계로 진행:

1. 독서에서 흥미로운 설정/관계/배경을 찾는다
2. 영감 둘레로 직업선(커리어 라인) + 감정선 확정
3. 페이스가 가장 빠르고 감정이 풍부한 노드에서 바로 진입
4. 각 단계별로 정보 격차 + 인간관계 + 감정 분해
5. 사건을 시간순으로 배열
6. 집필 전 장별 대강을 스케치

### 대강 추론법

예시: "임대인·세입자 관계 성립"을 실현하는 경우:

1. 목표: 남녀 주인공의 집주인·세입자 관계 실현
2. 분해: 주인공 집에 빈방이 있어야 하고, 고등학교와 가깝다
3. 추론: 빈방 = 가정 형편이 괜찮다 → 최선은 대출로 집을 샀고 부담이 있다
4. 반전 이유: 부모의 이전 생 투자 실패 → 이번 생 주인공이 반전 → 학군 집을 구매

### 대강 노드 형식

```
사건명:
정보격차:1. 주인공이 아는 것 / 조연이 모르는 것 2. 독자 관점 vs 인물 관점
인간관계 및 감정:1. 주인공 감정 2. 여주/조연 반응 3. 부정적 감정 제공자
```

### 핵심 원칙

- 대강은 본문 생성을 돕기 위한 도구이지 족쇄가 아니다
- 일상물은 호감 급증을 일으키는 대형 사건을 너무 많이 넣지 말고, 작은 사건을 엮어 천천히 성장시키라
- 직업선은 여주의 개인과 가족과 결합되어 일상과 직업이 서로 뒤섞이게 해야 한다

## 대형플롯기대감 유도법

### 상향식 창작 논리

순서대로 실행:

1. **핵심과 목적 명확화** — 이 큰 플롯의 쾌감 포인트를 먼저 정한다
2. **분량 목표 확정**
3. **단계별 플롯 설계** — 쾌감 포인트를 중심으로 여러 작은 플롯을 설계, 각 플롯은 다음 플롯의 포석
4. **기법 혼합으로 채우기**

### 사례 시연: 참가곡 '청화자' 무대

**핵심 쾌감**:주인공이 무대에서 '청화자'를 불러 충격을 일으킨다

단계별 설계:
1. 초대 수락 + 공원에서 '송별' 흥얼 → 심사위원이 놀람(전제 포석)
2. 리허설장에서 도발 → 압박 조성
3. 공연 전날 덩즈치(덩쯔치)에게 '포말' 편곡 → 실력 중첩
4. 무대 PK → 장비 고장(압박 가중) → '청화자' 연주 → 충격
5. 심사위원 점수 감점 → 점수 동점(반전 억압)
6. 가수가 주인공 작품을 불러 → 주인공이 창작자라는 폭로(2차 충격)
7. 장비 고장 해명 → 점수 역전(반전 배가)
8. 심사위원이 '송별'을 요구 → 기대감 지속

요점: 먼저 큰 쾌감이 있어야 하고, 그걸 단계별로 도달시킨다; 부분적으로 보면 템포는 빠르지만 전체적으로 보면 천천히 전진(여기서는 한 가지 일을 이야기함).

## 연속성추적과리듬관리

### 활성 상태

| 상태 | 정의 |
|------|------|
| hot | 현재 갈등을 주도하는 핵심 요소 |
| warm | 최근에 활동적이었던 요소 |
| cold | 안전선(휴면선)을 넘어 접근하지 않아 잊힐 위험이 있는 요소 |
| archived | 이미 종료되었거나 의도적으로 닫은 요소 |

### 유효 접촉(유효 접촉) 판단

다음은 유효한 접촉으로 간주된다: 해당 라인을 직접 추진, 압박 가하기, 관계 상태 변화, 실제적 결과 발생, 합리적인 휴면 이유 설명.

유효하지 않은 접촉: 단순 이름 언급, 실체 없는 되돌림, 무작위 언급.

### 재점검 임계(재점검 임계)

| 요소 유형 | 접촉 간격 |
|----------|----------|
| 핵심 인물 | 3-5 장 |
| 주요서브라인 | 4-6 장 |
| 활성 복선 | 2번 놓치면(기회 상실) |
| 불안정한 관계 | 2번 등장 |

### 장별 필수 자가 점검(장별 자가검사)

1. 현재 hot 요소는 무엇인가?
2. cold가 되었지만 warm으로 돌려야 할 것은 있는가?
3. 합리적으로 휴면 상태로 유지할 수 있는 것은 무엇인가?
4. 어떤 선(라인)의 복귀가 압박을 깊게 만들 수 있는가?

### 실패 신호(발생 시 즉시 수정)

- 독자가 "저 그 사람은 어디 갔어?"라고 묻는다
- 중요한 단서가 마지막에 갑자기 튀어나온다
- cold로 있던 포석이 예고 없이 hot의 보상으로 변한다(예열 없음)

### 핵심 갈등의 리듬 보호 규칙

1. 대미 장이 아닌 일반 장에서는 보통 전서(전권) 핵심 갈등을 해결하지 않는다; 단계적 핵심 갈등을 수렴했다면 동시에 다음 기대를 열어야 한다
2. 장 말미 약 200자 가량은서스펜스(서스펜스), 결정, 발견, 여운 또는 단계 목표를 남기는 것이 좋다; 저압 장에서는 강제적 서스펜스를 요구하지 않는다
3. 부분적 승리는 새로운 대가, 위험 또는 다음 임무를 동반해야 한다; 순수 보상/저압 회수 장은 명확한 이익과 후속 기대를 제공하면 된다

### 사건후의쿨다운장수(사건 후 쿨다운 장 수)

| 사건 유형 | 쿨다운(장) |
|----------|-----------|
| conflict_thrill (대충돌/격투) | 2 |
| bond_deepening (관계 심화) | 1 |
| faction_building (세력 구축) | 2 |
| world_painting (세계관 전개) | 3 |
| tension_escalation (압박 고조) | 2 |

규칙: 쿨다운 기간 내에는 해당 유형을 메인 비트로 쓰지 말 것; conflict_thrill은 연속 최대 2장; 매 5장마다 bond_deepening 또는 world_painting을 반드시 포함시킬 것.

### 전환장관리(전환 장 관리)

- 단위 스토리가 끝나기 전에 다음 목표를 미리 끌어온다
- 전환 장은 최소 한 개의 활발한 기대선을 유지해야 한다

### 지도 변경기대감연속(지도 변경 시 기대감 연속)

| 연속 방식 | 방법 |
|----------|------|
| 복수선 | 완료되지 않은 목표를 지도 간에 이어감 |
| 과거 관계선 | 구 인물이 새 지도에 등장 |
| 정보 격차 | 한쪽은 어떤 사실을 믿는데 실제는 다름 |
| 사전 포석 | 지도 변경 전에 새 지도 인물/전설을 주인공과 접촉시킴 |

### 금손의4단계 진화(금손의 4단계 진화: 기초→발전→성숙→승화)

| 단계 | 운영요점 |
|------|---------|
| 기초 | 핵심 역할을 명확히 하고, 독자의 인식을 구축 |
| 발전 | 새로운 사용 방식을 추가하되 핵심 역할은 유지 |
| 성숙 | 세계관과 깊이 결합, 다른 시스템과 연동 가능 |
| 승화 | 작용 대상이 개인에서 세계/천도 수준으로 확장, 충분한 복선 필요(출석 시스템 예: 출석으로 아이템 획득 → 모든 것이 출석 대상 → 사람/혈맥까지 출석 → 출석 자체가 세계 규칙이자 신앙) |

규칙: 금손의 중심은 전환할 수 있으나 충분한 복선이 있어야 한다; 부분적으로 약화는 가능하나 완전히 버리면 안 됨; 표현 강도는 단계에 따라 점진적 증대가 필요.

### 갈등망설계(갈등망 설계)

- 한 시점에 2–3개의 갈등 라인을 동시에 운영
- 갈등 라인 사이에는 연관성(인과, 이익 충돌, 정보 격차)이 있어야 함
- 하나를 해결할 때마다 다른 하나를 활성화하거나 심화시킬 것

| 단계 | 범위 | 설명 |
|------|------|------|
| 장 단위 | 2-3장 | 작은 갈등, 현재 유닛에 봉사 |
| 권 단위 | 한 권 | 그 권의 핵심 갈등, 권 말에 해결 |
| 작품 단위 | 전서 | 최종 갈등, 대미에서 해결 |

### "2장기 1단기" 기대 법칙

- 1개의 단기 기대: 현재 단위의 명확 목표(오직 하나만 허용)
- 1–2개의 장기 기대: 원거리 목표 예고/미스터리/조직/인물

### 지속적으로 기대를 끌어올리는 방법

1. '기초 기대' 위에 세부를 추가하고, 새로운 구체적 요구 공백을 주입한다
2. 여러 핵심 떡밥을 교차 운영(허세 선 A + 해독 선 B + 감정선 C)
3. 세계관 차원의 '비밀'과 '음모'를 설계한다

### 레벨업 차별화 관리

| 차원 | 설명 |
|------|------|
| 능력차별화 | 각 등급마다 질적 변화가 있는 신규 능력 부여(예: 연기 단계는 검을 다루는 정도 → 축기 단계는 물체를 조종하는 공격 능력 획득) |
| 대우차별화 | 등급에 따라 사회적 대우가 달라짐(연기 단계엔 잡역 → 축기 단계엔 독립 동굴 배치) |
| 인간관계망 차별화 | 등급별로 마주치는 인간관계 수준이 달라짐(연기 단계는 사형제와만 접촉 → 축기단계엔 장로의 주목) |

업/레벨 전후 이 세 차원에서 명확한 변화가 없으면 독자는 레벨업의 쾌감을 느끼지 못한다.

### 단위 스토리 중첩(단위 스토리 중첩)

- 첫 번째 단위 스토리의 클라이맥스 전에 두 번째 스토리의 기대선을 삽입
- 현재 목표를 완수하기 전에 다음 목표의 단서 복선을 미리 준다
- 현재 목표 완료 후 빠르게 반전이나 변고를 주어 새로운 기대를 만든다

### 장기리듬설계(장기 리듬 설계)

- 한 권 = 자체 기승전결을 가진 중간 ‘껍데기’
- 각 권의 시작은 몰입기(5–10장), 중간은 전개기, 결말은 클라이맥스+수렴
- 정보 밀도: 고밀도(감정 강함, 속도 빠름)와 저밀도(포석 축적)를 교차, 계속 고밀도나 저밀도만 유지하면 안 됨
- 각 저밀도 장에는 적어도 하나의 '독자가 다음을 궁금해할 지점'을 심어라

### 기대감 관리

세 층위 기대를 동시에 돌린다:
- 단기 기대(다음 장에 무슨 일이 일어날까)
- 중기 기대(현재 플롯 유닛이 어떻게 마무리될까)
- 장기 기대(주인공이 최종적으로 목표를 달성할 수 있을까)

## 플롯전환과연결

### 한 플롯 포인트에서 다음으로

핵심 문제: 주인공 실력이 올랐는데 다음 단계가 불명확하다. 해결책: 매번 향상이 있은 즉시 새로운 도전이나 목표를 도입하라.

### 플롯 중첩(껍데기 구조)

- 대껍데기: 책 전체의 메인라인
- 중껍데기: 각 권/단계의 단계 목표
- 소껍데기: 각 플롯 유닛의 즉시 목표
- 세 층을 동시에 운영해 독자가 항상 볼거리를 갖게 한다

### 장면 전환

- 전환 장은 건너뛸 수 있으면 바로 뛰어넘어라, 늘어지게 하지 말 것
- 전환은 채우기용이 아니다. 정보량이 없다면 삭제하라

### 감정 연결

- 이전 장면의 감정은 자연스럽게 다음 장면으로 이어져야 한다
- 바로 직전 장면이 열혈인데 다음 장면이 갑자기 평온하면 안 된다

### 정보 격차 연결

- 이전 장면에서 심어둔 정보 격차는 다음 장면에서 회수하라
- 독자는 궁금증을 안고 다음 장면으로 들어가게 되므로 연결이 자연스럽다

## 문턱 설정——늘리기플롯의핵심기법

### 문턱의 본질

문턱은 단순히 적 한 명을 세워 막는 것이 아니라 시스템적 조건 설정을 만들어야 한다: 주인공이 목표를 달성하려면 일련의 조건을 모두 충족해야 한다.

### 문턱 설정 구체 방법

| 문턱 유형 | 예시 |
|----------|------|
| 자원형 | 시스템 업그레이드에 1000 영석이 필요하지만 주인공에게 없음 |
| 성취형 | 최고의 학원 입학 조건: 기혈 수치 기준 + 홀로 XX급 몬스터 처치 + 대회 상위 5위 |
| 다중 조건형 | 큰 목표를 여러 단계의 소목표로 분해 |
| 동적 문턱 | 주인공의 자원이 과도해지면 문턱이 올라감 |
| 수집형 | 돌파에 여러 보물이 필요함 |

### 규칙

- 문턱은 핵심 매력(셀링 포인트) 주변에서 디자인해야 한다; 금손이나 단순 발상에서 벗어난 문턱은 무효한 플롯
- 문턱은 한 번에 모두 내놓지 말고 단계적으로 제시
- 하나의 문턱을 넘을 때마다 즉시 다음 문턱을 설정

### 설정에서 순환이 태어난다

- 핵심 매력은 '설정'을 통해 드러나며, 설정이 확정되면 자연히 피드백 메커니즘이 생긴다
- 설정이 한 줄 늘어날수록 순환 요소도 한 층 늘어나고 쓸 거리가 많아진다
- 쓰다 쓰다 설정을 잃어버리면 = 셀링 포인트를 잃어버린다

## 장면 전환 기법

- 전환 장에 정보량이 없다면 바로 건너뛰어라
- 이전 장면은 서스펜스를 남기고, 다음 장면은 그 서스펜스에 응답해야 한다
- 이전 장면을 뜨겁게 끝냈다면 다음 장면의 시작에 여운을 두어라
- 시점을 전환할 때는 서스펜스 포인트에서 잘라라, 평온한 지점에서 자르지 마라
- 각 라인을 전환하기 전에 '낚시바늘(훅)'을 남겨라
- 여러 라인의 독자 관심도는 다르므로 메인라인이 가장 큰 비중을 차지해야 한다

### 지도 변경의 심층 설계

- 새 지도 = 새 환경 + 새 인물 + 새 규칙 + 새 목표 + 새 갈등
- 지도 변경 전: 구 지도 핵심 갈등은 최소 단계적으로 해결되어야 한다
- 지도 변경 후: 처음 5장 내에 새 몰입감과 기대감을 빠르게 구축하라

피해야 할 것: 구 인물을 전부 버림, 새 설정을 한 번에 다 쏟아붓기, 새 지도와 구 지도가 전혀 연결되지 않음. 메인라인을 관통하는 최소 한 줄은 남겨라.

지도마다 순환을 업그레이드하라: 규모를 키우고 문턱을 높이며 상대를 강화하라.

### 지도 변경의지도그림상세·간략설계(지도 교체 시 상세/간략 설계)

- 새 지도(초보 마을 제외)는 세 가지 세력으로 간단히 배치: 훈련장(무관/학교), 향토 세력(호걸/지방 권력), 파괴자(산적/무리) — 이는 '지도 네 세력 프레임'의 축약판이며, 여전히 현금화/자원 루트(상인/약방)는 보존할 것. 단순히 싸움만 남기지 말 것
- 일상 루트는 관계망을 확장: 등교/장비 반납/시장 산책 등을 새 이야기 호의 다리로 활용

## 서스펜스와 복선 기법

- 소플롯 복선: 결말을 먼저 확정하고 뒤에서부터 단서를 깔아 논리적 완결성 확보
- 책 전체 복선: 대강 단계에서 핵심 장면을 확정하고 작품 전반에 걸쳐 세부를 심어 대응, 장기 복선은 기록하여 잊지 않기
- 수수께끼인물 vs 복선: 수수께끼인물은 고의로 설명을 하지 않아 독자 불만을 사기 쉬움; 복선은 자연스럽게 플롯에 녹아 들어야 함. 판단 기준: 정보 지연이 3장 이상이고 그 사이에 아무 진전이 없다면 = 수수께끼인물(삭제하거나 앞당겨라); 주인공이 가볍게 "물 무서워해"라고 말했는데 후에 빠지는 사건에서 회수하면 = 복선
- 뇌를 태우는(난해한) 플롯: 시점은 주인공만 따라가고 적의 시점을 쓰지 마라 — 서스펜스의 긴장감을 깨지 않기 위해

## 정보 단위개념(정보 단위 개념)

- 정보 단위 = 한 단락/한 구간이 전달하려는 핵심 정보 단위
- 각 정보 단위는 한 문장으로 요약 가능해야 한다 — "이 부분은 무엇을 말하는가?"
- 정보 단위들 사이에는 논리적 전진 관계가 있어야 한다
- 템포 빠름 = 정보 단위가 조밀; 템포 느림 = 정보 단위가 희박; '물장'(쓸데없는 장) = 정보 단위가 제로이거나 메인라인과 무관
- 예: 한 장에서 「주인공이 사기를 간파했다」는 1개의 정보 단위, 「덧붙여 악역 배경을 설명」은 2번째 정보 단위 — 두 개가 무관하면 물장이다, 둘 중 하나를 잘라내거나 첫 번째를 도와주도록 만들어라

## 자기만족 판정법(자기만족 판정법)

### 세 가지 자가검증 질문(모두 명확히 대답할 것)

1. 이 책을 누구에게 쓰는가?(최소 목표 독자의 연령대, 직업, 성별, 주 플랫폼, 인생 상황, 일반적 욕망 포함)
2. 내 목표 독자군은 웹소설을 읽을 때 어떤 내용을 기대하는가?
3. 내 책에는 목표 독자군이 보고 싶어 하는 어떤 내용들이 있는가?

판정 기준: 세 질문 중 하나라도 제대로 답하지 못하면 = 자기만족(자위). 즉시 중단하고 수정하라.

### 교정 방법

- 동류 작품의 독자 리뷰를 분석해 빈도 높은 긍정 키워드를 추출
- 동류 작품에서 상호작용이 높은 구간과 낮은 구간의 차이점을 비교
- 동류 작품의 목표 독자 페르소나로 본작의 플롯 선택을 역검증

## 품질 점검 체크리스트(퀄리티 체크리스트)

매번 한 구간의 플롯 설계나 한 권 분량의 대강을 완성한 뒤, 항목별로 점검하라:

### 기초완전성(기본 완전성)
- [ ] 메인라인이 '한 가지 일'로 명확한가?(요소 나열이나 레벨업 목록이 되지 않았는가)
- [ ] 순환 패턴이 장르 + 금손 + 주인공 정체와 일치하는가?
- [ ] 세 층의 껍데기(대/중/소)가 동시에 돌아가고 있는가?

### 리듬과 기대(리듬과 기대)
- [ ] 세 층의 기대(단기/중기/장기)가 동시에 살아 있는가?
- [ ] 장 말 약 200자는 서스펜스·결정·발견·여운·단계 목표 중 하나를 남겼는가?
- [ ] 정보 밀도에 고저 교차가 있는가?(항상 높거나 항상 낮으면 안 됨)
- [ ] 쿨다운 규칙을 준수했는가?

### 연속성(연속성)
- [ ] hot/warm/cold 상태가 정상인가?(warm이어야 할 것이 cold로 방치되지 않았는가)
- [ ] 핵심 캐릭터는 3–5장, 주요 서브라인은 4–6장 내에 유효 접촉이 있는가?
- [ ] 지도/단계 변경 후에도 최소 하나의 주선이 메인라인을 관통하고 있는가?

### 클라이맥스과전환(클라이맥스와 전환)
- [ ] 클라이맥스에 가짜 승리가 필요한가?(먼저 희망을 준 뒤 깨뜨릴지); 필요 없으면 다른 감정 격차/성취 방식이 있는가?
- [ ] 승리는 대가/위험/다음 임무를 동반하는가? 순수 보상 장이라면 보상이 충분히 명확한가?
- [ ] 전환 장에서 정보량 없는 부분을 삭제했는가?
- [ ] 장면 전환을 서스펜스 포인트에서 잘랐는가?

### 함정 회피 점검(피해야 할 것 점검)
- [ ] 문턱이 핵심 매력 주변에서 디자인되었는가?(무의미한 플롯이 아닌가)
- [ ] 금손은 4단계 진화를 따르고 있는가?(점프하거나 버려지지 않았는가)
- [ ] 자기만족 세 질문을 모두 명확히 답할 수 있는가?
- [ ] 각 정보 단위는 한 문장으로 요약 가능한가? ("무엇을 말하는가")
