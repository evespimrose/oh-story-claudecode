## 주인공과 상대의 단계적 대립법

### 핵심 원칙:힘겨루기이지 일방적 압살이 아니다

주인공과 악역의 대립은 처음부터 끝까지 일방적으로 으깨는 구도가 아니다. 매번의 작은 충돌에서 주인공이 약간 우위를 점하도록 만들고, 마지막에 큰 승리를 가져가라.

트럼프 비유:주인공은 3을 내고 상대는 4, 주인공이 A, 상대가 2, 마지막에 주인공이 조커(왕짜)로 한방에 결판을 낸다.

### 허세 레벨 분류

| 단계 | 특징 | 사용 장면 |
|------|------|----------|
| 일상형 소소한 허세 | 줄거리 필요 없음, 일상에서 우위 표현 | 다음 큰 쾌감 포인트까지 거리가 멀 때 독자의 인내 유지 |
| 핵심 쾌감 포인트 | 주 스토리에 맞춰 핵심 목표 주변에서 허세 부림 | 주선을 전진시키면서 독자에게 쾌감을 준다 |
| 주선 이탈형 쾌감 포인트 | 주선에서 벗어나 다른 데서 허세 부림 | 피해야 함, 독자의 인내 낭비 |

### 캐릭터 위상 관리

- 성장(업그레이드) 라인과 주인공의 반응선은 분리해서 관리하라.
- 같은 모욕을 당해도: 주인공이 분노해 반격한다 = 독성 포인트; 주인공이 미소 지으며 신경 쓰지 않는다 = 위상 유지.
- 주인공 반응 규칙: 업그레이드로 올라간 건 실력이며, 그것이 자동으로 주인공의 태도를 바꾸진 않는다. 저급한 도발 앞에선 주인공이 휘둘리지 않는 태도를 보여줘라.

### 쾌감 포인트 밀도 규칙

- 단일 쾌감 포인트의 포석을 억지로 늘리지 말고, 여러 개의 쾌감 포인트를 생각하라.
- 레벨 구분법으로 연쇄적인 충격을 만들어라: 현장 관객이 충격 -> 다른 장소의 관객이 충격 -> 전문가가 충격 -> 조연들 사이의 정보 차가 해소됨 -> 다시 충격.

## 감정 중심 구동과 사건 중심 구동

### 사건(이벤트) 중심 서사

- 이야기 흐름이 외부에서 보이는 사건으로 연결된다:굴욕 당함 -> 업그레이드 -> 반격으로 굴욕을 되갚음.
- 독자의 자극은 사건의 결과에서 온다: "그가 이길 수 있을까?"
- 장점:속도가 빠르고, 쾌감 포인트가 명확하며, 익숙해지기 쉽다.
- 단점:초반에 S급 사건을 쓴 뒤로 A/B급 사건이 이어지면 독자가 피로를 느낄 수 있다.

### 감정(인물) 중심 서사

- 이야기의 동력은 등장인물의 내부 동기, 감정 변화, 인간관계다.
- 사건형 서스펜스는 일회성인 반면, 인물형 서스펜스는 지속된다.
- 독자가 더 쉽게 감정 이입하고 감정의 끌림이 오래간다.

### 본질

두 방식의 공통 본질은 '감정의 기복'이다. 사건 중심은 외적 갈등으로 파동을 만들고, 감정 중심은 내부 갈등과 대인 긴장으로 파동을 만든다. 선택 기준:

- 토막형 쾌감물/굴욕 역전물 -> 사건 중심: 매 장마다 외부 결과(이겼다, 업그레이드했다, 상대가 망했다)를 준다.
- 추격·복수·멜로 -> 감정 중심: 사건은 적어도 인물의 심리적 매듭은 계속 걸어둔다(그가 후회했나? 그녀가 용서했나?).
- 혼합 -> 주선은 사건으로 밀고, 3–5장마다 감정 정지 구간(혼자 있는 장면, 회상, 시도)을 넣어 인물의 심리를 환기시킨다.

## 감정 업그레이드와 대비의 핵심 기법

### 감정 업그레이드

- 쾌감 포인트는 한 번에 완성되는 게 아니다. 층층히 포석을 깔고 점진적으로 올려야 한다.
- 부정적 감정은 점진적으로 포화 상태까지 올린 뒤, 정적(긍정) 감정으로 전환하라.
- 반복되는 거절, 조롱, 의심을 통해 부정적 감정을 계속 증폭시켜라.

### 대비 기법

- 대비는 쾌감물의 핵심 논리 중 하나다.
- 조연의 실패 vs 주인공의 성공(예: 관우가 술 마시며 화웅을 베다와 같은 대비).
- 조연의 자만 vs 주인공의 압도적 제압(예: 조연이 자랑하다가 주인공의 압도적 반격에 무너짐).
- "비교가 없으면 상처도 없다"는 원칙을 기억하라.

### 부정적 감정의 올바른 사용

- 부정적 감정은 알을 낳게 하는 수단일 뿐, 유일한 방법은 아니다.
- 핵심은 작품의 감정 사슬이 어느 방향으로 흐르는지 파악하는 것이다.
- 예: 《등신》은 거의 감정 억압 루트를 쓰지 않지만 여전히 큰 쾌감물을 만든다 — 독자가 느끼는 '감정 결핍'은 진부한 전개에 대한 피로에서 온다.

### 감정 끌어당기기용 실전 소재

- 전환, 일상, 평범한 플롯에서도 감정 끌어당기기를 할 수 있다.
- '남에게 부탁하는' 유형의 장면: 장애 요소 설정, 권력 과시, 후퇴하면서 전진하기.
- 후퇴하면서 전진하기, 좌우로 유도하는 기법은 과도기 챕터에서 효과적인 감정 끌기 구조다.

## 쾌감 포인트 설계체계

### 쾌감 포인트의 본질

- 쾌감 포인트는 단지 허세와 굴욕 역전뿐만 아니라 다양한 감정적 충족을 포함한다.
- 순수한 긍정 감정만으로도 쾌감을 줄 수 있지만, 쾌감을 최대화하려면 부정적 감정의 전환이 필요하다.
- 부정적 감정을 긍정으로 전환시키는 것이 독자의 만족을 극대화한다.

### 여섯 가지 쾌감 포인트 유형

| 유형 | 핵심 | 기능확장 |
|------|------|----------|
| 능력 압도 | 실력이 압도적으로 우월해지는 우월감 | -- |
| 목표달성 | 단계적 목표 달성 | 행동선과 다음 계획을 유도 |
| 수확정산 | 얻은 자원/인맥/능력을 정리 | 수확을 이용해 다음 플롯을 이끎 |
| 태도 변화 | 조연이 경멸에서 존경으로 태도 전환 | 조연을 이용해 다음 플롯을 이끎 |
| 숨은 신분/정체 폭로 | 신분이 점진적으로 드러남 | 계속해서 충격을 만듦 |
| 감정적 완결도 | 추격/복수 후 관계 회복의 만족감 | -- |

### 쾌감 포인트 설계의 역산법

1. 먼저 어떤 방식으로 독자를 만족시킬지(쾌감 포인트 유형)를 정한다.
2. 다음으로 기대감을 끌어올리는 요소를 설계한다(기대 포인트).
3. 마지막으로 그것을 어떻게 포석할지 설계한다(포석).
4. 장 구성을 잡을 때도 같은 순서로 생각하라.

## 감정 모듈과 드라마 단위 분류

### 추출(제련) 레벨

원형 스토리에서 단계적으로 재사용 가능한 도구로 추출한다. 핵심 원칙:드라마성은 닳지만, 감정은 닳지 않는다.

| 단계 | 명칭 | 내용 | 설명 |
|------|------|------|------|
| 0단계 | 구체적 이야기 | 원문 완전한 줄거리 | 그대로 옮기면 = 표절 |
| 1단계 | 고전적 이야기 줄거리 | 묘사를 제거하고 소재만 남김(인명/지명/사건) | 겉만 바꾼 수준, 여전히 유사 위험 |
| 2단계 | 이야기 구조 | 소재도 버리고 논리적 전개만 남김 | 드라마 단위 + 감정 모듈의 조합체 |
| 3단계 | 드라마 단위 | 드라마적 전개의 추상화 | 자유롭게 조합 가능한 논리 구조 |
| 4단계 | 감정 모듈 | 독자가 보고 싶어 하는 것의 추상 | 기대감 방향 + 쾌감 방향 |

이야기 구조 + 소재 = 구체적 이야기.사용법 두 가지:① 재구성(소재는 살리고 구성을 완전 재구성, 장편 필수);② 미세 조정(고전적 줄거리를 사용하되 인물성격에 맞춰 심화·미세조정, 단편에 적합). 인물 설정과 고전 줄거리가 충돌하면 반드시 재구성하라.

관통 예시(어떤 추격·복수물 하나를 단계별로 위로 분해):

- 0단계 = 원문 《어떤 후회물》 그대로, 대사와 장면까지 그대로 재현.
- 1단계 = 묘사 제거, 소재만 남김:"전 남편이 재결합을 청했으나 거절당함".
- 2단계 = 소재까지 버리고 전개만 남김:"가해자가 후회 -> 피해자가 이미 무관심".
- 3단계 드라마 단위 = "늦은 후회".
- 4단계 감정 모듈 = 독자가 보고 싶어 하는 두 가지:"나쁜 남자(헛된 사랑) 후회 + 주인공이 되돌아가지 않음".

각색 사례:2단계 전개 "가해자가 후회 -> 피해자가 무관심"를 잡고 소재를 바꾸면 새로운 이야기다 — 직장판(넌 던진 상사가 실패해 찾아오는데 넌 이미 이직해 사장 됨), 고전판(이혼한 남편이 몰락해 찾아오지만 넌 이미 높은 지위).

### 감정 모듈과 드라마 단위의 관계

- 대규모/중간 규모 드라마 단위 = 드라마적 추상, 작품 전체 또는 큰 구간의 톤을 덮는다.
- 감정 모듈 = 감정 핵심의 추상, 특정 쾌감 포인트에 대응.
- 서사 요소와 구조 기법은 '보조 도구'로, 단독으로 완전한 틀을 제공할 수 없다. 반드시 어떤 완전한 틀에 적용해야 한다.

### 드라마성 vs 감정의 관계

- 같은 루틴(예: 영웅이 미녀를 구함)을 반복해도 지루하지 않은 이유는 구조를 바꾸지 않아서다. 매번 배경을 바꾸거나 상대를 바꾸거나 새로운 감정을 추가하면 반복으로 느껴지지 않는다.

### 감정 모듈 카드

#### 수라장 카드

- 여러 사람이 같은 대상을 좋아해서, 그 대상 앞에서 서로 경쟁한다.
- 점진적 설계:초기(남1과 데이트하다 남2에게 들킴) -> 중기(남2와 키스하다 남주에게 들킴) -> 후기(남1·남2 격렬한 충돌).

#### 카운트다운 카드

- 카운트다운이 필요하며 시간이 다 되면 반드시 일이 벌어진다.
- 보통 실력 차가 큰 전투와 결합된다: 이길 수 없지만 싸워야 한다.

#### 원한과 애증 카드(대/중 드라마 단위)

- 특정 사건으로 인해 강한 감정적 또는 도덕적 족쇄가 생긴 관계.
- 초점은 '원한이 생기는 과정'이 아니라, 원한 형성 이후의 행동과 감정이다.
- 전체 책의 '톤'을 덮는 대규모 드라마 단위로 쓰인다.

#### 이중 신분 카드

- 두 신분이 겹치는 순간 독자에게 충격을 준다.
- 설계 포인트: A 신분의 일상 묘사 + 숨겨진 정보 + B 신분 폭로 시의 충격.

#### 특별 대우 카드

- 인물을 OOC(캐릭터 붕괴) 없이 구해내는 만능 카드.
- 특정 상황에서 역할의 행위 편차를 합리화하기 위해 '특별 대우'를 사용한다.

#### 호감 변화카드

- 핵심은 감정 사슬의 질적 변화를 보여주는 것.
- 영웅이 미녀를 구하는 장면은 수단일 뿐, 핵심은 관계의 질적 변화다.
- 반복 피하기: 각 권마다 복잡성과 수확을 높여 감정이 나선형으로 상승하게 하라.

#### 허세의 심층 이해

- 핵심은 잘남과 못남의 대비다.
- '얼마만큼의 힘'으로 비교할 수 있다: 한 판 더 붙인 다음 몇 할의 힘을 썼는지로 말한다.
- 전기 포석: 조롱과 억압된 감정, 주인공의 '꾀부림' 연출.

#### 작은 투자로 큰 수확 (작은 것으로 큰 것을 노림)

- 비용 대비 수확 비율이 커야 한다.
- 과정에 우연성과 주체적 판단이 있어야, 독자가 100% 성공을 확신하게 만들면 안 된다.
- 실패할 수도 있으나, 엉뚱한 성공이나 고수의 도움 등으로 감정적 빈틈을 메울 수 있다.

#### 오해 카드 (오해 카드)

- 오해의 단계: 핵심 오해 확정 -> 자연스러운 파생 소오해들 -> 해소 조건 확정 -> 해소 장애 설계.
- 오해 해소 규칙: 진로(커리어)나 로맨스에 부정적 영향을 주면 반드시 해소할 것; 부정적 영향이 없거나 오히려 긍정적이면 굳이 해소하지 않아도 된다.

### 서사 요소 카드

| 카드 | 핵심 사용법 |
|------|----------|
| 도구 인간 카드 | 특정 장면에서 서사를 만족시키는 인물: 분위기 조성/진전/정보 제공 |

| 은밀한 행동 카드 | 인물의 은밀한 행동/타인의 은밀한 조사/타인이 인물에게 하는 은밀한 행동 |

| 새 환경 역할극 카드 | 스파이/납치/기억상실/타임슬립, 확인 요소: 상대의 배경·성격·스킬·약점 |

### 구조 기법 카드

| 카드 | 핵심심사용법 |
|------|----------|
| 차이 평가 카드 | 두 방식: 깎아내리기 또는 뒤집기; 남의 손을 빌리는 건 변형 |
| 드라마 삼각형 카드 | 가해자·희생자·구원자 세 역할은 전환 가능 |
| 풍운을 뒤흔들기 | 주인공의 행동이 다른 인물들에게 주는 의미와 영향을 강조 |
| 수수께끼 설계 | 명제 P1/P2 설정 -> P3 도출 -> 반대로 P4 도출 -> P3을 숨겨 오도 유발 |

### 조합과 제련

- 1단계 추출:성공 작품에서 기본 서사 패턴을 추출.
- 2단계 추출:1단계 프레임에 특정 장르 요소를 더함.
- 서로 다른 카드 타입은 중첩 가능: 핵심 아이디어 카드 + 관계 카드 + 제약 카드 = 완전한 플롯 단위.
- 재구성 사용: 소재 명칭을 남기고 스토리 진행을 바꾼다.
- 미세조정 사용: 스토리 전개를 유지하며 새로운 감정 모듈을 추가.
- 나선형 상승: 같은 루틴이 등장할 때마다 복잡도와 보상이 전번보다 높아진다.

### 흔한 오해

1. 이야기의 유사성:단지 1단계 추출만 함(이름만 바꾸고 구조를 안 바꿈). 독자에겐 표절처럼 보인다.
2. 인물 붕괴:고전적 줄거리를 억지로 맞추려다 인물을 설정과 맞지 않게 행동하게 함.
3. 혁신의 실수:감정 모듈과 무관한 '혁신'은 독이 될 수 있다.
4. 핵심 창의성 짓밟기:"독자가 좋아하는 것"과 "내가 쓰고 싶은 것"을 서로 배타적으로 만들지 마라.

## 오해로 긴장 만드는 법

### 오해의 본질

"나는 원래 A라고 생각했는데 나중에 전부 틀렸다는 걸 알게 된다" — 정보 차이가 감정의 낙차를 만든다. 핵심은 정보 차이의 설계다. 실행 시에는 매 단계마다 명확한 정보 차이를 설계해야 한다.

| 장면 | 사용법 |
|------|------|
| 허세와 사이다 | 주인공이 겸손함 -> 조연이 주인공을 약하다고 오해 -> 반전으로 굴욕을 줌이 더 쾌감 |
| 감정선 | 오해가 마음의 염증을 만듦 -> 감정 발전을 막음 -> 풀릴 때 더 달콤 |
| 캐릭터 반전 | "주인공은 약할 줄 알았는데 사실 엄청 강함" |
| 세계관 설정 | "세상이 수련 가능하다고 생각했는데 사실 불가능함" |

### 실행 포인트

- 감정선에서는 진짜 이별로 이어지지 않게(진짜 헤어지지 않음). 대신 '마음의 염증'이나 '일시적 냉각'으로 유지하라.
- 관계를 좁힐 때는 영웅 구출을, 벌릴 때는 오해를 사용하라.
- 허세-굴욕 유형에서 주인공의 겸손/저자세 자체가 오해를 만드는 장치다.

## 밈으로 플롯 구성하는 법

### 4단 구성

1. 발생:초기 상황을 세우고 밈(밈)의 전제 조건을 만든다.
2. 전개:반복되는 좌절이나 축적을 통해 밈의 발동 지점으로 밀어간다.
3. 전환:치트 능력이나 핵심 수단으로 밈을 반전시킨다.
4. 클라이맥스:밈의 완전한 폭발 — 전후 대비를 극대화한다.

밈을 클라이맥스로 역산해 플롯을 짜면 잡무 연속을 자연스럽게 피할 수 있다. 새로운 밈만 있으면 계속 흥미로운 플롯을 쓸 수 있다.

## 독자 욕구를 자극하는 4단계 공식

핵심공식:생산적 요구 -> 희망 제공 -> 해결을 위한 노력 -> 소원 성취

### 1단계:요구 생성

- "낮은 지위", "곤경", "임박한 위협", "한 번도 가져본 적 없는 것"으로 독자의 공감과 분노를 유발하라.
- 독자는 부당한 누명, 불공정, 권력 남용을 보면 본능적으로 '이럴 리가 없다'는 감정을 품는다.

### 금손(치트)의 본질

금손(치트)은 현실에서 얻기 어려운 특성/능력이다. 금손이 없으면 곤경의 고통이 독자에게 무력감을 준다.

### 리듬(페이싱)의 본질

- 기존의 갈등을 계속 해결하면서 동시에 새로운 갈등을 꾸준히 만들어라.
- 방식 A:'서서히 좋아지기' — 목표를 쪼개서 해결.
- 방식 B:'새로운 곤경' — 갈등의 레벨이 단계적으로 상승.
- 좋은 리듬 = 곤경의 레벨이 점진적으로 오르고 종류도 다양하며 해결 방식도 다양함.

## 품질 점검 체크리스트

하나의 챕터 또는 한 덩어리 플롯을 완성한 뒤, 항목별로 점검하라:

- [ ] **결정 라우팅**:라우팅 표에 따라 올바른 방법을 선택했는가?
- [ ] **대립의 단계 상승**:주인공과 상대의 매 충돌이 단계적으로 상승하는가? 처음부터 일방적 압살은 없는가?
- [ ] **허세 단계**:일상 소소 허세 / 핵심 쾌감 포인트 구분이 명확한가? 주선에서 벗어난 허세는 없는가?
- [ ] **쾌감 포인트 유형**:여섯 가지 쾌감 타입 중 어느 것인지 명확한가? 설명할 수 있는가?
- [ ] **쾌감 포인트 역산**:먼저 쾌감 유형을 정하고 기대를 설계한 뒤 포석을 깔았는가?
- [ ] **감정 업그레이드**:부정적 감정을 점진적으로 증폭시켜 포화 상태로 만든 뒤 해소했는가? 한 번에 끝내려 하지 않았는가?
- [ ] **대비 기법**:조연의 대비를 사용해 주인공의 쾌감을 증폭시켰는가?
- [ ] **오해로 긴장 만들기**:연애선의 오해는 '마음의 염증' 수준으로 통제되어 실제 이별로 이어지지 않는가?
- [ ] **밈의 4단 구성**:발생 -> 전개 -> 전환 -> 클라이맥스가 완전한가? 전환 없이 바로 클라이맥스로 뛰지는 않았는가?
- [ ] **리듬 주기**:대클라이맥스가 7–10일 내에 완결되는가? 소클라이맥스는 약 3일인가?
- [ ] **독자 욕구**:"생산적 요구 -> 희망 제공 -> 노력 -> 소원 성취"의 네 단계를 완주했는가?
- [ ] **카드조합**:감정 모듈·서사 요소·구조 기법을 조합해 사용했는가, 단독 의존하지 않았는가?
- [ ] **나선형 상승**:같은 루틴이 재등장할 때마다 복잡성과 보상이 이전보다 높은가?
