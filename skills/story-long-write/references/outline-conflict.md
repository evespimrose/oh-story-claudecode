## 갈등 설계 방법

### 갈등의 4단계 상승

다음 순서로 갈등의 층위를 단계적으로 세운다. 자기 자신과의 갈등 -> 자연과의 갈등 -> 사람과의 갈등 -> 세계와의 갈등.

### 근본 갈등으로 세계 구축하기

가장 근원적이고 화해하기 어려운 갈등부터 세계관을 세운다. 핵심 소재가 이탈하지 않도록 해야 하며, 그렇지 않으면 중반부터 구독이 하락한다.

### 동기의 3가지 출처

| 출처 | 활용 방식 |
|------|---------|
| 세계 배경 | 환경 설정이 주인공을 강하게 만들도록 한다(예: 요괴와 마물이 난무하는 시대 -> 힘이 없으면 스스로를 지킬 수 없음). |
| 금손가락 | 금손가락의 메커니즘으로 이익을 추동한다(예: 요괴를 베어 실력을 얻음). |
| 인물 관계 | 가족·친구의 사건으로 감정적 동기를 만든다(예: 괴롭힘·살해 -> 복수·구출). |

### 동기 변화의 연결

- 위기가 해소된 직후 조연·악역을 통해 ‘더 강한 힘이 있어야 살아남는다’고 강조해 다음 단계로 자연스럽게 넘어간다.
- 생사의 위기는 모든 장르에 어울리지 않으므로 난관의 강도를 장르의 경계에 맞게 조절한다.
- 이전 위기를 해결할 때 다음 위기의 복선을 반드시 심는다.

### 갈등 출처 분류

장르에 따라 갈등의 출처를 선택한다.

| 출처 | 적합한 장르·상황 |
|------|----------|
| 자원·이익 | 범용 |
| 진영·종족 | 판타지·현대 판타지 |
| 초월 경로 | 비밀·미스터리 계열 |
| 신앙·종교 | 서양 판타지·역사 |
| 정교 대립 | 중세·권모술수 |
| 이념·가치관 | 모든 장르 |

## 구조 방법

### 절정 역추론법

다음 단계로 메인 플롯을 역추론한다.

1. 먼저 한 문장으로 결말을 확정한다.
2. 각 단계의 목표를 거꾸로 추론한다(세계 최고 부자 <-- 주 단위 <-- 국가 단위 <-- 성 단위 <-- 시 단위 <-- 현 단위 <-- 읍 단위 <-- 마을 단위 <-- 가정).
3. 큰 메인 플롯을 중간 메인 플롯으로, 중간 메인 플롯을 작은 메인 플롯으로 나누며 계속 세분화한다.
4. 작은 메인 플롯이 완료되면 중간 메인 플롯을 새로운 작은 메인 플롯으로 바꾸어 순환 추진한다.

### 메인 플롯 = 충돌의 동력

메인 플롯은 충돌을 해결하는 이야기다. 큰 충돌을 여러 작은 충돌로 나누어 플롯선을 만든다. 각 단계에는 반드시 당장 해결할 수 없는 핵심 충돌이 하나 있어야 한다.

### 서브 플롯 = 메인 플롯을 완성하는 수단

다음 논리로 서브 플롯을 조직한다. 돈을 번다(메인 플롯) -> 어떻게 버는가(서브 플롯) -> 무엇으로 버는가(금손가락 확정). 서브 플롯은 최종적으로 메인 플롯으로 모여야 한다.

### 이중선 구조법

#### 표면선과 암선

- **표면선**: 주인공선(독자가 직접 보는 행동과 성장).
- **암선**: 악역선·숨은 요소선(목적: 연결, 포석, 후속 플롯의 중첩).
- 암선은 후반에 반드시 표면선과 교차해 권 내부의 절정을 만들어야 한다.

#### 四象限结构

| | 明线 | 暗线 |
|--|------|------|
| **主线** | 主角能力升级+核心剧情推进 | 反派暗中行动/隐藏信息线 |
| **支线** | 资源线、人脉线、地位线 | 配角暗线 |

**性价比最高的结构**：明线有主线+支线（"二带一"），暗线只有主线。

高潮阶段：暗线与明线融合，支线融合到主线或暂时放下。

### 升级文AB交织法

| 线路 | 定义 | 内容 |
|------|------|------|
| A线（升级线） | 战力升级 | 加点、学技能、装备提升 |
| B线（剧情线） | 矛盾冲突 | 拉出矛盾->卷入矛盾->爆发冲突->解决冲突->收获 |

交织节奏：
```
变强 -> 拉出矛盾 -> 变强 -> 卷入矛盾 -> 变强 -> 引发冲突 -> 变强 -> 解决冲突 -> 收获 -> 变强 -> 拉出矛盾...
```

**核心原则**：保持主角稍占上风的角力，每次小角力以主角胜利告终，最后迎来大胜利。

丰富代入的方法：
1. A线中丰富：详细设定可掌握的资源、人脉、装备。
2. B线中丰富：插入世界观、环境、情绪、人物互动，给反派/配角贴标签。

## 冲突设计

### 문턱을 세워 플롯을 늘리는 법

문턱을 이용해 메인 플롯을 단계별 작은 메인 플롯으로 나누고, 각 단계에 분명한 추진력을 둔다.

| 문턱 유형 | 활용 방식 |
|----------|---------|
| 시스템 문턱 | 첫 승급은 무료, 두 번째부터 자원이 필요하고 이후에는 일반·초급 두 단계로 나눔 |
| 목표 문턱 | 최상위 교육 기관 진학에 기혈 수치 + 퇴치 전적 + 대회 순위가 필요하도록 하여 하나씩 달성 |
| 수집 문턱 | 경지 돌파에 여러 물건을 모아야 하도록 하여 하나씩 찾게 함 |
| 소모 문턱 | 자원이 너무 많을 때 문턱을 높여 소모시킴 |

### 3대 추진력으로 플롯 역추론하기

| 추진력 | 활용 방식 |
|--------|---------|
| 극성 | 뜻밖의 수확·우연한 엇갈림을 설계 |
| 갈등 | 피할 수 없는 충돌·재난을 설계 |
| 욕망·공포 | 무엇을 얻고 싶어 하는지·무엇을 잃을까 두려워하는지 활용 |

**실행 절차**: 먼저 주인공의 단계적 성장(금손가락 승급·무력 향상·CP 호감·보구·거물 인맥·돈·지위)을 확정하고, 각 성장마다 세 가지 추진력을 거꾸로 적용해 플롯을 설계한다.

장점: 집필이 막히지 않고 언제나 신선함을 유지할 수 있다.

### 충돌 설계 요점

#### 충돌의 핵심 기준

- 충돌은 반드시 상승해야 한다. 말 -> 행동 -> 격렬한 대립 -> 승패 결정.
- 충돌에는 반드시 분명한 결과가 있어야 한다.
- 본질은 ‘누군가 주인공이 원하는 것을 얻지 못하게 막는 것’이다.

#### 갈등과 충돌의 차이

- ‘갈등’은 1급 구조(작품 전체·권 단위)이고, ‘충돌’은 2급 구조(구체적 장면 단위)다.
- 갈등이 메인 플롯의 방향을 정하고 충돌은 그것을 장면으로 구현한다.

#### 1막의 함정

주인공이 첫 충돌을 해결하는 과정에서 다음 충돌이 터질 복선을 심는다. 기능은 이야기를 자연스럽게 연결하는 것이다.

#### 초과 보상 기법

초과 보상은 만능 기법이다. 후반의 복선·포석·플롯 훅이 될 수 있고, 등장하는 순간에도 하나의 사이다 포인트가 된다.

고전적인 방식: 보스가 세 가지를 떨어뜨린다. 1. 주인공이 바로 쓸 수 있는 것. 2. 다른 사람에게 주어 관계를 만들 수 있는 것. 3. 당장은 쓸 수 없지만 보기만 해도 강력한 것.

### 구원물 충돌 설계 8법

| 방법 | 활용 방식 |
|------|---------|
| 구원 목표의 충돌 | 구원이 상대의 희생에서 나오고, 상처를 만든 사람이 상대의 가까운 가족임 |
| 구원 행동의 충돌 | 거짓말로 구원을 유지하며, 자기 구원을 완성하려면 상대를 상처 입혀야 함 |
| 삼각관계 | 한 사람을 구원한 결과 제3자가 구원을 필요로 하게 됨 |
| 구원 카운트다운 | 어떤 일이 벌어지기 전에 끝내야 하며, 실패하면 나락에 빠짐 |
| 구원 비용 증가 | 치러야 할 대가가 갈수록 커짐 |
| 구원 자원의 희소성 | 자원이 한 사람만 구원할 수 있을 만큼 부족함 |
| 입장 대립 | 입장은 다르지만 서로의 도움이 필요함 |
| 성격 대비 | 낙관과 비관, 냉혈함과 연민의 대비 |

## 대항 설계

### 세력을 압박하되 개인을 누르지 않기

악역이 주인공 개인을 겨냥하기보다 지역·계층·집단을 겨냥한 계획을 실행하고, 그 결과 주인공이 객관적으로 곤경에 빠지게 한다.

실행 절차:
1. 악역에게 자기 목적을 부여한다(예: 특정 지역의 수련자를 억압).
2. 주인공을 억압받는 환경에 둔다.
3. 주인공이 악역을 쓰러뜨린 뒤에도 밑바닥 사람들은 여전히 무감각하게 남는다.
4. 밑바닥 사람들 또한 주인공의 선의를 이용해 이익을 취할 수 있다 -> 새로운 충돌.

장점: 갈등에 논리적 뿌리가 생겨 지속할 수 있다.

### 악역 시점과 정보 격차 기법

#### 기능

시점을 악역의 음모로 전환해 독자는 알고 주인공은 모르는 정보 격차를 만든다. 악역의 캐릭터성을 깊게 하고, 기대감을 끌어올리며, 독자가 악역이 망신당하기를 바라게 한다.

#### 작성법

- 수수께끼만 던지는 인물로 만들지 말고 악역의 계획을 당당하게 보여 준다.
- 정보 격차 = 독자에게 일부 정보를 미리 알려 기대를 만드는 것.

암선 규칙은 위의 이중선 구조법을 참고한다.

### 주인공 행동력 설계

다음 세 차원에서 주인공의 행동을 설계한다.

| 차원 | 의미 | 예시 |
|------|------|------|
| 다른 사람이 감히 하지 못하는 일 | 권위에 저항하고 강자에게 도전 | 상사를 베어 버림 |
| 다른 사람이 해내지 못하는 일 | 죽을 위기에서 탈출하고 한계를 넘음 | 필사 상황에서 생환 |
| 다른 사람이 이런 식으로 할 수 있다고 생각하지 못한 일 | 우연한 엇갈림, 우회적인 해결 | 소시지 비법으로 컬렉션을 채움 |

극성은 행동력을 드러내는 방법이고, 인물 설정은 그 행동이 나오는 이유다. 뜻밖의 전개를 만들겠다고 인물 설정을 무너뜨려서는 안 된다.

## 感情线设计

### 일선과 감정선의 결합

먼저 제목과 소개글에 끌려 들어온 독자가 무엇을 보고 싶어 하는지 판단한다.

| 방식 | 설계 초점 | 독자가 원하는 것 |
|------|---------|---------|
| 일선 중심 | 금손가락의 시연과 승급, 연애 대상은 보상 | 주인공이 강해짐 |
| 감정선 중심 | 관계의 변화, 상대 인물 설정에 따른 사건 | CP 상호작용 |

### 연애선 이야기의 4단계

다음 순서로 연애선을 전개한다.

| 단계 | 핵심 내용 | 핵심 조작 |
|------|----------|---------|
| 스쳐 가는 첫 만남 | 첫 만남, 첫인상 | 서로 다른 평가로 긴장을 만듦 |
| 로맨틱 코미디 | 강제·우연으로 잦은 접촉 | 탐색 단계가 핵심이며 플롯의 30~50%를 차지 |
| 사랑은 산과 바다를 가름 | 외부 압력·신분의 진실·오해로 떨어짐 | 강도는 높고 인물 변화는 기존 설정에 기반 |
| 대결말 | 최대 장애물을 극복 | 새 갈등은 더 만들지 말고 보상에 집중 |

#### 탐색 단계 작성법

탐색 단계는 연애선의 핵심이다. 두 사람이 서로의 마음을 확인하지 못한 채 반복해서 떠보고 밀고 당긴다. 매번의 탐색에는 ‘달콤함’과 ‘씁쓸함’이라는 두 가지 해석이 있어야 한다.

#### 인물 설정 변화의 상쇄법

연애선 절정 뒤 관계가 승급한다. **양쪽 모두 변화**하고, 변화 뒤에는 이전과의 대응 관계가 **반전**된다. 인물 변화는 원래 설정을 일부 바꾸는 데 기반해야 하며, 근거 없이 새 인물 설정을 만들면 안 된다.

## 금손가락과 신분

### 도입부와 진입점 설계(이중 신분·이중 금손가락)

| 요소 | 설계 요구 |
|------|---------|
| 표면 신분(사회적 신분) | 겉으로 드러난 표식 = 직업 + 상태. 계속 변해야 함 |
| 숨은 신분(출신) | 세상에 흘러든 황자, 이세계 전이자 등. 작품 전체의 핵심 갈등과 연결 |
| 표면 금손가락 | 시스템, 회귀 기억 등. 능력 묶음이어야 하며 매번 새 요소가 있어야 함 |
| 숨은 금손가락 = 주인공 성격 | 주인공을 남다르게 만드는 것이 금손가락. 중후반 사이다를 제공 |

**4요소 통일 원칙**: 사회적 신분·출신·금손가락·성격은 높은 수준으로 통일되어야 한다.

### 금손가락 설계 요점

#### 적합성 5문항

금손가락을 설계할 때 다음을 하나씩 확인한다.

1. 주인공의 남다름을 부각하고 계속 난관을 넘게 도울 수 있는가?
2. 세계 환경·설정과 긴밀히 연결되고 대비를 이루는가?
3. 금손가락이 주인공을 압도할 가능성이 있는가? 예방할 수 있는가?
4. 주인공의 자원이 백 배·천 배로 늘어난 뒤에도 주요 갈등을 해결할 수 있는가?
5. 금손가락으로 갈등을 해결하면서 생각과 주제를 표현할 수 있는가?

#### 조각화 처리

복잡한 금손가락 능력을 세분화해 조각 단위로 플롯에 넣는다. 모두 모으기 전의 기간은 장기 기대가 되고, 조각 하나를 얻을 때마다 최소 하나의 충돌을 해결해야 한다.

## 순환과 사이다 포인트

### 사이다 단계 설계와 순환 작성법

#### 순환(겹겹이 쌓기) 설계

핵심 창의점 -> 핵심 매력 발굴 -> 메인 플롯 확정 -> 금손가락이 메인 플롯과 결합해 파생.

#### 병렬식 작성법

플롯 A의 포석 안에 플롯 B를 끼워 넣고, B의 포석 안에 C를 넣어 포석과 사이다 포인트가 끊임없이 이어지게 한다.

#### 다층 사이다 포인트

다음 단계로 사이다 포인트를 쌓는다.

1. 현장 관객의 경악.
2. 다른 곳 관객의 경악.
3. 전문가가 수법을 보고 경악.
4. 조연의 정보 격차가 사라진 뒤 다시 경악.

사이다 포인트 = 주인공의 과시 + 조연의 인식 변화. 조연이 전후로 어떻게 달라지는지에 주의를 둔다.

### 核心梗三分法

| 类型 | 运行方式 | 适用 |
|------|----------|------|
| 可重复型 | 每个一级结构中重复运行 | 升级文、系统文、文抄娱乐 |
| 不可重复型 | 贯穿全文但只在最高潮爆发一次 | 追妻、掉马、禁忌之恋 |
| 长期铺垫型 | 以期待点形式贯穿 | 悬疑、复仇、解谜 |

运行节奏：第一个一级结构中必须运行一次或完成首次铺垫。连续多个一级结构不运行 = 读者弃书。

双线构思法：布两条线--一条重复运行核心梗，另一条不重复，交替推进。

### 按题材设计循环核心

根据题材确定循环核心，并确保持续条件不被破坏：

| 题材 | 循环核心 | 持续条件 |
|------|---------|----------|
| 肝熟练度/低位开局 | 地图（训练场/地头蛇/破坏者） | 地图不崩 |
| 长生 | 社会变迁 | 社会一直在变 |
| 无限游戏 | 副本与现实 | 副本现实不崩 |
| 公路文 | 人际交往 | 人物不崩 |
| 无敌流 | 敌人 | 敌人不崩 |
| 种田/签到/囤积 | 外部环境破坏 | 外部持续被破坏 |
| 脑洞文 | 核心卖点循环 | 核心卖点不偏 |

**警告**：循环偏离核心卖点 = 失去差异化竞争力。

## 동기와 곤경

### ‘인물에게 꿈을 주기’ 동기법

| 개념 | 특성 | 예시 |
|------|------|------|
| 동기 | 외력에 떠밀리며 물질을 향함 | 가난해서 -> 큰 집을 사고 싶음 |
| 꿈 | 내적 동력이며 정신적 가치를 추구 | 위대한 작가가 되고 싶음 |

활용: 외부의 압박·이익 추동 외에 인물에게 하나의 ‘꿈’을 준다. 두 층위가 결합하면 인물이 자연스럽게 살아난다.

인물의 목표는 반드시 인물 설정과 결합해야 한다. 잡역 제자가 종문을 구하겠다고 꿈꾸면 설득력이 약하지만, 종문의 성녀가 종문을 구하는 것은 자연스럽다.

### 곤경 순환 구조(극도형)

```
곤경(환경의 압박) -> 행동(금손가락 가동) -> 전환(더 큰 곤경) -> 행동(더 강한 힘으로 돌파)
```

핵심: 주인공에게 계속 강도를 높이되, 주인공이 언제나 능동적으로 문제를 해결하게 한다. 약한 척하다 강함을 드러내기 + 감정의 밀고 당김 + 망신 주기형 사이다를 결합한다.

요점: 압박에는 정도가 있어야 독자가 주인공에게 돌파 희망이 있다고 느낀다. 후반의 압박은 반드시 초반보다 높아야 한다.

### 设定推演剧情法

核心公式：**环境 + 人物 = 情节**

操作步骤：
1. 给出环境（时间/地点/情境）。
2. 给出人物（身份/关系/动机/弱点/梦想/过往）。
3. 每增加一个设定点，扮演法做逻辑推演。
4. 筛选最符合核心情绪的设定组合。

### 噱头-主线-核心爽点框架

#### 噱头类型

| 类型 | 特点 | 开篇写法 |
|------|------|---------|
| 事件噱头 | 书名就是事件 | 一上来就进入事件 |
| 金手指噱头 | 分布在全文，前期多后期少 | 先描写主角->困境->目标->金手指施展->少许成果 |
| 人设噱头 | 人设直接影响剧情 | 人设本身产生戏剧性 |

**规则**：事件噱头和金手指噱头写法不同。用金手指写法写事件，读者会弃书。

#### 噱头->主线嫁接

사건이 끝난 뒤 **곧바로 주인공의 목표를 연결**한다. 사건이 진행되는 동안 목표를 미리 깔아 두어도 된다.

#### 核心爽点 = 切在主线上的爽点

偏离主线的装逼是偏移爽点，不是核心爽点。

#### 逼格反应规则

逼格规则：主角面对挑衅时的反应力度应与其设定中的实力/阅历成正比。高实力角色的反应应为轻描淡写而非暴怒反击。根据角色实力等级设计反应模板：高实力→轻描淡写/一指灭杀；低实力→隐忍蓄力。被骂时的反应设计：
- 毒点：气得要死，面红耳赤
- 不毒：微微一笑--"他什么都不是"
- 歇斯底里->不爽；风轻云淡一指灭杀->爽

## 剧情组织

### 信息传达顺序体系

| 类型 | 结构 | 适用 |
|------|------|------|
| 直白剧情 | 提出疑问->公布答案 | 基础叙事 |
| 探索剧情 | 提出疑问->正常提示->公布答案 | 铺垫段 |
| 意外剧情 | 提出疑问->虚假提示->公布答案 | 反转段 |
| 意外+反转 | 提问->假提示1->假提示2->公布答案 | 高潮段 |

信息只有成为"疑问"时读者才关心。每个事件至少一个价值改变，且至少能推进主线。没有价值改变的事件 = 水章节。

### 主角生活路线扩展关系网

确定主角日常活动路线->在日常接触点引入新角色->新角色自带关系网->新的故事素材。

### 分步骤与缓冲区

- 缓冲区 = 主角和配角间因利益/事件/感情产生的距离，随着距离被攻略产生爽感。
- 目标分阶段拆解（类似练气/筑基/金丹），不只大目标，小目标也可拆。
- 剧情推进三种模式：主动处理推进目标的麻烦 / 主动推进目标遇到麻烦 / 被找上门的麻烦反而推动目标。

### 事件驱动原理

- 正文章节必须由事件组成，事件内容比重不能小于一半。
- 事件是价值改变的契机：没有事件，主角和主线不会改变。
- 设定尽量通过事件演绎，而非旁白强塞。

### 基于设定推演冲突

优先级：
1. **先有趣再有用**：先确保事件有戏剧性。
2. **拆出来的情节就是戏剧性**：拆书时有爽点的事件直接用。
3. **不够有趣时做铺垫拉期待**。

## 质量检查清单

完成矛盾与结构设计后，逐条检查：

- [ ] 矛盾是否按四重递进（自我->自然->人->世界）有层次推进
- [ ] 底层矛盾是否与世界观紧密绑定，不偏离核心梗
- [ ] 主角是否有三种动机来源中的至少两种（世界背景/金手指/人物关系）
- [ ] 主线结构是否用高潮逆推法拆分为大/中/小主线
- [ ] 冲突是否持续升级（言语->行动->激烈对抗->决定胜负），且有明确结果
- [ ] 每个阶段是否有无法解决的核心冲突驱动读者继续看
- [ ] 支线最终是否汇聚回主线
- [ ] 暗线（如有）是否在高潮与明线交汇
- [ ] 感情线（如有）是否按四阶段推进，试探阶段占30-50%
- [ ] 金手指是否通过合格五问，能力是否碎片化融入剧情
- [ ] 显性身份/隐性身份/显性金手指/隐性金手指四点是否统一
- [ ] 核心梗是否在第一个一级结构中运行一次或完成首次铺垫
- [ ] 循环核心是否匹配题材，是否偏离核心卖点
- [ ] 每个事件是否有至少一个价值改变，能推进主线
- [ ] 信息传达顺序是否匹配场景类型（基础/铺垫/反转/高潮）
- [ ] 动机过渡是否自然（上一危机解决时埋下下一危机伏笔）
