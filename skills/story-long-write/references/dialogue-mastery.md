# 대화 설계 운영 매뉴얼

> 대화 장면을 작성할 때 로드하세요. 먼저 결정 라우팅을 확인하여 올바른 대화 모드를 선택한 후, 운영 지시로 품질을 제어하세요.

## 결정 라우팅

| 당신의 대화 장면 | 이 모드 사용 | 운영 |
|-------------|---------|------|
| 주인공 압도/망신주기 | 압제 모드 | 상대방 장문 → 주인공 한 마디 응답 |
| 주인공 카드 공개/반전 | 반전 모드 | 상대방 거만 → 주인공 한 마디 팩트 → 상대방 침묵 |
| 관계 파탄/마음의 죽음 | 마음의 죽음 모드 | 대사가 점점 짧아짐: 변명 → 침묵 → "알아서" |
| 일상 상호작용/캐릭터 설정 | 일상 모드 | 다른 인물들을 갈등에 참여시키기, 주인공 독백만 하지 않기 |
| 대중 충격/댓글 반응 | 댓글 반응 모드 | 단계적 진행: 일반인 충격 → 전문가 분석 → 특수 신분자 반응 |
| 정보 표시/세계관 | 정보 임베드 | 캐릭터 톤으로 정보를 감싸기, 기계적 설정 설명 아님 |
| 감정 기복/가슴 아픈 | 감정 추진력 | 상승과 하강을 교대로, 톱질하듯 기대감 상승 |

### 대화 모드 선택 보충

| 대화 유형 | 일반적인 문제 | 수정 작업 |
|----------|---------|---------|
| 문답식(전체적으로 계속 묻고 답하는 형식 같은 심문) | 한 쪽이 주동적으로 말하고, 다른 쪽이 반응하도록 변경; 반응은 동작/표정/심리로 표현 가능 |
| 충돌식(너무 정중해서 임팩트 부족) | 5단계 점진적 상승: 완곡한 거절→우호적 인도→명령 거부→PUA식→직접 모욕 |
| 일상 대화（기능 없는 물이 되기 쉬움） | 기능은 인물 설정 구축; 참여를 유도하는 갈등이 있으면 주인공 독백으로만 진행하지 말 것 |
| 다중 인물 대화（혼란/영양가 없음） | 작성 전 각 역할의 기능 계획: 정보 제공자/감정 증폭기/갈등 조성자 |

## 대화 핵심 규칙

각 대사는 다음 중 최소 하나를 담아야 하며, 그렇지 않으면 삭제:

1. **플롯 진행**: 새로운 정보 공개, 사건 발전 추진
2. **기대감 조성**: 곧 일어날 사건을 암시하고 서스펜스 연출
3. **인물 설정 드러내기**: 언어 스타일을 통해 캐릭터 성격 전달

그리고 감정 장면에서는 매 문장마다 **상대방의 직전 감정 상태에 응답**해야 한다(이어받기/방향 틀기/고조하기/누그러뜨리기)——대화는 두 사람의 감정이 충돌하는 것이지, 돌아가며 정보를 보도하는 게 아니다. 단순히 줄거리만 진행하고 문장 사이에 감정 연결이 없다 = 기계적인 대사.

### 절대 금지

| 금지 | 이유 |
|------|------|
| 단역 인물이 주인공을 무분별하게 칭찬 | 거짓 |
| 독자가 이미 알고 있는 정보를 서로 설명 | 글자 수 채우기 |
| 긴 설명문식 대사 | 답답함 |
| 모든 인물의 말투가 똑같음 | 모호함 |
| 대사로 인물을 설득 | 현실에서는 아무도 몇 마디 말로 설득되지 않음, 돌발 상황으로 대체 |
| 감정 작성 완료 후 방향이 바뀜 | 감정 분해로 되돌아가야 함 |

## 권력 싸움 대화

### 규칙

대화 길이 = 권력 지위. 통제자는 말이 짧고 침착하며, 수동적인 사람은 말이 많고 감정적이다.

### 억압 모드

구조: 상대방의 긴 독백(3~5줄) → 주인공의 한 마디 응답.

```
"너 뭐라고 생각하니? 내가 말해주지. 이 집에서 너는 입 놀릴 자격도 없어. 시집온 그날부터 너는 네 위치를 알았어야 해."
"꺼져."
```

### 반전 모드

구조: 상대방의 거만함(2~3줄) → 주인공이 카드 공개(1줄 사실) → 상대방 침묵.

```
"넌 뭔 자격으로 참견하는 거야? 이건 우리 집 돈인데, 내가 쓰고 싶은 대로 쓸 거야."
"엄마 통장이 있는데, 비밀번호가 내 생일이야."
```

### 마음이 식은 모드

구조: 대화가 점점 짧아지고, 변명에서 침묵으로 나아가 「상관없어」가 된다.

```
"넌 내 말을 들어봐, 그날은 넌 생각하는 그런 게 아니야."
"음."
"정말이야, 증명할 수 있어."
"자유롭게."
```

### 조작 지침

- 지배자/주인공이 카드를 공개할 때: 대사 ≤ 10자, 동작 묘사 추가 금지
- 억압당하는 측: 대사 ≥ 20자, 동작 묘사 추가 가능(주먹 쥐기/입술 깨물기/일어서기)
- 두 사람이 대화할 때: 짧은 문장 측 = 권력 상위, 긴 문장 측 = 권력 하위

## 잠재된 의도와 의제

### 잠재된 의도 규칙

- 캐릭터의 진정한 동기는 절대 대사에 노골적으로 드러내면 안 됨
- 현실에서 사람들은 자신을 위해 변명을 찾고, 캐릭터도 마찬가지다
- 각 대사를 설계할 때 동시에 고려: 캐릭터의 동기(캐릭터 자신이 인식하지 못할 수도 있음)와 캐릭터의 변명

### 대화의 의제

- 각 캐릭터는 대화에 진입할 때 자신의 의제를 가지고 있다: 이 대화에서 무엇을 얻고 싶은가
- 두 캐릭터의 의제가 충돌할 때 긴장감이 생긴다
- 양측 의제가 일치함(같은 입장) = 복술, 의미 상실

### 어조는 세 가지 요소로 결정됨

관계 × 상황 × 목적 = 어조

| 상황 | 특징 | 적합한 내용 |
|------|------|----------|
| 개인(일대일) | 심층적, 감정 노출이 충분함 | 내심 고백, 음모, 고백 |
| 공중 | 체면을 고려하여 표현이 절제됨 | 충격력이 필요할 때는 깨뜨릴 수 있음(예: 공개적으로 결렬) |
| 친숙한 사람(친구/동료) | 깊이가 둘 사이의 중간 정도 | 편안한 상호작용과 정보 교환 |

사적인 이야기를 공개 장소에서 해야 충격력이 있다. 대화에서 완전히 표현할 수 없는 내용은 동작, 표정, 환경으로 보충한다.

## 감정이 대화를 주도한다

### 강한 감정의 대화

- 명령식+부정식이 독자 감정을 가장 잘 자극합니다: "내 말이 충분히 명확하지 않습니까?"
- 최고의 화술: 너를 위한다는 명목 아래, 매 문장마다 관심을 표하지만 매 문장마다 질린다·비난한다·혐오한다
- 직접 부정이 은유적 암시보다 더 상처를 줍니다

### 감정 연속성

인물의 감정은 연속적이고 단계적입니다. 화남에서 기쁨으로: 화남 → 덜 화남 → 화나지 않음 → 기쁨, 각 변화마다 사건이 촉발해야 합니다. 건너뛸 수 없습니다.

### 감정 4단계법(모두 필수)

1. 사건을 마주침(불균형 상태)
2. 감정 반응(외적 표현: 동작, 표정, 언어)
3. 내적 사고(생각이 없어도 "생각이 없음"을 작성하여 무분별함을 표현)
4. 행동 취함(앞의 세 단계 결과에 기반하여 대응)

### 대화를 밋밋하지 않게 만드는 세 가지 방법

- 대화 자체가 핵심 동기(기대감, 쾌감, 긴장감)를 불러오거나 강화한다
- 정보 교류가 어떤 이유로 차단되며, 이 차단이 동기를 만들어낼 수 있다
- 전개가 갑자기 독자의 예상을 벗어난다(단, 합리적이고 캐릭터에 부합해야 함)
- 긴 대화를 기대감과 쾌감 사이에 배치한다: 독자가 쾌감을 보기 위해 중간 대화를 참아낸다

## 정보 표시와 세계관 도출

- 대량의 정보를 대사로 전시하면 장황해 보이므로, 일부 정보는 플롯, 심리 묘사, 나레이션, 환경, 동작으로 전환
- 정보를 캐릭터의 어조와 입장으로 포장하되, 기계적인 설정 진술이 되지 않도록
- 설정은 필요할 때만 조금씩 드러내면 되고, 원인과 결과를 완전히 설명할 필요는 없음
- **캐릭터가 "설명 전담자"가 되지 않기**: 설정/원리/인과관계를 어떤 캐릭터(특히 정보 제공형/AI 조연)도 길게 강의하듯 설명하면 안 됨——Gate G는 캐릭터 대사에도 동일하게 적용. 압박 상황에서 겨우 짜내는 단편적 대사 + 신체 반응 + 여백으로 나누어서, 필요한 부분만 조금씩 드러내기

### 정보 끌어당김 예시 ("주인공의 신작이 대박났다"를 예로 들어)

| 역할 | 대사 | 기능 |
|------|------|------|
| 갑 | 들었는데 성적이…… | 서스펜스 + 기대감 유발 |
| 을 | 절대 아무도 안 볼 거야! | 하강 + 기대감 유발 |
| 갑 | 들었는데 성적이 정말 좋대 | 상승 + 기대감 유발 |
| 을 | 첫 주문이 1만 3천? | 핵심 정보 노출 + 쾌감 달성 |

상행과 하행이 교대로 나타나며, 감정이 톱질하듯 계속 기대감을 높인다.

## 인물 언어 차별화

각 캐릭터는 자신만의 말투를 가져야 한다. 대사를 쓸 때 그 캐릭터가 뭐라고 말할지 자주 막힌다면 → 인물 설정이 모호하다는 뜻이니, 비슷한 인물 설정의 말투를 정리해보자.

| 차별화 차원 | 작업 |
|------------|------|
| 말버릇과 관용구 | 각 주요 캐릭터마다 특징적인 용어 부여 |
| 말하기 속도 | 장황한 설명 vs 짧은 문장 연타 |
| 정보 선호도 | 기술형은 전문 용어 사용, 강호인은 은어 사용 |
| 입장 고정 | 특정 캐릭터는 항상 특정 관점에서 발언 (비관론자/낙관론자/현실주의자) |
| 신분이 표현에 미치는 영향 | 노인/소년/귀족/시민, 신분이 다르면 표현, 자칭, 경어 사용이 다름 |
| 성격이 어조에 미치는 영향 | 지략형은 말 속에 뜻이 있음; 무모형은 생각나는 대로 말함; 냉정형은 표현이 정확하며, 가끔 감정이 드러나는 것이 오히려 임팩트를 줌 |
| 진행도가 태도에 미치는 영향 | 초면/친숙함/대립/친밀함, 관계 단계가 다르면 어조와 정보량도 다름 |

## 댓글/군중 대화

세 가지 핵심 작용: 스토리 진행(주인공이 모르는 정보 노출), 기대감 증대(반전, 추측), 감정 표현(군중의 놀람/흥분/분노가 독자에게 전염됨). 부가 효과일 뿐, 주선을 대체하지 않음.

### 설계된 댓글 vs 설계되지 않은 것

- 설계 없음: "와, 정말 대단한데?"만 반복, 단조롭고 낭비적
- 설계함: 일반인 놀람 → 전문가 분석 → 특수한 신분 반응 → 감정 승화

### 조작 요점

- 인물별로 다른 톤, 모든 대사가 같은 맛이면 안 됨
- 짧고 강렬하게, 각 대사는 핵심 정보 한 문장 이내
- 단계적 전개를 잘 활용: 처음의 충격에서 점차 전체상을 인식하기까지
- "반전" 역할이 나타날 수 있음: 한 조연의 한마디가 모두의 인식을 바꾸기
- 모든 장마다 쓸 필요는 없음, 핵심 쾌감/감동/감동 포인트 전후로 집중 사용

## 리듬 제어

### 대량의 대사로 리듬 유지

- 인물의 성격을 드러내는 어조 조사를 "간결함"을 위해 삭제하지 마세요
- 대사 단락 사이에 동작 묘사, 환경 변화, 심리 활동을 섞어 리듬을 조절하세요
- 긴장된 단락의 대사는 짧게, 완화된 단락은 더 길게 할 수 있습니다
- 핵심 정보는 대사의 시작이나 끝에 배치하고, 중간에는 감정을 끌어당기는 데 사용하세요

### 동작과 표정 처리

- 모든 대사마다 의도적으로 표정/동작을 붙이면 문장이 기계적이 된다
- 동작과 표정은 주요 전환점에서 사용할 때 효과가 최고이며, 모든 대사마다 붙일 필요는 없다
- 담담한 분위기의 장면(차 마시기, 산책)은 미묘한 동작과 침묵으로 분위기를 표현한다

### 대사의 호흡감

- 연속된 여러 라운드의 대사 후에는 "숨을 고르기"가 필요하며, 환경 묘사나 인물의 심리를 삽입한다
- 적절한 멈춤(동작 묘사, 줄바꿈, 짧은 문장)이 연속 출력보다 더 큰 긴장감을 만든다
- "정말이야?"가 긴 설명보다 더 큰 압박감을 준다

## 분량 조절

### 대사가 많을 때

- 독자가 이미 알고 있는 정보의 대사는 서술 한 문장으로 요약한다: "앨리스가 안나에게 도시에 온 이유를 설명했고, 안나는 듣고 나서 계속 찡그렸다"
- 돌발 상황으로 대체 가능한 대사 구간은 직접 교체하기
- 어조사를 삭제한 후 밋밋함 = 대사 자체에 정보량 부족, 재작성 필요

### 대사가 부족할 때

- 다른 인물의 대사로 표현할 수 있는 내용은 주인공의 나레이션으로 나열식으로 풀어쓰지 않기
- 조역을 갈등과 대사에 참여시키되, 새로운 인물은 반드시 주선 장면에 배치하기

## 개그 요소로 대사 채우기

### 개그식 vs 일반식

- 일반식："형, 낙심하지 마. 넌 여기까지 오는 걸 내가 다 봤잖아. 이 정도 좌절이 뭐 하는 건데? 정신 차려!"
- 개그식："형, 낙심하지 마. 난 너를 믿어, 분명 넌... 어라, 그 말이 뭐였더라? 어쨌 그 말 있잖아... 아 맞다 뭐였더라? 형 내 뜻 알지......"
- 개그식은 "말은 못 하지만 의도는 통했다"는 상태로 재미를 만든다

### 운영

- 대사에 개그나 농담을 녹여내 전체적인 재미를 효과적으로 높인다
- 특히 주인공이나 중요 조연의 돋보이는 대사라면 개그로 기억점을 강화하기에 좋다
- 특정 개그를 클라이맥스 포인트로 삼아 전체 에피소드를 이를 달성하도록 설계할 수 있다
- **상황 예외(목소리 양보)**: 극심한 긴장/생사/슬픔/심각한 beat에서는 개그 담당과 경쾌한 조연의 농담, 입으로 하는 개그, 재미있는 대사들을 모두 자제한다. 목소리를 현재 감정 기조에 양보하고, 짧고 차갑고 감정적 무게가 있는 반응으로 대체한다. 개그는 안전하거나 숨 쉬는 beat에서만 사용한다. 자체 검토: 이 농담을 현재 기조에 집어넣으면 독자가 몰입에서 벗어날까? 벗어나면 삭제/수정한다

## 품질 검수

### 3가지 자가 검토 항목(1개 이상 개선 필요)

- [ ] 많은 정보를 대사로만 전달하고 있지는 않은가
- [ ] 대사가 일문일답 형식의 질문과 답변으로만 이루어져 있지는 않은가
- [ ] 스토리 진행이나 인물 변화를 대사에만 의존하는 습관은 없는가

### 핵심 지시 확인

- [ ] 권력 게임: 지배자 대사 <= 10자 / 억압당한 자 >= 20자, 명확한 억압/반전/절망 패턴이 있는가
- [ ] 잠재된 의도와 의제: 각 인물이 대화에 진입할 때 자신의 의제를 가지고 있으며, 진정한 동기는 대사에 드러나지 않음
- [ ] 인물 차별화: 인물명을 가린 후 누가 말하고 있는지 구분할 수 있는가 (7가지 차원 차별화)
- [ ] 댓글 진행: 일반 → 전문가 → 특수 신분, 계층감이 있는가
- [ ] 대화가 줄거리를 진행시키는가: 각 대화가 끝날 때 스토리가 한 걸음 앞으로 나아가는가
- [ ] 분량 조절: 단일 대화가 전체 섹션의 40%를 초과하지 않으며, 정보 밀도가 충분한가

### 대화 품질 검증

- 대화의 자연스러움 검사: 각 문장을 검토하여 대화가 자연스러운 구어체 교감처럼 들리는지, 서술적인 문답 원고처럼 들리지 않는지 확인
- 대화의 결말이 다음 섹션의 리듬 변화를 예고할 수 있는가
