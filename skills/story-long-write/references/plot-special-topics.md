## 금손 요소 분해와 전투력 붕괴 방지

### 금손 본질 분해

**작업**: 금손을 아래 요소들로 분해한 뒤 재조합하세요. 금손을 분해할 수 없는 하나의 덩어리로 보지 마세요.

| 요소 | 역할 | 예시 |
|------|------|------|
| 패널 | 목표감이 분명하고 가장 직관적인 수확감 원천 | 수치/레벨/진행바 |
| 비감소 | 반복 행동으로 얻은 향상이 지속되는 특성 | 숙련도는 감소하지 않음 |
| 반복 향상 | 핵심 루프 메커니즘 | A를 함 -> B를 얻음 -> 계속 A를 함 |

**조합 방법**: 분해 후 자유롭게 조합하세요. 예: "몬스터 처치+숙련도" = '섬멸 숙련류', "수집+등급 상승" = '이형불 수집류'.

**핵심 경고**: 후반에 금손이 '품질 상승' 단 하나의 차원만 남으면 상승감이 사라집니다. 반드시 여러 차원이 동시에 성장하도록(속성·기능·품질 등) 설계하세요.

### 전투력 붕괴의 세 가지 원인

**작업**: 아래 세 가지 함정에 해당되는지 차례대로 점검하고, 해당하면 해결책을 적용하세요.

| 원인 | 해결법 |
|------|------|
| 상승선(레벨업 라인)을 쓰지 않음 | 고전적 경지 체계로 상승 프레임을 제공하세요 |
| 금손 설계 결함 | 금손 상승은 다차원적이어야 하며, 단일 차원에 의존하면 안 됩니다 |
| 사회 환경이 너무 단순 | 술집·문파·친구·정보 조직처럼 제대로 된 사회 관계를 설계하세요 |

## 금손 고급 설계

### 엇박 시스템 설계

**작업**: 시스템이 '정상적으로' 작동하지 않게 하여, 시스템과 주인공 성격의 괴리에서 드라마를 뽑아보세요.

| 엇박 유형 | 예시 |
|----------|------|
| 시간 엇박 | 주인공이 이미 무적인데 역전 시스템이 뒤늦게 도착함; 대학생인데 유치원 공략 시스템이 옴 |
| 공간 엇박 | 주인공은 정상 세계에 있는데 깨어난 건 종말 시스템 |
| 대상 엇박 | 원래 황제에게 붙어야 할 시스템이 황후에게 붙음 |

**원칙**: 엇박으로 생긴 갭은 크게 가져가야 하고, 그 드라마성은 목표 독자가 기대하는 방향이어야 합니다.

### 시스템 반(반)트렌드 쓰기

- 제목은 시스템의 '반트렌드' 요소를 최대한 대놓고 어필하세요.
- 소개글은 시스템을 한 번 사용했을 때 오는 쾌감(한방성)을 분명히 써주세요.
- '반'이라는 말로만 낚지 말고, 반트렌드가 실제로 주인공에게 어떻게 이득을 주는지도 보여줘야 합니다.

### 자주 쓰이는 시스템 유형

**작업**: 이야기 요구에 맞춰 아래 유형에서 선택하세요.

| 유형 | 특징 |
|------|------|
| 스탯 포인트 시스템 | 직관적이지만 단일, 강압적 세계관에 적합 |
| 숙련도 시스템 | 감정선·보편성 확장이 가능하며, 하위 메커니즘 변형이 용이 |
| 뽑기(가챠) 시스템 | 독자에겐 익숙하면서도 포장으로 신선함 제공 |
| 상점/교환 시스템 | 자원 획득형, 경영·영농물에 적합 |

### 극도류 금손의 특별 고려사항

- 극도류 세계관 특징: 절대적 계급 고착, 규칙적으로 수련만 해선 계급을 뛰어넘기 어려움
- 극도류 진화 방향: 단일 극도 성장만으로는 한계. 요소 융합 필요(극도+공포+탐험, 극도+종말+생존류 등)

## 아이디어 소설 완전 집필 프레임

### 영감에서 단행본까지 네 단계 프로세스

**작업**: 이 네 단계를 순서대로 엄격히 수행하세요. 건너뛰지 마세요.

1. 아이디어 확보: 금손의 초안·장면·진입점 등
2. 소재 매칭: 그 아이디어가 어떤 소재와 섞일 수 있는지 고민
3. 프레임 구축: 상승 체계·금손·프레임 세 요소로 설계
4. 플롯 설계: 프레임 안에서 작은 플롯 루프들로 채움

### 금손 설계: 조건-피드백 모델

**작업**: 아래 표에서 하나를 골라 금손의 핵심 메커니즘으로 삼으세요.

| 변형 | 설계 | 예시 |
|------|------|------|
| 단일 조건·단일 피드백 | 시체 검사 -> 보물 획득 | 가장 기본 형태 |
| 단일 조건·단계별 피드백 | 시체 검사 -> 시체 포인트 획득 -> 레벨업으로 기능 해금 | 유지 메커니즘을 보존하면서 표현을 풍부하게 함 |
| 조건 업그레이드 피드백 | 처치 -> 단서(속성) 약탈 -> 속성 합성이 가능함 | 후반에 천장(확장성)이 높음 |

**혁신 기법**(선택적 중첩):
- 여러 조건이 하나의 피드백에 대응하도록 설정
- 하나의 조건에 확률적 피드백 부여
- 피드백이 새로운 하위 능력을 생성

### 주선(메인)과 전환 프레임 설계

**작업**: 프레임 = 주선 + 플롯 간 전환. 핵심 질문: 각 플롯은 어떤 목적을 위해 존재하는가?

설계 절차:
1. 주인공 초기 상태 확정
2. 각 플롯의 기능을 정하고 앞뒤로 연결
3. 이후 플롯이 이전 플롯으로 자연히 스며들게 설계
4. 프레임에 소규모 플롯 루프를 교차·중첩하며 삽입

프레임 내 구체적 소재는 유연하게 교체 가능하나, 핵심 기능은 유지되어야 합니다.

### 소플롯 루프 구상법

**작업**: 각 소플롯은 반드시 네 단계로 엄격히 진행하세요.

| 루프 단계 | 내용 |
|----------|------|
| a1 | 시작 깔기(주인공 처지 + 목표) |
| a2 | 난관 등장(구체적 갈등 도입) |
| a3 | 금손/전력의 개입 |
| a4 | 쾌감 방출(충격/수확/관계 돌파) |

**상승류의 소루프 리듬**: 난관 -> 금손 상승 -> 플롯 전개 -> 수확과 일상 -> 대목표 깔기·세계관 확장

**다중 레벨 중첩**: 소루프 -> 중루프(중간 목표) -> 대루프(큰 목표). 소루프 안에서 대루프의 기대를 반드시 포석하세요.

### 아이디어 소설을 장편으로 쓰는 세 가지 핵심

1. 반복 속의 변화: 동일 핵심 흥미를 다른 각도·다른 갈등으로 변주
2. 세계관 확장: 새로운 지도·세력·설정 점진 개시
3. 핵심 매력의 시장성 파악: 충분한 독자 수요 커버

### 다중 루프 교차 패턴

**작업**: 아래 표에서 루프 패턴을 골라 적용하세요.

| 패턴 | 효과 |
|------|------|
| 다각도 루프 | 핵심 매력에서 여러 각도를 뽑아 각 각도로 1~2권씩 전개 |
| 설정 확장 루프 | 아이디어 설정을 확장해 여러 루틴을 뽑음, 다각도 루프보다 단순 |
| 핵심 미확장(반면) | 같은 떡밥을 대상만 바꿔 반복(다른 적에게 계속 당하거나 다른 부하를 모음)하면 ~20만 자쯤 독자들이 질림 — 본질적 새로움이 없음 |
| 강감정 사건 루프(반면) | 계속해서 비참/잔혹을 자극하는 방식(주인공이 점점 더 비참, 적이 더 사악)으로 감정 문턱을 계속 높이면 이후 무엇을 써도 독자가 만족 못함 |

## 소재 경계 감각

### 실행 규칙

- 각 소재는 독자가 기대하는 경계가 명확하다. 경계를 넘으면 독자가 외면합니다.
- 소재 방향을 잘못 고르면 본문이 아무리 잘 써도 목표 독자의 기대를 충족시키지 못합니다.
- 경계 감각은 표적화용—경계 내에서 특화하면 폭발적 성과를 낼 수 있습니다.

### 경계 판단법

**작업**: 아래 절차로 소재 경계를 판단하세요.

- 같은 소재의 우수작에서 만 명 이상 구독(만독) 사이에 공통 요소가 있다면 그게 경계다.
- 경계를 넘는 '혁신'은 대개 독(독해)입니다.
- 맥락이나 소재 자산이 부족하면 경계를 깨지 마세요. 먼저 경계 내에서 핵심 기대를 충족한 뒤 미세 혁신을 하세요.

### 소재 경계와 금손의 관계

- 금손은 반드시 소재 경계와 호흡을 맞춰야 합니다.
- 금손의 핵심 매력 루프는 소재에서 벗어나면 안 됩니다.
- 판단 기준: 독자가 무엇 때문에 들어왔는지, 이후에도 그걸 계속 줘야 합니다.

## 차트 스캔 및 작품 분석 방법

### 차트 스캔 원칙

**작업**: 플랫폼별로 각기 다른 차트에 주목하세요.

- 판타오는 읽기 차트와 신작 차트 위주로, 기점는 삼강 추천과 각종 큐레이션을 보세요.
- 편집 선정 섹션(편집 선정)에 오른 글은 핫요소가 무엇인지 주로 본 것입니다 — 왜 그 글이 선정되었는가.
- 금상(금랭크)은 완성도 높은 작품이 많아 구조 표준을 추출하기에 적합합니다.
- 시장 스캔 시 우선적으로 같은 플랫폼·같은 소재·비톱 브랜드 작품을 보세요. 재현 가능한 구조 샘플을 얻기 쉽습니다.

### 작품 분석(작품 분석)의 올바른 자세

**작업**: 작품 분석 전 어떤 차원을 분석할지 명확히 하세요. 막연히 읽지 마세요.

- 개인 취향으로 가치 판단하지 마세요; 해당 작품이 재사용 가능한 구조/감정/리듬 모듈을 제공하는지 판단하세요.
- 구체적 질문을 가지고 분석하세요: 갈등은 어떻게 감정을 끌어당기는가? 갈등 장면 10개를 찾아 분석하세요.
- 중간 수준 샘플을 우선 분석하세요; 강한 브랜드·강한 팬층을 가진 톱 작품은 제외하세요(재현 불가).
- 매번 단일 차원만 분해하세요: 인물·리듬·대조 수법·미스터리 등.

### 작품 분석에서 추출할 포인트

- 차트 스캔 시에는 쓰기 기능 단위로 추출하세요: 핫요소, 갈등 구조, 감정 체인, 리듬 배치
- 분석 기록은 구체적 차원을 표기해야지 일반적 독후감이 되지 않게 하세요
- 목표 지향적 분해가 막연한 독서보다 가치가 큽니다
- 소재에서 벗어나 분해하지 마세요

## 동인 vs 창작의 리듬 차이와 핵심 프레임

### 동인 vs 창작의 리듬 본질적 차이

- 동인은 사전 깔림이 필요 없고, 이미 가져온 설정만으로 기대감과 쾌감을 즉시 발휘합니다.
- 같은 분량이라면 동인이 창작보다 쾌감이 빠르게 온다 — 깔림이 짧음.

### 창작의 리듬 문제 해법

**작업**: 창작을 쓸 때는 아래 리듬으로 전진하세요.

- 초반 일부 쾌감은 희생(작게라도 괜찮음)하고 핵심 루틴을 빠르게 반복시키세요.
- 독자를 붙잡은 뒤에 자세한 깔림을 합니다.
- 리듬 전진 패턴: 초반 1만자에 소플롯 x3 -> 2만자에 소플롯 x2 -> 3만자에 소플롯 x2 -> 8만자 이후 다수 반복

### 1차 구조 vs 2차 구조

**작업**: 플랫폼 특성에 맞춰 구조를 선택하세요.

| 구조 | 특징 | 구독 반응 |
|------|------|----------|
| 1차 구조(단위극) | 쾌감 분포가 고르게 배치되어 매일 작은 클라이맥스 존재 | 추적 읽기가 안정적 |
| 2차 구조(깔기->반전->대클라이맥스) | 대클라이맥스 이후 평탄기가 생김 | 구독 변동, 계단형 이탈 발생 |

### 장황함 자가진단

**작업**: 아래 항목을 하나라도 만족하면 되돌아가 삭제하세요.

- 한 문장으로 충분히 전달될 것을 불필요하게 길게 설명하지 마라
- 주선과 무관한 플롯은 최소화하라
- 부사 사용 빈도를 줄여라
- 같은 사안을 반복 기술하면 장의 초점이 흐려진다

### 동인 글쓰기 요점

- 제목은 사람을 끌어야 함: 가장 토론이 많은 사건에서 파고들 것
- 지선(보조선) 인물은 압축: 제목이 특정 고전 인물을 겨냥하면 보조 인물은 2장 이내
- 명명은 원작 세계에 맞게: 원작 인물은 공식 명/번역 그대로 사용, 신인물은 원작 지역의 문화·번역 스타일을 따르되 한 지역 내 언어 계열을 섞지 마라. 설정과 맞지 않는 현대적·정치적 이름은 피할 것

## 도시 고무 플롯 템플릿

### 공통 목표 풀

**작업**: 아래 표에서 목표 콤비네이션을 골라 쓰되, 모든 목표는 반드시 돈과 연결되어야 합니다.

| 목표 유형 | 구체 선택지 |
|----------|----------|
| 물질 | 집 바꾸기, 필수 자원 확보, 더 많은 돈 벌기 |
| 학업 | 대학 진학, 군학교 합격, 각종 시험 통과 |
| 직업 발전 | 무도청 입성, 치안국 입성, 군부 입성 |
| 친족 | 어머니 치료, 아버지 구하기, 본인 치료, 친척 돕기 |
| 감정 | 소꿉친구 호감, 천강강림 미녀 호감 |
| 동기부여 | 매일 세계 1등의 초상화를 보며 사기충전 |

**핵심 원칙**: 모든 목표는 돈과 연계되어 있어야 하고 반복적으로 돈을 연결하라. 돈 없이는 한 발짝도 못 나아감, 돈 있으면 천하를 제압.

### 상황별 사용 가능한 플롯 사건

**작업**: 현재 장면에 맞춰 아래에서 사건을 고르세요.

| 장면 | 사용 가능한 사건 |
|------|----------|
| 학교 | 천재반 진입, 상 수상, 가상 대회 우승, 월간고사, 전교 깡패와 충돌, 다교 연합 시험, 전국 수능 |
| 무관 | 관장에게 인정받음, 무공 전수, 선배와 대결, 시·성·국 대회 |
| 경찰서 | 강도와 합동 진압, 사악 세력 토벌, 악질 보스 소탕 |
| 경쟁 | 무관/학교/무도청/군부/국안/가상 네트워크/스타 대회 계약 경쟁 |

### 맵(무대) 전환 공식

**작업**: 무대가 소진되면 아래 공식으로 바꿔라.

고등학교 -> 대학, 무관 -> 천하제일무도회, 무도청 -> 중앙무도청, 블루스타 -> 다른 성역. 순환 반복.

로켓 점프법: 대학 교수 붙잡기 -> 학장과 대립 -> 재벌 타격 -> 미국형 모사 기관 공격 -> 중간 보스 타격 -> 대보스 타격 -> 악신 소탕.

## 다른 소재의 쓰기 방식과 신분·행동 이론

### 수·배·압·기(수준 조절) 리듬 이론

**작업**: 장을 쓰기 전 항상 '수(수축), 배(이완), 압(압박), 기(발동)'을 확인하세요.

- 소설은 수·배·압·기의 리듬을 중시해야 합니다.
- 클라이맥스 후 다음 장을 어떻게 처리하느냐가 실력을 드러냅니다.
- 어떤 클라이맥스를 쓰기 전 반드시 묻자: 주인공의 현재 레벨이 충분한가?

### 신분 행동의 경계

**작업**: 주인공의 신분을 확정했으면 그 신분이 허용하는 행동 범위 내에서 움직이게 하세요.

- 신분을 정하면 그 신분이 할 수 있는 행동과 할 수 없는 행동이 분명해집니다.
- 급선회(넘어서는 행동) = 구조적 훼손, 몰입감이 깨짐
- 너무 큰 걸음의 결과: 플롯이 도약형으로 변해 클라이맥스는 많지만 선형으로 이어지지 않음

### 소재별 쓰기 차이

**작업**: 자신의 소재를 대조표와 맞춰 필요한 점을 반영하세요.

| 소재 | 쓰기 요점 |
|------|----------|
| 서양 판타지(저위 배경) | 갈등을 쓰지 말고 환경을 쓰라; 반전·끌어당김이 필수는 아니며 흐름이 가장 중요 |
| 동방 현환(동양 판타지) | 불필요한 인물은 쓰지 말 것, 1장에는 주인공만 등장시키고 독백·심리로 밀어붙임 |
| 갈등이 있는 오프닝 | 계속 끌어당기는 구성이 필요해 리듬이 점점 빨라져 붕괴 위험이 큼 |
| 환경 위주의 오프닝 | 느린 리듬으로 진행되며 정보 밀도가 높지만 독서 경험은 매끄러움, 장편화가 쉽다 |

### 강감정 오프닝의 함정

**경고**: 강감정 오프닝은 이후 업그레이드 능력이 받쳐줘야 쓸 수 있습니다.

- 플롯 어프로치가 이후 더 높은 대가, 더 강한 상대, 더 깊은 감정 반전을 제시할 수 없다면 강감정 오프닝을 쓰지 마세요.
- 강감정 오프닝 후에는 이후 대노드마다 최소 하나의 차원을(대가·범위·진실·관계 파괴) 업그레이드해야 합니다.

### 유파 요소 합성법

**작업**: 유파 A의 요소를 추출하고 유파 B의 요소를 추출한 뒤 두 요소를 합성해 새로운 아이디어를 만든다 -> 새 책 창작. 스킨 변경법: 배경만 바꿔 같은 사고를 다른 소재에 적용.

## 러브라인 정제 전략

> 관련: 감정선 전체 프레임(호감도 체계/4단계/남·여 장르 차이)은 [character-relations.md](character-relations.md) '호감도 체계'를 기준으로 한다; 본문은 '두 가지 핵심 떡밥' 지지 방식의 정제 선택만 다룹니다.

### 러브라인의 두 가지 핵심 지지 방식

**작업**: 아래 두 패턴 중 하나를 선택해 러브라인의 핵심으로 삼으세요.

1. 특정하고 드라마틱한 사랑의 과정(금지된 사랑, 쫓는 자-후회류 등) — 단계별로 다른 핵심 감정 체인이 존재
2. 특정하고 드라마틱한 인물·인물 조합·두 사람의 관계 — 전권의 톤이 두 사람의 상호작용 패턴에서 온다

### 상호작용 패턴 불변의 철칙

**작업**: 남녀 주인공의 상호작용 패턴을 정하면 그 패턴은 작품 끝까지 유지되어야 합니다. 상호작용 패턴을 바꾸면 독자가 이 책을 쫓는 핵심 감각이 바뀌는 것과 같다.

### 커리어 라인은 러브라인에 봉사해야 함

**작업**: 러브라인을 중심에 둘 때, 모든 커리어 관련 플롯은 러브라인을 위해 기능해야 합니다.

- 커리어 라인의 기능: 만남을 유발 / 관계 변화를 일으킴 / 라이벌·장인(어른) 검증
- 과시 장면은 써도 되지만, 과시 후 반드시 러브라인 관련 전개가 이어져야 한다

### 후궁물 캐릭터 설계 원칙

- 여성 캐릭터들의 외형은 유사성을 유지 — 로리면 모두 로리, 오네상 계시면 모두 오네상 계열
- 최근 플랫폼 샘플에서 '남주 절친'이 매력을 떨어뜨린다면 '썸·인연으로 얽히는 소꿉친구형 여주' 등 관계 드라마를 만들 수 있는 포지션으로 대체

## 인물 심화 vs 이야기 심화

### 두 가지 심화 경로

**작업**: 프로젝트의 복잡도·기존 자료·목표 감정에 따라 심화 경로를 선택하세요.

| 경로 | 특징 |
|------|------|
| 이야기 심화 | 복잡한 음모·다층 추리·지략 싸움 — 상한선이 높지만 난이도가 큼 |
| 인물 심화 | 인물 관계와 상호작용에서 드라마를 찾음 — 주선이 이미 명확하고 지속적 신선감이 필요한 프로젝트에 적합 |

인물 심화의 핵심: 단순하고 독자가 익숙한 스토리 프레임에서 인물 상호작용으로 '재미'를 만든다. 몇 명의 인물 관계·욕망 차이·상호작용 패턴을 먼저 열거하고, 그 패턴을 반복 가능한 감정 포인트로 맵핑하세요.

## 플롯 각색 3단계법

### 핵심 원칙: 좋은 플롯은 각색으로 만들어진다

**작업**: 세 단계를 엄격히 따르세요.

1. 모순을 통해 목표 찾기: 주인공이 현재 어떤 모순에 직면했는가를 규정 -> '콘텐츠 라이브러리'에서 유사 플롯 검색 -> 원형 작품 찾기
2. 대조법: 원형 작품을 세부 시놉으로 분해해 왼쪽에 장면을 나열 -> 오른쪽에는 자신의 작품 상황을 배치 -> 장면별로 각색
3. 조정·최적화: 각색된 이야기가 원형과 달라졌음을 확인 -> 리듬·감정·미스터리·인물 동기를 항목별로 점검

**각색은 다르게 만드는 것**. 두 책의 기초가 다르면(세계관·인물 관계·금손 상황 전혀 다름) 그대로 베끼는 것은 불가능하다.

## 3만자 카포인트 역추적법과 중후반 작법

### 3만자 카포인트 역추적

## 진영 플롯 배치와 동기 보강법

### 진영 플롯의 네 가지 기본 패턴

**작업**: 현재 플롯에 맞는 네 패턴 중 하나를 선택하세요.

1. 주인공 -> 적대: 가장 일반적, 적이 직접 주인공을 괴롭힘
2. 아군 -> 적대 -> (동기 전환) 주인공 -> 적대: 아군이 표적이 되고 주인공이 나섬
3. 주인공 -> 적대 A -> (동기 확장) 주인공 -> 적대 B,C,D: 작은 보스부터 큰 보스 순으로 전개
4. 주인공 -> 아군: 오해/이념 차이/능력 증명 -> 플롯 완충 + 인물 부각

### 제3자 진영의 핵심 역할

구경꾼으로서의 충격 제공뿐만 아니라 '논리 완성'의 역할이 중요합니다 — 적이 얼마나 똑똑한지, 주인공 측의 고수들이 주인공 광채 때문에 억지로 도와주는지 판단 기준을 제공.

### 동기 보강의 핵심

- 감정은 동기의 불붙는 인자다 -> 감정이 충분할수록 독자와 인물의 감정이입이 강해짐
- 적대감 전환 시 동기는 강렬하고 논리에 맞아야 함
- 동기는 인물 성격을 기준점으로 삼아야 함

### 다층 포석법(동기 보강 사례)

**작업**: 아래 패턴으로 동기를 단계적으로 보강하세요.

단계적 포석:
1. 타임슬립 후 원 주인(원신)이 독살당한 걸 발견 -> 복수 동기
2. 원주의 기억 영향 -> 가족과의 유대가 깊음
3. 가족의 걱정이 아직 식지 않음 -> 감정 포석
4. 저녁 식사가 정성스러움 -> 친정 표현
5. 가정형편이 어려움, 부모가 밤낮으로 일함 -> 가족 곤경
6. 약값 마련하려 빚을 짐 -> 경제적 압박
7. 여동생이 풍류남의 가신이 되려 함 -> 극적 감정 폭발

**규칙**: 감정을 계속 억누르지 마라 -> 라이트 급쾌감(사이다물)의 감정은 파동식이다 -> 너무 낮게 눌러두지는 말고 금손으로 회복 포인트를 넣어라.

### 주인공 측의 강세(농사·영주·문파 건설물)

약한 주인공 진영 = 조연의 독립적 과시가 주인공과 무관 = 독자가 불만
강한 주인공 진영 = 영민·제자·관중이 주인공의 과시를 대신함 = 주인공 과시가 확장되어 쾌감 증가

## 진영 핸드법 — 카드 사고로 메인 플롯 설계

### 핵심 개념

프레임 = 주선 + 지선 + 일상의 비중과 배치 조합입니다.

| 유형 | 정의 |
|------|------|
| 주선 | 이야기를 최종 기대까지 밀어붙이는 과정 |
| 지선 | 보조 도구/능력을 얻는 임무 |
| 일상 | 캐릭터 상호작용의 따뜻한 채우기 |

### 진영 핸드법 운영

**작업**: 카드 게임처럼 각 진영이 턴을 내는 식으로 구성하세요.

- 주인공 관점에서 대응 수단(공법/법보/지식 포인트)을 생각하라
- 적과 관객 진영 관점에서 카드를 내고 토론하라
- 핵심: 각 진영 캐릭터를 전력 순으로 정렬 -> 단계별로 진행 -> 마지막에 주인공이 결정타

### 세 가지 버전

**작업**: 프로젝트 난이도와 사용 가능한 맥락에 따라 버전을 고르세요.

| 버전 | 구조 |
|------|------|
| 기초형 | 같은 사건에 대해 다른 입장의 캐릭터들이 각기 다른 태도를 보임 -> 선억후양(먼저 누르고 후에 끌어올림) |
| 중급형 | 고전적 구조: 관중 -> 조연A -> 조연B -> 적C -> 주인공의 압도 -> 대BOSS 소환 |
| 고급형 | 주인공이 직접 나서지 않고 부하에게 핵심 지식을 전수 -> 적이 수난 끝에 등장 -> 전멸 |

### 모든 유형에 공통되는 것

성장물 = 공법/법보가 지식/과학기술을 대체 = 핸드(카드)
전투 특징 = 대사 대체, 등단 = 회의 대체. 성장물이든 비성장물이든 플롯 설계 원리는 같다.

## 세 권의 책을 합쳐 새 이야기 만들기

### 작업 단계

**작업**: 아래 순서를 엄격히 따르세요.

1. 같은 플랫폼·같은 소재·같은 유형이고 최근 데이터/댓글로 검증 가능한 대조 도서 3권 선정
2. 각 도서에서 300~500자 내외의 이야기 시놉, 핵심 떡밥, 매력 구조, 독자 댓글 키워드 추출
3. 3중 분해: (1) 이야기 시놉 추출 — 핵심 떡밥과 매력 구조 (2) 서술 기법 분석 — 리듬 배치와 감정 유발 메커니즘 (3) 독자 흡인력 귀속 — 댓글 속 고빈도 긍정 키워드 분석
4. 융합 시 기능 단위만 재사용: 핵심 떡밥·리듬·감정 유발·인물 관계는 쓰되 구체적 장면은 재사용 금지
5. 새 이야기의 핵심을 도출한 뒤 우선 200자 요약으로 검증, 통과하면 대강으로 진입

### 검증 방법

**작업**: 먼저 쓰려는 내용을 200자로 요약해 핵심 항목을 점검: 핵심 갈등 명확성·감정 훅·금손 노출이 충분한지. 세 항목 중 최소 두 항목 충족 시 합격, 아니면 이야기 핵심이 불분명함.
