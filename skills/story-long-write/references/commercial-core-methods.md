# 상업 창작 핵심 방법

> 매력 설계, 감정 조율, 리듬 통제, 금손가락 원리, 기대감 관리, 전 과정 창작 방법을 다룬다. 개요 설계·소재 선정·상업화 전략을 세울 때 참고한다.

---

## 의사결정 라우팅

| 작업 내용 | 참고할 모듈 |
|-----------|-------------|
| 소재·매력 확정 | 매력론과 실전법 -> 감정 결핍 분석과 사용자 페르소나법 |
| 금손가락 설계 | 금손가락의 핵심 원리와 시스템물의 변화 |
| 리듬 통제·붕괴 방지 | 창작 리듬법 -> 세 가지 기대감과 붕괴 원인 분석 |
| 도입부 설계 | 소재 선정부터 독자 유지까지의 창작 흐름 -> 도입부 설계 |
| 독자 요구 분석 | 감정 결핍 분석과 사용자 페르소나법 -> 핵심 매력 이탈 진단과 수정 |
| 개요 구조 기획 | 창작 사고 범용법 -> 소재 선정부터 독자 유지까지의 창작 흐름 |
| 독자 유지·추독 설계 | 핵심 매력 이탈 진단 -> 세 가지 기대감과 붕괴 원인 분석 |
| 상업적 감정 전달 점검 | 감정 조율과 상업화 실행 규칙 |
| 창작 품질 점검 | 품질 체크리스트(문서 하단) |

## 지시 어조

이 파일은 ‘창작 전략’의 어조로 작성한다. 모든 공식과 원칙은 소재·매력·리듬·감정·도입부에 적용할 수 있는 실행 제약으로 바꾼다. 충돌이 발생하면 현재 표본·사용자 요구 > 독자 감정 > 개인 표현의 순서로 우선한다.

---

## 균준 집필 지침 핵심 요점

- 금손가락이 작품의 기조를 결정하며, 추독 붕괴는 높은 확률로 핵심 소재에서 이탈했다는 뜻이다.
- 승급은 너무 빠르면 기대를 잃고, 너무 느리면 인내심을 잃는다.
- 승급 뒤에는 새 능력의 위력을 보여 주어 사이다를 방출하는 동시에 더 큰 위기를 도입해 기대를 다시 세운다.
- 주인공의 행동은 플롯을 밀어야 하며 목적 없이 배회해서는 안 된다.
- 기본 3막 구조: 구축 -> 대항 -> 해결.
- 각 막 사이에는 ‘간극’이 있어야 한다. 주인공의 계획과 실제 결과의 차이 -> 뜻밖의 일 -> 긴장 -> 추독으로 이어진다.

---

## 전통형·발상형 작품의 독자 유지 기법

### 독자 유지의 네 기둥
- **승급**: 실력·지위·돈·자원.
- **자원 곤경**: 수련에 자원이 필요함 -> 기대감을 유도.
- **목표 설정**: 큰 목표 + 작은 목표 + 가짜 목표(목표가 실패해도 합리적이고 오히려 신선해야 함).
- **해독**: 빙산의 일각 -> 단계별 해독 -> 안개를 걷어 냄.

### 지도 전환 프레임 설계(목적 + 절정)
새로운 장소에 도착할 때마다 두 가지를 정한다.
1. 새 장소에 온 목적 -> 무엇을 얻거나 어떤 진실을 밝혀야 하는가.
2. 큰 절정으로 마무리 -> 독자가 여운을 느끼며 다음을 기다리게 한다.

### 평이한 플롯을 빠르게 전환하기
- 격렬한 목표를 설정하고 큰 절정으로 전환한다.
- 곧바로 강한 충돌을 배치해 플롯을 먼저 흥미롭게 만든다.
- 같은 장르의 고속 전개 작품이 사용하는 도입 구조를 참고해 현재 단락의 목표·충돌 밀도를 500자마다 최소 한 번의 전환점이 있도록 높인다.

---

## 집필의 세 요소: 소재 활용·리듬·감정

**소재 활용**: 현재 표본이나 비교 작품에서 검증된 구조적 기능을 우선 재사용한다. 소재가 여전히 유효한지는 목표 플랫폼 표본으로 검증해야 한다.

**리듬**: 쓸모없는 대화·멋있다고 착각한 세부·긴 포석을 덧붙이는 것이 흔한 문제다. 해결법은 덜어 내는 것. 한 문장으로 말할 수 있으면 두 문장을 쓰지 않는다.

**감정**: 사이다물의 핵심은 결국 ‘사이다’이며, 감정의 형성은 오르내림과 강하게 연결된다.

---

## 집필의 핵심 소재와 구조 사고

- 핵심 소재 = 핵심 매력을 바탕으로 여러 변주를 거듭하며 순환하는 고정된 플롯 발전 방식이다.
- 대부분의 순위권 작품은 저마다 핵심 소재를 갖고 있다.
- ‘x급 구조’ 대신 ‘세분화’를 사용한다: 한 문장 주선 -> 권 개요 -> 장 개요 -> 본문.
- 반복 가능한 패턴을 우선 선택해 주선을 응축하고, 몇 가지 지선을 열어 호흡을 늦춘다.

---

## 집필의 감정 처리와 인지 기법

### 선입견과 피크-엔드 법칙
- 인식을 형성할 때 먼저 제시한 정보의 영향력이 더 크다.
- 부정을 앞당긴다: 부정적 요소를 앞에 배치하면 부정의 감각이 강해진다.
- 제목·소개·브랜드 평판 = 독자의 첫인상이며 매우 중요하다.

### 감정 강화 기법
- 지식은 예시를 통해 전달하는 것이 가장 좋다.
- 기법을 쓰기 전에 왜 필요한지 생각하고, 사용을 위한 사용은 피한다.

---

## 집필 기법의 분류와 흔한 오용

### 두 가지 유형
1. 독자를 처음 끌어오는 요소: 제목·소개·도입·사이다·미끼·폭발적 소재.
2. 독자가 계속 읽게 하는 요소: 세계관·인물·승급감·리듬감·기대감·몰입감.

### 흔한 오용
- ‘지속적인 기대감을 가르치는’ 기법으로 도입부를 쓰는 것. 목표가 다르다.
- 사이트별 적용성을 구분하지 않는 것. 플랫폼마다 기법을 변주해 적용해야 한다.

### 写作三要素
소재 선정(목표 독자와 장르 경계) + 플롯 설계(전체·권·장 개요) + 문체(집필 결과물)의 세 요소는 모두 artifact에 구현되어야 한다.

## 창작에서의 클리셰 전복과 반복 인식

### 볼거리와 소재는 다르다
- 어떤 핵심 매력 소재는 한 번만 끌어당기는 힘이 있으므로 도입 소재로만 써야 한다.
- 하나의 매력이 수백만 자를 완벽하게 지탱하는 경우는 드물다. 플롯·세계관·인물이 함께 버텨야 한다.

### 반복 지점의 데이터 기반 판정
- 반복에는 인물 반복점·클리셰 반복점·플롯 반복점이 있으며, 가치의 밀도는 순서대로 높아진다.
- 핵심 볼거리를 잡지 못함 -> 지표 하락 -> 볼거리 교체 -> 성과도 하락한다면, 독자가 원한 것은 바로 그 반복점이라는 뜻이다.
- 핵심 볼거리가 현재 표본·독자 피드백에서 안정적이면 반복 전략을 유지한다. 피드백이 떨어지면 반복 방식을 승급해야 하는지 분석한다.

## 창작 리듬법

### 일상물 실행 규칙
일상은 평이함과 다르다. 수라장은 일상 안에 있어도 충돌로 가득하다. 핵심은 갈등을 설정하고 소재를 영리하게 활용하는 데 있다.

### 리듬 자가 점검법
각 장을 쓰기 전에 상태 요약 `追踪/上下文.md`을 읽고, 그 안의 `## 近三章速记`로 현재 리듬을 판단한다.
- 늘어짐 신호: 연속 2장에 목표 추진·장애물 상승·새 정보가 없다 -> 다음 장에서 충돌 밀도를 높인다.
- 과속 신호: 연속 2장이 폭발점만 있고 반응의 여파가 없다 -> 1~2개의 연결 장면을 넣되 관계·복선을 반드시 추진한다.

### 절정 리듬 기준
- 대절정: 7~10일 안에 끝낸다. 10일을 넘으면 추가 독서가 떨어진다.
- 소절정: 약 3일 안에 끝낸다.
- 절정 뒤 -> 1~2장의 일상 전환을 넣는다.

### 중후반 추가 구독 하락의 두 원인
1. 사이다 포인트의 반복 -> 독자의 심미 피로.
2. 장기 기대감의 부재.
- 해결: 개요 단계에서 먼저 결말을 정하고, 결말을 중심으로 중후반 폭발점을 설계한다.

### 복선 vs 수수께끼 인물
- 수수께끼 인물: 이유를 일부러 말하지 않고 비밀이 있음을 암시해 호기심을 자극한다.
- 복선: 플롯에 영리하게 녹여 이후 공개로 놀라움을 만든다.

## 核心卖点偏移诊断与修正

### 卖点偏移
- 卖点偏移 = 核心吸引元素被稀释或替换
- 常见：爽文写着写着变成种田文 -> 核心读者流失
- 自检：每隔十章问"当初吸引读者的卖点还在吗？"
- 根源：核心卖点被写作过程替换，但读者期待没有同步改变

### 读者需求与网文类型对应

| 需求层次 | 网文类型 |
|----------|----------|
| 生理需求 | 肉文/后宫文 |
| 安全需求 | 无敌流/系统流 |
| 社交需求 | 后宫/团队文 |
| 尊重需求 | 爽文/打脸文 |
| 自我实现 | 升级流/探索流 |

跨层满足 = 爆款潜力。创作前明确满足哪层需求，所有设计围绕展开。

### 金手指+矛盾=剧情
- 金手指太强 + 矛盾不够 = 无聊
- 金手指太弱 + 矛盾太强 = 读者焦虑
- 最佳：金手指刚好解决当前矛盾 -> 暴露更大矛盾 -> 层层递进

### 主题统一性
- 一本书从头到尾要有统一的核心情绪
- 小情绪服从大情绪
- 检验：随机翻开一章 -> 情绪是否指向全书核心

## 可读性提升的矛盾性技巧

### 矛盾三层次
- 一般故事 -> 矛盾停留在角色之间
- 好故事 -> 矛盾放置在大背景中
- 巧妙故事 -> 矛盾放在作品与读者之间 -> 观念错位

### 观念错位
- 让主角的常识跟世界常识对着干 -> 读者边看边想"这也行？"
- 例：穿越古代主角当众算账揭穿伪善 -> 读者认同主角的现代价值观、配角震惊 -> 把主角"异类反应"和配角"正常反应"并置成反差
- 两种模式：
  - 同认知背景+不同认知主角：主角特立独行吸引眼球
  - 同认知主角+不同认知背景：穿越/末世/中世纪 -> 读者参照主角视角对抗世界

## 向精品冲击的攻略

### 黄金三章
前三章必须承担定调与留存功能。若项目已有强势作者品牌/IP 基础或用户另有要求，可降低套路化程度；否则按“核心冲突、金手指/优势、长期期待”三项检查。刻意套模板破坏既定基调时，以当前作品基调为准。

### 留住读者的核心：不间断的期待
- 即将得到但还没得到 -> 期待感最高
- 得到之前套上另一个钩子 -> 循环
- 一本书随时保持两条以上期待线 -> 大期待 + 小支线穿插

## 商业网文六大核心模块

### 一、定调——黄金三章的核心是回应期待
- 公式：令人不安的处境 + 亟待提升的地位 + 充满希望的外挂 + 能被展望的美好未来
- 定调三层次：情绪氛围 -> 故事走向 -> 价值观倾向

### 二、金手指——简单是核心
- 内核归类：信息挂（最优，不易失控）、加速升级挂、物体调用挂
- 最核心要素：简单。游戏化面板一眼就懂最好

### 三、角色——脸谱化不是坏事
- 为所有角色打下标签，越重要标签越多，行为基于标签
- 构建角色充满算计——送资源/被打脸/当小弟/当向导，分工明确

### 四、节奏——循环嵌套
- 本质循环：确立目标 -> 做出行动 -> 完成目标 -> 获得提升 -> 确立新目标
- 对抗审美疲劳：从数值对抗转为机制对抗

### 五、爽点——先不爽再拿掉不爽
> 相关：爽点的本质/六种类型/倒推设计法以 [plot-emotion-system.md](plot-emotion-system.md)「爽点设计体系」为准；本文只覆盖商业留存视角的爽点处理。
- 公式：生产诉求 -> 给予希望 -> 努力解决 -> 得偿所愿
- 无敌文本质是"人前显圣"

### 六、冲突与悬念
- 冲突简单直接可套路化；悬念需精巧构思
- 悬念信息释放梯度：每章末尾营造"即将达成"的临界状态

### 题材微创新三套路
- 热门设定+套路化流派写法
- 热门分类体系+热门噱头
- 成熟世界观的不同视角

## 감정 결핍 분석과 사용자 페르소나법

- 흥행작의 감정은 한 줄기로 일관되지만, 비흥행작의 감정은 여러 갈래로 흩어진다.
- 승급·복수·보물 찾기 같은 작은 감정은 주감정 아래에 통합한다.
- **사용자 페르소나법**: 흥행 웹소설에서 플롯 요소를 추출 -> 독자 페르소나를 설정 -> 심리적 요구를 추정 -> 현재 설계와 대조 분석.
- 깊이 파고들 때는 독자의 요구뿐 아니라 독자 자신도 모르는 심리적 매듭까지 찾아야 한다.
- 독자 댓글에서 빈도가 높은 감정 키워드(사랑·증오·갈망·회피)를 추출하고 현재 설계의 감정 매력과 하나씩 대조해 충족되지 않은 요구를 식별한다.

### 분석 사례

**종말 회귀물**:
- 종말 = 사회 질서의 전복 -> 높은 자리에 있던 사람이 추락하고 밑바닥의 평범한 사람이 올라서기를 바람.
- 물자 비축 = 거대한 불안감 -> 수백억 규모의 물자를 손에 넣음 -> 안전감이 폭발함.
- 회귀 = 허점을 주워 이득을 얻음 -> 작은 투입으로 큰 수확.

**신매체 전쟁신 데릴사위물**:
- 핵심 고통: 무능 -> 부모를 부양하고 아이를 돌볼 수 없음.
- 두 번째 층위: 가족의 부정 -> 온갖 노력을 해도 인정받지 못함.
- 세 번째 층위: 열등감 -> 자신의 무능을 마주하지 못함.
- 전쟁신의 귀환 -> 모든 것이 뒤집힘 -> 폭발적인 사이다.

## 감정 조율과 상업화 실행 규칙

### 올바른 모방 방향
- 모방해야 할 것: 이야기 패턴·극적 기법·서사 구조·인물 유형.
- 모방하지 말아야 할 것: 문장 표현·고전 장면·언어 스타일.

### 상업화의 본질
- 웹소설은 본질적으로 상품이며, 상업화란 목표 독자의 읽기 기대를 존중하는 것이다.
- 웹소설의 본질은 독자의 감정을 지속적으로 조율하는 데 있다 -> 매 장 명확한 감정 전달이 필요하다.

### 감정 조율에 대한 핵심 인식
- 성공작은 여러 요인이 함께 작용해야 하며 단일 기법만으로 만들어지지 않는다.
- 독자의 기대감은 대부분 표면적인 문장보다 오랜 시간 인물에게 감정적으로 투자한 데서 나온다.

## 패턴의 다면적 활용

- 하나의 패턴과 사이다 포인트도 최소 다섯·여섯 가지 방식으로 쓸 수 있다 -> 정방향 전개·반클리셰·재반전·연속 반전·반전 뒤 정방향.
- ‘잘난 척하는 상대를 망신 주기’의 다섯 가지 예:
  - 정방향 = 상대가 막 조롱을 끝내자 주인공이 현장에서 신분을 드러내 망신을 줌.
  - 반전 = 주인공이 일부러 약한 척해 상대가 더 날뛰게 한 뒤 뒤집음.
  - 재반전 = 상대는 주인공이 약한 척한다고 생각했지만, 주인공은 실제로 강했고 연기한 것이 아니었음.
  - 연속 반전 = 상대가 연달아 오판하고, 매번 주인공을 간파했다고 생각할 때마다 되받아침.
  - 반전 뒤 정방향 = 한 바퀴 돌아 여러 변주를 거친 뒤 결국 압도적인 실력으로 제압.
- 고급 활용: 패턴의 기본 논리를 유지한 채 외피·장면·인물을 바꾼다 -> 겉보기에는 달라도 핵심은 같은 구조가 된다.

## 장 개요 세분화 단계 선택

| 작품 복잡도 | 장 개요 세밀도 | 사용 조건 |
|------|------|------|
| 고복잡도 | 2차 구조·기승전결을 항목별로 추론 | 다중 플롯, 강한 반전, 복잡한 세계관 |
| 표준 장편 | 장마다 300~400자 장 개요 | 첫 권, 핵심 권, 절정 권 |
| 저복잡도·연속 집필 | 열몇 자의 목적문 + 핵심 감정·훅 | 권 개요와 추적 파일이 이미 뒷받침됨 |

선택 규칙: 맥락이 적고 반전이 강하며 인물선이 많을수록 장 개요를 세밀하게 쓴다. 안정된 구조와 추적 파일이 있으면 간략화할 수 있다.

## 卖点论与实操法

### 卖点四步法
1. **思考**：想清楚整本书卖点、书名卖点、简介卖点、每段剧情卖点
2. **设计**：围绕卖点做扩散设计
3. **细化**：卖点面对什么读者群？什么风格合适？
4. **表现**：每章一个目的词，盯紧章纲和目的来写

### 卖点的表达技巧
- 让读者在阅读中自己发现 -> 发现比告知爽十倍
- 隐性展示：通过剧情/对话/反应来展示
- 三层递进：开头暗示 -> 中间深化 -> 高潮爆发

### 书名简介卖点
- 书名=第一道门，简介=第二道门，开篇=第三道门，层层传递并兑现核心卖点
- 不要使用无法传递核心卖点的文青书名

### 章纲目的法
- 每章一句话概括内容 + 标注"目的"词（铺垫/高潮/爽点/打脸/人物塑造/设定）
- 盯紧章纲和目的来写 -> 不容易跑偏

## 金手指的核心原理与系统流演变

故事流程：激励事件 -> 产生欲望 -> 建立目标 -> 开始行动 -> 遭遇阻碍 -> 克服困难 -> 收获奖励

**金手指可替换流程中的任一环节**：
- 替换"建立目标"：系统发任务
- 替换"克服困难"：按一下解决问题但要承受代价
- 替换"准备环节"：跳过准备直接快进到遭遇阻碍
- 替换"激励事件"：穿越到千年后
- 替换"收获奖励"：系统使主角做公益获利

**金手指为什么包装成系统**：系统的限制保证故事结构完整 -> 有限制的系统 = 主角必须一步步行动。

## 需求驱动与节奏的本质

### 消遣之物的本质逻辑
为读者创造某种需求，然后满足。
- 公式：生产诉求 -> 给予希望 -> 努力解决 -> 得偿所愿
- "不该如此"是根本冲动 -> 读者看到不公/遗憾 -> 天生想看改变
- 好题材具备勾起惋惜/渴望改变的特质

### 题材的核心不在表面设定
- 只写设定有趣的作品往往成绩差 -> 抓住核心矛盾的作品才好

### 节奏的本质
- 不断解决现有矛盾 -> 不断制造新的矛盾
- 好节奏：困境层级层层提高 + 难度逐步提升 + 困境种类不尽相同

## 创作理念：地图切换与节奏

### 换地图时的读者过渡设计
都市到仙界订阅直线下降。解决：建立缓冲区 -> 将读者慢慢引导到新题材。

### 大纲哲学
- 只列主线 -> 分支在写作中慢慢完善
- 大纲必须可修改 -> 太严谨缺少灵性

### 节奏与情绪
- 节奏 = 让读者有愉悦的阅读感觉 -> 打脸不在多而在经典
- 爽文不等于打脸 -> 爽文意义是读得轻松+有期待感

## 三种期待感与崩盘原因分析

### 三种期待感
1. **剧情期待**：大目标 + 过程中挖的坑 + 立起来的妹子 -> 吊胃口
2. **主题**：每章给读者甜头的东西 -> 主题不偏，大多数章节读者想看
3. **新鲜感**：世界观矛盾的新鲜 + 剧情形式的多样

| 类型 | 定位 | 节奏 |
|------|------|------|
| 剧情期待 | 吊胃口 | 偶尔满足 |
| 主题 | 每天的甜头 | 持续满足 |
| 新鲜感 | 放下还愿意捡起来 | 间歇刺激 |

三者合一 = 不崩之书。

### 崩盘根因：偏离卖点
- 套路循环类：同一卖点重复角度不足 -> 读者审美疲劳
- 技术到位但仍然崩 -> 优先检查核心卖点是否仍在、期待线是否仍有兑现空间

### 拉长板vs补短板
- 优先强化题材长板：核心卖点、目标情绪、最高频爽点。
- 不为补短板引入会稀释核心卖点的支线。
- 开书前检查：(1)核心卖点背后的情绪清晰 (2)同一卖点能延展出至少 3 个角度 (3)题材长板与现有素材/对标资产匹配。

## 创作思路普适法

### 创作思路三步法
确定主角身份 -> 匹配金手指类型 -> 设定开局环境

### 开篇压力的两种类型
- 冲突型压力：指向性明确，节奏快但后期容易崩
- 环境型压力：生活上的小压力，更容易写长
- 推荐：优先用环境型压力开局

### 金手指反馈法
- 给出金手指后必须有即时变化
- 把金手指带来变化的过程掺杂在故事里
- 金手指契合主角当前职业，或作为打开困境的钥匙

### 不同题材不同写法
- 东方玄幻：快节奏，第一章只出现主角一人，迅速切入
- 西幻低位背景：慢节奏，多人物对话营造氛围，逐步带出世界设定
- 不能公式化，要根据题材和金手指调整

## 梗收集与阶级跃迁爽点

### 梗收集方式
- 从目标平台的近期评论、弹幕高频词中提取可用梗元素，建立梗-场景映射表
- 梗是创作灵感源泉，不是简单堆积
- 经典梗读者仍会期待 -> 巧妙运用满足期待

### 阶级跃迁爽点
- 描写赚第一桶金实现阶级跃迁 -> 爽感最强
- 从贫穷到有点小钱更容易引起大众读者共鸣

### 过渡避免流水账
- 每个副本结束必须留一条矛盾线 -> 串联到下一个副本

### 设置钩子拉期待
- 提前透露人物特殊技能/背景 -> 读者期待后续运用
- 设置阶段性钩子 -> 高潮时完整呈现

## 从选材到留存的创作流程

### 题材定位与读者筛选
- 题材关键词能否作为目标读者筛选信号 -> 快速触发读者自动解压信息
- 微创新 = 在经典题材上套皮新噱头
- 题材组合公式：新东西+旧东西+热门载体 = 新题材
- 代偿 = 给主角现实里缺的东西（赘婿其实是隐藏战神，弥补"被人看不起"）
- 捷径 = 金手指让主角跳过苦熬（签到系统/一夜暴富），开局就给"不用努力也能赢"的解压感

### 吸量要素
- 书名构建：冲突报复+人无我有+槽点句子
- 简介最高标准：有趣+有槽点+悬念
- 简介不能依赖作者品牌，必须直接交付卖点

### 留存=情绪+饥饿
- 情绪：快速代入 -> 快速沉浸 -> 与角色共鸣
- 饥饿：利用信息差在读者视角植入问号
- 剥洋葱技法：简介植入核心悬念 -> 章节开头植入小问号 -> 章节末尾卡住关键信息

### 开篇设计
- 开篇两万字只需解决一件事：活下去
- 轻松向开篇：主角一无所有 + 金手指一眼就知道怎么用
- 300-500字内交代：处境+危险来源+破局希望
- 开篇主角的所有都不能是完美的 -> 否极泰来的开端

### 大纲与细纲
- 随笔 = 表达库；大纲 = 核心骨架+人物+背景
- 细纲 = 舞台上人与人发生的故事
- 장별 개요 = 세부 개요의 가독성과 리듬을 조정
- 核心梗 = 一套固定的剧情发展模式 -> 不断换花样循环

## 卖点原理补充：核心情绪的艺术化

卖点不能按"卖的人多"粗暴判定。核心情绪是凡人都会遇见、感同身受的东西。

소설의 본질은 누구나 품고 있는 평범한 감정 하나를 뽑아내 예술적으로, 추상적으로, 극단적으로 변주하는 데 있다.

| 处理方式 | 操作 | 例子 |
|----------|------|------|
| 极端化 | 把日常委屈推到生死/巨额对赌 | 赘婿被瞧不起 -> 战神归来当众甩出百亿 |
| 艺术化 | 别写"他很委屈"，用动作演 | 他默默把工资卡推过去，转身就走 |
| 抽象化 | 只抓一种情感贯穿全书，砍掉旁枝情绪线 | 全书只咬住"不被认可"，亲情爱情都为它服务 |

## 质量检查清单

完成大纲/选题/卖点设计后，逐项检查：

- [ ] **核心卖点明确**：一句话能说清这本书卖什么情绪
- [ ] **卖点无偏移**：每十章自检"当初吸引读者的卖点还在吗？"
- [ ] **金手指简单**：读者一眼就懂怎么用，功能与升级规则清晰
- [ ] **金手指+矛盾匹配**：金手指刚好解决当前矛盾，暴露更大矛盾
- [ ] **三种期待线并存**：剧情期待 + 主题甜头 + 新鲜感
- [ ] **节奏有标尺**：大高潮7-10天，小高潮3天，高潮后1-2章过渡
- [ ] **升级节奏合理**：不太快（失去期待）也不太慢（失去耐心）
- [ ] **主题统一**：随机翻开一章，情绪指向全书核心
- [ ] **书名简介开篇三道门**：层层过滤，不使用无法传递核心卖点的文青书名
- [ ] **章纲有目的词**：每章标注铺垫/高潮/爽点/打脸/人物塑造/设定
- [ ] **留存双引擎**：情绪（快速代入）+ 饥饿（信息差植入问号）
- [ ] **拉长板而非补短板**：题材长板与能力长板吻合
