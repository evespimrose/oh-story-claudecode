# 개요 핵심 방법

Phase 3에서 개요 구축 시 로드한다. 개요 작성법, 구조 계층화, 노드 설계, 세부 개요 실전법을 포함한다.

## 결정 라우팅:지금 어떤 방법을 써야 하나

| 당신이 개요의 어느 단계에 있는가 | 사용할 방법 |
|--------------------|------------|
| 막 개요을 세우기 시작했을 때 | 5단계 개요 작성법 |
| 이미 프레임이 있고 세부화할 때 | 노드 설계법 + 3층 구조법 |
| 단권 구조 설계 시 | 8노드 스토리 구조 |
| 세부 개요/장별 개요 작성 시 | 세부 개요 및 장 개요 절 |
| 글이 막혔거나 역추적이 필요할 때 | 추론 및 역추적 방법 |

## 이야기 구조 계층화

| 레벨 | 특징 | 적용 범위 |
|------|------|----------|
| 1급 | 에피소드들이 느슨하게 연결되어 시간으로 이어지며, 마지막에 대형 클라이맥스 | 입문용 |
| 1.5급 | 에피소드 사이에 논리적 단서가 있어 핵심 목표로 향함 | 중급 |
| 2급 | 소클라이맥스 → 의외의 하강 → 반등 전환 → 대클라이맥스 체인 | 고급 |

## 5단계 개요 작성법

### 1단계:클라이맥스 플롯 확정

클라이맥스는 절대 우선순위를 가진다: 최대 규모의 충돌, 가장 많은 등장인물, 가장 강렬한 감정 기복.

체크리스트:
- [ ] 이 장(권)이 최대 충돌을 담고 있는가?
- [ ] 등장인물이 가장 많은가?
- [ ] 단계 목표와 고도로 일치하는가?
- [ ] 독자의 감정 기복이 가장 큰가?

### 2단계:단위극(에피소드) 확정

각 단위극 = 주인공이 금손(특수능력)을 이용해 쾌감 포인트를 얻는 장면. 같은 유형의 반복 = 플롯 루틴. 논리적으로 엮여 그룹을 이루면 = 루틴 체인.

운영 요구사항:
- 각 단위극은 금손의 서로 다른 활용을 보여줘야 한다
- 인접한 단위극은 동일한 금손 로직을 사용해선 안 된다
- 단위극들 사이에는 인과관계를 세워야 한다

### 3단계:스토리 라인 구성 및 정보 포석

동시에 8개의 스토리 라인을 관리하고, 각 라인에 포석(예비 배치) 시점을 반드시 표기한다:

| 스토리 라인 | 내용 | 어떤 것을 포석하는가 |
|--------|------|--------------------|
| 지도선 | 계층적 장소(지역) | 새로운 지도 해금 시점 |
| 진영선 | 세력과 지도의 매칭 | 진영 충돌 폭발 지점 |
| 인물선 | 인물을 유형별로 그룹화 | 새로운 인물 등장 시점 |
| 금손선 | 획득한 아이템/스킬 | 능력 업그레이드 노드 |
| 세계관선 | 세계 설정 규칙 | 설정 공개 시점 |
| 갈등선 | 갈등을 모순 네트워크에 투입 | 갈등 심화 체인 |
| 수집선 | 재료/단서 수집 | 점진적 수집 레벨 |
| 감정선 | 감정 관계 진전 | 친밀도 상승 노드 |

### 4단계:오프닝 무대 확정

다음 순서로 오프닝을 구성한다:

```
플롯 훅(Hook) → 빠르게 이상 상태로 진입 → 금손 획득/소개 → 갈등/욕망 등장, 주인공이 금손을 운용 → 목표 수립
```

오프닝에 반드시 심어야 할 기대감: 새로운 목표/갈등 업그레이드 방향, 전력 업그레이드 암시, 자원 업그레이드 암시, 감정선 업그레이드 암시, 인간관계 네트워크 확장 암시, 혼란도 상승 암시, 새로운 단서/새 설정 암시.

(참고: 오프닝은 in media res로 시작하고 Hook을 빠르게 걸 것)

### 5단계:마무리(엔딩) 확정

체크리스트:
- [ ] 주선 및 부선의 클라이맥스 해결, 후속 영향 보여주기
- [ ] 주인공이 충분한 보상 + 추가 보상(다음 단계용) 획득
- [ ] 본 권의 인물들에게 적절한 결말 제공
- [ ] 리듬을 느리게 해서 호흡을 줌
- [ ] 다음 권을 위한 포석 마련

## 플롯 품질 관리

### 플롯 유사도 검사

두 플롯이 과도하게 유사한지 비교한다. 검사 차원: 충돌/모순 유형, 금손 사용 방식, 플롯 체인 구간, 플롯 결말.

### 플롯 적합도 검사

| 차원 | 검사 항목 |
|------|----------|
| 단계 적합도 | 플롯/감정선 진행이 해당 권의 단계와 맞는가 |
| 장면 적합도 | 장면이 본 권의 장면 목록에 있는가 |
| 인물 적합도 | 등장 인물 조합, 관계, 행동이 일관되는가 |

### 제약 규칙(반드시 준수)

- 시공간 연관: 논리적 연관 >= 1:3 (각 1개의 인과 추진에 대해 최소 3개의 장면 추진)
- 후속 플롯의 감정값은 전구간보다 현저히 낮아져선 안 됨
- 동일한 금손 로직은 연속 사용 금지
- 동종 플롯 루틴 간격 >= 3개의 서로 다른 유형 플롯

## 노드 설계법

### 핵심 프레임(시작 → 종료 → 핵심 노드)

- 시작 상태: 주인공의 초기 상태(패배자/빈곤/약함)
- 최종 상태: 주인공의 최종 상태(무적/재벌/최강)
- 노드: 이야기가 최종 상태에서 벗어나지 않도록 보장하는 핵심 성장 포인트

### 설계 원칙

- 시작과 종말은 극적일수록 좋다
- 한정어: 하나는 상승, 하나는 하강(좋은 것은 더 좋게, 나쁜 것은 더 나쁘게)
- 장르 = 주인공이 시작에서 종말로 가는 수단
- 노드가 확정되면 개요은 이 노드들의 배열이다

### 노드 설계 실전 단계

1. 주인공의 시작 상태와 최종 상태 확정
2. 종말에 도달하기 위한 경로 분해(경지 상승선/실력 상승선/수집선 등)
3. 각 라인마다 하위 노드 설정
4. 노드 사이에 이야기를 채워 넣음

## 개요 체계

### 개요 3층 구조법

| 계층 | 내용 | 자유도 |
|------|------|--------|
| 개요 | 주체 발전 방향, 수백 자 분량 | 반드시 고수 |
| 플롯 개요 | 완전한 스토리 라인, 비교적 섬세함 | 적당한 변경 허용 |
| 세부 개요 | 창의적 폭발점, 대사, 작은 장면들 | 완전 자유 |

플롯이 개요에서 벗어날 때 반드시 복귀 가능해야 한다. 제약이 많을수록 오히려 더 좋은 이야기가 나올 수 있다.

### 세 가지 개요 작성법

| 방법 | 적용 장르/상황 | 핵심 작업 |
|------|----------------|----------|
| 맵식 | 판타지/무협 등 | 지도를 따라 집필 진도 교체, 전력 변동/조연/대사건/쾌감 포인트 표기 |
| 분권식 | 중급 | 주된 플롯 노드로 권을 나눔, 시작점+종결점+중요 노드 설정 |
| 채워넣기식 | 창작 초기 | 먼저 프레임을 세우고 내부를 채워 넣음 |

### 개요 설계 우선순위

1. 핵심 창의 포인트를 먼저 정하고 → 핵심 판매 요소 파고들기
2. 핵심 판매 요소에 따라 주선(메인 라인)을 정하고, 금손은 주선과 연계해 파생
3. 금손은 두 가지 기능을 반드시 가져야 함: 주인공에게 '오버파워' 제공 + 지속적으로 목표를 끌어내며 주선을 추진
4. 금손이 핵심 판매 요소에서 벗어나면 = 작품 전체가 흔들림, 반드시 수정해 중심으로 복귀

## 세부 개요과 장 개요

### 세부 개요

- 세부 개요 : 본문 = 1 : 2.5~1 : 3
- 구체적 플롯 전개는 펼치지 말고 목표와 효과만 집중
- 각 노드에 "상세 작성"인지 "약식"인지 표시
- 핵심 목적: 이후 글쓰기가 빠르게 전달해야 할 목적과 효과를 포착하게 함

### 장 개요

- 개요과 세부 개요만으로 충분하면 장 개요은 생략 가능
- 핵심 사건을 기준으로 거친 개요 작성(하나의 핵심 사건 당 약 3~5장)
- 훅, 복선, 집필 목적 표기

### 즉흥 집필 주의사항

- 연속 집필 중 세부 개요을 너무 촘촘히 쓰지 말고 조정 여지 남기기
- 개요은 동적이다; 핵심 소재를 중심으로 주요 노드만 유지
- 집필 후 점검: 현재 주인공의 행동이 목표와 관련 있는가? 새 장이 후속 기대를 만들었는가?

### 클라이맥스식 개요 작성법

- 매 10만 자마다 한 번의 대클라이맥스 설계
- 대클라이맥스는 사전에 확정(200~300자로 정리), 그 전 5~6만 자는 소플롯으로 채움
- 소플롯은 반드시 감정선을 진전시키거나 대클라이맥스와 관련돼야 함
- 권장 분량 한계 약 40~50만 자

## 8노드 스토리 구조

장편 웹소설에서 통용되는 구조로, 각 권/대아크에도 적용 가능. 각 노드는 여러 장에 걸칠 수 있다.

### 노드 속성 빠른 확인표

| 노드 | 핵심 임무 | 비중 | 장 수 | 리듬 |
|------|---------|------:|------:|------|
| 1. 오프닝 | 독자 사로잡기, 기대 형성 | 5–10% | 1–2장 | 빠름 |
| 2. 전개 | 연속 사건으로 플롯 추진, 복선 깔기 | 30–40% | 5–15장 | 중간 |
| 3. 1차 전환 | 예측을 깨고 긴장 상승 | 5–10% | 1–3장 | 빠름 |
| 4. 2차 전환 | 판을 키워 더 깊은 곤경으로 | 5–10% | 1–2장 | 빠름 |
| 5. 클라이맥스 | 핵심 충돌의 정면 대결 | 10–15% | 2–4장 | 극속 |
| 6. 갈등 결과 | 갈등 해결, 독자에게 숨 돌릴 시간 | 10–15% | 2–3장 | 느림 |
| 7. 3차 전환 | 최종 반전, 마지막 한 방 투척 | 5–10% | 1–2장 | 빠름 |
| 8. 결말 | 감정 수습, 여운 남기기 | 10–15% | 2–5장 | 느림 |

### 각 노드의 핵심 규칙

**오프닝**:반드시 in media res로 시작하고, 앞 500자 내에 훅(Hook)이 있어야 한다. 배경 설명/날씨/풍경으로 시작하는 것을 금지.

**전개**:3–5개의 연속 사건이 각기 주선을 밀어붙인다. 매 3000–5000자마다 하나의 쾌감 포인트. 최소 2개의 복선 심기.

**1차 전환**:예상을 깨는 정보/사건으로 판도를 바꿈. 세 가지 요소: 의외성 + 합리성 + 추진력.

**2차 전환**:1차 전환보다 더 높은 판돈으로 업그레이드. 유형은 1차 전환과 달라야 함.

**클라이맥스**:빠른 리듬, 불필요한 물러섬 없음. 주인공은 반드시 성장한 모습을 보여줘야 함.

**갈등 결과**:주요 갈등을 해결하고, 전리품(전리품은 단순 목록이 아니라 플롯을 통해 드러냄)을 보여주며 다음 아크를 위한 훅을 심는다.

**3차 전환**:독자의 '결말' 예상치를 뒤집는다. 반드시 초기 포석(복선)이 있어야 한다.

**결말**:핵심 미스터리를 정리하고 감정을 수렴한다. 모든 복선을 다 회수할 필요는 없으며, 남김이 여운을 준다.

### 쾌감 포인트 리듬 공식

- 각 장마다 최소 1개의 마이크로 쾌감 포인트(장 구성별: 고압/진행 장은 반드시; 저압/관계/수련/정보 정리 장은 강요하지 않지만, 각 장은 독자가 다음을 읽게 할 이유 — 마이크로 호기심/단계적 목표/묘한 기대 — 를 제공해야 함)
- 3장마다 1개의 충돌 해결
- 7장마다 1개의 대형 쾌감 포인트

### 5대 구동 체크(3–5장마다 점검)

1. 압력 원천: 주인공이 직면한 구체적 위협은 무엇인가?
2. 실력 시연: 어떤 능력으로 해결하는가? 방식에 새로움이 있는가?
3. 인식 전복: 어떤 인식이 뒤집혔나? 반전은 합리적인가?
4. 자원 증식: 무엇을 얻었나?
5. 서스펜스 증식: 해결 후 어떤 새로운 의문이 생기는가?

## 사이다물 5단계 작은 순환

| 단계 | 정의 | 핵심 포인트 |
|------|------|-------------|
| 안정상태/위기 잠복 | 주인공은 비교적 안정하나 잠재 위기 존재 | 반드시 좋은 상태는 아님 |
| 위기 유발 | 외부가 위기를 만들어냄 | 시선을 끌어야 함 |
| 돌파 행동 | 금손을 이용해 음모를 좌절 | 쾌감 포인트 폭발, 기대감 대량 축적 가능 |
| 수익 정산 | 가치 있는 보상이 명확해짐 | 자원/권력/명성/인맥/능력 |
| 새 균형 및 포석 | 더 높은 안정에 도달하고 새로운 도전 등장 | 다음 순환과 연결 |

## 감정 끌어당김 5단 곡선 구조

| 단락 | 방향 | 내용 |
|------|------|------|
| 1단락 | 상승 | 포석 / 주인공이 유리한 조건을 얻음 |
| 2단락 | 전환 + 하강 | 불리한 전환(주인공의 실수여서는 안 됨) |
| 3단락 | 상승 | 주인공이 행동/전환기 등장 |
| 4단락 | 전환 + 하강 | '속임수 한 번' — 잠시 풀어놓았다가 의외 발생 |
| 5단락 | 쾌감 폭발 | 금손이 발휘되어 목표 달성 |

10만 자 규모는 이 5단 곡선으로 계획하고, 각 단을 다시 중첩할 수 있다. 글이 막힐 때 구조로 방향을 밀어붙여라.

### 플롯 하강 원칙(반드시 준수)

- "공은 모두 주인공 몫, 책임은 전부 타인에게"
- 감정 하강의 원인은 절대 주인공의 실수여서는 안 된다
- 주인공을 괴롭힐 때 1의 억울함을 주면 복수는 10배로 돌려줘라
- 하강 후에는 의외의 행운, 귀인(도움), 좋은 보상으로 감정 결손을 메워라

## 추론·역추적 방법

### 추론식 개요 설계

핵심 설정에서 출발해 단계별로 추론: 주인공의 시작 상태 → 가정 환경 → 금손의 합리성 → 충돌의 근원. 각 단계의 추론에서 새로운 플롯 포인트가 발견될 수 있다.

### 역추적법으로 장 개요 설계

설계 순서: 쾌감 포인트 → 기대 포인트 → 포석. 어떤 방식으로 독자를 만족시킬지 명확히 한 뒤, 그를 위해 어떻게 포석할지를 역으로 설계한다.

여섯 가지 쾌감 포인트 유형: 능력 압도, 목표 달성, 수확 정산, 태도 변화, 정체/가면 벗음(베일 벗김), 감정적 완결.

### 진상(진실) 역추적법

1. 핵심 진상을 확정
2. 진상을 조각내어 여러 장에 분산해 포석
3. 각 조각이 밝혀질 때마다 캐릭터 행동이나 전환을 유발
4. 고급 변형: 서술적 트릭 — 정보를 이용해 독자를 오도

적용: 서스펜스 라인, 정체성 라인, 환생 등 전생 라인, 복선이 빽빽한 이야기.

### 역추적 앵커법

작품을 [세계관]과 [플롯] 두 부분으로 나눈다. 먼저 시작과 결말 앵커를 정하고, 앵커를 중심으로 질문을 던진다. 각 질문은 한 개의 라인을 파생시킨다.

권 단위 역추적: 클라이맥스 포인트를 먼저 생각 → 클라이맥스를 앵커로 역추적 → 질문 제기 → 역추적으로 포석과 주선을 도출 → 세부 개요 완성

## 장 제목 전략

1. "시작", "각성", "업그레이드"처럼 빈약한 요약형은 금지
2. 가장 임팩트 있는 문장 한 줄이나 가장 충돌적인 정보를 사용
3. 포석용 장 제목도 낚시 요소를 넣을 것
4. 장에서 가장 '멋있는' 한 문장을 제목으로 선택
5. "분석", "국면", "대결" 같은 단어는 피하라
