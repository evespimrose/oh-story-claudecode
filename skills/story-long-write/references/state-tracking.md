# 상태 추적 프로토콜

> 이 문서는 "본절 요약"의 추출 로직과 "캐릭터 상태 기록"의 형식을 정의한다. 작성용 skill은 글쓰기 전 준비 단계의 상태 필터링에서 이 파일을 불러온다.

---

## 본절 요약

글을 쓸 때 각 장/절을 시작하기 전, 로드된 모든 콘텍스트에서 이번 절과 직접 관련된 정보만 골라낸다. 목적은 전체 콘텍스트를 전부 로드해 LLM의 문맥이 관련 없는 정보로 희석되는 것을 막는 것이다.

### 필터링 로직

콘텍스트에서 다음 세 가지 유형의 정보를 추출한다:

1. 현재 상태:이번 장에 관련된 인물들의 최신 능력, 관계 변화, 공적 이미지
2. 역사적 인과:이번 장 사건과 직접 관련된 복선의 원인, 이전 사건
3. 세계 제약:이번 장과 관련된 세계관의 규칙(능력 체계, 사회 규범, 지리적 제약)

### 필터링 기준

**"이것을 모르면 이번 장을 잘못 쓰게 된다"는 정보만 남긴다.**

구체적 판단 방법:
- 이번 장 시놉시스에서 특정 캐릭터가 언급되었다 → 해당 캐릭터의 현재 상태를 보존
- 이번 장에 복선 회수가 있다 → 복선의 매설 세부와 이전 전개를 보존
- 이번 장이 특정 장소/능력/규칙을 다룬다 → 관련 세계관 제약을 보존
- 순수 배경 지식(이번 장 사건과 인과 관계 없음) → 삭제

### 출력 형식

필터링 후 간결한 "본절 요약"을 출력한다:

```
## 이번 절 요약（제{N}장）

### 캐릭터 상태
{캐릭터A}: {한 문장 현재 상태, 최근 변화 포함}
{캐릭터B}: {한 문장 현재 상태}

### 관련 복선/전사
{복선1}: {매설 세부, {매설 장}}，이번 장에서는 {회수/진행}

### 세계 제약
{제약1}: {이번 장과 관련된 규칙/설정}
```

**예시(demo《네가 계정을 맡아, 고열 편집으로 전 세계를 뒤흔들다》 제10장):**
```
## 본절 요약（제10장）

### 캐릭터 상태
장천: 로켓군 문공단 선전병, 《제군, 용의 울음에 귀 기울여라》이 폭발적 히트를 기록해 군 선전 신인에서 군 내부에서 인정받는 창작자로 자리매김하는 중
종가가: 군사 기자, 인터뷰 원고가 심사 완료되어 장천과 인터뷰 관계에서 안정적인 협력 관계로 전환
주박삼: 문공단 부단장, 이전에 장천의 문제를 걱정하던 태도에서 그의 창작 능력을 인정하는 쪽으로 변화

### 관련 복선/전사
5일 100만 팔로워 과제: 제1장에서 게시, 제10장까지도 정산되지 않음; 이번 장은 노출량만 끌어올리고 제11장에서 정산 예정
전문 팀 재촬영: 이번 장은 고화질 전문판의 '영혼이 빠졌다'는 평가로 장천의 스마트폰 원본이 대체 불가능함을 대조

### 세계 제약
군 선전 작품은 조직의 결정을 거쳐야 함; 장천은 작품 효과로 인정받을 수는 있지만 군 내부 절차를 건너뛰고 바로 최종 결재를 내릴 수는 없음
```

## 캐릭터 상태 기록 형식

> ⚠️ **이 절은 장편 집필에만 적용된다.** 단편은 보통 독립적인 캐릭터 상태 추적이 필요 없다.

동적 상태는 핵심 캐릭터별로 `追踪/角色状态/{角色名}.md`에 저장한다. 파일은 `tracking_commit.py`가 트랜잭션 JSON에 따라 전체를 덮어쓴다; 정적 원래 설정은 여전히 `设定/角色/{角色名}.md`에 남긴다. 이후에 재사용될 주인공, 빌런, 핵심 조연에 한해 스냅샷을 만들고, 엑스트라나 일회성 기능 캐릭터는 파일을 만들지 않는다.

### 형식

```markdown
# 장천｜현재 상태

- 기준 장: 제10장
- 신분: 로켓군 문공단선전병; 군 선전 히트 창작자
- 위치: 로켓군 문공단 고위진 시사회
- 현재 목표: 5일 100만 팔로워 과제를 완료하고, 지속해서 진짜로 통하는 군 선전 콘텐츠를 제작
- 심신 상태: 전문 팀의 반대 검증으로 원본의 가치가 확인되어 군 내부에서의 인지도 지속 상승

## 능력 및 자원
- 이전 MCN 히트 운영 경험
- 《중국 군혼》 반주
- 대가급 연출 능력

## 주요 관계
- 종가가가 지속적으로 군사보도 리소스를 제공
- 주박삼과 장요조는 이미 그의 창작 능력을 명확히 인정

## 알려진 정보
- 《군보》 인터뷰 원고는 이미 심사 완료됨
- 원본 영상은 정식 군 선전 콘텐츠로 계속 사용될 예정

## 미결 사항
- 5일 100만 팔로워 과제는 아직 정산되지 않음
- 종가가가 말한 '단지 절반만 맞췄다'는 발언은 아직 설명되지 않음
```

### 갱신 규칙

1. 각 장마다 신분, 위치, 목표, 심신 상태, 능력·자원, 관계, 알려진 정보, 미결 사항 중 실제로 변경된 항목만 기록한다.
2. 핵심 재사용 캐릭터에 변화가 있을 때에는 같은 트랜잭션의 `character_changes`에 변화를 기록하고, `character_snapshots`에 그 캐릭터의 **현재까지 작성된 마지막 장을 기준으로 한 완전한 스냅샷**을 제출한다; 도구는 스냅샷 존재 여부로 핵심/임시 캐릭터를 판단하며, 핵심 캐릭터 소파일은 전체를 덮어쓰고 과거 이력을 추가하지 않는다.
3. 구장(수정)을 할 때에는 수정한 장부터 마지막으로 작성된 장까지 검토해 각 차원과 각 관계 대상별로 현재 상태를 재계산한 뒤 완전한 스냅샷을 제출한다; 마지막 한 건의 단일 차원 변화만을 캐릭터의 전체 상태로 간주해서는 안 된다.
4. 변화가 없으면 스냅샷을 제출하지 않아도 된다; 핵심 캐릭터가 다시 현재 장면으로 들어올 경우 기존의 소파일을 바로 읽어오고, 트랜잭션 도구가 필요한 정보를 이어쓰기 상태 카드에 반영한다.
5. 캐릭터 변화의 연혁은 `逐章记录/第NNN章.md`에 기록하고, 현재 스냅샷에는 장별 이력을 중복 저장하지 않는다.
6. 전체 JSON 필드, 4096 바이트 목표 및 8192 바이트의 하드 상한은 [tracking-transaction.md](tracking-transaction.md)를 참조.
