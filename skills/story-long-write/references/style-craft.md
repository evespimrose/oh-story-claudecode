# 글쓰기 기법

> 카메라 시점 글쓰기, 백묘(간결 묘사), 시점 선택, 문체, 독성 포인트 회피, 도입부 톤 설정. 본문 작성과 문장 품질 향상 시 참고용.

---

## 결정 경로

| 당신이 하는 일 | 참고할 모듈 |
|-----------|-------------|
| 본문 쓰기, 문체 다듬기 | 글쓰기 네 가지 핵심 -> 글쓰기 기초 기술 -> 카메라 시점 글쓰기법 |
| 글의 감정 밀도 조절 | 행문 검수 두 글자 비결 -> 문체 세 요소와 군더더기 통제 |
| 시점과 서술 방식 선택 | 시점 선택과 서사 |
| 독자 혐오 포인트 회피 | 독성 포인트 분석 및 회피 |
| 도입부 3장 설계 | 황금 3장 = 톤 설정과 기대 관리 |
| 문단의 화면감(이미지감) 최적화 | 텍스트 구성 요소 -> 문체 전면 해설 |

## 지시형 어조

이 문서는 "작업 지시" 어조로 작성되었다. 모든 규칙은 **반드시 준수**해야 하는 글쓰기 제약이다. 규칙이 충돌할 경우 우선순위는 다음과 같다: 카메라 시점 글쓰기법 > 기초 기술 > 인지 참조자료.

## 글쓰기 네 가지 핵심

### 핵심 1: "그다음엔" 기준법
각 문단은 독자의 머릿속에 떠오르는 "그다음엔?"에 답해야 한다. 하나의 정보점을 쓰면 곧바로 다음 정보점으로 이어라.

### 핵심 2: 간접 묘사법
직설적 묘사는 깔아놓는 역할일 뿐, 측면 반영이 쾌감을 준다. 조연이 과자를 씹는 모습을 세세히 묘사하거나 사람들이 몰려드는 장면을 그리는 것이 "이 과자는 최고"라고 마른 문장으로 쓰는 것보다 수백 배 효과적이다.

### 핵심 3: 핵심 감정에 맞춰 모든 사건 설계
글을 시작하기 전에 목표 독자의 핵심 감정 요구(인정받고 싶음/복수/연애/성장 등)를 확정하라. 모든 사건, 인물 설정, 갈등은 그 감정 줄을 중심으로 연주되어야 한다.

### 핵심 4: 거시·미시의 통합 통제
거시적 관점으로는 전체 리듬과 감정의 흐름을, 미시적 관점으로는 각 문단의 디테일과 긴장감을 통제하라.

## 글쓰기 기초 기술

### 백묘(간결 묘사)
백묘 = 최소한의 글자수 + 가장 정확한 정보와 감정. 정밀한 동사·명사로 장면을 바로 그려 독자에게 상상할 여지를 남겨라.

### 오감 묘사법
- 적어도 2~3가지 감각(시각/청각/촉각/후각/미각)을 동원하라.
- 단순히 "봤다"가 아니라 "무엇을 느꼈는가"를 써라.
- 오감은 감정을 서빙해야 한다 — 공포라면 차갑고 어둡고 정적인 감각, 흥분이라면 밝고 빠르며 시끄러운 감각.

### 동적 묘사가 정적 묘사보다 우수
- 인물 특징은 형용사 쌓기가 아니라 동작과 반응으로 보여줘라.
- 예시: 사람들이 그녀를 볼 때, 말소리가 무의식적으로 낮아졌다.
- 환경은 장황하게 늘어놓지 말고, 인물의 행동에 끼워 넣어 은근히 묘사하라.

### 대화 묘사 요점
- 한 문장은 최소한 하나를 만족해야 한다: 플롯 진행 / 인물성(캐릭터) 전시 / 갈등 생성
- 어투, 행동, 생략으로 말밑(은밀한 의미)을 암시하라.
- 일상어를 사용하라, 문어체를 피하라.

### 장면 전환과 트랜지션
- 유사한 사물/유사한 오감/유사한 감정으로 전환하라.
- 시간 점프: 동작이나 사물로 연결하라.
- 공간 전환: 소리나 빛과 그림자로 연결하라.

### 카메라(미장면)과 분할 구상
- 각 문단 = 하나의 카메라 샷, 분명한 '촬영 대상'이 있어야 한다.
- 샷 유형: 원경(환경/분위기) -> 중경(인물 관계) -> 근경(표정/디테일) -> 클로즈업(핵심 소품/감정)
- 빠른 리듬: 짧은 문장·짧은 문단·집약적 동작·빠른 컷 전환
- 느린 리듬: 긴 문장·환경 묘사·심리 활동·정지된 샷

### 몰입감 구축
- 주인공의 목표는 분명하고 독자가 공감할 수 있어야 한다.
- 주인공의 행동 동기를 독자가 이해할 수 있어야 한다.
- 서술 입장은 반드시 주인공 편에 서야 한다.

### 인물 중심 심화 vs 이야기 중심 심화
- 이야기 중심 심화: 복잡한 음모, 다층 추리 — 상한선은 높지만 난도가 높다.
- 인물 중심 심화: 인물 관계와 상호작용에서 드라마를 찾는다 — 접근하기 쉽다.
- 핵심은 독자가 "구경하러 온 기분"을 느끼게 만드는 것 — 인물 간 화학작용 자체로 충분히 재미있어야 한다.

### 높은 감성/영리한 인물 설정
- 영리함은 행동으로 보여줘라, 내레이션으로 "똑똑하다" 하지 말라.
- 실제 사례의 핵심 로직을 뽑아 웹소설 문맥에 맞게 적용하라(논리 뼈대는 유지하고 구체 디테일은 교체).

## 글 흐름 점검 — 두 글자 비결

### 첫 글자: 원활
| 막힘 유형 | 해결법 |
|----------|------|
| ‘了’자(어투)로 인한 흐름 끊김 | 불필요한 ‘了’자 사용 빈도 조절 |
| 밈(짤)로 인한 끊김 | 목표 독자군이 익숙한 밈만 사용 |
| 정보 누락으로 인한 끊김 | 필요 정보는 제때 보충 |
| 복선이 너무 멀리 떨어져 있는 경우 | 공개 전에 짧게 전제(힌트)를 제시 |

### 둘째 글자: 정확
어떤 감정인지에 맞는 맛을 써라 — 뜨거워야 뜨겁게, 따뜻해야 따뜻하게, 공포는 공포답게.

| 감정 | 핵심 | 반대 신호 |
|------|------|----------|
| 비장함 | 희생은 무게감 있게, 대가는 진짜여야 한다 | 인물이 죽어도 독자가 무감각함 |
| 따뜻함 | 일상 디테일 속의 배려 | 억지로 끌어내는 감상 |
| 공포 | 미지와 통제 불능 | 피와 살만 쌓아 놓는 묘사 |
| 열정(열혈) | 선언(선언감) | 근거 없는 구호, 준비 없는 외침 |

## 카메라 시점 글쓰기법

전지적 관점을 잊어라. 너는 주인공 뒤를 따라다니는 카메라다. 독자는 주인공이 보는 것만 볼 수 있다.

### 핵심 원칙
1. 보거나 들을 수 있거나 냄새 맡고 만질 수 있는 것만 쓰고, "그가 마음속으로 생각했다"나 "그가 느꼈다" 같은 내면 독백은 쓰지 마라.
2. 모든 대화는 플롯을 전진시키거나 인물을 보여주거나 정보를 전달해야 한다.
3. 행동으로 설명을 대체하라: "그는 매우 긴장했다" -> "손이 떨렸다"
4. 휴대폰 화면 우선: 동작/정보 변화마다 줄바꿈을 하고 읽기 답답하면 문단을 쪼개라; 쪼갤 것은 문단이며 서술 문장은 여전히 쉼표로 이은 긴 문장 위주(문장 길이 기준은 anti-ai-writing.md 규칙 3 참고).

### 고위험 체크리스트

**위험한 시점**
- 전지적 서술: "이때 그는 아직 몰랐다, 3일 후..."
- 전지성(신의 시점): "그녀가 진실을 알았다면..."
- 심리 분석: "그의 내면 깊은 곳에는 사실..."

**위험한 단어**
仿佛, 犹如, 一丝, 一抹, 深吸一口气, 不禁, 眼中闪过, 嘴角勾起, 眉头微皱, 不容置疑, 不易察觉
("好像"은 문맥에 따라 판단, 기계적 대체 금지; 缓缓, 微微, 轻轻, 淡淡은 밀도 조절하여 1000자당 합계 ≤ 3, 단독으로 자연스럽게 쓰는 것은 허용)

(위 중국어 단어들은 원문 탐지 예시이므로 번역된 문장에서는 해당 표현에 대응하는 한국어 위험 표현을 확인한다.)

**위험한 문장 패턴**
- ‘...,带着...’(예: ‘그는 말했다, 한 줄의 체념을 띠며’) 같은 구조
- 대화 태그 과다/공식화된 태그 -> 빈번할 경우 행동이나 표정으로 대체; 평범한 "말했다"는 유지 가능
- "그는/그녀는 알고 있었다" -> 직접 보여줘라, 알려주지 마라
- 상투적 비유/만능 비유 -> 생활형 비유나 백묘로 교체

### 대체 기법

| 금지 표현 | 대체 예시 |
|------|------|
| 그가 긴장했다 | 그의 손이 떨렸다 |
| 그녀는 매우 슬펐다 | 그녀가 고개를 돌리자 어깨가 떨렸다 |
| 고빈도 공식화된 대화 태그 | 행동·어투·문맥으로 이어주기; 평범한 "말했다"는 허용 |
| 그는 깊게 숨을 들이켰다 | 그는 담배를 재에 끼워 눌렀다 |
| 그녀의 눈에 놀라움이 스쳤다 | 그녀의 손이 공중에서 멈췄다 |

### 대화 작성 규범
각 대화는 최소 하나를 만족해야 한다: 플롯 진행 / 인물 묘사 / 긴장 생성

**대화 형식**
- 긴 대화는 행동으로 끊어라.
- 한 번에 말하는 분량은 최대 3문장.
- 고빈도/공식 태그 사용을 피하라; 평범한 "말했다"는 허용, 반복되거나 어투가 단조로울 때는 행동/문맥으로 대체.

**대화 감정 5단계 상승**
1. 사실의 객관적 진술
2. 객관적 진술 + 제안 제시
3. 주관적 비난
4. 주관적 비난 + 강제 명령
5. 주관적 비난 + PUA식 자기 고양(최고 수준)

### 삼중 앵글법(세 기위법)

| 앵글 | 시점 | 내용 | 기능 |
|------|------|------|------|
| 앵글1 | 근경 | 주인공의 동작, 표정, 심리 | 주선 진행, 독자 몰입 |
| 앵글2 | 원경 | 조연 반응, 환경 변화, 구경꾼 | 정보 면 확장, 대비 생성 |
| 앵글3 | 설명부 | 설정 보충, 배경 해설 | 필요할 때 적절한 정보 보충 |

앵글 교대 원칙: 핵심은 앵글1과 2, 앵글3은 간헐적으로 끼워 넣는다. 설정은 갈등에서 유도하라.

## 텍스트 구성 요소

### 핵심 분류
- 화면감(장면): 인물 + 환경(정지/동적), 마치 고화질 카메라가 기록하는 것처럼
- 사상(사고): 계획/목표/욕설/추측/분석 등 내면 활동
- 감정: 화면감과 사고 속에 숨겨져 있으며 직접 쓰지 않는다
- 설명부(나레이터): 출신/설정/인물 관계/회상은 가능한 한 간결하게

### 감정 표현 계층(낮음 → 높음)
1. 최하: "xx는 분노했다/슬펐다/기뻤다" — 감정을 직접 전달하면 독자가 느끼지 못함
2. 낮음: 사고로 표현 "xx가 속으로 욕했다"
3. 중간: 표정으로 표현 "xx의 얼굴이 창백해졌다"
4. 높음: 행동으로 표현 "xx가 주먹을 쥐어 박으며 손톱이 살을 파고들었다"

핵심: 감정에서 멀어질수록 표현 수준은 높아진다 = 측면 묘사가 고급 표현이다.

### 환경 상호작용(환경 묘사의 핵심)
상호작용 없는 환경 묘사는 쓸 가치가 없다.
- 물리적 상호작용: 배꽃이 코끝에 날아와 재채기를 유발한다 / 설산이 떨린다 / 강물이 얼굴을 씻겨준다
- 정신적 상호작용: 음식으로 인물 관계 비유 / 밥을 먹여주는 행위 = 애정/미묘함 / 식칼로 생선을 자르는 행위 = 위협
- 장르적 상호작용: 선협은 하늘을 가리는 거대한 새, 무협은 치열한 분노 한 번에 피가 튀는 묘사

## 문체 세 요소와 군더더기 통제

### 문체 세 요소
- 정밀성: 한 단어로 설명할 수 있으면 문장으로 늘리지 마라. 동사 선택이 화면감을 결정한다.
- 리듬: 서술은 기본적으로 쉼표로 이은 긴 문장, 짧은 문장은 드문 리듬 타격으로 사용하고 다시 긴 문장으로 복귀하라; 통째로 같은 길이의 문장으로 채우지 말고, 기계적 장단 교대로도 피하라(문장 길이 기준은 anti-ai-writing.md 규칙 3 참고).
- 화면감: 오감을 동원하여 "봤다" 외의 표현을 사용하라.

### 군더더기(수분) 통제
- 군더더기 = 플롯을 진행하지도, 인물을 만들지도 않는 내용
- 합리적 군더더기: 복선 설정/분위기 조성/인물 상호작용 — 속에 미묘한 흐름이 있어야 한다
- 해로운 군더더기: 이미 알려진 정보의 반복/무의미한 환경 묘사/인물의 의미 없는 독백
- 검사법: 이 문단을 삭제했을 때 독자가 혼란스러워하지 않으면 = 군더더기

### 장편 웹소설의 문체 선택
장편은 정교한 문체보다 가독성과 유려함이 필요하다. 문체의 목표는 독자가 글을 읽고 있다는 사실을 잊고 장면을 바로 보게 만드는 것이다.

## 문체 전면 해설과 환경 상호작용법

### 문체 중요성의 단계별 차이

| 단계 | 중요도 | 설명 |
|------|--------|------|
| 초등 수준 문체 | 10점 | 기초가 안 되면 다른 얘기 자체가 무의미 |
| 기본 충족 | 5점 | 기준 충족 후 약점은 구조와 소재 선택 |
| 고품질 수준 | 7점 | 고품질 간 차이는 문체에서 벌어진다 |
| 백만 부(베스트셀러) | 10점 | 최상위 작품은 문체가 핵심 경쟁력 |

판단: 성과는 좋은데 문체가 약하면 문체 개선의 가성비가 매우 높다; 성과는 낮은데 문체만 좋다면 소재와 플롯을 보완하라.

### 한 문장 다용도
한 문단이 동시에 여러 기능을 수행하게 하라:
- 환경 상호작용 + 인물성 + 감정선 = 한 문장으로 세 가지
- 설정을 사건에 녹여라: 세계관은 작은 이야기로 끼워 넣기
- 복선을 심어라: 표면 정보 아래 숨겨진 정보 넣기
- 탄탄한 리듬: 지루한 배경 설정을 재미있는 작은 사건 속에 숨겨라

### 구조 단순화
"x급 구조"의 핵심은 "세분화"다: 한 문장 주제 -> 세분화 -> 권장 개요(권) -> 세분화 -> 권별 장 개요 -> 세분화 -> 본문. 역추적(역공정)이 순추진보다 효율적이다.

## 문체의 본질과 계층

### 세 항목 산출 검사
- 선정(선택) 소재: 목표 독자, 장르 경계, 핵심 판매 포인트가 명확한가
- 플롯 설계: 대강/권별 개요/장별 개요가 목표 감정을 지속적으로 만들어내는가
- 문체: 본문이 구체적 동작, 대화, 소품, 리듬으로 감정을 전달하는가

본문의 문제 원인이 소재나 플롯 설계에 있으면 문장만 다듬지 말고 해당 산출물(artifact)로 돌아가 수정하라.

### 감정 표현의 계층(낮음 → 높음)

| 계층 | 방식 |
|------|------|
| 최하 | 직접 "xx가 분노했다" 쓰기 |
| 낮음 | 사고로 "xx가 속으로 욕했다" |
| 중간 | 표정으로 "얼굴빛이 창백해졌다" |
| 높음 | 동작으로 "주먹을 꽉 쥐고 손톱이 살을 파고들었다" |

핵심: 감정 자체를 쓰지 말고, 감정이 일으킨 외적 표현을 써라.

## 시점 선택과 서사

### 웹소설에서 흔히 쓰는 시점

| 시점 | 특징 | 적합 |
|------|------|------|
| 3인칭 제한 시점 | 주인공 시점을 따라간다 | 가장 흔하고 몰입감 강함 |
| 1인칭 | "나" 서술 | 추리·일상 장르에 적합 |
| 3인칭 객관 시점 | 외적 행동만 서술 | 군상극 |
| 점프 시점 | 다양한 인물 사이 전환 | 정보 격차 생성용 |
| 전지적(신의) 시점 | 전지전능 | 전통 문학용, 웹소설에선 드묾 |

### 사용 요점
- 웹소설에는 3인칭 제한 시점을 가장 권장한다.
- 점프 시점은 주로 "독자는 아는데 주인공은 모르는" 정보 격차를 만들 때 사용한다.
- 시점 전환에는 명확한 구분 표시가 필요하다.
- 1인칭은 신중히 사용하라 — 정보량이 제한되고 후반 전개가 어렵다.

### 추상과 구체의 균형
- 틀(레퍼토리)은 공통점이고, 각 책의 개성은 독자를 붙잡는 이유다.
- 좋은 웹소설 문체 = 누구나 읽을 수 있는 평이한 말투지만, 불필요한 것을 지우면 행동과 대사만으로 감정을 전달한다.
- 좋은 웹소설 문체는: 대충 보면 평범한 말투, 자세히 보면 수준이 있다.

## 독성 포인트 분석 및 회피

### 다섯 가지 독성 방향

| 방향 | 회피 방법 |
|------|----------|
| 주인공 묘사 | 서술 입장을 주인공 편에 두고, 주인공의 행동엔 반드시 긍정적 결과(정피드백)를 배치 |
| 장르 금기 | 목표 독자군을 이해하고 민감 주제는 피하라 |
| 분위기 몰입도 | 웃음거리(밈) 글 제외하고는 분위기 몰입감이 밈보다 100배 중요 |
| 기대 파괴 | 리듬을 잘 조절해 적시에 만족시키거나 새로운 기대를 던져라 |
| 장르 선택 | 톱플(최상위) 작품보다 3~5천 부 정도의 동종 작품을 참고하라 |

### 핵심 원칙
- 주인공은 내 사랑: 서술 입장은 반드시 주인공 편에 선다.
- 독자 층 명확화: 독성 포인트는 장르와 독자층에 따라 달라진다. 모든 독자를 만족시키려 하지 마라.
- 기대 관리: 반복적인 기대 파괴는 신뢰를 잃게 한다.
- 도입부 간결: 첫 장에서 핵심 요소를 드러내라.

## 황금 3장 = 톤 설정과 기대 관리

황금 3장 = "실물이 사진과 일치하는지 검증"하는 장, 독자의 기대에 빠르게 응답한다.

### 공식
불안한 처지 + 향상 가능성이 있는 지위 + 희망적인 외부 장치(오버파워 장치) + 전망 가능한 아름다운 미래

### 톤 설정의 세 층위
1. 감정 분위기
2. 이야기 진행 방향
3. 가치관 성향

### 두 가지 쓰기 방식
- 몰입 경로: 주인공에 빠르게 몰입시키는 방식
- 기대 경로: 도입에서 위기를 만들어 기대를 형성하는 방식

규칙: 황금 3장을 인위적으로 만들면 전체 톤을 해칠 수 있으므로 무리하게 강요하지 마라.

### 독자를 붙잡는 핵심: 끊이지 않는 기대
- 주인공이 곧 얻을 것 같지만 아직 얻지 못한 상태 -> 기대감 최고 -> 가장 많은 추적
- 얻으면 추적률이 즉시 떨어짐 -> 해결책: 얻기 직전 다른 미끼를 던져라 -> 순환
- 한 작품은 항상 두 개 이상의 기대선을 유지하라.

## 품질 점검 체크리스트

글을 쓴 뒤 각 문단/장마다 다음 항목을 점검하라:

- [ ] 문단 단위 제어: 동작/정보 변화에 따라 문단을 끊어 읽기 흐름이 끊기지 않는가
- [ ] 위험 단어 스캔: "마치/듯이/한 줄기/참을 수 없이/눈에 스쳤다/입가가 올라갔다" 등 틀에 박힌 표현을 적게 썼는가
- [ ] 위험 문장 패턴 스캔: 공식화된 대화 태그/ "그는 느꼈다"/"…를 띠며" 등 과잉 사용하지 않았는가
- [ ] 감정 표현: 핵심 감정 지점에서 "그가 분노했다/슬펐다/긴장했다"를 직접 쓰지 않고 동작·표정으로 대체했는가; 낮은 강도의 지나가는 감정은 한 문장으로 직접 표기 허용
- [ ] 대화의 유효성: 각 대화가 적어도 플롯 진행/인물 표현/긴장 생성 중 하나를 만족하는가
- [ ] 오감 동원: 각 장면에서 2개 이상의 감각을 동원했는가
- [ ] 환경 상호작용: 환경 묘사가 인물과 상호작용하는가, 비어 있는 화면만 나열하지 않았는가
- [ ] 카메라 감각: 각 문단에 분명한 촬영 대상이 있고 원경/중경/근경/클로즈업이 교차되는가
- [ ] 군더더기 점검: 임의의 문단을 삭제했을 때 독자가 혼란스러워하지 않는다면 그 문단은 불필요한가
- [ ] 시점 일관성: 전지적 서술/전능한 시점/심리 분석이 섞여 있지 않은가
- [ ] 리듬 교체: 서술 기본은 쉼표로 이은 긴 문장(문장 길이 기준은 anti-ai-writing.md 규칙 3), 짧은 문장은 드문 리듬 타격으로 사용하고 다시 긴 문장으로 돌아오는가; 통문장 동일 길이 또는 기계적 장단 반복을 피했는가; 빠른 장면과 느린 장면을 교차했는가
- [ ] 몰입감: 주인공의 목표가 분명하고 행동이 이해되며 서술 입장이 주인공 편에 서 있는가
