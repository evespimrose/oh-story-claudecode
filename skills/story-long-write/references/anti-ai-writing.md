### 장 끝 요약체

**금지**되는 장 마무리 방식:
- 총괄적 깨달음("그는 마침내 깨달았다……")
- 승화식 감탄("이 밤은 분명 아무도 잠들지 못할 것이다")
- 철학적 결말("인생이란 원래 이런 것이다……")
- 복선식 예고("그가 모르는 것은 더 큰 폭풍이 곧 닥쳐올 것이라는 점이었다")

**올바른 방법**: 장의 끝을 동작, 대사 또는 서스펜스로 마무리하여 플롯 자체가 여운을 만들도록 한다.

### 중첩식 묘사(같은 동작을 세 번에 나누어 쓰기)

**검출 패턴**: 하나의 동작/감정을 먼저 발생하는 것으로 쓴 후, 감각적 세부사항을 보완하고, 신체 반응을 보완하여 세 구간에 걸쳐 순차적으로 완성한다. 독자가 보는 것은 같은 동작이 세 번에 나누어 쓰인 것이다.

**전형적인 특징**:
- 먼저 포괄적인 동작을 쓴 후, 같은 동작의 세부 사항을 전개하고, 신체 반응을 쓴다: 세 단락이 같은 일을 말한다
- "발생층→인지층→반응층" 순서대로 단락으로 나타난다
- 각 차원이 독립적으로 단락을 이루며, 같은 단락의 연속 본문에 섞이지 않는다

**오류 예시**:
> 림 아버지가 고개를 숙인 채 왼손으로 문서를 누르고, 오른손으로 펜을 들어 종이에 내려놓았다.
>
> 팔꿈치에서 손목까지 손이 떨렸다.
>
> 펜 끝이 종이 위에서 멈췄다가 가로 한 획을 긋고 또 멈췄다. "림"자의 왼쪽 곁줄기가 삐뚤어졌다.

→ 동일한 동작(손 떨림/글자 쓰기)을 세 단락으로 나누어 쓴 것으로, 각 단락은 같은 순간의 다른 차원을 표현함

**올바른 방법**: 발생, 지각, 반응이라는 세 가지 차원을 동일한 연속 본문에 섞어서 작성하면, 독자는 하나의 완전한 순간을 읽게 됨:

> 림부(林父)는 왼손으로 문서를 누르고 오른손에 펜을 들어 종이 위에 내려놓았는데, 펜 끝이 종이에 닿는 순간 밀렸고, 팔꿈치부터 손목까지 떨려서 그은 가로선이 비스듬히 질질 끌려갔다.

→ 발생, 감지, 반응이 한 단락 안에서 동시에 나타남

**처리 원칙**: 기능하는 감정 디테일은 보존하되, 같은 순간의 반복 묘사는 연속된 장면으로 통합하세요. 통합 후 내용이 현저히 약해지면 원문의 기능하는 정보를 우선 복원하거나, 기존 정보를 더 자연스러운 동작/대사로 표현하세요. 원문에 없던 에피소드, 설정, 관계, 또는 타임라인을 새로 추가하면 안 됩니다.

## 핵심 규칙

> **문장 길이는 규칙 3을 기준으로 합니다**: 규칙 1-4와 본 문서 다른 곳의 「짧은 문장 / 문장 분리 / 삭제 가능하면 삭제」라는 설명이 규칙 3과 충돌할 때는 규칙 3을 따르세요.

### 규칙 1: 단락 밀도 진단

단락의 길이에 정해진 장단점은 없습니다. 점검의 중점은 음독과 휴대폰 읽기에서 막히는 부분이 있는지입니다:

- 한 단락은 보통 한 가지 동작, 한 가지 정보 변화 또는 긴밀하게 연관된 한 무리의 반응만을 담아야 합니다.
- 쉼표로 이어진 문장이 너무 길거나 여러 개의 완전한 동작이 한 단락에 몰려 있어 읽을 때 숨을 쉬어야 하면, 동작이나 정보 변화에 따라 나누세요.
- 연속된 짧은 단락이 개요처럼 조각나 있으면, 같은 화면 내의 인접한 문장들을 병합하여 장면의 연속성을 유지하세요.

```
과밀: 그는 창밖의 빗소리를 바라봤고, 마음속에 설명하기 어려운 감정이 솟아올랐으며, 이 몇 년간 걸어온 길과 이미 잊어버린 많은 일들이 이 순간 떠올랐다.

더 자연스러움: 그는 창밖의 빗소리를 뚫어지게 바라봤고, 빗은 오후부터 해질 때까지 내렸다.
"넌 여전히 그녀를 생각하고 있어?"라고 노 류가 물었다.
그는 말이 없었다.
```

### 규칙 2: 동작 + 대사 + 감정 반응

세 요소를 순환적으로 진행하세요. 심리 활동만 2단락 이상 연달아 쓰지 마세요:

```
동작 -> 대사 -> 감정 반응 -> 동작 -> 대사 -> ……
```

감정을 "그는 느껴/그는 생각해"라고 쓰지 말고, 신체 반응과 행동으로 표현하세요:
- "그는 매우 긴장했다"라고 쓰지 말고 -> "손바닥이 온통 땀이 나서 젓가락을 거의 떨어뜨릴 뻔했다"고 쓰기
- "그녀는 매우 화났다"라고 쓰지 말고 -> "그녀가 컵을 바닥에 내팽개치자 산산조각 난 조각들이 발등에 튀었지만 줍으러 몸을 구부리지도 않았다"고 쓰기
- "그는 매우 슬펐다"는 쓰지 말고 → "그는 차 안에서 20분을 앉아 있다가 그제야 시동을 걸었다"고 쓴다

위의 치환은 핵심 감정 전환점에 적용되며, 약한 강도의 과도 감정은 직접 쓸 수 있다("그는 좀 짜증났다"). 곳곳마다 외화할 필요는 없다.

### 규칙 3: 문장의 적절한 길이(짧은 문장은 도구일 뿐, 기본이 아니다)

서술(나레이션)의 기본은 **쉼표 긴 문장**으로 작성한다: 한 문장에 쉼표로 2-4개의 동작이나 정보를 연결한 후 마침표를 찍는다; 쉼표 사이는 8-12자, 전체 문장은 20-30자. 짧은 문장은 가끔씩 고립된 강조 도구일 뿐, 서술의 기본 문법이 아니다.

| 장면 | 문장 길이 | 예시(장편 말뭉치 원문) |
|------|------|------|
| 일상 / 추진 / 묘사（대부분 서술문） | 쉼표 사이 8-12글자, 전체 문장 20-30글자 | 음산하고 축축한 기운이 얼굴을 스치고, 몸 아래는 얇은 짚단이 깔려 있으며, 축축하게 피부에 들러붙어 있다. |
| 대사 | 구어체, 길이는 인물의 성격에 따라 | "넌 미쳤어?""아마도." |

**부적격（AI 톤과 동급）**：
- 쉼표 사이가 모두 ≤5글자의 단편들（"그가 손을 들고, 문을 열고, 방으로 들어가고, 앉는다"식）
- 전체가 3-8글자 문장, 마침표가 개요처럼 빽빽함（전보체, 패턴 9 참고）
- 길게 한 번, 짧게 한 번 기계적으로 번갈아가기 (역시 템플릿)

> **베스트셀러 코퍼스 보정**(톈마오 장편 현언/도시/고언/현환/역사 125권 × 처음 8장 내레이션 통계): 쉼표 사이 평균 8.8-9.6자; 문장 전체 평균 22-24자; 쉼표 긴 문장이 서술문의 74-80% 차지; ≤5자의 짧은 구간은 약 2할 정도로, 대부분 고립된 시간 표현, 접속사, 동작 강조. 단편(염언체) 문단은 더 짧음 (≤15자의 단일 문장이 절반 가까워질 수 있음, 장편은 약 2-3할), 하지만 문장 내부의 리듬은 장편과 동일: **문단은 장르에 따라 짧아지지만, 문장 내부는 끊기지 않음**.

### 규칙 4: 구어적 표현

- 속어, 거친 표현 허용 (인물의 신분에 맞을 경우)
- 대사는 문어체 금지 ("나는 이 일이 부적절하다고 생각한다" -> "나는 이게 좀 믿을 수 없는 것 같아")
- 서사도 거만하게 쓰지 말 것("그의 눈빛이 날카롭다" -> "그는 눈알을 꼼짝 않고 노려봤다")
- 성어보다 일상적인 표현 우선("어쩔 수 없다" -> "어떻게 할 수 없다")——대사와 인물의 목소리에 맞는 서사만 사용; 나레이션은 관용구(태연함, 정신 산만함 따위)는 그대로 유지

## Show Don't Tell 원칙

| Tell(말로 전하기) | Show(행동으로 보여주기) |
|-------------|-------------|
| 그는 겁쟁이였다 | 그는 검사 보고서를 손에 들고 몇 번이나 앞뒤로 뒤적거렸지만, 여전히 열 수 없었다 |
| 이 바는 매우 시끄럽다 | 바텐더가 그의 귀에 다가가 두 번이나 소리쳐야 겨우 들렸다 |
| 그녀는 매우 부유하다 | 그녀는 아무렇게나 신용카드 한 장을 테이블 위에 내팽개쳤는데, 카드 앞면의 숫자가 이 끼니보다 열 배나 비쌌다 |
| 두 사람의 관계가 매우 나쁘다 | 그는 담배를 그녀가 방금 우린 찻잔에 짓눌러 껐고, 그녀는 표정 없이 잔을 밀어냈다 |
| 그는 매우 똑똑하다 | 3초. 그는 3초만에 서류를 덮었다. "세 번째 페이지, 두 번째 줄." |

**핵심 방법**:
1. 형용사 대신 행동으로 표현하기
2. 요약 대신 세부 묘사로 표현하기
3. 나레이션 대신 대화로 표현하기
4. 감정 표현어 대신 반응으로 표현하기

## 품질 차원 검토

### 1. 핵심 일관성（가중치 최고）
- 줄거리가 대강/선행 내용과 일치하는지 여부
- 인물의 행동이 인물 설정과 부합하는지 여부
- 설정에 앞뒤 모순이 있는지 여부

### 2. 표면 개작（AI 지문 방지）
- AI 고주파 용어 포함 여부(위 표 참고)
- 장 끝에 요약/승화 부분 있는지 여부
- 대량의 순수 심리 묘사 포함 여부
- 단락이 극적 단위/쇼트에 따라 자연스럽게 끊어지는지, 기계적 단문 단락이나 개요식 세분화 피하기(웹소설 단락 규칙)

### 3. 형식 일관성
- 대화 형식 통일: 프로젝트/플랫폼 규약에 따라 동일한 인용부호 스타일 유지; 지후 염언 단편은 「」 사용 가능
- 문장부호 리듬이 어조와 일치: 온통 마침표로 끝내기 피하기; 기능하는 물음표와 소량의 느낌표는 보존; 주저함이나 끊김을 표현할 때 동작/짧은 문장으로 표현하되, 줄임표나 대시로 억지로 멈춤을 만들지 않기
- 장면 전환에 명확한 표시
- 시간선이 명확하고 추적 가능

### 4. 가독성
- 연속된 긴 문장들이 읽기 속도를 압도하고 있으며, 동작, 대사, 짧은 문장으로 쉬어갈 부분이 부족한지 확인
- 대사가 구어체로 표현되었는지 확인
- 설명되지 않은 생소한 단어/설정 용어가 있는지 확인
- 리듬감이 빠르고 느린 부분이 섞여 있는지 확인 (한 가지 리듬만으로는 안 됨)

### 5. 논리적 연결성
- 인물의 동기가 합리적인가
- 사건의 인과관계가 명확한가
- 시간 순서가 일치하는가
- 인물의 지식 범위가 합리적인가(신의 관점으로 보면 안 됨)

```
한 가지 사건은 한 문단으로, 장면을 자연스럽게 끊으세요.
대화는 사람이 말하는 것처럼 해야 합니다.
심정은 심리 묘사로 드러내세요.
결말에서 무리하게 승화시키지 마세요.
전투 장면은 나열식으로 쓰지 마세요.
일상적으로 복선을 깔아두세요.
```

## 10가지 AI 작성 패턴 감지

### 패턴 1: AI 고빈도 단어

| 비활성화 | 대체 |
|------|--------|
| 불금지 | 삭제 |
| 마치/꼭 | 삭제하거나 구체적인 묘사로 대체 |
| 눈에 띄다 | 삭제 |
| 마음속으로 생각하다 | 동작으로 사고 표현 |
| 무거운 목소리로 말하다/담담하게 말하다 | 동작 태그로 변경 |
| 표정이 변하다 | 구체적인 표정/동작으로 표현 |
| 입꼬리가 살짝 올라감 | 그가 웃었다/그가 입꼬리를 올렸다 |
| 저도 모르게 | 삭제 |
| 다만 보였다/바로 이 순간 | 삭제 |
| 눈빛이 날카롭다 | 삭제하거나 구체화 |

### 패턴 2: 약화된 부사 남용
임계값: 1000자마다 3개 초과 = AI 서명. 중점 모니터링: 미미하게, 담담하게, 천천히, 살짝.

### 패턴 3: 의미 부풀리기
- "의미심장하다" -> 구체적인 결과를 작성하기
- "전례 없는" -> 비교 참조 제시하기
- "이라 할 수 있다" -> 삭제하기

### 패턴 4: 만능 결론
- "미래는 밝다" -> 미해결의 긴장감으로 끝내기
- "앞날이 창창하다" -> 삭제
- "희망으로 가득 차다" -> 구체적인 다음 단계 행동 작성

### 패턴 5: 논문체 문단 구조
소설에 다음과 같은 도입 문장이 나타남 = AI 침투:
- "보기 쉽듯이" "이로부터" "사실상" "종합하면"

### 패턴 6: 서면어 연결사 남용
서사 산문에 빈번하게 나타남: "그러하여" "동시에" "따라서" "그리하여" "물론" -> 구어체로 대체하거나 직접 삭제.

### 패턴 7: 삼중 병렬 구조 중독
AI는 일을 세 가지로 만들어서 "완전해" 보이게 좋아한다. → 가장 강력한 것 하나만 남긴다.

여러 문단에 걸친 「A가 아니다./B도 아니다./오직 C일 뿐이다.」는 `formulaic-parallelism`을 advisory로 작동한다: 정연한 배열일 수도, 반박·의문 제거·감정의 점진적 심화를 담당할 수도 있다; 개요만 반복되거나 장면이 느려질 때만 압축한다. 이런 제시문과 「X에 관해서는 X 아니고, 어떻게 X인지」, 같은 동사를 쓴 「V하지 않은 A, V하지 않은 B」는 모두 언어적 검토만 한다: 대사도 확인해야 하지만 명확한 인물 목소리나 작업 기능이 있을 때는 유지할 수 있다; 세부 개요의 여러 항목에서 같은 요구사항이 반복된 것이라면 본문에서는 한 번만 다룰 수 있고, 항목별로 복술할 수 없다.

### 패턴 8: 해석 톤 / 신의 시점 / 배치감
가장 알아차리기 힘들지만 가장 "AI처럼" 보이는 부류다. 서술자가 인물의 당하 시점에서 뛰어나가 설명하고, 스토리를 까발리고, 요약하고, 정의하고, 격상시킨다. 독자는 "작가가 현장에 있다"와 "스토리가 이미 정해졌다"는 냄새를 맡을 수 있다. 이것이 바로 "설교감/신의 감각/해석 톤/기계감/억지스러움/배치감"의 출처다.

| 표현 | 예시(삭제/수정) |
|---|---|
| 인과관계 설명 | 「그래서…이는 때문이다」「원래…」「이는 의미한다」「바로 이것이 때문이다」-> 삭제. 인과관계는 역할의 동작, 대사, 반응에서만 독자가 스스로 연결하도록 |
| 전지적 관점 스포일러 | 「그녀는 몰랐지만」「그런데 알고 보니」「몇 년 뒤에」「어쩐지 모르게」「마치 예고하는 듯」-> 삭제. 오직 역할이 이 순간 알고 있는 것만 쓰고, 서스펜스는 독자가 스스로 느끼도록 |
| 독자를 위해 결론/정의 내리기 | 「연기를 잘했다」「이 연극은 한 번 봤던 것」「그는 원래 이렇게 냉정한 사람이다」-> 삭제. 증거(표정, 동작, 대사)만 제시하고, 정의는 독자에게 맡기기 |
| 역할의 심리 대신 요약하기 | 「그녀는 깨달았다, 이 모든 것은 운명이다」-> 편견 섞인 순간적 생각이나 신체 반응으로 바꾸기 |
| 요약/동기/평가 연쇄로 의미를 다 말하기 | 「그는 마침내 깨달았다」「이것이 최선의 선택이다」「모두가 이 순간을 기억할 것이다」-> 정의를 삭제하고, 역할이 지금 처리해야 할 구체적 공백, 미완료 동작 또는 부분적 피드백으로 바꾸기; 평가를 유지한 후 억지로 물건/동작을 집어넣지 않기 |
| 배치된 느낌/억지 복선 | 후속 내용을 위해 억지로 배경 교대, 긴 회상 역서술 -> 배경을 등장인물의 현재 실제 필요에 따라 순간의 생각, 반문장, 물건 조각으로 드러내기, 한 곳에 집중해서 교대하지 않기 |
| 승화식 결말 | 결말의 대구 격상, 명언으로 주제 점철 -> 하나의 동작이나 여백의 문장으로 마무리하고, "의미"를 화면 속에 압축하기 |
| 추상적 운명/시작 마감 | 「운명이 마침내 송곳니를 드러냈다」「이미 배치된 바둑판」「이 순간 마침내 깨달았다」「그에게 속한 반격이 이제 막 시작되었다」-> 등장인물이 현재 볼 수 있는 문서, 동작, 대사 또는 물리적 결과로 바꾸기; `check-ai-patterns.js`가 `abstract-summary-tic`을 보고할 때 우선 처리 |
| 상용구 밀도 과다 | 마치/한 줄기/한 점/깊이 숨을 쉬며/잔잔한 파도/손가락 마디가 창백함 등이 연쇄로 반복 (`cliche-density-tic`) -> 동의어 교체가 아니라, 전체 문단을 등장인물의 현재 증거로 돌아가기: 문서, 동작, 대사, 물리적 결과 |
| 비유 밀도 과다 | 마치/처럼/마냥/같은 등 비유 표시가 곳곳이 반복 (`metaphor-density-tic`) -> 가장 정보나 감정을 전달하는 한두 개만 남기고, 나머지는 구체적 동작, 물건, 소리, 결과로 되돌리기; 새로운 비유로 바꾸지 않기 |
| 시스템 공지 공문체 과다 | 대괄호 규칙/패널/공지 행의 하드 규칙 단어 집중(`system-notice-formality-tic`) -> 캐릭터가 보는 화면/공지/규칙 매체로 유지; 매체 내부의 하드 단어만 구어체로 변경하거나 캐릭터가 현장에서 이해할 수 있는 구체적 결과를 추가하고, 서술자 설명으로 바꾸지 않기 |

**더 은폐된 층(가장 자기 검토가 어렵고 표지어가 없음)** — 동일한 배치감/신의 관점:
- 평가성 부사/보어: 「걱정이 정확히 알맞다」「웃음이 마땅하다」「많지도 적지도 않다」-> 저자가 독자를 위해 「이건 꾸민 것이다」라고 인감 날인. 행동만 쓰기(「그녀가 손수건을 덮었고, 눈은 움직이지 않았다」), 꾸민 것 아닌 것은 독자가 스스로 판단하게 하기.
- 스포일 식 잠재 의미 드러내기: 「그 웃음을 그녀가 뚜렷이 봤다」「누가 봐도 그가 거짓말하는 걸 안다」-> 숨겨진 것을 명확히 하기. 숨겨두기.
- 성질 규정 은유/관형구: 「이미 정해진 일을 선고하는 것처럼」「죽은 물건을 보는 것처럼」-> 은유가 캐릭터를 대신해 정론 내리기. 캐릭터의 현 순간 강렬한 주관적 감정이 아니면 삭제; 남길 경우에도 편견을 가진 순간의 감각만 가능하고, 객관적 단정은 안 됨.

자기 검토: 매 문장마다 물어보세요——이건 "인물이 겪고 있는 것"인가, 아니면 "작가가 설명/배치하는 것"인가? 작가가 튀어나와 설명하는 부분은 삭제하거나, 인물의 관점 안에서 보여주는 방식으로 바꾸세요. 근본적인 해결법은 깊이 제한적 관점을 고정하는 것입니다(writing-craft.md의 「관점 태도: 깊이 제한적 관점」 참조). 카메라를 인물의 몸 안에 고정하면 작가가 튀어나올 자리가 없어집니다.

수정 우선순위: 오염된 문장을 먼저 삭제하거나 원래 위치에서 교체하고, 문단 끝에 따로 "인간미" 꼬리를 붙이지 마세요. 정보를 보충해야 할 때는 기존의 요약/동기/평가 문장을 인물이 지금 당면한 구체적인 문제, 절차, 답장, 송금, 문밖의 소리 등으로 바꾸세요. 휴대폰/화면/공지/문패/서식 같은 정보가 이미 있다면, 인물이 본 장면 속 매체로 우선 보존하고 해설자의 설명으로 옮기지 마세요. 구체적인 매체는 플롯에 맞춰가며, 정해진 체크리스트에 끼워 맞추지 마세요.

**업무 병목은 고정된 공식도 아니고 범용 보완 절차 버튼도 아닙니다**: 기존의 설명을 인물이 지금 처리해야 할 부족한 부분으로 되돌릴 뿐입니다. 먼저 원문에 "해야 할 일"과 "막힌 부분"이 있는지 묻으세요. 있으면 업무 병목으로 압축할 수 있고, 없으면 설명만 삭제하거나 동작/대사를 바꾸되, 새로운 사건 연쇄는 만들지 마세요. 수정 후 "삭제해서 확인해보기"를 하세요: 삭제해도 정보, 감정, 관계, 대가, 복선에 영향을 주지 않으면 압축하거나 삭제하세요.

**하지만 설명 목소리를 삭제한다 ≠ 독자를 혼란스럽게 한다**: 새로운 개념/설정/도구가 처음 나타날 때는 독자가 한 가지 닻을 잡게 해야 합니다——인물의 동작 반응, 대사에서 자연스럽게 반쯤 언급하기, 또는 장면의 물리적 결과로 일필휘지 그려내기로, 현재의 역할이나 무게를 드러내세요. 전체 설명을 쓰거나 정보 없는 생소한 단어만 던지지 마세요. 인물의 기억, 감정 완충, 인과 연결도 마찬가지입니다: 한 문장이 설명/평가로 보이지만 실제로는 작은 연결 작업을 한다면(독자에게 인물이 왜 얼굴이 뜨거운지, 왜 멈추는지, 왜 이 한마디를 누르지 못하는지 알려주기), 기계적으로 요약 목록으로 삭제하지 마세요. 인물이 지금 쓰는 평어, 동작, 사물, 반쯤 떠오르는 생각으로 압축하세요. 예: 「파란 수정」이 처음 나올 때 "기억을 저장하는 장치"라고 쓰지 마세요. 하지만 그녀가 파란 수정을 태양혈 위에 누르고, 다른 사람의 기억 조각이 눈앞에서 튀어나오는 장면은 쓸 수 있습니다——기능이 독자에게 보이고, 전체 모습은 의문으로 남습니다. 구분: 닻은 "인물이 지금 맞닥뜨린 감지 가능한 결과/기억이나 감정 연결"(보존하거나 압축), 설명은 "작가가 튀어나와 설정의 유래/원리/독자를 위해 결론을 내려주기"(삭제).

### 패턴 9: 과도한 압축(전보체)

AI 같은 느낌을 지우려다 과하게 역지문을 삭제하고 있습니다. 모든 문장을 최단으로 압축하고, 구조 허사를 완전히 제거하며, 각 동작에 「했다/잠깐 했다」식 가벼운 반응을 덧붙입니다. 단문만 봐도 깔끔하지만, 연달아 읽으면 개요처럼 느껴지고, 독자는 "매끄럽지 않고 숨 쉴 틈이 없다"고 체감합니다. 삭제의 목표는 허사(설명, 물 채우기, 분량 맞추기)를 없애는 것이지, 한국어 자연스러운 중복을 없애는 것이 아닙니다.

| 표현 | 수정 방법 |
|---|---|
| Compress all narrative sentences, not just climactic ones, to shortest form | Keep climactic sentences (action/emotion/suspense peaks) short; preserve structural particles like 铺垫, transitions, everyday actions in natural colloquial style, retaining 있었다/의/그냥/할 때 structures |
| 「했다/잠깐 했다/두 번 했다/반 바퀴 풀었다」식 미세 동작의 고밀도 반복(check-ai-patterns.js 보고: micro-action-tic) | 동작 병합, 구체적 디테일로 교체; 모든 동작에 반응 꼬리를 붙일 필요는 없음 |
| 강조 부사(마저/야/또/오직/모두/오히려)가 전부 제거됨 | 삭제 전 의미 판단: 인물설정, 대비, 풍자 의미를 담당하면 보존(「겨우 23일」에서 「겨우」를 삭제하면 인물설정 강조가 역전됨) |
| 대화 어조 단어 초기화 | 캐릭터별로 자연스러운 저빈도의 "네/밖/아"를 유지하되, 역으로 무리하게 추가하지 않기—인간미는 구조의 자연스러움에서 나오지, 채팅투에서 나오지 않음 |
| 서술 중 공문/문언체 잔여(할 수 없다/반드시/아직/이미/마땅히) | 일상어로 변환(할 수 없다/해야 한다/아직/지금). 시스템 공지, 규칙 조항, 패널 안내는 냉정한 기능성 유지 가능; `system-notice-formality-tic` 경고 시 원래 형식 내에서만 일부 일상어화하되, 서술자의 설명으로 변경하지 않기 |
| 긴 텍스트 내 짧은 서술 구간이 연쇄적(``overcompressed-prose-tic``) | 모든 짧은 구간을 길게 늘이지 않기. 먼저 직접 정독: 짧은 문장 재배치, 밀집된 장면이 문맥상 자연스러우면 유지; 개요처럼 읽히는 과도 문장만 처리해서 같은 장면으로 합치고, 독자가 동작·공간·인과관계를 따라 읽어가도록 하기 |
| Narrative outside quotation marks causes low-connective-density-tic | Do not supplement "의/었/就" globally, do not process natural shortness of dialogue/comments/system messages. First find breakpoints reading like outline/telegraphic style in narrative layer, then restore necessary connectives, anaphoric relations, and medium-long connecting sentences; can retain low-function-word text with medium-long sentence sequences |

자체 검토: 삭제 후 처음부터 읽을 때 개요나 유창한 암송처럼 읽히면 과하게 삭제한 것—비정점 문장을 자연스러운 일상어로 복구하되, 계속 삭제하지 않기.

이 모드는 삭제의 정도를 제약하는 것이지, 정제 강도를 낮추는 것이 아닙니다: 금지어, 상투적 문체, 안내식 심리 묘사는 그대로 삭제 및 수정하며, 모드 1-8과 Gate A-G는 전부 실행합니다. 회복은 구조 허사와 연결만 되돌리며, 템플릿 문구는 보존하지 않고 복구하지 않습니다.

### 모드 10: 이차 수정 가짜 자연스러움 (번들거리는 도치 / 감시 동작 체크리스트 / 대화 지표화)

일부 "반검지 프롬프트"는 텍스트를 다른 템플릿으로 몰아갑니다: 돌발성을 높이려고 무작정 도치하고, 실제감을 위해 기계적으로 실수와 욕설을 더하고, 모바일 열람을 위해 모든 문장을 억지로 줄바꿈하고, 대화 비중을 위해 심리와 서술을 강제로 대사로 바꿉니다. 이런 것들은 자연스러운 네트 소설이 아니라 이차 수정의 흔적입니다.

| 표현 | 수정법 |
|---|---|
| 번들거리는 도치 | "손에 칼을 들고, 그가 돌진했다" 같은 반동작 전치를 쓰지 마세요. 같은 주어가 연속될 때는 장면 내 물체, 소리, 국소 신체 또는 환경 반응으로 자연스럽게 문장 시작을 바꾸는 것을 우선하고, 무생물 의인화를 남용하지 마세요. |
| 감시카메라식 동작 체크리스트 | 같은 문단의 연속된 "손을 뻗어 집어 들고, 가져가고, 들추고, 내려놓고, 몸을 돌리고……" 같은 단계 목록. 사소한 동작을 병합하고, 감정·서사·공간 기능이 있는 동작만 보존; 필요시 인물의 망설임, 오판, 주변인의 반응이나 환경 피드백으로 완화 |
| 고긴장 장면 탈수 | 갈등, 추격, 전투는 설명과 논리적 접착제 삭제 가능; 일상, 모호함, 복선은 장 전체 탈수 불가. 삭제는 폐기, "의/었/그냥/하지만" 등 자연스러운 연결은 아님 |
| 먹음 표현 누락 | AI 제거 후 동사에 목적어가 없거나, 동작 대상이 불명확하거나, 독자가 누가 누구에게 무엇을 했는지 모르면 필요한 목적어, 담지물이나 물리적 피드백을 복구; 중국어는 생략 가능하나 개요처럼 줄여서는 안 됨 |
| 대사의 수치화 | 대사 비중 50%-60% 맞추려고 억지로 대사 확장 금지. 대사는 인물이 실제로 할 말이고, 이 순간 반드시 필요할 때만 증가; 긴 대사는 동작으로 분할 가능, 설명적 대사는 우선 갈등·회피·불완전한 정보로 압축 |
| 하드 포맷 투기 | 매 문장 줄바꿈 강제 금지, 50-60자 일렬 강제 금지, 생략부호를 영문 점으로 변경 금지, `지/득` 전부 잘못 변경 금지. 플랫폼과 프로젝트 기존 포맷 따르기 |

`check-ai-patterns.js`의 `action-list-tic`은 동작 체크리스트만 모니터링하며, 차단(blocking)이 아닙니다. 기능적 싸움/추격/의식 단계의 동작 시퀀스가 정보를 담고 있다면 유지하거나 `[재검토 필요]`로 표시할 수 있습니다. 토마토 고득점 샘플에서 이런 경우의 적중률이 0이므로, 경기 실패 항목이 아닌 "정독 필요한" 스타일 가이드로 활용하기에 적합합니다.

#### 도구 메시지 처리

`check-ai-patterns.js`는 로컬 작문 lint입니다. 차단(blocking)은 확실한 문장 구조/구두점 문제에만 적용되며, 권장사항(advisory)은 완료 조건이 아닙니다. 사용자가 다른 도구 리포트를 제시할 때, 본문에 해당하는 문장 구조·단락·어휘 문제만 구체적인 수정점으로 변환하고, "0% AI / 100% 진정성" 또는 "고정 공식" 같은 표현을 쓰지 않으며, 점수를 중심으로 반복 미세 조정하지 마세요.

도구 메시지는 읽기감 규칙을 초과할 수 없습니다. 참고 텍스트에서 "마치/매우/느껴지다" 같은 상용구나 서술식 심리 표현이 나타나면, 패턴 1-8에 따라 정리하세요. 기계적으로 단어를 채우거나, 의도적 오류나 주제별 템플릿을 적용하지 마세요.

**AI 스타일 제거를 위한 추가 판단**:
- 우선 처리: 저자의 해석·요약, 의미 꼬리, 플롯을 "그는 깨달았다 / 이는 의미한다 / 정말 중요한 것은 / 이번 성장"으로 번역하는 부분을 우선 삭제하거나, 장면 내 동작·대사·물체 상태·작업 상태 및 캐릭터가 그 자리에서 처리해야 할 결과로 되돌리세요.
- 장면 내 매체 우선: 원문에 이미 휴대폰·화면·공지·문패·양식·청구서·증거물·규칙이 있을 때, 캐릭터가 보거나/읽거나/처리하는 텍스트 또는 물체로 보존하세요. 같은 정보를 서술자의 규칙 해설로 다시 쓰지 마세요.
- 구어체이지만 물 타지 않기: 세련된 드라마 반응 표현(두피가 타이트함, 눈꺼풀이 한 번 떨림, 가슴 속이 무거워짐, 배가 뒤집힘)을 연속으로 플롯 진행을 대체하지 마세요. 평범한 동작/평범한 감각을 쓸 수 있으면 평범한 동작/평범한 감각을 쓰고, "의/었/그냥/하지만/이미/그 후/없다" 같은 자연스러운 연결을 보존하세요.
- 주제·문체 우선: 문체 참고는 도움이 되지만, 반드시 목표 주제/본 작품의 문체 지문에서 나와야 합니다. 판롱 톤, 구식 웹소설 톤, 1인칭 목소리 등을 크로스 주제 만능 수정법으로 사용하지 마세요.
- 만능 수정법으로 쓰지 마세요: 단순히 제목 추가·물체 보충·동작 꼬리 보충·문장 길이 조절/압축·줄 세우기/문제 점검/기록체 추가는 구체적인 플롯·시점·언어 문제 처리를 대체할 수 없습니다.

#### 개요 문장을 연속적인 단락으로 작성하기

텍스트에 blocking / 명백한 advisory가 없지만 읽기에 여전히 개요처럼 느껴질 때, 단절된 부분만 처리하세요:

1. 논리 리포트처럼 읽히는 단락을 표시하세요: "그는 알았다/그는 깨달았다/이는 의미한다/진정한 문제/반드시/필요하다" 같은 판단 연쇄가 계속 나타나면서도 현재의 행동, 대상 또는 대화 반응이 부족한 경우입니다.
2. 서술자의 결론을 현실화하세요: "그는 깨달았다/이는 의미한다"를 등장인물이 현재 만질 수 있고, 들을 수 있으며, 처리하도록 강요받는 결과로 대체하세요. 고정된 대상 목록을 적용하지 마세요. 어떤 장면의 껍질을 보편적 규칙처럼 취급하지 마세요.
3. 단절된 부분에서만 자연스러운 연결과 구조 허사를 복원하세요; 비율 목표를 설정하지 마세요. 기계적으로 연결을 보충하지 마세요.
4. 시스템 공지, 규칙 조항, 패널 방송은 냉정하고 짧은 문장으로 유지할 수 있습니다. `system-notice-formality-tic` 경보 시 원래 매체 내에서만 일부 경직된 규칙 용어를 쉬운 말로 바꾸거나 캐릭터가 그 자리에서 구체적인 결과를 보도록 하며, 서술자의 설명으로 바꾸지 마세요.

`overcompressed-prose-tic` / `low-connective-density-tic`의 구체적 수정 방법:

1. 연속된 짧은 서술 단락을 원으로 표시한 후 단락별로 기능을 표기합니다: 반전/반격/공포 반복, 집중된 화면은 계속 짧게 유지 가능; 복선, 공간, 인과관계, 동작 연결은 같은 화면으로 병합해야 합니다. 자연스럽게 읽히면 이 권고사항으로 인해 계속 길어져야 할 이유가 없습니다.
2. When merging, first supplement "action sequence, spatial orientation, causal connection." Example: expressions like "고개를 들 때/문밖에/이미/아직/바로/이미". Do not forcibly insert "의/었/就" into each sentence.
3. 병합 후 반복 표현과 심리 진술을 삭제합니다: 자연스러운 읽힘은 AI식 표현을 복구하는 것이 아니며, "마치/느껴지는/매우/인 것 같은" 같은 표현을 대량으로 다시 추가할 수 없습니다.

검수 처리: `overcompressed-prose-tic` / `low-connective-density-tic`을 제거한 후에도 읽는 느낌이 여전히 어색하면, 국소 미세 조정을 중단하고 단락 수준의 재작성 또는 인공 읽는 느낌 대조로 전환하세요.

예시:

```
과도 압축:
린야오가 고개를 들었다.
우산 덮개 바깥의 가로등이 꺼졌다.
바람도 멈췄다.
계산대 위의 종이컵이 두 번 흔들렸다.

매끄럽게 읽은 후:
린야오가 고개를 들었을 때, 빗막 밖의 가로등이 하나둘 꺼져 가고 있었다. 바람이 갑자기 멈췄고, 계산대 위의 종이컵은 여전히 제 자리에서 살금살금 회전하고 있었다.
```

## 체계적인 AI 제거 3회독법

### Pass 1: 범용 표현 제거(Strip Generic)
- 추상적 감정 요약 문장 → 삭제하거나 구체적 행동으로 대체
- 겉핥기식 심화 문장 → 삭제
- 의미 부풀리기 → 구체적 영향으로 축소
- 공허한 결론 → 삭제
- 정렬된 대비 문장 구조 -> 흩어서 다시 쓰기
- 장식적 형용사 남발 -> 백묘법(간결한 표현)
- "그러므로" "그러나" "이 순간" 과다 사용 -> 절반 삭제하기
- 모든 캐릭터가 똑같이 "고급스럽게" 말하는 문제 -> 말투 구분하기

**원칙**: 삭제할 수 있으면 삭제하고, 삭제할 수 없으면 구체적인 세부 사항으로 대체하세요. 이 단계에서 AI 문체의 80%를 제거할 수 있습니다.

### Pass 2: 서면체 제거하기 (Cut Professional Diction)
- 분석적 용어("메커니즘" "구조" "로직" "체계"가 소설에 나타남) -> 일상 표현으로 바꾸기
- 추상명사 남용 -> 직접 사실을 말하기
- 관료체 용어("더욱" "심화" "추진" "실행") -> 삭제
- 전문 용어 난적 -> 필요한 것만 보존, 쉬운말로 설명

**예외**: 전문성이 필요한 장면(역사 소재의 정식 용어, 문학적 의도의 밀도감, 코미디 과장 수사법)은 유지합니다.

### Pass 3: 자연스러움 회복(Restore Natural Presence)
- 구체적인 감각 세부사항(냄새, 온도, 촉감)
- 인물 말투의 구분(인물마다 다른 톤)
- 문장 시작의 다양화: 연속 3개 이상의 문장이 같은 주어나 같은 품사로 시작할 때는 다르게 구성(행동, 장면, 대사 도입)
- 리듬 변화(장단 문장 교차): 감정 비트, 행동 전개, 드라마 단위에 따라 자연스럽게 문장 길이 조절; 연속된 여러 문단이 같은 길이인 것을 피하고, 짧음을 맞추기 위해 개요처럼 나누는 것도 금지. 장단은 무작위가 아니며, 가라앉는 지점에서는 속도를 늦추고, 갈등/반전 지점에서는 급격히 짧게 하며, 완전한 추론과 감정 흐름을 우선 연결된 상태로 유지
- 사회적 위치감이 드러나는 대사(상급자와 부하의 말투가 다름)
- 장면 고유의 인상적 포인트
- 프로젝트 고유의 언어 습관(캐릭터의 버릇 있는 표현)

**원칙**: 단순함이 최고. 각 문단에 구체적인 세부 사항 1~2개만 더하면 충분.

## AI스러움 제거 보충 기법

### Show vs Tell

| 표현 유형 | AI 표현법 | 자연스러운 표현법 |
|----------|--------|----------|
| 기대감 표현 | "그는 매우 기대했다" | 기대감→감정→만족의 연결고리를 보여주기 |
| 캐릭터 목적 표현 | "그녀는 이혼하고 싶었다" | 행동으로 목적을 보여주기 |
| 캐릭터 태도 표현 | "그녀는 매우 침착했다" | 대사와 반응으로 표현하기 |
| 플롯 진행 알리기 | "곧 큰 일이 일어날 거야" | 복선→반전→지속 전개로 표현 |

### 심리 묘사는 자연스럽게

- 괄호로 내심 표기 = 몰입감 파괴
- 긴 내적 독백으로 동기 설명 = AI 특징
- "그녀는 느꼈다" "그녀는 깨달았다" 직접 표현 = 감정을 알려줌

**자연스러운 표현법**：심리 활동을 서사에 자연스럽게 녹여내되, 행동으로 심리를 암시하고, 침묵/동작/비상적 행동으로 내심을 표현합니다.

### 몰입감 검증
- 주인공의 행동을 독자가 이해하고, 공감하고, 수용할 수 있나요?
- 악역이 충분히 강한가요? (약한 악역 = 독자가 주인공의 승리를 무의미하게 느낌)
- 인물 설정에 맞춰 행동을 구성했나요? (행동/대사/사고가 성격을 중심으로 전개되나요?)
- 독자가 알고 있는 정보가 효과적으로 조작되었는가? (정보 격차로 인한 감정 변동)

## 개작 예시 라이브러리

### 감정 외화 예시

**긴장**
- '그는 긴장감을 느꼈고, 심장이 저도 모르게 빨리 뛰기 시작했다'
- 그는 손에 들린 종이컵을 꼭 쥐었고, 물이 조금 쏟아졌다

**분노**
- '분노가 그의 마음속에서 타올랐고, 그는 자도 모르게 주먹을 쥐었다'
- 그는 젓가락을 탁 테이블에 내려쳤고, 그릇 안의 국물이 튀어나왔다

**슬픔**
- '한 줄기 슬픔이 마음에 밀려왔고, 그녀의 눈에 눈물이 맺혔다'
- 그녀는 고개를 숙여 커피를 저었고, 한참을 저었다

**두려움**
- '공포가 순간 그를 휩쌌고, 그는 한 줄기 전율을 느꼈다'
- 그의 등이 벽에 붙어 있었고, 감히 움직이지 못했다

**실망**
- '그녀는 미묘한 허전함을 느꼈고, 마음이 마치 무언가에 움켜잡힌 듯했다'
- "아."그녀는 휴대폰 화면을 잠금 해제했다

**놀람**
- '그의 동공이 미미하게 수축했고, 명백히 이런 말을 듣게 될 줄은 예상하지 못했다'
- 그는 입을 벌렸다가 아무말도 하지 못했다

### 장면 묘사 예시

**AI식 장면**
- '햇빛이 커튼 틈새로 스며들어 바닥에 얼룩진 그림자를 드리웠다. 공기 중에는 은은한 꽃향기가 퍼져 있고, 마치 온 세상이 고요하고 평화로운 분위기에 잠겨 있는 듯했다.'
- 오후 3시, 거실에는 시계 소리만 들렸다.

**AI 스타일 날씨**
- '하늘이 어두컴컴하고 검은 구름이 가득 찬 가운데, 마치 언제라도 쏟아질 듯한 폭우가 내릴 것 같았다. 매서운 찬바람이 휘몰아치며 뼈를 에는 듯한 한기를 전해왔다.'
- 비가 내릴 것 같다. 바람이 밖에 널어 둔 옷을 흔들어댔다.

**AI 스타일 격투**
- '그의 주먹은 마치 급풍과 소나기처럼 맹렬하게 날아왔으며, 한 번의 타격도 의심의 여지가 없는 힘을 품고 있었다. 상대방의 동공이 미세하게 축소되었고, 분명히 이렇게나 날카로운 공격을 예상하지 못했던 것 같았다.'
- 그가 주먹을 날렸고, 상대는 피하지 못해 입가가 터졌다.

### 결말 개쓰기 예시

**승화식 결말** -> '그는 창문 앞에 서서 멀리 지평선을 바라보며 마침내 인생의 진리를 깨달았다: 때로는 손을 놓는 것이 최선의 선택이다.' -> 그가 담배를 꾸 끝내고 집에 들어가 잤다.

**요약식 결말** -> '이 순간, 모든 것이 변했다. 그녀는 알았다. 이제부터 그녀의 인생은 새로운 페이지를 펼칠 것이다.' -> 그녀는 그 문을 닫았다. 뒤돌아보지 않았다.

**감회식 결말** -> '세월이 흐르는 물처럼 조용히 흘러간다……' -> 이런 단락은 그냥 삭제해라.

### 리듬 조정 예시

> 다음 예시에서 다루는 것은 장황한 수식어, 비유의 중첩, 추상적 요약이지, '길면 무조건 자르기'가 아닙니다. 개작 후에도 서술은 여전히 쉼표 긴 문장을 주로 합니다(규칙 3). 정상적인 쉼표 긴 문장을 짧은 문장들로 쪼개지 마세요.

**병렬 구조 문장**
- '그는 그녀의 눈을 보고, 그녀의 입술을 보고, 미세하게 떨리는 그녀의 속눈썹을 보며, 마음속에 말로 표현할 수 없는 감정이 솟아올랐다.'
- 그는 그녀를 바라봤고, 그녀는 말이 없었다.

**장황한 긴 문장 수식 제거**
- '그가 마침내 무거운 나무 문을 밀어젖혔을 때, 눈에 들어온 것은 어두운 방이었고, 공기 중에는 묵은 냄새가 가득했으며, 벽 모서리에는 먼지가 소복이 내려앉은 상자들이 쌓여 있었다.'
- 그는 나무 문을 밀어젖혔고, 방 안은 어두웠으며, 벽 모서리에 먼지가 소복이 내려앉은 상자 몇 개가 쌓여 있었다.

**정연한 단락 깨기**
- '그녀는 봄의 꽃을 좋아하고, 여름의 햇빛을 좋아하고, 가을의 낙엽을 좋아하고, 겨울의 백설을 좋아한다. 매 계절마다 저마다의 독특한 아름다움이 있다.'
- 그녀는 봄을 좋아하고, 다른 계절도 괜찮다.

## 갈등 대화 개선 사례

### AI식 온화한 대화
- '나는 당신이 이렇게 하는 것이 별로 적절하지 않다고 생각하는데, 제 감정을 한 번 고려해 주시겠어요?' -> "당신의 눈에 나는 더 이상 없나요?"

### AI식 완벽한 설명
- '실은 이렇게 한 데에는 이유가 있었어. 당시 상황이 정말 복잡했거든……' -> "그럼 뭐 어떻게 하겠다고?"라고 그녀는 찻잔을 내려놓으며 말했다.

### 대화 감정 5단계 점진 사례

같은 갈등 장면, 약함에서 강함으로:

1. **객관적 진술**:"넌 내 물건을 버렸잖아."
2. **진술+건의**:"넌 내 물건을 버렸잖아. 앞으로는 먼저 나한테 말해줄 수 있을까."
3. **주관적 비난**："당신이 뭐 하는 거예요, 제 물건을 만져요."
4. **비난+명령**："당신이 뭔데 제 물건을 건드려요? 나가요."
5. **비난+PUA**："제가 먹는 것도 챙겨주고 입는 것도 챙겨줬는데, 물건 하나도 제대로 못 놔둬요. 당신은 이 정도가 고작이야, 저 없이는 아무것도 못 해요."

### 놀라움 계층별 개작 사례

**AI식 일괄 처리**：모두가 놀랐고, 자신의 귀를 믿을 수 없었다.

**자연스러운 계층적 충격**:
1. 맞은편의 남자가 손을 떨었고, 찻잔 속의 물이 흘러내렸다.
2. 옆의 사람들이 서로 눈을 마주쳤고, 누군가는 한 발 물러섰으며, 구석에 있던 누군가는 휴대폰을 꺼내기 시작했다.
3. 방금 전까지 거만하던 여자의 얼굴에 웃음이 굳어 있었다. 그녀가 입을 열었지만, 한 마디도 나오지 않았다.

### 대입감 수정 예시

**수동적 주인공**: 그녀는 매우 두려워했고, 어떻게 해야 할지 몰라서 사건이 지나가기만을 기다릴 수밖에 없었다.

**능동적 주인공**: 그녀는 문을 잠그고, 휴대폰을 무음으로 설정하고, 녹음을 시작했다.

## 품질 검수 체크리스트

각 장을 완성한 후 이 체크리스트에 따라 항목별로 검토하세요:

- [ ] **문단 조절**: 문단이 동작/정보 변화에 따라 끊어져 있고, 읽을 때 자연스럽다
- [ ] **정문에 파선 없음**：정문(서술 및 대사 포함)에 `——`/`—`/`--`이 없음(마침표, 쉼표, 짧은 문장 또는 동작으로 끊음), 대사 예외 설정 없음
- [ ] **AI 고빈도 단어 스캔**：금하다/마치/눈에 띄다/마음속으로 생각하다/낮은 목소리로 말하다/입꼬리가 미세하게 올라가다/자도 모르게/보이다 등의 표현 없음
- [ ] **약화 부사 계수**：1000자당 "미미하게/담담하게/천천히/살짝" 3개 초과 금지
- [ ] **삼연 배비 없음**：AI식 "세 개 한 묶음" 수사 없음
- [ ] **정제된 부정 체크리스트 재검토 완료**：구간을 걸친 「A가 아님 / B도 아님 / 다만 C」 및 기타 `formulaic-parallelism` advisory 항목을 대사와 함께 항목별 재검토 완료, 기능성 수사는 보존 가능
- [ ] **문체 제약 없음**: "쉽게 알 수 있듯이/이로부터 알 수 있듯이/사실상/종합하면" 같은 표현 미사용
- [ ] **서면 연결사 남용 금지**: "그러므로/동시에/그리하여/따라서/물론" 같은 표현 과다 사용 금지
- [ ] **장 끝의 총괄 승화 금지**: 동작/대사/반전으로 마무리하며, 감상/철학/예고 미포함
- [ ] **심리 묘사 대량 금지**: 심리 활동 2문단 이하, 괄호로 표시된 내심 미포함
- [ ] **감정을 동작으로 표현**: 핵심 감정 지점에서 "분노/슬픔/긴장"을 직접 표현하지 말고 신체 반응으로 대체; 저강도 과도 감정은 한 줄로 직서하면 되고 모든 곳에서 외화할 필요 없음
- [ ] **대화 구어체화**：서면체 없이, 역할마다 톤을 구별할 수 있어야 함
- [ ] **마침표 평탄화 금지**：의문·폭발·망설임을 모두 마침표로 압축하지 말 것; 또한 `？`/`！`를 무작정 쌓거나 `……`/`——`로 억지로 멈춤을 만들지 말 것
- [ ] **Show Don't Tell**：형용사 대신 행동으로, 요약 대신 세부 묘사로
- [ ] **문장 길이 기준 충족**：서술은 기본적으로 쉼표 긴 문장（쉼표 사이 8-12자, 전체 문장 20-30자, 규칙 3）; 짧은 문장은 간헐적 강조로만 사용하고 쉼표 긴 문장으로 복귀; ≤5자 단편이 연속하거나 전체가 제목처럼 짧은 문장으로 이루어져서는 안 됨
- [ ] **detector advisory 항목별 재검토**：`micro-action-tic` / `abstract-summary-tic` / `cliche-density-tic` / `metaphor-density-tic` / `reasoning-chain-tic` / `system-notice-formality-tic` / `overcompressed-prose-tic` / `low-connective-density-tic` / `action-list-tic` 명중 시 스크립트의 수정 방법에 따라 처리: 먼저 전체를 읽고 기계적 반복인지 판단하여 실제라면 수정; 기능적 표현은 유지하거나 `[재검토 필요]`로 표시, 동의어 치환이나 기계적 채우기 금지
