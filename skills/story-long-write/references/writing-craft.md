## 1. 신체 디테일로 정서어 대체

### 규칙

핵심 정서 노드에서는 직접 정서어를 쓰는 것을 금지하며, 신체 상태, 물리적 손상, 일상 동작으로 대체；강도가 낮은 과도 정서는 한 마디로 직접 써도 됨（"그는 좀 짜증이 났다"）, 굳이 모든 곳을 외재화할 필요 없음.

### 치환 조작

正文 중 정서어를 스캔하여 하나씩 치환：

| 금지 | 치환 |
|------|--------|
| 심통/심쇄 | 손가락이 살 속을 파고드는 줄 자신도 모름 / 그녀가 찻잔을 내려놓고, 거품을 불어 불었지만, 마시지는 않음 |
| 비애/슬픔 | 그가 외투를 세 번 개어서, 옷장 가장 안쪽 층에 다시 넣음 |
| 분노/화가 떨림 | 그녀 등 위의 핏줄이 하나하나 솟아오름 |
| 무서움/공포 | 그의 손이 문고리에 닿았다가 다시 움추림, 세 번이나 만지고 나서야 잡음 |
| 억울함 | 그녀가 아랫입술을 깨물어, 하얀 자국이 났다가, 떼자마자 금방 붉어짐 |
| 절망 | 그가 거기 앉아, 재가 바지통에 한 소매 떨어져도 털지 않음 |
| 심혈이 죽음 | 그녀가 핸드폰을 뒤집어 탁자에 엎어놓고, 다시는 들지 않음 |

오른쪽 열은 방향만 제시하며, 그대로 베끼는 것을 금지：매번 캐릭터, 장면, 소품에 맞춰 자가 작법을 만들고, 같은 작법은 전서에서 기껏해야 1회만 출현；그대로 베끼거나 재사용하면, 치환 산출물 자체가 새로운 템플릿 지문이 됨.

### 신체 부위 속조

작법：구체적인 부위 + 구체적인 동작/상태를 쓰고, 추상적인 느낌을 쓰지 않음.

| 부위 | 문식 템플릿 |
|------|----------|
| 손/손가락 | 「그녀의 손이 무릎 위에 놓여, 손끝이 치마 주름을 하나하나 꼬집고 있다」 |
| 눈/동공 | 「그의 동공이 한 번 축소됐다가, 곧바로 다시 평온으로 돌아갔다」 |
| 입술 | 「입술이 일직선으로 다물어, 한참 동안 떼지 않았다」 |
| 호흡 | 「그녀가 숨을 한 입 들이마셨다가, 뭔가 말할 것 같았다가, 다시 천천히 내뱉었다」 |
| 등/어깨 | 「그의 등이 곧게 펴져 있다가, 문을 나서고 나서야 축 처졌다」 |
| 흉터/멍 | 「소매가 위로 한 토막 미끄러져, 손목에 둘러진 낡은 흉터가 드러났다」 |

## 2. 관통 소품 시스템（3회 출현 규칙）

### 규칙

각 서사 단위（단편/장편 권）마다 1-2개의 관통 소품을 설계. 각 물건은 반드시 3회 출현해야 하며, 매번 의미가 달라야 함.

### 3회 출현 편성

| 출현 시점 | 기능 | 예시 |
|----------|------|------|
| 제 1 회 출현（앞 1/4） | 초기 의미 수립 | 금빛 자물쇠 = 언니가 준 생일 선물（따뜻함） |
| 제 2 회 출현（중간부 전환） | 의미가 전복됨 | 금빛 자물쇠 = 금으로 싼 구리짜리 가짜（위선） |
| 제 3 회 출현（결말부） | 정서 폭격 | 금빛 자물쇠가 쓰레기통에 던져짐（완전한 결별） |

### 소품 설계 템플릿

이하 템플릿을 기입하여, 设定.md 에 기입：

```
소품：{명칭}
제1회 출현：제{N}절 | {장면} | 의미：{초기 의미}
제2회 출현：제{N}절 | {장면} | 의미：{전환 의미}
제3회 출현：제{N}절 | {장면} | 의미：{결말 의미}
```

### 소품 유형 속조

| 유형 | 특징 | 대표 |
|------|------|------|
| 신물형 | 관계를 담은 상징물 | 금빛 자물쇠（매형이 길 가져다줌）, 나무로 된 조그만 말（황제 동생） |
| 도구형 | 일상적으로 쓰는 기능성 물건 | 채점 본（准며느리）, 장부（20년 늦게 온 것） |
| 흔적형 | 남겨진 신체/환경 흔적 | 손목 낡은 흉터, 벽에 있는 키 눈금 |
| 숫자형 | 관계를 담은 구체적인 금액/연한 | 팔만 위안 청구서, 이십 년, 800 위안 |

## 4. 숫자/금액을 서사 도구로

### 규칙

구체적인 숫자로 모호한 묘사를 대체. 숫자가 정서 무게를 담고, 숫자 변화가 플롯을 추동.

### 조작 지령

| 장면 | 조작 | 예시 |
|------|------|------|
| 무게 수립 | 구체적인 금액/연한으로 「오래」「많다」를 대체 | 「사랑한 지 팔 년」이지 「함께한 지 오래」가 아님 |
| 상해 증가 | 숫자가 차례로 커짐 | 800 → 1000 → 8 만 → 120 만 |
| 반차 폭격 | 극단적으로 부풀렸다가 갑자기 극소값으로 내려감 | 「내 누나가 내가 공부하게 하려고, 팔만 위안을 빚졌어. 내 매형이 나한테 일 위안을 돌려줬어.」 |
| 시간 무게 | 연한으로 정서를 담음 | 「이십 년 만에, 그녀가 처음으로 나를 엄마라 불렀다」 |

### 숫자 서사 템플릿

```
숫자선：
제{N}절 | {숫자1} | 의미：{초기}
제{N}절 | {숫자2} | 의미：{업그레이드}
제{N}절 | {숫자3} | 의미：{폭격/반전}
```

## 5. 일동 일정 리듬

### 규칙

각 소절 내부에서 동작과 고요를 교차. 동한 뒤에는 반드시 고요가 오고, 고요한 뒤에는 동작이 올 수 있음.

### 동과 정의 분류

| 유형 | 내용 | 예시 |
|------|------|------|
| 동 | 물리적 충격, 폭력, 갈등 폭발 | 사람 패기, 물건 던지기, 뺨 때리기, 피 토하기, 상 엎기 |
| 정 | 일상 디테일, 미세한 동작, 고요한 관찰 | 먼지 닦기, 죽 먹이기, 옷 개기, 거품 불기, 옷깃 정리 |

### 조작 지령

- 각 소절은 반드시 ≥ 1 개의 「동」 + ≥ 1 개의 「정」을 포함
- 연속 2 절 전부 「동」인 것을 허용하지 않음（폭력 피로）
- 연속 2 절 전부 「정」인 것을 허용하지 않음（리듬이 늘어짐）
- 정서 최고점（얼굴 때리기/반전/폭로）에는 「동」을 사용
- 정서 최저점（심사망/여운/석연）에는 「정」을 사용

### 리듬 편성 예시

```
절5（동）：소연이 명령 하나로, 소랑에게 스무 대의 곤장을 때림
절6（정）：소연이 쪼그려 앉아, 아들身上의 먼지를 조금씩 닦아내고, 옷깃을 정리함
절7（동）：왕씨가 달려들어, 땅에 무릎 꿇고 절함
절8（정）：소연은 그녀를 보지 않고, 아들을 안고 일어나, 걸어감
```

## 6. 도입부 사건 밀도

### 규칙

앞 100 자는 반드시 ≥ 3 개의 사건을 포함. 배경 깔지 않고, 곧바로 사건 연쇄를 제시.

### 조작 지령

- 모든 도입부 배경 소개를 삭제（「고대 XX 연간에」「그녀는 XX한 소녀였다」）
- 제 1 문장이 바로 사건이지, 묘사가 아님
- 사건 밀도 검사：앞 100 자에 몇 개의 독립적인 「일어난 일」이 있는지 셈

### 사건 밀도 예시

```
❌ 저밀도（1 건/100 자）：
「심지는 심家의 적녀이며, 어려서부터 총명하여, 부친의 총애를 깊이 받았다. 이날, 그녀는 성지 한 통을 받았다.」

✅ 고밀도（4 건/50 자）：
「소연이 조정에 돌아온 날, 모후는 이미 죽었고, 아들은 황제 동생에게 바보가 되도록 맞았으며, 그는 칼을 들고 곧바로 궁에 들어갔다.」
（조정 귀환 → 모후 사망 → 아들 학대 → 사람 패기, 4 건의 사건）
```

밀도는 한 단락에 몇 건의 일이 일어나는지를 가리키는 것이지, 한 건의 일을 한 문장 한 문장 쪼개어 끊는 것이 아님；위 예시는 쉼표로 네 건의 일을 한 문장으로 이었으며, 그대로 고밀도임.

### 밀도 검사 템플릿

도입부를 쓴 뒤, 앞 100 자의 사건 목록을 나열：

```
사건1：{사건}
사건2：{사건}
사건3：{사건}
（만약 나열한 것이 < 3 개라면, 도입부를 재작성）
```

## 7. 소절 밀도 진단

### 규칙

한 소절을 썼는데 짧은 느낌이 들면, 이하 진단 목록으로 점검. 글자 수 채우려고 묘사를 추가하지 말 것.

### 진단 목록

소절을 썼는데 짧은가？순서대로 검사：

| 검사항 | 짧은 원인 | 구제 |
|--------|----------|------|
| 하위 사건 3차원을 모두 녹여넣었는가？ | 동작만 있고 감각 앵커포인트와 신체 반응이 없음 | 감각 디테일과 신체 동작을 녹여넣기（제8절 참조） |
| 대화가 1-2 회밖에 없음？ | 대화 교차가 부족함 | 권력 게임 대화를 한 회 추가（제3절 참조） |
| 정서어（심통/비애/분노）가 있음？ | 추상 정서어를 씀 | 신체 디테일로 치환（제1절 참조） |
| 3차원 녹여넣은 뒤에도 여전히 짧음？ | 대화나 회상이 부족함 | 대화를 한 회 추가（제3절）하거나 간략한 회상 추가（제7절 확장 규칙） |

### 하위 사건이 부족할 때 어떻게 확장할 것인가

outline 을 쓸 때 하위 사건이 부족한가？이하 순서로 선택：

```
IF 주 사건이 갈등/대항 → 「방해」 추가：주인공이 중간에 방해받거나 저지당함
IF 주 사건이 조연을 수반 → 「반응」 추가：조연의 예상 밖 반응
IF 주 사건이 공간 이동이 있음 → 「발견」 추가：이동 도중 새로운 단서 발견
IF 주 사건이 회상을 촉발 → 「플래시백」 추가：2-3 문장의 간략한 회상을 삽입
IF 주 사건이 연쇄 동작임 → 「점층」 추가：동작이 유발한 연쇄 반응
```

### 임무 카포："일本来 막힐 것"일 때만 사용

임무 카포는 절차를 길게 쓰는 것도 아니고, 자연스러워 보이게 하려는 것도 아님；그것은 캐릭터가 구체적인 일을 이루려 할 때 잠시 막히게 하고, 막힘으로써 변화를 만들어내는 것임.

판단문：캐릭터가 본래 이 일을 하려던 참 → 이 단계에서 막힘 → 캐릭터가 선택/대가를 치름 → 막힘으로써 정보, 관계, 대가, 선택 또는 복선 변화가 생김.

사용 가능한 시기：
- 주 사건이 대항：카포가 상대의 권력, 규칙 허점 또는 숨겨진 뒷수를 폭로.
- 주 사건이 실증：카포가 새로운 증거, 새로운 증인 또는 새로운 정보차를 밀어냄.
- 주 사건이 관계 추진：카포가 캐릭터에게 표명, 도움, 거절 또는 배신을 강요.
- 주 사건이 저압 과도：카포는 가벼운 저항력으로만 쓰여, 관계, 복선 또는 생활 질감에 복무하며, 주제를 넘보지 않음.

지워보고 시험：지운 뒤 정보, 정서, 관계, 대가 또는 복선 손실이 없다면, 유용한 카포가 아님；자연스러워 보이려고 절차를 보충하거나 글자 수 채우려 하지 말 것.

### 반 주입 규칙

이하 행위를 금지：
- 글자 수 채우려고 환경 묘사 추가（"창밖으로 햇살이 화사하다"）
- 글자 수 채우려고 이미 표현한 정서를 반복
- 글자 수 채우려고 캐릭터 내면 독백 요약 추가
- 글자 수 채우려고 캐릭터가 무의미한 동작을 하게 함
- 자연스러워 보이려고 절차 디테일을 추가；지워도 손실 없으면 지울 것
- 글자 수 채우려고 정서어로 신체 디테일을 대체（반대로 해야 맞음）

## 8. 장면 작법（3차원 녹여넣기）

### 细纲에서 正文로：규격을 장면으로 연기하지, 형태를 그대로 베끼지 않음

细纲 각 필드는 본장에서 "무슨 일이 일어날 것인가"에 대한 규격이지, **正文의 형태가 아님**. 细纲의 형태를 따라 한 칸 한 칸 채우면, 正文은 한 줄 한 줄交代하는 전보체, 한 박자 한 마디 평탄하게 밀어붙이는 딱딱한 해설이 된다——이것은 "大纲 형태를 그대로 베끼는 것"이며, 범례 형태를 그대로 베끼는 것과 함께 AI 맛의 근원이다.

- 플롯 포인트 시퀀스는 "무슨 일이 일어날 것인가"의 목록이지, 문장 템플릿이 아님：한 플롯 포인트를 한 문장이나 한 단락으로 쓰고, 순서대로 평탄하게 밀어붙이지 말 것；각 포인트를 캐릭터가 지금 당장 감지할 수 있는 동작, 대화, 소품과 신체 반응으로 연기할 것——**연기해서 보여주지,交代해서 알려주지 말 것**.
- 동일한 제약이 「핵심 사건 / 내용 개괄 / 플롯 편성 / 플롯 포인트」에 중복 출현할 경우, 생성 전에 **하나의 의미 포인트**로만 합병；중복 필드는 강조가 아니며, 더더욱 네 번 되풀이하여复述하는 할당량이 아님. 正文은 提纲에서 되풀이 출현하는 동일한 문구를 따라 항목별로交代해서는 안 됨.
- 5단식（발단/전개/전환/고조/결말）은 细纲 저자를 위한 기능 분해이지, 正文의 5개 자연 단락이 아님；正文은 반드시 단락별로 순서대로 서술할 필요도 없고, 한 단락이 한 칸에 대응할 필요도 없음.
- "누가 무엇을 했는가"의 개괄문, "A→B→C" 화살표 연쇄, "어떤 상태로 수습되는가"는 기획 구경이므로, 그대로 서술에 옮겨 쓰지 말 것.
- 플롯 포인트 사이에는 합병, 삽입, 재배열이 가능하며, 인접한 포인트를 같은 연속 장면에 짜넣을 수 있음；밀도가 높은 포인트는 슬로우 모션으로 전개하고, 밀도가 낮은 포인트는 넘기고 지나감（「소밀 배분」참조）.
- 장미는 마지막 구체적인 동작, 화면, 대사 또는 현안에 떨어뜨림；细纲「결말 설정/수습 상태」는 기획 구경이므로, 正文에서 "이렇게……""그는 드디어 깨달았다……"식의 상태 총결문으로 쓰지 말 것（결말에서 승화시키는 것은 anti-ai-writing.md 참조）.

### 시각 자세：심도 제한 지각（땅에 붙어 몰입）

3차원을 녹여넣기 전에, 먼저 서술 자세를 정함. 기본값으로 주 시점 캐릭터의 "지금 당장의 지각"을 고정——그가 지금 보고, 듣고, 맡고, 신체로 느끼고, 뇌리에 스치는 것만 씀. 이 한 조항은 동시에 두 가지 가장 완고한 AI 맛을 해결：대입감 부족, 그리고 "작가가 현존하는" 듯한 훈계/신적 내음.

- **렌즈를 멀리 당기지 않고, 부감하지 않으며, 타인의 내면으로 자르지 않음**："홀 전체가 적막에 빠졌다"这类 카메라 시점을 쓰지 말고, "그녀는 자신의 심장 박동 소리를 들었는데, 옆의 숨 소리가 싹 사라졌다"를 쓸 것.
- **독자는 캐릭터와 동기에 정보를 얻음**：캐릭터가 모르는 것은 쓰지 않음；미리 스포일러하지 않고, 배경을 보충하지 않음. 현안은 "그녀도 모른다"에서 오며, 미리 스포일러하는 문장을 금지, 예를 들어 "그녀가 모르는 것은"这类.
- **생각은 동작의 일부임**：심리는 "섬광 + 신체"로 제시——반 문장의, 끼어들려다 끊긴, 정서 편견이 담긴 주관적 판단으로, 정리된 내면 독백을 완성해서 쓰지 않음.
- **주관적 편차가 객관적 서술을 대체**：장면이 캐릭터 정서에 물듦. 그녀가 누군가를 미워하면, 그 누구는 가증스럽게 묘사됨；그녀가 당황하면, 빛이 흔들림. 중립적인, 누가 봐도 같은 묘사를 쓰지 않음. 다만 그녀가 지금 당장 편견을 가진 순간적인 느낌일 수는 있어도, "마치 이미 정해진 일을 선고하는 듯한"这类 객관적인 관 단정을 써서는 안 됨（그것은 작가가 나서서 정성 내리는 것이며, anti-ai-writing.md 모드 8 참조）.

심도 제한 지각은 "자연스럽게 AI를 제거"하는 근본：렌즈를 캐릭터 신체 속에 못 박아 두면, 작가는 뛰쳐나와 설명하고, 총결하고, 안배할 자리가 없어짐（anti-ai-writing.md 모드 8 와 배합）.

### 문풍 지문：소재에 따라 cadence 를 빌려, 만능 어조를 끼워 맞추지 않음

소재마다 실제 문풍의 cadence 가 독감에 영향을 줌；유효한 작법이 다름. 남빈/군사 소설은 구 웹소설의 연속 서사 관성을 빌릴 수 있고, 현대 일상물은 보통 임무 추진을 쓸 수 있음；서스펜스/미스터리, 공상과학(SF), 고대물은 억지로 반포반 용, 구 웹소설 용 또는 1인칭 어조를 끼워 맞추지 말고, 먼저 본서 `设定/文风.md`, 대상/벤치마크 작품 분석과 매치 장 요약을 읽을 것.

落地 순서：먼저 본장 정서와 소재 문풍에 따라 술술 쓴 뒤, 해설 총결, 과도한 압축과 비유 더미를 처리；문장을 기계적으로 길게/짧게 만들지 말 것, 또한 전역적으로 어떤 대상/벤치마크 서의 어휘법으로 치환하지 말 것.

### 규칙

각 하위 사건은 한 문장으로 끝나는 것이 아니라, 세 가지 차원을 포함해야 한다：무슨 일이 일어났는가, 주인공이 무엇을 주목했는가, 신체가 어떻게 응답했는가. 세 가지 차원을 동시에 같은 단락의 연속된 正文에 녹여넣어, 차원별로 단락을 나누어 쓰지 않음.

### 3차원 녹여넣기 규칙

상세히 쓰는 하위 사건은 ≥100-150 자：세 가지 차원이 각기 다른 정보（발생, 지각, 반응）를 담고, 같은 단락에 짜넣어, 따로따로 쓰지 않음. 하지만 모든 하위 사건을 꽉 채워 쓰는 것은 아님——과도, 길 안내, 정보交代类 하위 사건은 1-2 문장으로 넘기고 지나가면 됨（「소밀 배분」참조）, 정서 노드에 글자 수 예산을 양보할 것.

| 차원 | 내용 | 요점 |
|---|---|---|
| 발생 | 일이 나타났다 | 1-2문장, 하나의 구체적인 디테일을 포함 |
| 지각 | 주인공이 무엇을 주목했는가 | 적어도 1개의 감각 디테일（시각+촉각/청각/후각）, 하나의 소품 또는 하나의 신체 부위에 초점 |
| 반응 | 신체가 어떻게 응답했는가 | 구체적인 신체 동작（손/눈/호흡/자세）, 한 마디의 극히 짧은 심리 정착을 포함할 수 있음 |

임무 카포 작법도 마찬가지로 3차원에 따라 녹여넣기：발생 = 일이 잘 안 풀림；지각 = 반송된 종이, 걸린 소품, 멈춘 동작, 상대의 반 문장 등 구체적인 증거；반응 = 캐릭터가 전략을 바꾸고, 대가를 치르고, 도움을 구하고, 억지로 밀어붙이고, 양보하거나 한 수 적어둠. "왜 막혔는가"를 한 단락의 설명서로 해석하지 말 것, 또한 scene 말미에 따로 동작 꼬리를 붙여 의미를 설명하지 말 것.

### 반모드：더미식 묘사（절대 금지）

세 가지 차원을 세 단락으로 나누어 차례로 쓰는 것은, AI 가 가장 흔히 남기는 작작 흔적임. 독자는 같은 동작이 세 번으로 나뉘어 쓰이는 것을 보게 된다：

> ❌ **더미식（오류）**：
> 임 부는 고개를 숙이고, 왼손으로 문서를 누르며, 오른손으로 붓을 들어, 종이에 내려놓았다.
>
> 손이 떨고 있었다.
>
> 팔꿈치부터 손목까지 온통 떨려서, 붓끝이 종이 위에서 잠시 멎었다가, 한 획을 썼다가 또 멎고, 그 "임" 자의 뺄을 잘못 썼다. 그는 잠시 멎었다가, 붓을 아래로 눌러 다시 썼고, 다 썼는데도 붓이 손에서 여전히 안정되지 않았다.

→ 한 가지 일을 발생→지각→반응 세 단락으로 써, 같은 동작을 세 번으로 나눔

### 정확한 작법：녹여넣기식

세 가지 차원을 같은 단락의 연속된 正文에 녹여 넣어, 독자는 하나의 완전한 순간을 읽게 된다：

> ✅ **녹여넣기식（정확）**：
> 임 부는 왼손으로 문서를 누르고, 오른손으로 붓을 들어 종이에 내려놓았는데, 붓끝이 종이에 닿자마자 빗나갔고, 팔꿈치부터 손목까지 멈추지 않고 떨려서, 그 한 획이 비스듬히 끌려나갔다. 그는 잠시 멎었다가 붓을 아래로 눌러 다시 썼는데, 다 쓴 "임" 자의 뺄은 비뚤어졌고, 붓은 손에서 여전히 안정되지 않았다.

→ 발생, 지각, 반응이 한 단락에 동시에 제시되어, 독자는 연속된 한 화면을 보게 된다

### 자가 검사 방법

한 단락을 쓴 뒤, "세 손가락 가리개법"으로 검사：발생 정보, 지각 정보, 반응 정보를 각각 가려 보아, 각 차원마다 내용이 있는지 확인. 어떤 차원이 결여되면, 대응하는 디테일을 같은 렌즈 속으로 다시 짜넣을 것, 뒤에서 따로 단락을 일으켜 보충하여 쓰지 말 것.

### 화면 분단（한 단락으로 끝까지 가는 것을 방지）

3차원 녹여넣기는 한 하위 사건을 한 긴 단락에 처넣는 것이 아님. 녹여넣기는 "동일한 순간이 발생/지각/반응 세 단락으로 나뉘는 것"의 문제를 해결；분단은 "휴대폰 독해 시 한 단락이 너무 밀집되는 것"의 문제를 해결.

분단은 렌즈/정보 변화에 따르지, 차원 변화에 따르지 않음：

| 트리거 포인트 | 분단 방식 |
|---|---|
| 새로운 동작 시작 | 단락을 새로 일으켜, 독자가 다음 박자를 보게 함 |
| 새로운 소품/단서 출현 | 단락을 새로 일으켜, 이 정보를 단독으로 담음 |
| 캐릭터 시선 전이 | 단락을 새로 일으켜, 렌즈 전환을 형성 |
| 직접 인용 출현 | 대화는 독립하여 단락을 이룸 |
| 심리 정착/판단이 내려짐 | 한 문장이 단락을 이루게 하여, 정지를 만들 수 있음 |

판정 규칙：

- 한 단락은 오직 하나의 렌즈 촬영 포인트/하나의 동작 단위, 또는 아직 끝나지 않은 연속된 추리, 분위기, 정서 연쇄만 담음.
- 통상 서술 단락은 짧을 수는 있으나, 문장 내부가 부스러져서는 안 됨——서술문은 한 동작 한 마침표로, 문장마다 끊어지지 않게（서술은 기본적으로 쉼표가 있는 긴 문장, anti-ai-writing.md 규칙 3 상세 참조）；세밀한 묘사, 추리 판단, 분위기 압박, 정서 침전은 조금 길어져도, 여전히 같은 일을 이야기하는 전제 하에 그렇게 할 수 있음.
- 길이는 단지 진단일 뿐, 강제적인 임계값이 아님：읽기에 혼잡하고, 여러 개의 동작/정보/시선 전환을 포함할 때에만 나눔；완전한 드라마 단위가 끝나지 않았을 때 짧게 맞추려고 억지로 나누지 말 것.
- 통상 正文은 짧은 단락, 조금 긴 단락, 대화, 동작 단락을 교대로 유지；고압 갈등, 얼굴 때리기, 반전 단락은 더 부스러지고 짧을 수 있음.
- 연속하여 여러 단락이 같은 길이인 것을 하지 말 것, 또한 하나의 완전한 추리 연쇄를 기계적인 파편으로 자르지 말 것.

출력 전에 반드시 한 차례 자연스러운 리듬 재배열을 할 것：

1. 각 자연 단락을 스캔；먼저 "이 단락이 오직 한 가지 일/하나의 렌즈/하나의 추리 또는 정서 연쇄만 완수하는가"를 물어볼 것. 그렇다면 보존하고, 글자 수만으로 따로 나누지 않음.
2. 만약 같은 단락에서 새로운 동작, 새로운 소품, 새로운 정보, 새로운 대화, 시선 전이, 장면 종료가 나타나면, 이 위치들에서 분단할 것.
3. 만약 연속하여 여러 개의 극단적으로 짧은 단락이 여전히 같은 렌즈/같은 일에 속한다면, 인접한 문장들을 합병하여, 提纲이나 시행처럼 부스러지는 것을 피할 것.
4. 만약 한 긴 문장을 낭독하면 끊김이 생기거나 정보 과부하가 되면, 먼저 수식을 삭제하거나 문장을 나눌 것；문장을 나눈 뒤에도 같은 단락의 드라마 단위 완전성을 유지할 것.

### 주어와 이름 리듬（"주어 과밀" 방지）

주인공명/캐릭터명은 「주어 리셋」과 「강조」 기능을 담당하지, 매 문장마다 라벨을 붙이는 기능을 담당하지 않음：

- 단두, 장면 전환, 다인 동장, 시각 리셋 시, 주인공명으로 주어를 수립.
- 동일한 동작 연쇄/같은 단락 내부에서는, 우선 "그/그녀", 동작 접속 또는 주어 생략을 사용하여 문장이 자연스럽게 흐르게 할 것.
- 핵심 전환, 정서 폭발점, 신분 반차, 독자가 주인공을 다시 붙잡아야 할 때, 다시 이름을 대고 강화할 것.
- 역전 신호：연속하여 여러 문장 또는 연속하여 여러 단락이 모두 같은 주인공명으로 시작하나, 중간에 주어 혼동, 장면 전환 또는 강조 필요가 없는 경우.
- 전장 이름 출현 횟수로 기계적으로 심판하지 않음；최종 기준은 읽었을 때 "매 문장마다 이름을 대는" 듯한 끊김이 있는지 없는지임.

잘못된 수법：짧게 하려고, 하나의 완전한 추리/분위기 연쇄를 여러 단락으로 자름；주어를 아끼려고, 다인 동장을 지시 불명료하게 씀.

정확한 수법：같은 일의 연속성을 보존하고, 새로운 동작, 새로운 소품, 새로운 정보, 새로운 대화에서 끊음；단두에서 이름을 대어 주어를 수립하고, 단중에서는 대명사/생략으로 흐르게 하며, 핵심 전환에서 다시 이름을 대어 강조할 것.

### 소밀 배분（상략이 고르지 않음）

모든 beat 를 같은 길이, 같은 세밀함으로 쓰지 말 것——평균적으로 힘을 쓰는 것은 AI 투의 근원이며, 읽었을 때 "어디나 꽉 차 있으나, 어디도 돋보이지 않는" 이유이기도 함. 플롯 가중치에 따라 필묵을 배분：

| beat 유형 | 필묵 | 작법 |
|---|---|---|
| 쾌감점/얼굴 때리기/반전/정서 고조 | 밀（상세히 씀） | 지각, 동작, 대화 교차를 가득 채워, 슬로우 모션으로 한 박자 한 박자 전개 |
| 과도/길 안내/정보交代/시간 도약 | 소（약술） | 1-2 문장으로 넘기고 지나가며, 심지어 한 문장으로 개괄하여 3차원을 전개하지 않음 |
| 복선/일상/관계 승온 | 중 | 대입감 있는 디테일 한두 개를 골라 실사로 쓰고, 나머지는 약술 |

원칙：한 장에서 상세히 쓰는 beat 는 정서 노드에 집중하고, 과도는 단호하게 압축. 독자가 기억하는 것은 밀处의 화면이며, 소处는 그들을 단지 다음 쾌감점으로 빨리 보낼 뿐임. 밀도에 기복이 있어야, 리듬에 호흡이 있음.

### 하위 사건 연결

하위 사건 사이에는 신체 동작으로 연결하고, 서술 과도로 연결하지 않음. 연결 동작 ~20자：

- ❌ "그리고 나는 다음 페이지를 넘겼다."
- ✅ "나는 장부를 무릎 위에 얹어, 손바닥에 얇은 땀 한 층이 났다."

### 지각 소재고

| 장면 유형 | 사용 가능한 지각 디테일 |
|---|---|
| 열독/넘김 | 글씨의 짙고 옅음, 종이 촉감, 먹이 번짐, 모서리가 구부러짐 |
| 대화 장면 | 상대 표정 변화, 어조 정지, 공기 속의 침묵 |
| 회상 장면 | 화면 중의 어떤 디테일이 갑자기 선명해짐（냄새/소리/촉각） |
| 실내 장면 | 빛 변화, 물건의 위치, 온도 |
| 이동 장면 | 발걸음 소리, 지면의 촉감, 바람의 방향 |

### 3차원의 경계

- ✓ 지각은 주인공이 능동적으로 주목한 디테일（주의력의 초점이 있음）
- ✓ 반응은 구체적인 신체 동작（손, 눈, 호흡, 자세）
- ✗ 지각은 장식적인 장면 묘사일 수 없음（"햇살이 창틀에 쏟아진다"）
- ✗ 반응은 정서어일 수 없음（"마음이 칼로 베이는 듯하다"）
- ✗ 세 가지 차원이 동일한 정보를 중복하여 표현할 수 없음

## 9. 어조 문보 계보（문보는 어조를 따라감）

### 규칙

문보는 어조, 권력 관계와 정서 박자를 담당하며, 장식으로 쓰여서는 안 됨. 正文를 쓸 때 먼저 "이 문장이 장면에서 무엇을 하는가"를 판단한 뒤, 마침표, 쉼표, 물음표, 느낌표, 쌍점 또는 개행/동작 beat 중 무엇을 쓸지 결정；더 이상 줄임표와 파선으로 정지를 만들지 않음.

### 문보 계보

| 어조 / 기능 | 사용 가능한 문보 | 조작 지령 | 금기 |
|---|---|---|---|
| 압박 / 냉정 / 절제 | 마침표, 쉼표, 쌍점, 짧은 문장 | 동요 없는 진술로 압박하고, 쌍점으로 판단을 내림；적게 설명 | 「변화가 있으려고」 함부로 `！` 를 더하지 말 것 |
| 질문 / 시험 / 반문 | 물음표, 짧은 후속 문장, 동작 정지 | 핵심 질문에는 `？` 를 쓰고, 추궁은 짧은 문장을 독립하여 행에 세울 수 있음 | 연속 5 문장 전부 `？` 를 쓰지 말 것 |
| 놀람 / 폭발 / 얼굴 때리기 | 소량의 느낌표, 단문 성단 | 오직 정서 피크에서 1 개의 `！` 만 쓰고, 폭발점 전후에는 짧은 문장으로 접속 | `!!!` 와 단락 전체의 고함을 금지 |
| 망설임 / 끝내지 못함 / 가슴 졸임 | 쉼표, 마침표, 짧은 문장, 삼키기/손 멈춤 등 동작 | 동작 또는 문장 길이 변화로 정지를 만듦；필요시 짧은 문장을 새로 일으킴 | `……` 로 정지를 대체하지 말 것 |
| 가로막힘 / 소리가 길어짐 | 동작 가로막기, 개행, 짧은 문장, 미완성 동작 | 「그가 손을 들어 그녀의 말을 가로막았다.」这类 동작으로 끊음 | 正文와 대화 모두 `——`/`—`/`--` 를 쓰지 않음 |
| 정보 폭로 / 판단 낙하 | 쌍점, 세미콜론, 짧은 문장 | 「증거는 하나뿐：문쇄가 안에서 걸려 있었다.」쌍점으로 낙하를 만들 수 있음 | 논문식의 긴 세미콜론 연쇄를 쓰지 말 것 |

### 집행 절차

1. 본 장면 목표 정서와 캐릭터 성선을 읽고, 각 핵심 대화 beat 에 한 부류의 어조（압박/시험/폭발/망설/가로막힘）를 표기할 것.
2. 정밀 수정 시 문말을 한 바퀴 스캔：만약 한 단락이 마침표밖에 남지 않는다면, 질문, 망설임, 폭발점을 눌러 평탄하게 만들었는지 검사；만약 온통 `？`/`！` 라면, 기능이 있는 위치만 남기고 삭제할 것.
3. 正文（대화 포함）의 `……`、`——`、`—`、`--` 를 모두 마침표, 쉼표, 짧은 문장, 개행 또는 동작 단어로 고칠 것. 즈후 옌옌(知乎盐言) `「」` 는 그저 인용부호 스타일일 뿐, 물음표, 느낌표의 합법 사용에 영향을 주지 않음.
