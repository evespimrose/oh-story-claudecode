## 3층 라벨 대비 인설법

### 3층 구조

| 계층 | 이름 | 의미 | 예시 |
|------|------|------|------|
| 1계층 | 신분 태그 | 외부에서 보는 신분 | 명문가의 버려진 아내 |
| 2계층 | 표현 태그 | 캐릭터가 외부에 보여주는 행동 | 참고 표현하지 않음, 순순히 따름 |
| 3계층 | 핵심 태그 | 캐릭터의 진정한 내심 | 냉정함, 계획성, 신중한 진행 |

### 실행 지시

1. 캐릭터의 3계층 태그를 작성하세요. 각 계층 간에 반드시 대비를 만들어야 합니다—대비 = 입체감
2. 신분 태그와 표현 태그는 유사할 수 있지만(고정관념을 강화), 핵심 태그는 반드시 역전되어야 합니다
3. 역전이 클수록 캐릭터의 "정체 공개 순간"이 더 임팩트 있습니다
4. 중요한 모든 캐릭터는 최소한 한 단계의 역전을 가져야 합니다
5. 행동 대비로 역전을 드러내세요. 직접 설명하지 마세요:

```
신분 태그: 재벌 버려진 아내
표면 행동: 욕을 먹어도 대응하지 않고, 쫓겨나도 저항하지 않음
핵심 행동: 몰래 녹음하고, 증거를 수집하고, 미리 재산을 이전함
```

## 삼층 태그 행동 반차 심화

관계가 제3층(친밀한 관계)으로 진입한 후, 역할은 제1, 2층 관계에서 할 수 있던 행동을 오히려 할 수 없게 된다.

| 관계 단계 | 가능한 행동 | 불가능한 행동 |
|----------|---------|-----------|
| 정체성 태그 기간(낯설음) | 장난스러움, 냉담함, 거리 유지 | — |
| 표현 태그 기간(친숙함) | 이전의 행동 패턴 지속 | — |
| 핵심 태그 기간(친밀함) | 진정한 자아 노출 | 이전의 장난스러움/냉담함은 오히려 더 이상 할 수 없음 |

### 실행 지침

1. 현재 캐릭터가 어느 관계 단계에 있는지 확인
2. 행동의 대비는 그 자체로 인물 설정의 일부이며, 반드시 스토리에 반영해야 합니다
3. "행동 퇴화 = 감정 심화"로 긴장감을 조성하세요. 초반에는 신분 꼬리표처럼 주인공을 놀리던 발칙한 여성이 친밀해진 후에는 오히려 고백을 못하게 됩니다
4. 친밀한 단계에서도 초반 행동을 유지하게 하면 안 됩니다. 그렇지 않으면 대비 효과가 사라집니다

## 인물 설정 관련성 계층화(강/중/약 관련성)

| 계층 | 정의 | 기능 | 수량 요구사항 |
|------|------|------|---------|
| 강관련 | 플롯 진행과 핵심 설정에 직접 영향을 미치는 설정 | 인물 충돌, 플롯 진행 추동 | 각 캐릭터당 최소 3개 |
| 중관련 | 조역의 강관련 설정, 주인공 역할을 빼앗을 수 없음 | 조역에 기능성과 식별성 제공 | 적절한 양 |
| 약관련 | 인물 깊이를 풍부하게 하는 개인 선호도 설정 | 캐릭터 사실감과 기억점 증가 | 제한 없음 |

### 실행 지시

1. 주인공의 실력, 자금, 인맥, 배경 등 플롯 진행에 영향을 미치는 속성을 강관련으로 분류
2. 강한 연관성이 각 캐릭터마다 최소 3개 이상 있는지 확인하세요
3. "케이크 먹기를 좋아함", "미녀 보기를 즐김" 등을 약한 연관성으로 분류하여 인설을 풍부하게 할 때만 사용하세요
4. 약한 연관성이 주객이 전도되지 않도록 주의하세요——강한 연관성이 스토리 확장의 핵심입니다

## 인설 실행 규칙

인설 ≠ 인물 설정표입니다.

- 인물 설정표 = 키, 외모, 가정 배경 등 정보의 나열（외적 정보）
- 인설 = 캐릭터의 "영혼/독특한 성격"을 중심으로 전개되는 기능적 설계
- 인설의 사명: 드라마 긴장감과 감정 변화에 기여하기, 성격이 행동을 주도하도록 하며 스토리에 의해 억지로 밀려나지 않기

**검토**: 작성한 인물 설정이 키, 체중, 취미만 있고 "영혼/독특한 성격"의 기능적 설계가 없다면 다시 작성하세요.

## 조연 기능화 설계

### 핵심 원칙

1. 조연의 능력과 특질은 반드시 스토리와 밀접하게 연관되어야 한다
2. 조연은 주인공을 돋보이게 하기 위해 쓰인다 — 조연의 능력은 주인공이 사용하고, 조연이 어려움에서 벗어나는 것은 주인공의 도움에 의존한다

### 복합형 조연 — 화이트글러브 역할

| 기능 | 설명 |
|------|------|
| 주인공을 대신해 말하기 | 주인공이 말하기 부적절한 말은 자신이 대신 말한다 |
| 주인공을 대신해 강경하게 나서기 | 주인공이 강경하게 나서면 안 되는 일은 자신이 나선다 |
| 절대적 옹호 | 주인공의 이익을 침해하는 자에게 단호히 맞서 반격한다 |
| 거친 듯하면서도 섬세함 | 반파의 음모를 녹음해 재생하여 대중의 지지를 얻는다 |
| 적절한 유머 | 지속적으로 긍정적 피드백을 제공하여 긴장감을 완화한다 |

**설계 원칙**: 후광 역할은 주인공보다 약간 약하게, 목을 내세우지 않기; 인상적인 등장; 주인공에 대한 의문에 즉시 반박하기.

### 입체적 인물 vs 평면적 인물

1. 모든 역할을 입체화할 필요는 없으며, 먼저 기능성을 살피기
2. 평면적 인물은 신비성을 유지하며, 오히려 더 공포스럽거나 강력해 보임
3. "악역을 선하게 표현하면 약해지고, 흑화하면 강해진다"——고수가 입체화되면 약해짐
4. 필요한 도구를 설계하되, 모든 캐릭터를 입체적으로 만들려고 하지 마세요

### 인설 대비 육차원 방법

| 대비 쌍 | 활용 |
|--------|------|
| 외적 성격 vs 내적 성격 | 웃는 호랑이/독설가의 착한 마음 |
| 외모 vs 외적 성격 | 흉한 외모 실제론 부드러움 |
| 외모 vs 내면 성격 | 보기엔 부드럽지만 실제론 냉정함 |
| 신분 vs 생활 방식 | 부잣집 자제가 지하실에 산다 |
| 신분 vs 취미 특기 | 살인청부인이 꽃꽂이에 능하다 |
| 신분 vs 내면 성격 | 군인이 내심으로 예술을 사랑한다 |

### 실행 지침

1. 조연을 설계할 때는 먼저 그 역할을 정하세요(주인공을 대신해 말하기/위력 드러내기/웃기기/정보 제공)
2. 6가지 차원의 대비 중 1-2개를 선택해 조연에 라벨을 붙이세요
3. 조연의 카리스마를 조절하되 주인공을 초과하지 마세요
4. 기능적 조연은 무리해서 입체화하지 마세요

## 조연 인물 설정 논리

1. "정극 역쓰기"——겉으로는 긍정적인 행동 뒤에 반파 동기가 숨어 있음
2. 조연의 감정 보호막: 겉으로는 냉담하고 무정해 보이지만, 실은 깊은 감정 동기가 있음
3. 인설 붕괴 방지: 캐릭터의 행동 선택은 반드시 이미 확립된 인설 논리와 일치해야 함
4. 먼저 소재의 "대표 인물"을 직접 사용——성숙한 소재의 인설 캐릭터들은 모두 시장 검증을 거친 것들임

## 인설을 돋보이게 하는 방법

### 실행 지침

1. 핵심을 강조하기—캐릭터의 가장 두드러진 특질을 찾아 집중적으로 표현하기
2. 행동으로 인물설정을 표현하기, 나레이션으로 설명하지 않기(예: 출소 후 당당함, 이익 추구, 노련함 표현)
3. 대비 충돌로 긴장감 만들기
4. 대비로 긴장감을 만들면 독자를 선별하니, 정도를 조절하기—대비가 너무 크면 일부 독자가 이탈함

---

## 높은 정서지능/똑똑한 인물 장면 작법

### 실행 지침

1. 높은 정서지능은 구체적인 극정에서의 표현으로 드러내되, 방백으로 칭찬하지 마세요
2. 말투를 살피고 그 자리에서 대응하며 분위기를 주도하고 말을 받아치는 구체적인 장면을 작성하세요
3. 높은 정서지능 표현은 고전 네트워크 소설의 성공 사례 패턴을 참고하되, 각 장면마다 최소한 하나의 "독자가 예상하는 어색함을 주인공이 화해"하는 반전을 포함하세요
4. 각 구간마다 최소한 하나의 "반전"이 있어야 한다——독자가 어색할 거라고 예상했는데 결과적으로 주인공이 완벽하게 극복한다

---

## 조역을 기대 지점으로 활용하기(인물 후킹)

### 실행 지시

1. 한 명의 조역을 "임무 기지"로 선정한다——한 인물이 동시에 여러 단기 및 장기 기대를 담당한다
2. 주인공이 매번 사건을 해결하고 멋을 낸 후 그 인물을 찾아가서 새로운 라운드의 멋 내기를 시작한다
3. 각 스토리 단원이 끝난 후 동일한 인물을 활용하여 새로운 스토리 전개
4. 인물이 하선할 때 더 큰 이익을 가져오며, "우연히 예상 외의 수확을 얻음"으로 독자의 "손실 회피" 심리 전환

## 군상 쓰기법

### 실행 지침

1. 각 역할의 등장마다 기능이 있어야 하며 불필요한 부분이 없음—기능이 명확하지 않은 역할은 등장시키지 말 것
2. 캐릭터 간의 관계는 계층적이어야 합니다(길잡이, 대적자, 동료, 장애물)
3. 서로 다른 캐릭터는 고유한 말투와 행동 특성을 가져야 합니다
4. 방백이 아닌 행동을 통해 캐릭터의 특점을 표현하세요

### 조연의 전형화된 묘사

1. 1~2개의 두드러진 특징을 포착하여 명확한 라벨을 만듭니다(버릇/상징적 행동/극단적 성격)
2. 태그화하면 독자가 빠르게 기억할 수 있으며, 지면을 과하게 차지하지 않습니다.
3. 기능성 조연은 명확한 역할을 가져야 합니다: 플롯 진행, 주인공 부각, 정보 제공

### 캐릭터 사용의 리듬

1. 인기 캐릭터의 등장 빈도는 3~5장마다 한 번 정도로 조절하여 기대감을 유지하면서 미각 피로를 피합니다. 매 등장마다 새로운 정보나 새로운 역할이 있어야 합니다.
2. 독자가 관심 없는 캐릭터라면 과감하게 제거하고 자연스럽게 "퇴장"시킵니다.
3. "캐릭터로 캐릭터를 끌어오기"로 새 캐릭터 도입하기——호감도 연장

### 캐릭터 풀 직조법

1. 캐릭터로 캐릭터를 끌어오기: 여주 호감도 → 여주 부모/언니/친구 쓰기 → 호감도를 새 캐릭터로 연장
2. 그물처럼 계속 직조하기 → 곧 고갈되지 않는 캐릭터 풀 확보
3. 새 캐릭터마다 라벨을 붙이기, 각각 개성 있게

## 인물설정 심화법

### 실행 규칙

먼저 현재 프로젝트가 "스토리 심화"에 적합한지 "인물설정 심화"에 적합한지 판단하세요:

| 조건 | 우선 방향 | 실행 동작 |
|------|------|------|
| 주선이 이미 복잡하고, 다중 세력, 다중 반전 | 인물설정 심화 | 스토리 구조는 단순하게 유지하고, 인물의 욕망, 반차, 관계 상호작용에서 신선감을 만들어내기 |
| 주선이 너무 직선적이고 인물은 명확하지만 사건 부족 | 스토리 심화 | 방해 요소, 목표 변화, 정보 차이 또는 대가 추가, 기능 없는 역할 신규 추가 금지 |
| 단편/경량 분량 | 인설 심화 | 1-2개의 강한 인설 태그로 갈등 유도, 대규모 세계관 구축 금지 |
| 장편 핵심 권/클라이맥스 권 | 두 가지 결합 | 스토리를 한 차원 상향, 동시에 주요 인물 관계 변화 시각화 |

### 실행 단계

1. 단순하거나 심지어 진부한 스토리 구조 하나 선택
2. 인물에 "드라마성"을 더하기——목표 독자가 재미를 찾을 수 있는 설정
3. 여러 인물의 상호작용 순환을 통해 지속되는 스토리 생성하기

### 순환 쓰기법(하나의 간단한 줄거리를 5장 이상으로 작성 가능)

- 제1장: 주인공 자랑 → 사부가 더 긴박해짐
- 제2장: 사부가 여생을 괴롭힘 → 연인이 협박과 회유를 돕기
- 제3장: 여자가 주인공에게 접근 → 연인이 몰래 쾌재를 누림
- 제4장: 여자가 돌아와 울며 호소 → 연인이 겉으로는 위로하면서 몰래 쾌재를 누림
- 제5장: 복명하여 상을 받음 → 여자가 연인이 상에 그리 기뻐하지 않음을 발견

## 인물 조성 기법

### 여성 캐릭터 조성(남성향)

1. 독자가 좋아하는 것은 여주인공의 태그(고귀하고 우아함, 피부 하얀 긴 다리)이지, 외모 묘사가 아니다
2. 고정관념을 활용하라: 흡혈귀=고귀하고 우아함+뛰어난 외모이므로, 특별히 묘사하지 않아도 독자는 안다
3. 웹소설에서 미모는 가장 저렴한 자원이다——외모 묘사에 많은 지면을 할애하지 말 것
4. 성격 설정을 극단화할 수 있다: 츤데레의 극치, 주인공을 깊게 사랑함, 자신의 이익을 고려하지 않음
5. 성격 일관성을 유지하라: 설정 후 언행이 항상 일치해야 함

### 주인공은 실수할 수 있지만 그 정도를 파악해야 합니다

| 용서할 수 있는 것 | 용서할 수 없는 것 |
|--------|---------|
| 불가항력이나 정보 격차로 인한 실수 | 어리석음이나 성모심 범람으로 인한 실수 |
| — | 실력과 어울리지 않는 실수(투제 강자가 소인물처럼 어리석게 행동) |

### 주인공의 인설 내외 반차

1. 표면과 내심의 대비를 설계할 수 있습니다(예: 표면상 쾌활하지만 실제로는 내성적인 성격).
2. 대비감은 인물의 깊이와 흥미를 증가시키며, 풍부한 플롯 갈등 가능성을 제공합니다.

### 반파의 본질

반파 = 주인공과 입장이 다르고 이해관계가 충돌하는 인물입니다. 반파에게 자신만의 생각과 추구를 부여하되, 순수한 악을 표현하지 마세요.

### 나쁜 인물 설정 작성법

1. 시작부터 명확하게 주인공의 인물설정을 전달하고, 시간 이동 전후로 일관성 유지
2. "이중잣대"를 피하기 — 앞에서 주인공이 색광이라고 묘사하지 않았는데 나중에 갑자기 여성 독자를 쫓아다니면 반감 유발
3. 명확한 인물설정 = 이런 유형의 인물을 받아들이는 독자 선별 = 기대치 관리

## 직장 사고방식으로 웹소설 관계 구조 이해하기

### 실행 규칙

웹소설의 본질: 한 "직장"에서 통쾌함을 느낀 후, 다른 "직장"에서 다시 통쾌함을 느낀다.

### 공통점과 차이점

| 공통점 차원 | 설명 |
|---------|------|
| 계층 | 모든 환경에서 상하 관계가 존재함 |
| 상호 보조 | 동급 간의 협력과 상호 이익 |
| 상호 해치기 | 동급 간의 경쟁과 견제 |

| 차이 차원 | 설명 |
|---------|------|
| 협력 방식 | 환경에 따라 협력 모델이 다름 |
| 자원 유형 | 다양한 환경에서 경쟁하는 자원이 다름 |
| 개인 능력 | 주인공의 독특한 장점 |

### 실행 단계

1. 주인공을 위해 "직장 환경"(학교/종파/회사/군대)을 설계합니다
2. 계층 관계 설정(상급자/동급자/하급자/대적자)
3. 계층 관계를 활용하여 자연스럽게 모순과 갈등을 만들기
4. 주인공이 이 환경에서 충분히 만족한 후, 더 큰 "직장"으로 이동

## 몰입감 구축법

### 실행 규칙

- 몰입감 유지 규칙: 리듬과 감정 연결고리가 끊기지 않아야 함. 단절 신호 = 독자가 현실 논리로 플롯을 평가하기 시작
- 독자가 현실 논리로 판단하기 시작하면 = 리듬에 문제가 생긴 것
- 핵심은 감정 연쇄가 끊기지 않는 것

### 실행 방법

| 방법 | 하는 법 | 효과 |
|------|------|------|
| 공감 진입점 | 일상생활에서 흔히 볼 수 있는 사건 활용 | 순간에 거리를 좁힘 |
| 세부 사실성 | 일상적 세부사항 채우기 | 세계관 사실성 강화 |
| 고양이 구하기 장면 | 도입부에서 주인공의 특정 측면을 강조하는 장면 | 독자가 빠르게 친숙해지고 대입 |
| 공감 전제 | 캐릭터의 진정한 모습(약점/곤경) 노출 | 독자의 보호욕 유발 |
| 합리화 고민점 | "돈이 부족하다" 같이 누구나 아는 곤경 | 자연스러운 공감 |

### 공감 3단계

1. **표층 공감**: 유사한 경험
2. **심층 공감**: 유사한 감정
3. **동감**: 가치관 일치

### 대입감을 해치는 행동(피할 것)

- 캐릭터가 독자가 이해할 수 없는 선택을 하는 경우
- 긴 설정 설명이 이야기 흐름을 방해함
- 느린 템포로 인한 감정 연결 끊김
- 주인공의 가치관이 목표 독자층과 심각하게 어긋남

## 안정감과 핵심 감정 제어

1. 장르에 따라 독자가 요구하는 안정감이 다르므로, 먼저 장르를 확인하세요
2. 극도 장르 등 긴장감 소재: 안정감 폭발 = 위기감 소실 = 핵심 감정 이동——주인공에게 과도하게 강한 후원자를 주지 마세요
3. 주인공에게 언제든 위기를 해결할 수 있는 강력한 후원자를 설정하는 것 금지——후원자의 존재는 반드시 긴급함을 약화시키지 않아야 합니다. 이 규칙을 위반할 때 "후원자 과다"로 표시하세요
4. 인력이 제한적일 때, 플롯은 항상 첫 번째 우선순위이고, 세계관은 단지 가산 항목일 뿐입니다
