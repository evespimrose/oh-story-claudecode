## 업그레이드 감 3단계 설계법

### 1단계: 출발점 정리

주인공의 현재 신분, 계층, 지위, 자원 등을나열한다.

### 2단계: 도착점 정리

해당 권/단계가 끝났을 때의 획득과 향상 내용을나열한다.

### 3단계: 감정 격차를 역으로 설정

| 획득하는 것 | 깔아놓는 것 |
|------------|-------------|
| 핵심 소지품 | 조역(조연)이 희소성을 강조 + 타인이 얻지 못함 + 효과 시연 |
| 지위 상승 | 그 지위가 주는 권력 강조 + 등급별 대우 차이 부각 |
| 인물의 도움 | 해당 인물의 가치를 드러냄 + 타인의 태도 변화 제시 |

### 업그레이드 순환 중첩

도전 A 던전 → B 도구 획득 → C 목적 달성 → 업그레이드 → 도전 D 던전.

핵심: 항상 업그레이드 중이거나 업그레이드를 준비하는 상태. 업그레이드 후에는 이전에 못하던 일을 해낼 수 있어야 한다.

### 다각도 대조 강화

| 대조 요소 | 업그레이드 전 | 업그레이드 후 |
|----------|---------------|---------------|
| 수치/전투력 | 평A 300 데미지 | 평A 650 데미지 |
| 스킬 수 | 다 쓰면 도망가야 함 | 두 번째 스킬이 있음 |
| 랭킹/지위 | 아무도 신경 안 씀 | 사람이 먼저 찾아옴 |
| 사회적 태도 | 조롱받음 | 박수와 감탄 |
| 자원 획득 | 힘들게 재료 모음 | 고가치 정보가 알아서 들어옴 |

### 업그레이드 표현 구체 기법

업그레이드 전후 깔아놓기:
- 업그레이드 전: 미승인 상태의 대우 차이, 자원 획득의 어려움 등을 깔아놓는다.
- 업그레이드 후: 전력, 대우, 대인관계, 자원 획득 등 여러 측면에서 변화를 보여준다.

업그레이드 횟수 관리: 주인공의 업그레이드는 가급적 3회 이내가 좋다. 횟수보다 질적 향상을 우선한다.

즉시 피드백과 지연 피드백:

| 피드백 유형 | 역할 | 예시 |
|------------|------|------|
| 즉시 피드백 | 매 행동마다 작은 보상으로 동기 유지 | 몬스터 드랍 |
| 지연 피드백 | 일정량 축적 후 대형 보상 폭발 | 경험치 만레벨 업 |

업그레이드와 현실 개념 연관: 일상적인 비유일수록 이해가 쉽다 — 호흡이 강해짐, 잠을 자서 강해짐, 자손을 많이 둬서 강해짐 등.

업그레이드 후 서사를 길게 쓰는 세 가지 방식:

| 방식 | 방법 |
|------|------|
| 지도 확장 | 힘체계 상한을 늘리고, 다층 세계를 도입 |
| 등급 압축 + 복잡화 | 하나의 승급 목표를 세 개의 이야기 분량으로 분해 |
| 서사 핵심 전환 | '업그레이드 쓰기'에서 '인물 서술'로 전환 — 조연 라인과 서브플롯으로 확장 |

## 감정 모듈 시스템

### 추출 계층

| 계층 | 명칭 | 내용 |
|------|------|------|
| 제0계층 | 구체적 이야기 | 원문 그대로의 사건 |
| 제1계층 | 고전적 이야기 줄거리 | 묘사 제거, 핵심 소재만 보존 |
| 제2계층 | 이야기 구조 | 모든 소재 제거, 논리적 흐름만 남김 |
| 제3계층 | 극적 단위 | 극적 요소의 추상화 — 대략적 극성(드라마성) |
| 제4계층 | 감정 모듈 | 독자가 보고 싶어하는 감정적 욕구의 추상화 |

### 극적 단위 vs 감정 모듈

| 차원 | 극적 단위 | 감정 모듈 |
|------|-----------|----------|
| 본질 | 극적 논리 구조를 구성 | 독자가 보고 싶어 하는 감정적 요구 |
| 마모성 | 반복되면 마모된다(같은 구조 여러 번 쓰면 식상) | 마모되지 않음(영웅이 미인을 구하는 구조는 시대 불문) |
| 예시 | 「오해→충돌→반전」 같은 흐름의 골격 | 「독자가 보고 싶어하는 타격/반전」 같은 요구 |

한 문장 판단: 흐름도를 그릴 수 있는 것은 극적 단위, 「독자가 ~를 보고 싶다」로 쓸 수 있는 것은 감정 모듈이다.

### 사용 방식

1. 재구성 사용: 소재는 유지한 채 이야기 구조를 수정한다. 장편(수십만~백만자)에서 필수적으로 숙지.
2. 미세조정 사용: 고전적 줄거리를 그대로 사용하되 인물성격을 깊게 파고 미세 조정한다. 단편에 적합.

## 자주 쓰는 감정 모듈 공식

### 영웅 구원

```
관계는 보통 혹은 악화 + 위기 발생 + 위기 해소 + 관계의 질적 변화
```

핵심: 관계의 질적 변화가 주는 쾌감. 인물 관계의 긍정적 전환 지점에 모두 적용 가능.
- 직업/성장선 중심: 금손(금손 능력) 과시를 강조
- 연애선 중심: 관계 변화 자체를 강조

### 허세 연출 (허세 연출)

```
억압/조롱(선택) + 능력 시연 + 격차 형성 + 충격
```

핵심: 격차 — 전후 반전의 차이 + 평행 대조로 보강.

다섯 패턴: 대조를 통한 효과, 허세로 타격, 자기 부정 + 타인의 찬사, 타인의 부정 + 역으로 제압, 타인의 손을 빌림.

### 작은 투자로 큰 수확 (작은 투자로 큰 수확)

```
작은 비용 + 물에 빠진 생선 같은 환경(유리한 기회) + 큰 수확 획득
```

핵심: '좋은 손해' 심리. 비용 대비 보상의 배율이 클수록 쾌감이 강함. 과정에 우연성 + 주인공의 주관적 능동성을 병치.

### 무명에서 가치 창출 (무명에서 가치 창출)

```
저평가된 물건/인물 + 주인공의 개조(변형) + 가치 창출
```

### 통찰로 진실을 밝힘

```
주인공은 가치를 알고 있음 + 대중은 무시 + 주인공만 아는 정보 + 진실 공개 + 대중의 충격
```

### 엉뚱한 적중

```
보물의 중요성 암시 + 주인공이 잘못된 방향으로 노력 + 우연히 보물 획득 + 대중 충격
```

### 소년 열혈

```
주인공 그룹이 강력하고 혹독한 환경 직면 + 불가능함을 알면서도 돌진 + 고난 돌파
```

### 위기 속 임무 수락

```
현장의 능력 초과 위기 + 조역이 모든 수단을 다 써도 해결 불가 + 주인공이 떠맡아 완수
```

### 감정 모듈 조합

| 조합 | 효과 |
|------|------|
| 작은 투자로 큰 수확 + 영웅 구원 | 이중의 쾌감 |
| 무명에서 가치 창출 + 허세 연출 | 먼저 억제하고 나중에 폭발 |
| 소년 열혈 + 신기한 도구가 주인을 인정함 | 고전적 조합 |
| 위기 속 임무 수락 + 허세 연출 + 영웅 구원 | 위기 속 능력 발휘 묘사 |

## 장면과 리듬의 구조화 설계

### 장면의 표준 4장 구조

300만자 ≈ 40–50개 유닛 → 유닛 당 4–5개 장면 → 장면 당 약 4장.

4장 1장면 표준 구조:

| 장 | 기능 | 요점 |
|----|------|------|
| 제1장 상 | 몰입: 일상 + 익숙한 인물 상호작용 | N+1 원칙 |
| 제1장 하 | 정보 차이: 적/곤란 노출 | 컷 전환으로 제시 |
| 제2장 | 긴장 증폭: 조역 반응 | 엔딩에서 주인공이 허세를 시작하게 |
| 제3장 | 이행: 쾌감을 충분히 쓰기 | 가장 잘 써야 하는 장 |
| 제4장 | 연결·전환 | 마무리 혹은 다음 목표 개시 |

범위 내 우선 원칙: 먼저 콘텐츠의 범위를 정하고, 책 전체를 그 범위(핵심 판매 포인트 관련) 내에서만 쓴다.

### 클라이맥스 리듬의 철칙

- 대클라이맥스: 7–10일 내 완료(일 2회 업데이트 / 약 14장). 10일 초과하면 독자 반감.
- 소클라이맥스: 약 3일 내 완료.
- 클라이맥스 후: 1–2장 일상으로의 완충.

### 단계 연결의 세 가지 해법

1. 클라이맥스 중에 훅(Hook) 심기: 이전 클라이맥스 확산 중 다음 구간의 훅을 놓기.
2. 꼬리에서 목표 제공: 한 구간 끝에 주인공의 다음 목표를 명확히 제시.
3. 연속적 작은 기대: 전환 장에서 계속 작은 훅을 던지기.

## 클라이맥스 분류와 역추적

### 클라이맥스의 두 대분류

1. 현실 클라이맥스(사회적 화제): 도로 분노, 불륜, 집단 괴롭힘 등. 그대로 복제하지 말고 감정을 극한으로 증폭시킬 것. 보통 도입부나 서비스 플랫폼 상위 노출 시점에 배치.
2. 작품 클라이맥스(8종):

| 분류 | 전형 |
|------|------|
| 감정 공감 | 열혈, 감정의 기복, 연애 |
| 육감 충격 | 대형 판타지 연출, 공포 비주얼 |
| 충돌 폭발 | 권력 쟁탈, 배신과 이권 다툼 |
| 업그레이드 수확 | 경지 돌파, 장비 획득 |
| 반전 충격 | 허세 타격, 신분 폭로 |
| 고지능 해독 | 서스펜스 추리, 계략 해명 |
| 괴기 기괴 | 규칙이 뒤틀린 괴담, 크툴루류 |

### 클라이맥스 역추적 4요소

클라이맥스를 정하면 역으로 설계:
1. 인물
2. 배경
3. 스토리라인
4. 감정의 전개(3번과 4번은 반드시 결합)

## 도입(오프닝) 공식

### 황금 5장 공식

| 장 | 내용 | 기능 |
|----|------|------|
| 제1장 | 이세계/배경/인물성격/금손 능력/욕망 설정 | 기본 인지 구축 |
| 제2장 | 주선 명확화 | 핵심 제시 |
| 제3장 | 금손 능력의 강함 시연 | 금손 운용 전개 |
| 제4장 | 원한 유발/정·반대 세력 설정/정보 차이/깔아놓기 | 기대감 끌어올리기 |
| 제5장 | 허세 성공/새 사건 촉발 | 첫 쾌감의 완결 루프 |

### 도입 간소화법

1. 도입에서 첫 번째 1차 구조의 갈등을 정리한다.
2. 소개형·서정형 문장을 하나씩 위로 연결해 — 가능한 바로 갈등과 직접 연결되게 시도한다.
3. 여러 층의 논리를 거쳐서야 연결되는 문장 → 무효 정보, 삭제.
4. 이후에 역할이 없는 조역에는 이름을 주지 않는다.

### 도입 리듬의 최소선

| 요구 | 기준 |
|------|------|
| 쾌감/기대 포인트 등장 | 1000자 이내에 보이기 |
| 전투 | 제1장에서 바로부터 전투를 열지 않기 |
| 연애 대상 | 첫 번째 1차 구조 내에서 등장을 보장 |
| 금손 능력 시연 | 첫 갈등을 금손으로 해결하게 하고, 주인공이 사용을 선택하게 함 |

## 기대 단절 진단과 복구

### 네 가지 근본 원인

| 원인 | 독자 느낌 |
|------|----------|
| 만족 지연 과다 | "도대체 언제 시원해질까?" |
| 맵(무대) 전환 처리 부적절 | "기대하던 게 다 사라졌네" |
| 핵심 떡밥 반복도 과다 | "또 이거야? 지루하다" |
| 쾌감 만족감 부족 | "이게 다야?" |

### 기대 지속 원칙

핵심 공식: 기대 유도 속도 > 기대 단절 속도

1. 현재 목표 완료 전에 다음 목표의 실마리를 미리 깔아라.
2. 현재 기대를 충족시킨 뒤 즉시 새 기대를 제시하라.
3. 핵심 떡밥과 관계없는 서브플롯은 과감히 자르라.
4. 주인공의 목표를 항상 명확히 유지하라.
5. 동일 핵심 떡밥은 차별화를 두어 반복하라.

### 기대 공백기 응급처치

| 수단 | 조치 |
|------|------|
| 빌런 시점 전환 | 빌런의 행동을 보여 정보차를 만든다 |
| 돌발 사건 | 계획에 없던 사건을 강제로 끼워 넣는다 |
| 조역 레버리지 | 조역의 위기를 이용해 긴급감 재생산 |
| 초과 수확 | 예측을 훨씬 초과한 추가 보상 제시 |

## 판매 포인트와 독자 요구 매칭

### 판매 포인트 이탈론

추락의 근본 원인은 흔히 '판매 포인트의 이탈' — 쾌감이 실제로 충족하는 욕구와 독자가 보고 싶어하는 것이 어긋나 있음.

요구 항목 목록: 삼대 정(가족·연애·우정), 대인물 환상(큰 인물이 됨), 무노동 획득 환상, 존중/인정/이해, 악을 벌하고 선을 세움, 공정성, 우월감, 모험 욕구, 호기심, 성장, 수확, 폭력적 카타르시스, 안전감, 신선함, 향수, 보상적 회복 등.

폭발 작법: 하나의 욕구를 잡아 놓고 끝까지 놓지 않는다.

### 판매 포인트의 이중 구조론

- 작품 장르의 판매 포인트: 왜 독자가 이 장르를 읽는가?
- 이 책의 판매 포인트: 왜 독자가 '이 책'을 읽는가?

자가 점검: 쾌감이 다른 장르의 판매 포인트에 기울어졌다면 = 주제 이탈.

## 전투 시스템 설계

### 턴제 카드 사고

매 턴 보통 한 장의 '카드'만 사용 가능. '콤보'를 낼 때도 독자가 처음 보는 카드는 최대 한 장만 허용.

### 강약 대결의 비용효율

| 대결 유형 | 난도 | 효과 | 사용 규칙 |
|----------|------|------|-----------|
| 강이 약을 때리기 | 쉬움 | 좋음 | 자주 사용 |
| 약이 강을 이기기 | 쓰기 어려움 | 설득력 필요 | 적게 사용 |
| 강대강 대결 | 가장 어려움 | 최고 효과 | 하나의 중대한 이야기 내에서 최대 한 번 |

### 전력 설정 규칙

- 높은 등급은 지위 고위 혹은 영향력이 큼을 의미.
- 고등급 전투는 반드시 '서사적 스케일'을 써야 한다.
- 큰 경지 차이를 넘는 전투는 합리적 이유가 필요하다.

## 지략 구성(세 단계·두 축법 — 세 단계·두 축 법)

1. 적은 3단계 계획을 세운다(목표 → 수단 → 타임라인).
2. 주인공은 자신의 계획을 갖는다.
3. 양측의 계획이 서로 얽힌다.

얽힘 방식: 자원 쟁탈, 이익 위협, 간접 충돌.

지략의 요점: 적도 관찰에 따라 계획을 조정한다. 정보차로 적을 오판하게 만든다.

## 창작 보조 방법

### 개작법

1. 목표 갈등 유형을 정하고, 플롯 원형 라이브러리에서 검색.
2. 일치하는 플롯을 세부 개요로 쪼개 왼쪽에 배치하고, 자신의 상황을 오른쪽에 배치해 점별로 개작.
3. 개작 후 감정 목표 충족 여부, 주선과의 연결성, 논리적 허점 유무를 검증.

### 팬픽·파생형 대강법

읽기 → 자료 수집 → 정보 추출(고급스러움과 극단적 감정 중점) → 파생 창작(분해·융합).

### 삼중 반복 순환법

- 보이는 점의 반복: 독자가 보고 싶어하는 포인트를 고정해서 반복. 경계: 동일 보상 감정이 3회 이상 무차별 반복될 경우 차별화 필요.
- 인물의 반복: 동일 행위를 다른 장면에서 반복.
- 루틴의 반복: 기본 템플릿은 유지하되 장면만 바꿈.

### 극간결 개요법

업그레이드 체계 자체를 개요로 삼는다. 각 권 = 하나의 관문: 입장 조건 → 핵심 도전 → 보스전 → 통과 보상.

## 품질 점검 체크리스트

구간의 리듬 설계를 마친 뒤 항목별 점검:

- [ ] 업그레이드 감: 출발점과 도착점이 명확한가? 감정 격차가 적절히 깔려 있는가?
- [ ] 업그레이드 순환: "항상 업그레이드 중이거나 업그레이드를 준비"하는 흐름인가? 업그레이드 후 이전에 못하던 일을 보여주는가?
- [ ] 대조 전시: 업그레이드 전후 최소 3개 이상의 차원에서 대조가 있는가?
- [ ] 감정 모듈: 현재 장면의 감정 모듈이 명확한가? 공식이 완전하게 작동하는가?
- [ ] 장면 구조: 4장 1장면의 체인(몰입 → 정보차 → 긴장 → 이행 → 연결)이 완전한가?
- [ ] 클라이맥스 리듬: 대클라이맥스가 7–10일 내 제어되는가? 소클라이맥스가 약 3일로 제어되는가? 클라이맥스 후 일상 완충이 있는가?
- [ ] 단계 연결: 클라이맥스 종료 후 훅을 심었거나 새 목표를 제시했는가?
- [ ] 도입 점검(해당 시): 전 5장이 황금 5장 조건을 만족하는가? 1000자 이내에 쾌감/기대 포인트가 드러나는가?
- [ ] 기대감: 기대 유도 속도가 기대 단절 속도보다 빠른가? 처리되지 않은 기대 공백기가 존재하는가?
- [ ] 판매 포인트 일관성: 쾌감이 충족하는 요구가 책의 판매 포인트와 일치하는가? 다른 장르의 판매 포인트로 이탈하지 않았는가?
- [ ] 전투/지략(해당 시): 대결 유형 선택이 합리적인가? 지략에 정보차와 계획 얽힘이 있는가?
- [ ] 반복 경계: 동일 보상 감정의 무차별 반복이 3회 초과하는가? 조정이 필요한가?
