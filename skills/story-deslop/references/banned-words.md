## 최우선 금지 문식(나오면 즉시 수정)

웹소설에서 가장 치명적인 AI식 문장입니다. 한 번 습관이 들면 반복되므로 Gate A 1차 검사에서 반드시 탐지해야 합니다.

| 위험도 | 문식 | 잘못된 예 | 수정 방향 |
|------|------|------|------|
| ★★★★★ | "不是A，（而）是B" / "不是A，不是B，（而）是C"("而"는 생략 가능하며 생략해도 탐지) | "他不是冷漠，而是绝望" | B를 직접 쓰거나 더 자연스럽게 표현 |
| ★★★☆☆ | 단락을 가로지르는 「不是A。/也不是B。/只是C。」 | 「不是嚎啕大哭。/也不是扯着嗓子喊不舍。/只是一个人走远了……」 | 의미를 재검토. 개요 반복이나 장면 지연이면 C로 압축하고, 변명·긴장 배제 기능이 있으면 보존 가능 |
| ★★★★ | "，带着……" 만능 부사어 | "他笑了一下，带着一丝不易察觉的嘲讽" | 부사어를 삭제하고 주절만 남기거나 구체적인 행동으로 교체 |
| ★★★★ | 감정 없는 목소리: "声音不大，却带着……" / "语气毫无波澜" / "平静无波" / "声音平直/平平/听不出情绪" | "她声音不大，却带着不容置疑的力量" | 대사의 내용, 목소리의 특성 또는 행동을 직접 씀 |
| ★★★★ | "他/她知道……" | "他知道这一切都来不及了" | 행동으로 인식을 보여 줌 |
| ★★★ | "仿佛/犹如/宛若……一般" | "仿佛能穿透一切一般" | 삭제하거나 백묘로 전환 |
| ★★★ | "眼中闪过一丝……" / "嘴角勾起一抹……" | "眼中闪过一丝悲伤" | 他垂下眼 / 他嘴角一扯 |
| ★★★ | "心中涌起一股……" / "心头一震" | "心中涌起一股暖流" | 신체 반응으로 표현 |
| ★★★ | 추상적인 운명·시작·수렴: "命运……棋局/獠牙" / "这一刻终于明白" / "反击才刚刚开始" | "命运终于露出獠牙；属于他的反击才刚刚开始" | 캐릭터가 지금 볼 수 있는 문서, 행동, 대화 또는 물리적 결과로 되돌림 |
| ★★ | 장 끝 예고 "他不知道的是……" | "他不知道的是，更大的风暴即将来临" | 구체적인 훅 물건·사건으로 닫고 공허한 예고를 피함 |

> ★★★★★가 한 번이라도 나오면 AI 문체가 짙다는 강한 증거로 간주합니다. ★★★★가 2개 이상이면 중간 강도 재검사를 실행합니다.

`check-ai-patterns.js`의 `formulaic-parallelism`은 「至于X不X，怎么X」와 동일 동사의 「不V A，不V B」도 안내합니다. 이 두 유형은 기능성 구어일 수 있으므로 advisory로만 처리합니다. Gate B에서는 대사와 함께 문맥을 재검토하고, 세부 개요나 앞 문장의 반복이면 한 번의 판단으로 압축합니다. 훅 면제를 이유로 대사 검사를 건너뛰지 않습니다.

**문장 부호**: 본문(서술과 대화 포함)에서는 대시 `——`/`—`, 이중 하이픈 `--`, 줄임표식 멈춤을 금지하고 마침표·쉼표·짧은 문장·행동으로 끊습니다. 대화의 대시 예외는 두지 않습니다. 염언체의 「」 인용부호는 이 규칙에 포함되지 않습니다.

## 1급 금지어(나오면 즉시 교체)

> 1급은 실제 사람 글에서는 거의 나오지 않고 AI 문체에 특유한 표현만 수록합니다. 실제 사용 빈도가 높은 자연스러운 부사와 허사는 1급에 넣지 않고 2급 밀도 관리로 보냅니다.

### 양태류
仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约、毫无征兆、几不可闻、微不可察

### 동작류
深吸一口气、不禁

### 표정류
眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩、瞳孔收缩、瞳孔一缩、指节泛白、眼神锐利、目光锐利

### 심리류
心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得、心中一凛

### 판단류
不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认、前所未有

### 형용류
坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷

### 전환류
不由自主、情不自禁、自然而然、话锋一转

## 2급 금지어(빈도가 높을 때 교체)

### 문맥 민감어
突然、陡然、骤然、猛然、好像、似乎、瞬间、猛地、死死地(캐릭터의 구어, 실제 돌발 상황, 시간 압축, 시점 불확실성에서는 보존 가능. 동의어를 바꿔 반복을 피하는 것은 면제가 아니며 동일 단어로 밀도 계산)

### 약화 부사(밀도 관리)
缓缓、微微、轻轻、淡淡(매 1,000자 합계 ≤3. 네 단어는 `cliche-density-tic`의 상투어 밀도 통계에도 함께 계산합니다. 단독으로 자연스럽게 쓰는 경우는 보존할 수 있으나, 줄줄이 나오거나 모든 동작에 덧붙을 때 교체)

### 문어체 → 구어체

| 문어체 | 구어체 대체 |
|--------|-----------|
| 瓦解 | 消失 / 散了 / 没了 |
| 无名火 | 烦躁 |
| 往我心上捅刀子 | 心烦意乱 |

### 요약 문식

- "他/她终于明白..."
- "他/她这才意识到..."
- "这一刻，他/她终于明白/意识到..."
- "从这一刻开始..."
- "属于X的反击/复仇/故事，才刚刚开始"
- "命运/宿命 + 齿轮/棋局/獠牙/改写/安排"
- "此刻，他/她..."
- "一切...都..."
- "原来..."

### 열거 문식

- 같은 구조의 3문장 이상 연속 열거
- "有的...有的...有的..."
- "一边...一边...一边..."

### 승화 문식

- "这一刻..."
- "他知道..."
- "她明白..."
- "这就是..."

## 금지 문식 템플릿

| 문식 | 예시 | 문제 |
|---|---|---|
| "不是A，而是B" | "他不是冷漠，而是绝望" | 최악의 AI 문식. B를 직접 씀 |
| "...，带着..." | "他说，带着一丝无奈" | 만능 부사어 |
| "声音不大，却带着……" | "她声音不大，却带着不容置疑的力量" | AI가 선호하는 목소리 묘사 |
| "仿佛能...一般" | "仿佛能穿透一切一般" | 문어체투 |
| 대화 태그 과밀·공식화 | "好的，他说道" | 보통의 "说"은 보존 가능하나 빈번하거나 공식화되면 처리 |
| "他/她感到..." | "她感到一丝失落" | 보여 주지 않고 말해 버림 |
| "他/她意识到..." | "他意识到事情不对" | 인식을 직접 고지 |
| "眼中闪过一丝XX" | "眼中闪过一丝悲伤" | 템플릿화 |
| "嘴角勾起一抹XX" | "嘴角勾起一抹冷笑" | 템플릿화 |
| "心中涌起一股XX" | "心中涌起一股暖流" | 템플릿화 |
| "取而代之的是" | "笑容消失，取而代之的是冰冷" | AI 전환 템플릿. 새 상태를 직접 씀 |
| "淬了/淬着X" | "眼里淬了毒" | AI식 공감각. 행동이나 대사를 씀 |
| "显得（有些）X" | "他显得有些兴奋" | 보여 주지 않고 말해 버림 |
| "心底/心里某个地方+软" | "心里某个地方软得一塌糊涂" | 연애물 상투구. 행동을 씀 |
| "（浑身）散发着一股X气息/气场" | "浑身散发着一股生人勿近的气息" | 만능 분위기 묘사. 주변 반응을 씀 |
| "命运/宿命 + 齿轮/棋局/獠牙/改写/安排" | "命运终于露出獠牙" / "早已布好的棋局" | 추상적인 작가 요약. 현재 캐릭터가 마주친 문서·행동·대화·물리적 결과로 전환 |
| "这一刻终于明白/从这一刻开始/才刚刚开始" | "这一刻，他终于明白" / "反击才刚刚开始" | AI식 수렴어. 요약을 지우고 행동이나 미해결 문제로 마무리 |

## 비유 분류(기본 재검토, 일괄 삭제 금지)

"像/如/仿佛/犹如/宛若"가 들어간 비유가 모두 AI식인 것은 아닙니다. 위험한 것은 비유를 한꺼번에 쌓거나, 만능 문학 비유를 반복하거나, 정교한 비유로 플롯 추진을 대신하거나, 단락 끝에서 독자를 대신해 의미를 결론 내리는 경우입니다.

| 비유 유형 | 예 | 처리 |
|---------|----|------|
| 생활·캐릭터화 | "像一头被抛弃的野狗" | 캐릭터 시점에 붙고 정보·감정을 전달하면 보존 |
| 물건·현상 | "像一把刀" / "脸色惨白得像这漫天的雪" | 일반적인 기능성 비유는 보존 가능. 템플릿화·반복이면 백묘로 전환 |
| 상태형 상투어 | "梨花带雨" / "如沐春风" | 우선 삭제하거나 구체적인 행동·표정으로 교체 |
| 추상형 | "像命运的齿轮" / "像上辈子的尘埃" | 위험도가 높으므로 행동·물건·소리·결과로 되돌림 |
| 가정형 | "力道大得像是要把骨头捏碎" | 캐릭터의 신체 감각이면 보존 가능. 과장된 나열이면 사실적 결과로 전환 |

처리 원칙은 기능을 먼저 보고 밀도를 다음에 보는 것입니다. 정보·감정을 가장 잘 전달하는 한두 개만 남기고 나머지는 직접 묘사, 동사, 명사, 작용, 결과 또는 사실로 바꿉니다. 삭제한 비유를 새로운 비유로 대체하지 않습니다. 예를 들어 "脸色惨白得像这漫天的雪"이 단순 상투어라면 "脸色惨白"으로 바꾸고, 눈 풍경이 캐릭터를 압박하는 장면이라면 보존하거나 캐릭터가 지금 보는 구체적인 화면으로 바꿉니다.

> `metaphor-density-tic`은 advisory입니다. 통독 재검토를 알리는 신호이지 blocking이 아닙니다. 생활감·캐릭터성이 있고 단독 기능을 하는 비유는 보존할 수 있습니다.

## 교체 전략 요약

| 원문 유형 | 교체 방법 | 예시 |
|----------|----------|------|
| 추상 감정어 | 구체적인 행동 | "紧张" → "手在抖" |
| "感到XX" | 외현화 | "感到愤怒" → "攥紧拳头" |
| 형용사 적층 | 백묘 | "美丽动人的笑容" → "她笑了" |
| 문어체 표현 | 구어체화 | "不容置疑" → "就是" |
| 설명적 묘사 | 여백 | "他因为害怕而..." → "他退后一步" |
| 연속 열거 | 가장 강한 한 줄만 보존 | 3문장을 1문장으로 |
| 요약·승화 문장 | 직접 삭제 | "这一刻，她终于明白了..." → 삭제 |
| "不是A，而是B" | B를 직접 쓰거나 자연스러운 표현 | "他不是冷漠，而是绝望" → B를 직접 씀 |
| 불필요한 수식(형용사·관형어·수량사·지시어) | 삭제 | "白色的药片" → "药片"; "手里那截链子" → "链子"; "飞驰的汽车" → "车" |

**교체 결과를 재사용하지 않기**: 오른쪽 열은 방향 예시이지 정답이 아닙니다. 같은 금지어가 한 장에서 여러 번 탐지되면 매번 다른 구체화 방식을 사용합니다. 같은 교체 문장(매번 「垂下眼」, 모든 동작에 「了一下」 추가)을 반복하면 교체 결과 자체가 새 템플릿 지문이 됩니다.

**상투어 밀도를 먼저 처리하기**: `check-ai-patterns.js`가 `cliche-density-tic`을 보고하면 금지어가 우발적으로 한 번 나온 것이 아니라 템플릿 문체로 뭉친 것입니다. 동의어 교체가 아니라 추상 요약을 먼저 지우고 감정·판단을 캐릭터가 지금 볼 수 있는 행동·물건·대화·구체적 결과에 내려놓습니다.
