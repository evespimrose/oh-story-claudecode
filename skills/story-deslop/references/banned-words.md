## 최상위 독성 금지 구문(발견 즉시 수정, 최우선 순위)

웹소설 집필 시 가장 독성이 강한 AI 구문으로, 작가가 한 번 익히면 반복적으로 나타납니다. Gate A 첫 스캔에서 반드시 걸러야 합니다:

| 독성 등급 | 구문 | 오류 예시 | 수정 방법 |
|------|------|--------|------|
| ★★★★★ | "A가 아니라 (오히려) B다" / "A도 아니고 B도 아니고 (오히려) C다" ("오히려" 생략 가능, 생략해도 탐지) | "그는 냉정함이 아니라 절망이었다" | B를 직접 쓰거나 더 자연스러운 표현으로 교체 |
| ★★★☆☆ | 문단 간 「A가 아니다. / B도 아니다. / 그저 C일 뿐이다.」 대구 형식 | 「대성통곡하는 것이 아니다. / 목청 높여 아쉬움을 외치는 것도 아니다. / 그저 혼자 멀리 떠나갔을 뿐이다……」 | 의미 재검토; 개요 반복이거나 전개가 늘어지면 C로 압축, 논리 전개/반전 기능이 있으면 유지 |
| ★★★★ | "，~을/를 머금고 / ~와 함께" 만능 부사구 | "그는 살짝 웃으며, 감지하기 어려운 비웃음을 띠었다" | 부사구 삭제 후 주절만 남기거나 구체적인 동작으로 교체 |
| ★★★★ | 무감정 목소리 묘사: "목소리는 크지 않았지만 ~을 담았다" / "말투에 파동이 없었다" / "아무런 감정도 느껴지지 않았다" / "덤덤한 목소리" | "그녀의 목소리는 크지 않았지만, 부정할 수 없는 힘이 실려 있었다" | 대사 내용 자체, 목소리의 특징 또는 동작으로 직접 묘사 |
| ★★★★ | "그/그녀는 ~임을 알고 있었다……" | "그는 이 모든 것이 이미 늦었다는 것을 알고 있었다" | 행동으로 인지 상태를 보여주기 |
| ★★★ | "마치 / ~인 듯 / ~와도 같이" | "마치 모든 것을 꿰뚫어 볼 수 있을 것만 같았다" | 삭제하거나 백묘(직접 묘사)로 교체 |
| ★★★ | "눈가에 한 줄기 ~가 스쳤다" / "입가에 한 자락 ~가 떠올랐다" | "눈 속에 슬픔이 스쳐 지나갔다" | 그가 눈을 내리깔았다 / 그의 입꼬리가 살짝 올라갔다 |
| ★★★ | "마음속에 한 줄기 ~가 솟구쳤다" / "가슴이 철렁 내려앉았다" | "마음속에 따뜻한 기운이 솟구쳤다" | 신체적 반응으로 표현 |
| ★★★ | 공허하고 막연한 운명/수미상관: "운명의…… 톱니바퀴/송곳니" / "드디어 깨달았다" / "반격은 이제 시작일 뿐" | "운명이 마침내 송곳니를 드러냈다. 그만의 반격은 이제 막 시작되었을 뿐이다" | 캐릭터가 현재 눈앞에서 확인할 수 있는 문서, 동작, 대화 또는 물리적 결과로 회귀 |
| ★★ | 장 끝부분의 예고 "그가 몰랐던 것은……" | "그가 몰랐던 것은, 더 큰 폭풍우가 다가오고 있다는 사실이었다" | 구체적인 복선 소재/사건으로 마무리하고, 공허한 예고는 피할 것 |

> ★★★★★ 한 곳이라도 나타나면 중증 AI 냄새의 강력한 증거로 간주합니다. ★★★★ 2곳 이상 나타나면 중등도 재스캔을 트리거합니다.

`check-ai-patterns.js`의 `formulaic-parallelism`은 "X하든 말든, 어떻게 X할지" 및 동일 동사의 "A를 V하지 않고, B를 V하지 않는다" 형식도 안내합니다. 이 두 유형은 기능적인 구어체일 수 있으므로 advisory로만 처리합니다. Gate B에서 반드시 대사 문맥과 함께 읽으며 복합적으로 검토해야 하며, 단순히 세부 개요나 앞 내용을 반복하는 것이라면 일괄적으로 압축 판정합니다. hook이 대사를 면제해 준다고 해서 그냥 넘어가서는 안 됩니다.

**문장 부호**: 본문(서술 및 대화 포함)에서 대시 `——`/`—`, 쌍반각 하이픈 `--`, 말줄임표 중간 사용을 엄격히 금지합니다. 마침표, 쉼표, 짧은 문장 또는 동작으로 문장을 끊으세요. 대사 내 대시 사용도 예외로 두지 않습니다. 「」 인용부호는 해당하지 않습니다.

## 1급 금지어(발견 즉시 교체)

> 1급 포함 어휘: 실제 작가의 코퍼스에는 거의 나타나지 않고 AI 특유의 어휘만 수록합니다. 실제 작가가 빈번하게 사용하는 자연스러운 부사와 허사는 1급에 넣지 않으며, 2급 밀도 제어로 처리합니다.

### 정서·태도류
마치, 흡사, 완약, ~와 같이, 한 줄기, 한 자락, 약간의, 어느 정도의, 은연중에, 예고 없이, 거의 들리지 않는, 미세하여 알아차리기 어려운

### 동작 관련
심호흡을 하다, 나도 모르게

### 표정 관련
눈빛이 스치다, 입꼬리를 올리다, 미간을 찌푸리다, 눈매를 내리깔다, 동공이 수축하다, 동공이 작아지다, 동공이 떨리다, 손마디가 하얗게 질리다, 눈빛이 날카롭다, 시선이 날카롭다

### 심리 관련
마음이 움직이다, 가슴이 철렁하다, 속으로 알아차리다, 속으로 생각하다, 마음속에서 피어오르다, 나도 모르게, 가슴이 서늘해지다

### 판단 관련
의심의 여지가 없다, 말참견을 허용하지 않다, 알아차리기 어렵다, 명백하다, 의심할 여지 없이, 부정할 수 없다, 전례 없는

### 형용 관련
확고한, 빛을 발하는, 교활한, 깊은, 매서운, 차가운

### 전환 관련
자신도 모르게, 억제할 수 없이, 자연스럽게, 화제를 돌려

## 2급 금지어(빈번하게 나타날 경우 교체)

### 문맥 민감어(빈도가 높거나 안일한 표현을 사용할 때만 처리)
갑자기, 돌연, 갑작스럽게, 문득, 마치 ~인 듯, ~인 것 같다, 순간, 확, 꽉(캐릭터 구어, 실제적인 돌발 상황, 시간 압축, 시점 불확실 시 유지 가능; 동의어 변형으로 돌려막으며 반복을 피하는 것은 예외로 인정하지 않고 같은 단어 밀도로 집계)

### 약화 부사(밀도 조절)
천천히, 약간, 가볍게, 담담하게(1,000자당 합계 ≤3; 이 네 단어는 동시에 `cliche-density-tic`의 상투어 밀도 통계에 포함; 독립적으로 자연스럽게 사용된 경우 유지 가능하며, 연달아 등장하거나 모든 동작에 하나씩 붙는 경우에만 교체)

### 문어체 → 구어체

| 문어체 | 구어체 교체 |
|--------|-----------|
| 와해 | 사라짐 / 흩어짐 / 없어짐 |
| 울화 | 짜증 |
| 가슴에 비수를 꽂다 | 마음이 어지럽다 |

### 총결식 구문
- "그/그녀는 드디어 깨달았습니다..."
- "그/그녀는 이제야 깨달았습니다..."
- "이 순간, 그/그녀는 마침내 깨달았습니다/알아차렸습니다..."
- "이 순간부터..."
- "X의 반격/복수/이야기는 이제 시작일 뿐"
- "운명/숙명 + 톱니바퀴/바둑판/송곳니/개편/짜임"
- "지금, 그/그녀는..."
- "모든 것은... 다..."
- "알고 보니..."

### 병렬·병렬식 구문
- 연속 3문장 이상 동일 구조의 병렬
- "~하기도 하고, ~하기도 하며, ~하기도 하다..."
- "하면서... 하면서... 하면서..."

### 승화·총결식 구문
- "이 순간..."
- "그는 알고 있다..."
- "그녀는 깨닫는다..."
- "이것이 바로..."

## 금지 구문 템플릿

| 구문 | 예시 | 문제 |
|------|------|------|
| "A가 아니라 B다" | "그는 냉담한 것이 아니라, 절망한 것이다" | 독성 매우 높음; B를 직접 묘사할 것 |
| "...하며, ...를 머금고/품고" | "그가 말했다, 약간의 허탈함을 담고" | 만능 부사구 |
| "목소리는 크지 않았으나 ...를 담고 있었다" | "그녀의 목소리는 크지 않았으나, 의심의 여지 없는 힘을 담고 있었다" | AI가 가장 즐겨 쓰는 음성 묘사 |
| "~인 것처럼 / ~하듯이" | "마치 모든 것을 꿰뚫을 수 있을 것만 같이" | 문어체 남발 |
| 대사 태그 밀도 과다/정형화된 태그 | "좋아요, 그가 말했다" | 평범한 "말했다"는 유지 가능; 빈도가 높거나 정형화된 경우에만 처리 |
| "그/그녀는 ...를 느꼈다" | "그녀는 약간의 상실감을 느꼈다" | 묘사하지 않고 설명만 함 (Telling) |
| "그/그녀는 ...를 깨달았다/알아차렸다" | "그는 상황이 잘못되었음을 깨달았다" | 직접적인 서술 |
| "눈가에 ...가 스쳐 지나갔다" | "눈가에 한 줄기 슬픔이 스쳐 지나갔다" | 정형화된 표현 |
| "입가에 ...가 번졌다/어린 비소" | "입가에 한 자락 냉소가 번졌다" | 정형화된 표현 |
| "가슴속에서 ...가 솟구쳤다/밀려왔다" | "가슴속에서 한 줄기 온기가 솟구쳤다" | 정형화된 표현 |
| "그 자리를 대신한 것은" | "웃음이 사라지고, 그 자리를 대신한 것은 차가움이었다" | AI 전환 템플릿; 새로운 상태를 직접 묘사할 것 |
| "...가 서려 있다 / ...를 머금다" | "눈에 독이 서려 있다" | AI 공감각 클리셰; 동작이나 대사로 대체 |
| "(다소) ...해 보이다" | "그는 다소 흥분해 보였다" | 묘사하지 않고 설명만 함 (Telling) |
| "마음속 한구석이 말랑해지다/약해지다" | "마음속 한구석이 완전히 말랑해졌다" | 로맨스 클리셰; 동작으로 묘사할 것 |
| "(온몸에서) ...한 기운이 풍기다" | "온몸에서 낯선 이의 접근을 거부하는 기운이 풍겼다" | 만능 기운 묘사; 주변 인물의 반응으로 묘사할 것 |
| "운명/숙명의 톱니바퀴/바둑판/마수/직조" | "운명이 마침내 송곳니를 드러내다" / "이미 다 짜인 바둑판" | 추상적인 작가의 개입; 캐릭터가 마주한 상황, 동작, 대화, 물리적 결과로 구체화할 것 |
| "드디어 깨달았다/이 순간부터/시작일 뿐" | "이 순간, 그는 마침내 깨달았다" / "반격은 이제 막 시작되었을 뿐이다" | AI 특유의 수미상관 남발; 요약 삭제, 동작이나 미해결 과제로 마무리 |

## 비유 유형 분류(기본적으로 재검토 대상, 일괄 삭제 지양)

"~처럼/같다/마치/~인 듯"이 붙은 비유라고 해서 무조건 AI 문체인 것은 아닙니다. 진짜 고위험군은 비유를 줄줄이 나열하거나, 상투적인 문학적 비유를 끼워 맞추거나, 정교한 비유로 플롯 전개를 대신하거나, 문단 끝에서 독자를 대신해 의미를 요약하는 경우입니다. 본 표는 재검토가 필요한 비유 유형을 식별하는 데 사용됩니다.

| 비유 유형 | 예시 | 처리 |
|---------|----|------|
| 생활/캐릭터 특화 | "버려진 들개처럼" | 캐릭터 시점에 부합하고 정보나 감정을 전달할 수 있으면 유지 가능 |
| 사물/현상류 | "칼날처럼", "안색이 흩날리는 눈처럼 창백하다" | 평범한 기능적 비유는 유지; 정형화되거나 반복될 경우 직접 묘사로 교체 |
| 상태류(진부한 표현) | "이화대우(배꽃이 비에 젖은 듯함)", "여목춘풍(봄바람을 쐬는 듯함)" | 우선 삭제하거나 구체적인 동작/표정으로 교체 |
| 추상류 | "운명의 톱니바퀴처럼", "전생의 먼지처럼" | 고위험군, 우선적으로 동작, 사물, 소리, 결과 등으로 구체화 |
| 가정류 | "뼈를 으스러뜨릴 듯한 강한 힘" | 캐릭터의 신체 감각이라면 유지; 과장되게 나열된 경우 사실적인 결과로 교체 |

처리 원칙: 기능을 우선순위로 두고 밀도를 고려합니다. 정보나 감정을 가장 잘 전달하는 한두 개만 유지하고, 나머지는 직접적인 묘사, 동사, 명사, 작용, 결과 또는 사실로 교체합니다. 삭제한 비유를 새로운 비유로 다시 채워 넣지 마세요. 예: "안색이 흩날리는 눈처럼 창백하다"가 단순 클리셰라면 → "안색이 창백하다"; 눈 내리는 풍경이 캐릭터를 압박하고 있다면 유지하거나 캐릭터가 현재 눈앞에서 보는 구체적인 장면으로 교체합니다.

> `metaphor-density-tic`은 권고 사항(advisory)입니다. 전체적인 재검토를 안내할 뿐 차단(blocking)하지는 않습니다. 생활 밀착형, 캐릭터 특화형, 단독 기능을 수행하는 비유는 유지할 수 있습니다.

| 원문 유형 | 교체 방법 | 예시 |

| 설명적 묘사 | 여백 주기 | "그가 무서워서..." → "그가 한 물러섰다" |
| 연속 병렬 | 가장 강한 한 줄만 유지 | 3문장 병렬은 1문장만 남김 |
| 요약 및 승화형 구문 | 직접 삭제 | "이 순간, 그녀는 마침내 깨달았습니다..." → 삭제 |
| "A가 아니라 B다" | B를 직접 쓰거나 더 자연스러운 표현으로 | "그는 냉막한 것이 아니라 절망한 것이다" → B 직접 쓰기 |
| 과잉 수식(형용사/관형사/양사/지시대명사) | 삭제 | "하얀 알약" → "알약"; "손에 쥔 그 쇳조각" → "사슬"; "질주하는 자동차" → "차" |

**교체 표현 재사용 금지**: 우측 항목은 방향 예시일 뿐 정답이 아닙니다. 동일한 금지어가 한 챕터 내에서 여러 번 적발될 경우, 각각 다른 구체화된 표현을 적용하세요. 동일한 교체 표현이 반복적으로 등장(예: 매번 '눈을 내리깔다', 모든 동작마다 '~를 살짝 했다' 붙이기)하면, 수정된 결과물 자체가 새로운 템플릿 지문이 되어버립니다.

**상투어 밀도 우선 처리**: `check-ai-patterns.js`에서 `cliche-density-tic`이 보고될 경우, 금지어가 드문드문 오용된 것이 아니라 지문이 템플릿으로 도배되어 있다는 뜻입니다. 처리 순서는 단순한 동의어 치환이 아닙니다. 먼저 추상적인 요약을 삭제한 다음, 감정이나 판단을 캐릭터가 현재 눈앞에서 확인할 수 있는 동작, 사물, 대화 및 구체적인 결과로 구체화해야 합니다.
