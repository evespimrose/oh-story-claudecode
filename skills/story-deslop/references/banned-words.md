## 최고 독성 금지 구문（발견 즉시 수정，최우선순위）

웹소설 작성 시 가장 독성이 강한 AI 구문으로，작가가 한 번 익히면 반복적으로 나타납니다. Gate A 첫 스캔에서 반드시 걸러야 합니다：

| 독성 등급 | 구문 | 오류 예시 | 수정 방법 |
|------|------|--------|------|
| ★★★★★ | "A가 아니라（오히려）B다" / "A도 아니고 B도 아니고（오히려）C다"（"오히려" 생략 가능，생략해도 걸림）| "他不是冷漠，而是绝望" | B를 직접 쓰거나 더 자연스러운 표현으로 교체 |
| ★★★☆☆ | 문단 간「A가 아니다. / B도 아니다. / 그저 C일 뿐。」형식 | 「不是嚎啕大哭。/也不是扯着嗓子喊不舍。/只是一个人走远了……」 | 의미 재검토；개요 반복이거나 장면 진행을 느리게 하면 C로 압축，변명/반전 기능이 있으면 유지 |
| ★★★★ | "，……를 품으며 / ……를 담아" 만능 부사구 | "他笑了一下，带着一丝不易察觉的嘲讽" | 부사구 삭제 후 주절만 남기거나 구체적 동작으로 교체 |
| ★★★★ | 무감정 음성 묘사："목소리는 크지 않았지만 ……를 담았다" / "말투에는 파동이 없었다" / "아무런 감정도 드러나지 않았다" / "평탄한 목소리" | "她声音不大，却带着不容置疑的力量" | 대사 내용 자체、목소리 특징 또는 동작으로 직접 묘사 |
| ★★★★ | "그/그녀는 알고 있었다……" | "他知道这一切都来不及了" | 행동으로 인식을 보여주기 |
| ★★★ | "마치 / ~인 것처럼 / ~와도 같았다" | "仿佛能穿透一切一般" | 삭제하거나 백묘（직접 묘사）로 교체 |
| ★★★ | "눈에는 한 점의 ……가 스쳤다" / "입가에는 한 점의 ……가 떠올랐다" | "眼中闪过一丝悲伤" | 그가 눈을 내렸다 / 그가 입꼬리를 살짝 올렸다 |
| ★★★ | "마음속으로 한 줄기 ……가 밀려올랐다" / "가슴이 철렁 내려앉았다" | "心中涌起一股暖流" | 신체 반응으로 표현 |
| ★★★ | 추상적 운명/시작 수미상관："운명……바퀴/송곳니" / "드디어 깨달았다" / "반격은 이제 시작일 뿐" | "命运终于露出獠牙；属于他的反击才刚刚开始" | 캐릭터가 현재 눈앞에서 확인 가능한 문서、동작、대화 또는 물리적 결과로 회귀 |
| ★★ | 챕터 말미 예고 "그는 모르고 있었는데……" | "他不知道的是，更大的风暴即将来临" | 구체적인 갈고리 소재/사건으로 마무리，공허한 예고는 피하기 |

> ★★★★★ 한 군데만 걸려도 중증 AI 냄새의 강력한 증거로 간주；★★★★ 2군데 이상 걸리면 중등도 재스캔을 트리거합니다.

`check-ai-patterns.js` 의 `formulaic-parallelism`은 또한「X하든 안 하든，어떻게 X할지」와 동일 동사의「A를 V하지 않고，B를 V하지 않는다」형식을 알립니다. 이 두 유형은 기능적인 구어일 수 있으므로 advisory로만 처리；Gate B에서 반드시 대사와 함께 문맥을 읽어 재검토해야 하며，단순히 세부 개요/앞 내용을 반복하는 것이라면 한 번의 판단으로 압축，hook이 대사를 면제시킨다고 건너뛰면 안 됩니다.

**문장 부호**：본문（서술과 대화 포함）에서 대시 `——`/`—`、쌍반각 하이픈 `--`、말줄임표 중간 사용을 금지하며，마침표、쉼표、짧은 문장 또는 동작으로 문장 끊기；대사용 대시 예외는 설정하지 않습니다. 옌옌 「」인용부호는 해당 없음.

## 1급 금지어（발견 즉시 교체）

> 1급에 포함되는 단어：실제 작가 코퍼스에 거의 나타나지 않고 AI 특유인 단어만 수록합니다. 실제 작가가 고빈도로 사용하는 자연스러운 부사와 허사는 1급에 넣지 않으며，2급 밀도 제어로 처리합니다.

### 정서·태도类
仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约、毫无征兆、几不可闻、微不可察

### 동작类
深吸一口气、不禁

### 표정类
眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩、瞳孔收缩、瞳孔一缩、指节泛白、眼神锐利、目光锐利

### 심리类
心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得、心中一凛

### 판단类
不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认、前所未有

### 형용类
坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷

### 전환类
不由自主、情不自禁、自然而然、话锋一转

## 2급 금지어（고빈도 출현 시 교체）

### 문맥 민감어（오직 고빈도 또는 게으른 표현 사용 시만 처리）
突然、陡然、骤然、猛然、好像、似乎、瞬间、猛地、死死地（캐릭터 구어、실제적인 돌발 상황、시간 압축、시점 불확실 시 유지 가능；동의어 변형으로 돌려막으며 반복 피하는 것은 면제로 인정하지 않고 같은 단어로 밀도 집계）

### 약화 부사（밀도 제어）
缓缓、微微、轻轻、淡淡（천 글자당 합계 ≤3；이 네 단어는 동시에 `cliche-density-tic`의 상투어 밀도 통계에 포함；고립되어 자연스럽게 쓰인 경우 유지 가능하며 줄줄이 등장하거나 모든 동작마다 하나씩 붙이는 경우에만 교체）

### 문어체 → 구어체

| 구문 | 예시 | 문제 |
|------|------|------|
| "A가 아니라 B다" | "他不是冷漠，而是绝望" | 최고 독성；B를 직접 쓰기 |
| "...，……를 품으며" | "他说，带着一丝无奈" | 만능 부사구 |
| "목소리는 크지 않았지만……를 담았다" | "她声音不大，却带着不容置疑的力量" | AI가 가장 즐겨 쓰는 음성 묘사 |
| "~할 수 있는 것처럼" | "仿佛能穿透一切一般" | 문어체 투성 |
| 대사 태그 밀도 과다/공식화된 태그 | "好的，他说道" | 평범한"말했다"는 유지 가능；고빈도 또는 공식화될 때만 처리 |
| "그/그녀는 ……를 느꼈다" | "她感到一丝失落" | 보여주지 않고 말만 하기 |
| "그/그녀는 ……를 알아차렸다" | "他意识到事情不对" | 직접 통지 |
| "눈에는 한 점의 XX가 스쳤다" | "眼中闪过一丝悲伤" | 템플릿화 |
| "입가에는 한 점의 XX가 떠올랐다" | "嘴角勾起一抹冷笑" | 템플릿화 |
| "마음속으로 한 줄기 XX가 밀려올랐다" | "心中涌起一股暖流" | 템플릿화 |
| "그 대신 들어선 것은" | "笑容消失，取而代之的是冰冷" | AI 전환 템플릿；새로운 상태를 직접 쓰기 |
| "XX가 스며들다 / 서려 있다" | "眼里淬了毒" | AI 공감각 클리셰；동작이나 대사로 쓰기 |

| "（온몸에）XX의 기운/기류가 흐르다" | "浑身散发着一股生人勿近的气息" | 만능 기운 묘사；주변 인물의 반응으로 쓰기 |
| "운명/숙명 + 톱니바퀴/바둑판/송곳니/개편/짜임" | "命运终于露出獠牙" / "早已布好的棋局" | 추상적 작가 총결；캐릭터가 현재 눈앞에서 마주치는 문서、동작、대화、물리적 결과로 바꾸기 |
| "드디어 깨달았다/이 순간부터/시작일 뿐" | "这一刻，他终于明白" / "反击才刚刚开始" | AI 수미상관 투성；총결 삭제，동작 또는 미해결 문제로 마무리 |

## 비유 유형 분류（기본적으로 재검토，전체 삭제가 기본 아님）

"~처럼/같다/마치/~인 듯"이 붙은 비유라고 일률적으로 AI인 것은 아닙니다. 진정 고위험군인 것은：줄줄이 쌓아 올리거나，만능 문학 비유를 끼워 맞추거나，정교한 비유로 플롯 진행을 대체하거나，문단 끝에서 독자를 대신해 의미를 총결하는 경우입니다. 본 표는 재검토가 필요한 비유 유형을 식별하는 데 사용：

| 비유 유형 | 예시 | 처리 |
|---------|----|------|
| 생활/캐릭터 특화 | "像一头被抛弃的野狗" | 캐릭터 시점에 부합하고 정보나 감정을 전달할 수 있으면 유지 가능 |
| 사물/현상类 | "像一把刀" "脸色惨白得像这漫天的雪" | 평범한 기능적 비유는 유지；템플릿화되거나 반복될 때 직접 묘사로 교체 |
| 상태类（진부한 표현） | "梨花带雨" "如沐春风" | 우선 삭제하거나 구체적 동작/표정으로 교체 |
| 추상类 | "像命运的齿轮" "像上辈子的尘埃" | 고위험，우선적으로 동작、사물、소리、결과로 낙하 |
| 가정类 | "力道大得像是要把骨头捏碎" | 캐릭터의 신체 감각이라면 유지；과장되게 쌓아 올린 경우 사실적 결과로 교체 |

처리 원칙：기능을 먼저 보고 밀도를 다음에 봅니다. 정보나 감정을 가장 잘 전달하는 한두 개만 유지하고，나머지는 직접적인 묘사、동사、명사、작용、결과 또는 사실로 교체；삭제한 비유를 새 비유들로 다시 채워 넣지 않습니다. 예："脸色惨白得像这漫天的雪"가 단순 클리셰라면 → "脸色惨白"；눈 내리는 풍경이 캐릭터를 압박하고 있다면 유지하거나 캐릭터가 현재 눈앞에서 보는 구체적 장면으로 교체.

> `metaphor-density-tic`은 advisory：통독 재검토를 안내할 뿐 blocking은 아닙니다；생활밀착형、캐릭터 특화형、단독으로 기능이 있는 비유는 유지 가능합니다.

## 교체 전략 속성

| 원문 유형 | 교체 방법 | 예시 |
|----------|----------|------|
| 추상 감정词 | 구체적 동작 | "긴장" → "손이 떨린다" |
| "XX를 느끼다" | 외적 표현 | "분노를 느끼다" → "주먹을 꽉 쥐다" |
| 형용사 나열 | 직접 묘사 | "아름답고 감동적인 미소" → "그녀가 웃었다" |
| 문어적 표현 | 구어화 | "의심의 여지가 없이" → "그냥" |
| 설명적 묘사 | 여백 주기 | "그가 무서워서..." → "그가 한 물러섰다" |
| 연속 병렬 | 가장 강한 한 줄만 유지 | 3문장 병렬은 1문장만 남김 |
| 총결 승화식 구문 | 직접 삭제 | "이 순간，그녀는 드디어 깨달았습니다..." → 삭제 |
| "A가 아니라 B다" | B를 직접 쓰거나 더 자연스러운 표현으로 | "他不是冷漠，而是绝望" → B 직접 쓰기 |
| 과잉 수식（형용사/관형사/분류사/지시대명사） | 삭제 | "하얀 알약" → "알약"；"손에 쥔 그 쇳조각" → "사슬"；"질주하는 자동차" → "차" |

**교체 표현 재사용 금지**：오른쪽 칸은 방향 예시일 뿐 정답이 아닙니다. 동일 금지어가 한 챕터 내에서 여러 번 걸렸을 때，각기 다른 구체화된 표현을 적용；같은 교체 표현이 반복적으로 등장（매번「눈을 내리깔다」、모든 동작마다「~를 살짝 했다」붙이기）하면，교체 산출물 자체가 새로운 템플릿 지문이 됩니다.

**상투어 밀도 우선 처리**：`check-ai-patterns.js` 에서 `cliche-density-tic`가 보고될 경우，금지어가 드문드문 오용된 것이 아니라 템플릿 투성으로 뭉쳐 있다는 뜻입니다. 처리 순서는 동의어 치환이 아니라，먼저 추상 총결을 삭제한 다음 감정/판단을 캐릭터가 현재 눈앞에서 확인 가능한 동작、사물、대화와 구체적 결과로 낙하하는 것입니다.
