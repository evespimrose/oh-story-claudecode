# 文风协议

> **로드 시점**: story-long-analyze Stage 6 실행 전. 하위 집필 skill은 `文风.md`를 직접 읽으며 이 프로토콜은 로드하지 않는다.

## 산출물 정의

`拆文库/{书名}/文风.md`는 작품 전체의 집필 기법을 보여 주는 뷰이며 다음을 종합한다.

- 문장 길이·문장부호·단락 리듬(원문 표본에서 통계)
- 대화의 속뜻 패턴과 인물 말투 구분
- 장 안·장 사이의 감정 교대 주기(각 장의 기조 변화 확인)
- `拆文报告.md`에 이미 기록된 ‘작성 기법’과 ‘참고할 만한 패턴’
- 단계별 모방 권장안(기초·심화·적용 단계, 기법만 배우고 장면은 옮기지 않음)
- 300~500자 원문 앵커 구간 4~6개(예시 구간용)

## 파일 경로

- **기록**: `拆文库/{书名}/文风.md`(analyze 전용)
- **읽기**: 해당 작품이 다른 프로젝트의 외부 비교 대상으로 명시적으로 선택되면 story-import 또는 story-long-write가 최초 참조 시 `{项目}/对标/{书名}/文风.md`로 동기화한다. story-long-write는 프로젝트 비교 뷰를 읽고, 없으면 拆文库로 대체한다. story-import가 재구성 중인 본문에는 이 동기화를 적용하지 않는다.

## 글자 수 예산

- **하드 상한 약 4000자**
- 설명 부분(전체 어감 + 대화 기법 + 감정 교대 패턴 + 참고 기법 + 단계별 모방 권장안) ≤ 1800자
- 원문 앵커 구간 4~6개 × 300~500자 ≈ 1600~2400자
- 모방 금지 + 생성 기록 ≤ 100자

## 템플릿

```markdown
# {书名} 문체

## 생성 기록
- 참고 자료: 拆文报告.md, 황금 3장 심층 분석, 장별 요약
- 표본 장: 제 {K1}/{K10}/{K20}장(장마다 약 1000자)
- 생성 시간: {date}
- 적용 비교 작품 경로: 拆文库/{书名}/
- 문체 사용 가능: 예  # 원문이 없거나 앵커가 부족하면 ‘아니오: 이유’로 기록

## 整体语感
- 句长分布：{由 `style-profile-generator.md` Step 4 的跨平台 Python 1-liner 在 3 章拼接样本上确定性测量——短句(<15字)占比 X%、中句(15-30)Y%、长句(>30)Z%、平均句长 N 字、标点密度 M%。一句概括语感。`confidence: high`（数据由脚本算出，不是抽样估计）。}
  - confidence: high | med | low
- 문장부호 습관: {대시/줄임표/마침표/느낌표/세미콜론의 빈번한 사용법. 원문 짧은 구간 예시 2~3개를 덧붙임.}
  - confidence: high | med | low
- 단락 리듬: {평균 단락 길이, 한 단락 한 행동과 여러 행동의 누적 여부, 줄바꿈 습관.}
  - confidence: high | med | low

## 대화 기법
- 속뜻 패턴: {대표적인 속뜻 기법 2~3가지(질문과 다른 대답 / 말투의 반전 / 정보 은닉 등). 각 기법에 원문 예시 1개를 덧붙임.}
  - confidence: high | med | low
- 대화 태그 습관: {발화 동사의 다양성, 행동으로 대화 태그를 대체하는 빈도, 대화와 행동의 교차 비율.}
- 인물 말투 구분: {주인공과 핵심 조연 1~2명의 말버릇·문장 구조 차이. 원문 표본 문장을 인용.}

## 감정 교대 패턴
- 장 안의 기조 전환: {장 안의 플롯 지점 기조 순서를 통계화한다. 대표 장이 긴장↔가벼움 또는 열혈↔따뜻함 사이를 오가는지, 전환 빈도는 장마다 N회인지 기록.}
  - confidence: high | med | low
- 장 사이의 기조 주기: {앞 20장의 ‘장 기조’ 순서에서 ‘피폐 3장, 사이다 1장’과 같은 주기를 식별.}
- 희극↔강타 전환 기법: {비교 작품이 가벼움→슬픔의 급격한 전환에 사용한 기법을 원문 앵커 1~2개와 함께 기록.}

## 참고할 수 있는 기법(`拆文报告.md`에서 직접 인용)
- 작성 기법 Top 5:
  1. {技巧名}：{一句话用法说明}
  2. ...
- 참고할 만한 패턴 Top 3:
  1. {套路名}：{适用场景}
  2. ...

## 단계별 모방 권장안
- 基础层（必学）：{词汇偏好、句式节奏、对话标签、描写重心中最容易迁移的 3-5 条；只学表达习惯，不复制原句}
- 进阶层（结构）：{节奏推进、伏笔埋回、视角切换、场景衔接中最值得复用的 3-5 条；替换人物/场景/道具后再使用}
- 适配层（本书化）：{哪些技法适合当前项目，哪些会导致人设/题材错位；明确不要搬运专名、标志性台词、独特桥段和事件顺序}
```

## confidence 필드 의미

| 값 | 발동 조건 | 하위 처리 |
|---|---|---|
| `high` | 데이터를 직접 읽을 수 있음(예: 요약에서 기조 순서를 grep으로 추출) | narrative-writer가 우선 채택하며 기본 Gate를 덮어씀 |
| `med` | 표본에서 충분한 자료를 귀납함(예: 장별 기조 흐름, 대화 속뜻 정리) | narrative-writer가 참고하고 기본 Gate와 조율 |
| `low` | 표본 부족 또는 원문 누락 | narrative-writer가 기본 Gate에 양보하며 강제 채택하지 않음 |

## 사용 가능성 의미

- `文风可用：是` → 문체를 집필에 사용할 수 있으며, narrative-writer가 confidence 등급에 따라 사용한다.
- `文风可用：否：{原因}` → 문체 품질이 부족함(예: 원문 누락, 앵커가 모두 플레이스홀더). story-explorer가 읽을 때 `gaps.profile_degenerate: true`를 반환하고, narrative-writer는 문체를 건너뛰고 기본 Gate로 집필해 오도되지 않도록 한다.

## 우선 적용과 모방 금지 원칙

- **우선 적용**: 문체는 Gate D(리듬 조정), Gate B(문장 구조의 상투성 제거), 문장부호 기본 습관보다 우선한다. 이 Gate들은 AI 문체 제거를 위한 **기본값**이므로 문체에 더 구체적인 지시가 있으면 문체를 따른다.
- **덮어쓸 수 없음(하드 제약)**: banned-words / Gate F의 장 끝 승화 금지 / 만능·누적 비유 금지 / 장 끝 예고 금지 / 글자 수 하한. 문체 예시가 반대 사용법을 보여도 이 하드 제약이 항상 우선한다.

정확한 결정표는 `.claude/agents/narrative-writer.md`의 ‘호출 프로토콜’ 절을 참조한다.
