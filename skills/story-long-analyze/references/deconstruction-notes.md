## 핵심 감정 제어

### 자가 점검 규칙

분석 또는 심사 시 표시: 텍스트가 핵심 설정에서 벗어났는지, 독자 기대에 부응하지 않고 표현 욕구만 채우는 단락이 있는지. 핵심 설정에서 벗어날 때, 주관적 평가가 아닌 리텐션 리스크로 출력.

### 핵심 감정 붕괴 사례

| 문제 | 교훈 |
|------|------|
| 주인공이 혼자 세상을 평정하고 주변 사람들 다 죽음 | 독자가 대입한 뒤 "천하무적인데 얻는 게 없어서" 답답함 |
| 맵 바꿀 때 모든 조연을 죽임 | 리텐션/추독 리스크 현저히 상승, 독자가 대입 자산이 리셋되는 걸 받기 힘들어 함 |
| 모든 사람이 희생당해 도구인 됨 | 시작은 화려하지만 끝은 초라, 핵심 감정 붕괴 |

수정: 비극은 좌절을 창조해 보여주는 거지, 중요 역할을 죽이는 게 아님; 맵 바꿀 때 기존 인물이 위험에 처하게 해 주인공이 행동할 이유를 줌.

### 인물 퇴장 원칙

- 인물 퇴장은 수단이지 목적이 아님, 필력에 대한 요구가 극도로 높음
- 꼭 퇴장시켜야 할 땐, 복선을 깔아두고 보상 공간을 남김
- 프로젝트에 충분한 복선, 보상 메커니즘과 후속 감정 회수 방안이 없을 때, 중요 역할을 퇴장시키지 말 것
- 비극 강도는 반드시 목표 플랫폼 최근 표본으로 보정; 기본값으로 비극이 핵심 쾌감이나 안정감을 덮게 하지 말 것

### 강한 감정 표본 검증

목표 플랫폼 최근 표본에 고빈도로 강한 감정문이 등장할 경우, 분석 시 기록: 감정 발동 조건, 해방 리듬, 어그로 위치, 리텐션 증거. 최근 표본이 없을 때, 강한 감정을 경직된 트렌드로 삼지 말고, 후보 가설로만 삼을 것.

## 소재 경계와 핵심 설정

### 핵심 설정 = 독자 니즈, 벗어나면 = 독자를 버리는 것

| 벗어난 유형 | 결과 |
|----------|------|
| 핵심 대비가 사라짐(도시 고무→평범) | 독자 직감 |
| 핵심 메커니즘 미업그레이드(게임소설이 초보자 마을에 갇힘) | 상한선 제한 |
| 소재의 맛이 변함 (현환에서 영감/서스펜스가 현환으로 샘) | 양쪽 독자 모두 불만족 |
| 후반 삼관이 벗어남 | 수용층 선별이 너무 심함 |

### 핵심 설정 확장 4차원

"역전 시스템 (조기 도착 류)"을 예로: 1. 임무 수량 2. 보상 난이도 3. 등급 계층 + 숨겨진 발동 4. 보상 발동으로 새 극적 임무 생성. 앞의 두 가지만 쓰면 극성이 빨리 소진되며, 4가지를 결합해야 지속됨.

### 핵심 설정 밀도 참고

《미식부사사조》 11장 내 핵심 설정 적용 5회, 밀도 극도로 높음.

## 분석 방법론

### 6원칙

목적 있음 / 방법 있음 / 이론을 분석해냄 / 호불호 버림 / 장점은 취하고 단점은 피함 / 자신이 좋아하는 책을 분석함

### 프로세스

한 마디로 요약 → 구조 단위 식별 (기승전합, 점진적 확대) → 프레임 추출 + 감정 사슬 → 프레임을 참고하고 내용은 베끼지 않음

### 조건 프레임 추출법

스토리를 조건으로 추출 (예: 일부 재능 노출 + 양 세력 쟁탈 + 정보 차이로 식견 있는 인물 발견), 인물/배경/특수 능력을 교체한 뒤 재사용, 감정 유사성 유지.

### 추상 5단계법

요약 → 정보 덩어리 (감정 전환점)로 분해 → 상승/하락/전환으로 분류 → 범용 조건 프레임 추출 → 소재로 채움

### 감정선 분석법: 이중표준법

같은 일(콜라 주기), 남2가 주면 여주가 거절, 남주가 주면 여주가 수락. 3요소: ①거의 같은 일이 연속으로 벌어짐 ②여주 태도가 판이하게 다름 ③남주는 모름.

## 구조 설계와 리듬

### 감정 이끌기 도구

| 테크닉 | 방법 |
|------|------|
| 익숙한 감정 루트 선택 | 루트 선택→캐릭터 설정→스토리 채우기 |
| 기대가 끊기면 이어주기 | 새 역할/새 사건 도입으로 다시 끌어올리기 |
| 약점 노출 후 보여주기 기본 | 비하 사슬 + 인간관계 무대 + 정방향 역방향 전파 |
| 복합형 조연 | 주인공의 "장갑": 주인공 대신 발언 + 절대적 지지 + 웃음 유발 |

### 망원경 기대법

카운트다운 구조: 끊임없이 "발견→관측→인양→실패→추락" 묘사 → 독자는 총알이 주인공에게 쏠릴 걸 알고 → 거대한 기대감.

### 분권 리듬(천재클럽 사례)

매 20-30만자마다 한 권, 명확한 핵심과 목표 있음; 권 내에서 여러 실타래가 얽혀 선형적인 "기승전합"을 깸; "기"는 반드시 훅을 던져야 함; 매 권 끝은 다음 권에 복선을 깔아둠.

### 시대 적응

강한 갈등 오프닝 → 인정미 + 기본 수요 전개; 문풍이 더 세밀해짐; 화면 편집감이 극도로 강함; 루트는 익숙하지만 2-3장에 속전속결.

## 매력 포인트 순환 설계

### 완벽 순환(천재사신)

부계정으로 약점 노출 후 보여주며 이점 챙기기 → 이점 갖고 메인 퀘스트 수행 → 보상 획득 → 부계정 무력 상승 → 새 맵에서 약점 노출 후 보여주기 → 순환. 핵심: 매번 내용이 다름; 감정 진전이 기대감을 붙잡음; 최종 부계정 정체 노출 = 과시했던 위세가 주인공에게 돌아옴.

### 정보 집약형 순환(초성종에 틀어박힘)

"윤회"로 나눠, 매 윤회 = 완전한 스토리. 힘 체계가 붕괴하지 않으면 무한히 늘일 수 있음.

### 방송 류 순환

목표 있음(확정적 기대) → 대항 있음(숏패스 승부) → 단계성 있음(임무 업그레이드) → 정면 피드백

## 분석 실전 테크닉

### 기대감에서 출발

- 선지선각류 특수 능력 사용 장면: 세계관 소개 / 실력 향상 / 약점 노출 전 / 고수와 비교 전 / 새 인물 소개 전
- 과도 스토리는 수확/애매/소규모 스토리를 쓰고, 갈등 없으면 갈등 직전 1초로 점프 가능

### 감정 꺾은선 그래프

횡축=장, 종축=감정 정음. 리듬 제어 = "극적인 정보 덩어리" 출현 속도 제어. 정보 덩어리 = 감정 전환을 일으킬 수 있는 스토리.

### 단락별 기능 표기법

원문과 대조해 단락마다 서사 기능（복선/전환/클라이맥스/과도）표기, 감정 추이, 곤경 설계, 복선 연결 추적, 재사용 가능 프레임 출력; 스토리 내용이나 표현 복제 금지.

## 벤치마크 책 선택

| 오류 | 원인 |
|------|------|
| 한 권의 벤치마크 책만 분석 | 최소 5권의 동일 사이트 동일 소재 동일 유형 참고 |
| 유일한 헤드 대작만 분석 | 헤드 작품은 복제 불가능한 작가 브랜드나 역사적 트래픽에 의존할 수 있음, 동일 플랫폼 동일 소재, 데이터 안정적, 유일 헤드가 아닌 복제 가능한 표본을 우선 선택 |
| 사이트를 넘나들며 벤치마킹 | 사이트마다 독자 집단이 달라, 작성법 차이가 큼 |

프로세스: 동일 소재 표본 광범위 수집 → 방향 확정 → 참고 도서 5-10권 확정 → 벤치마크 책 확정

## 영상 편집과 감정 제어

- 인물 태도 변화 = 감정을 가장 잘 보여줌
- 격투 사이에 리액션을 끼워 넣되 글자 수 제어, 아니면 리듬이 끊김
- 감정으로 상황을 드러냄(한숨/충격/희열) 장단점 표현
- 매 동작 단락은 감정 변화를 이끌어내야 함

## 다선 서사와 구조 순환

### 다선 분석 차원

사건 노드(새 인물/갈등 폭발) / 감정 사슬 노드(한 문장으로 요약) / 플롯라인 / 감정선

감정선 템플릿(단일 역할): 만날 때 태도→핵심 전환→태도 변화(혐오→호기심→설렘→몰입)→관계 발전 폭발점

### 순환 층위감

동일 프레임 순환 시 매번 내용이 반드시 달라야 함(맵/역할/갈등/감정 디테일 갱신). 힘 체계가 붕괴하지 않으면 무한히 늘일 수 있음.

## 소재 실전

| 소재 | 핵심 요점 |
|------|----------|
| 역사문 | 본질 = 동인류 쓰기법; 제목 "왕조+오프닝 사건"; 핵심 설정 = 선견지명으로 명인 충격 + 역사 변경 |
| 군사문 | 매력 포인트 = 선정성 + 생생한 현장감; 핵심 모순 = 국가 간/신념/이념 |
| 전정/브레인 | 고밀도 소규모 쾌감 포인트(소장/능력/패널/충격); 패널 설정을 세밀하게 |
| 방송 류 | 목표(확정적 기대)+대항(숏패스)+단계성+쾌감 쓰기법: 독자에게 어떻게 과시할지 먼저 알려준 뒤, 더 큰 걸 보여줌 |
| 양계 왕복 | 제목이 곧 매력 포인트; 핵심 설정 = A세계에서 저자세로 B세계 자원 이용; 장수 범인류: 시간 스케일 큼 + 조연 세대 교체 |
| 회생 류 | 천연 기대감; 전생에 배신당함 → 이번 생에 복수; 쾌감 포인트를 재사용 가능하되 매번 형태는 달라야 함; 토마토 표준 = 단순 직설적으로 태그 달기 |

## 캐릭터 설정 조형

### 제1장 캐릭터 설정 세우기

작은 사건으로 성격 보여줌 → 태그 붙여 확정; 긴급 사건으로 스토리에 신속 진입; 여자 역할 첫 번째 반응은 성격을 체현해야 함.

### 일상으로 캐릭터 설정 체현

캐릭터 설정에 부합하는 행동이 반복 출현; 조연 기능화(질투형: 의기양양→질투; 숭배형: 의문→감탄); 조연 감정 변화를 적어줘야 함.

### 오프닝 로직

수동 입국 → 교류로 세계관 이해 → 곤경에 처함 → 목표 명확히 → 특수 능력 과시 → 특수 능력으로 수확
