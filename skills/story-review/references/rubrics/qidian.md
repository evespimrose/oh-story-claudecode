# 기점 중문망 Quality Rubric

## 평가 기준

| 지표 | PASS 기준 | FAIL 기준 |
|------|----------|----------|
| 쾌감 밀도 | 매 3000자 ≥1 감정 노드 (승급/얼굴치기/보물 획득) | 연속 5000자 감정 노드 없음 |
| 승급 리듬 | 매 50장마다 등급/실력 돌파 | 100장간 아무런 승급 없음 |
| 금사용 사용 | 매장 금사용 언급 또는 사용 (시스템/반지/공법) | 연속 5장간 금사용 미언급 |
| 일일 갱신 지원 | 개요가 4000자/일 리듬 지원 (매장 2000자, 하루 2장) | 일일 갱신 계획 없고, 장 길이 불규칙 |
| 훅 밀도 | 매 장 끝에 현안/훅 있음 | 연속 3장 끝에 훅 없음 |
| 캐릭터 존재감 | 주인공이 매장 출현하고 추진 | 연속 2장 주인공 미출현 또는 추진 없음 |
| 추독 비 | 장말 훅 + 감정 연속성 → 추독 비 예측 >30% | 연속 3장간 훅 없거나 감정 단절 → 추독 비 예측 <15% |

## 사용 방식

- story-review의 story-architect 시각에서 이 기준을 인용
- advisory only, blocking 아님
- 사용자가 임계값을 커스터마이즈할 수 있음
