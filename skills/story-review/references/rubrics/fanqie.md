# 판타지 소설 Quality Rubric

## 평가 기준

| 지표 | PASS 기준 | FAIL 기준 |
|------|----------|----------|
| 시작 매력도 | 앞 3단에 갈등/현안/훅 포함 | 앞 3단이 순수 묘사/배경 소개 |
| 독자 잔류율 | 매 장 끝에 "넘기는 동기" (현안/반전/새 정보) | 연속 3장 끝에 넘기는 동기 없음 |
| 소재 매치 | 내용이 태그 유형과 일치 (총애/역습/환생 등) | 태그 유형에서 3장 이상 벗어남 |
| 알고리즘 친화 | 짧은 단락, 빠른 리듬, 높은 정보 밀도 | 큰 단락, 느린 리듬, 낮은 정보 밀도 |
| 감정 노드 | 매 1000자마다 감정 기복 있음 | 연속 2000자 감정 평탄 |
| 완독률 예측 | 3장 Hook 효과 + 리듬이 느리지 않음 → 완독 예측 >40% | 앞 3장에 Hook 없거나 연속 늘어짐 → 완독 예측 <20% |

## 사용 방식

- story-review의 story-architect 시각에서 이 기준을 인용
- advisory only, blocking 아님
- 판타지 알고리즘은 빠른 리듬, 강한 감정을 선호
