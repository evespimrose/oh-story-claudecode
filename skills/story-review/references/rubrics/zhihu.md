# 즈후 단편 기준 (Zhihu Quality Rubric)

## 평가 기준

| 지표 | PASS 기준 | FAIL 기준 |
|------|----------|----------|
| 1인칭 | 전편 ‘나’ 시점 사용 | 3인칭 사용(다중 시점 설계 제외) |
| 감정 당김 | 매 단 감정 변화 있음 (기대→실망→놀람 등) | 연속 3단 감정 변화 없음 |
| 반전 설계 | 최소 1개 이상 유효한 반전 (앞서 복선 있음) | 반전 없거나 반전에 복선 지지 없음 |
| 끝 맛 | 끝에 생각할 여지와 정서적 여운이 남음 | 끝이 완전히 닫혀 여운이 없음 |
| 형식 준수 | 단락이 짧고 (장단/조밀 변화 있음), 빈 줄 없고, 대화 형식 올바름 | 통일된 길이거나 연속 초장 단락/빈 줄/대화 태그 과다 |
| 시작 훅 | 첫 문장에 정보량 포함 (동작/갈등/현안) | 첫 문장이 순수 묘사/배경 |
| 분량 통제 | 8000-13000자 (즈후 염언 표준) | 초과 또는 부족 |
| 시작 이탈률 | 첫 문장에 동작/갈등/현안 포함 → 이탈률 예측 <30% | 첫 문장 순수 묘사/배경 → 이탈률 예측 >50% |

## 사용 방식

- story-review의 story-architect와 character-designer 시각에서 이 기준을 인용
- advisory only, blocking 아님
- 즈후 염언 스토리는 1인칭 몰입감과 감정 당김을 중시
