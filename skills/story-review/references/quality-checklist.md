## 1. 공통 검사

### 장 구조
- [ ] 시작에 훅이 있는가(날씨·풍경·일상으로 시작하지 않음)
- [ ] 중반에 추진이 있는가(빠른 전개의 장르는 눈에 보이는 사건, 느린 전개의 장르는 상태 변화면 충분)
- [ ] 국면이 달라졌는가(이 장을 읽고 나면 세계가 이전과 달라져 있는가)
- [ ] 결말이 변화 위에 놓이는가(요약으로 끝내지 않음)

### 도입부 검사(앞 300~500자)
- [ ] 주의를 붙잡는 훅이 있는가
- [ ] 날씨·풍경·일상으로 시작하지 않는가
- [ ] 주인공이 빠르게 등장하는가
- [ ] 작품의 매력 또는 위기가 보이는가
- [ ] 같은 장르의 기본 공식과 충돌하지 않는가(훅이 있다고 해서 차별화된 것은 아님. 다른 동종 작품에 통째로 옮겨도 성립하면 동질화된 도입)

### 장 추진
- [ ] 이번 장에서 목표 / 위험 / 정보 / 관계 / 자원 / 신분 / 감정 입장 중 하나 이상이 바뀌는가. 빠른 전개(番茄/爽文)는 눈에 보이는 사건 또는 쾌감 포인트가 있어야 하고, 느린 전개·감정물은 낮은 강도의 작은 변화만으로도 달성할 수 있으며 매 장 절정을 요구하지 않음
- [ ] 글자 수만 늘린 장이 아닌가(이 장을 삭제하면 어떤 상태 변화가 사라지는가? 답하지 못할 때만 압축)
- [ ] 임무의 막힘이 기능하는가(막힌 뒤 위 상태 변화가 발생하는가)
- [ ] 추진의 강약이 이 작품에 이미 세운 장르, 회수 리듬, 대조작과 맞는가. 고정된 범용 글자 수를 따르지 않음

### 정보 전달
- [ ] 설정 설명이 긴 단락으로 몰려 있지 않은가
- [ ] 정보가 갈등을 따라가는가(사건을 통해 설정을 전달)
- [ ] 설정의 양이 통제되는가(한 장에서 새 개념은 3개 이하)

### 장면 검사
- [ ] 장면에 목표가 있는가(인물이 무엇을 원하는가)
- [ ] 장면에 장애물이 있는가(무엇이 가로막는가)
- [ ] 장면에 변화가 있는가(끝난 뒤 이전과 달라졌는가)
- [ ] 인물이 실제로 행동하는가. 일을 느끼기만 하지 않는가
- [ ] 삭제할 수 있는 단락이 남아 있지 않은가

### 장 끝
- [ ] 결말이 변화 위에 놓이는가
- [ ] 위기·결정·발견·반전 중 하나 이상이 있는가
- [ ] 요약식 결말이 아닌가
- [ ] 독자가 다음 페이지를 넘기게 만드는가

### 언어
- [ ] 공허한 서정 단락이 없는가
- [ ] 같은 감정이 여러 단락 연속으로 반복되지 않는가
- [ ] 대사가 인물의 신분에 맞는가(사람마다 말투가 다른가)
- [ ] 문장 부호의 리듬이 어조와 인물의 목소리에 맞는가. 문장 전체를 마침표로 만들거나 물음표·느낌표를 무작위로 쌓지 않으며, 본문(대화 포함)에 `……`/`——`가 남아 있지 않은가. 망설임·중단은 행동·짧은 문장·쉼표·마침표로 처리
- [ ] 감정이 행동으로 드러나는가(“그는 매우 슬펐다”라고 직접 쓰지 않음)
- [ ] 제목 행 이외에 장·집필 메타 정보가 없는가. `第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者` 같은 표현은 넣지 않음. 앞 내용을 이어야 할 때는 인물이 감지할 수 있는 사건의 닻이나 상대적 시간으로 바꿈. 이야기 안에서 실제로 “제X장”을 읽거나 논의하는 장면, 실제 독자 신분을 말하는 문맥은 예외

### 연재 연속성
- [ ] 이전의 약속·복선을 잊지 않았는가
- [ ] 갑자기 대량의 새 설정을 끼워 넣지 않았는가
- [ ] 복선이 추진되고 있는가
- [ ] 이야기 엔진이 계속 작동하는가

### 물 채우기(filler) 검사
다음 신호가 나타나면 분량만 늘린 장일 수 있습니다.

- 장 전체의 대화에 새로운 정보가 전혀 없음
- 하나의 감정을 3단락 이상 반복함
- 장면 묘사가 500자를 넘지만 플롯을 추진하지 않음
- 인물이 앞서 일어난 일을 회상하지만 새로운 시점이 없음
- 2장 이상 연속으로 갈등이 없음
- 삭제해도 손실이 없는 절차 세부·임무의 막힘은 물 채우기이므로 압축하거나 삭제

## 2. 장편 전용 검사

### 황금 3장 검사
- [ ] 1장 앞 500자 안에 훅이 있는가
- [ ] 주인공이 1장에 바로 등장하는가
- [ ] 1장에 사건이 있는가(순수한 포석만으로 채우지 않음)
- [ ] 2장에서 상승이 있는가(갈등 심화)
- [ ] 3장에 계속 읽을 이유가 있는가
- [ ] 앞 3장에 쾌감 포인트가 최소 2개 있는가
- [ ] 세계관 설명이 긴 단락으로 몰려 있지 않은가
- [ ] 매 장 끝에 계속 읽을 이유가 있는가(저압·과도기 장은 약한 훅이나 단계 목표면 충분하며 강한 미스터리를 강요하지 않음)

### 리듬 검사
- [ ] 최근 5장에 명확한 진전이 있는가
- [ ] 쾌감 포인트 사이가 5,000자를 넘는가(장 위치에 따라 고압·추진 장만 간격을 검사하고, 저압·관계·정보 정리 장은 제외)
- [ ] 2장 이상 연속으로 갈등이 없는가(호흡 장은 정상. 연속 2장의 압력 등급이 ≤1이거나 인접 장의 감정이 비슷하면 경고)
- [ ] 한 권에 장 위치의 고저가 있는가. 전체가 같은 강도로 흐르지 않는가(저압+과도기 장은 합계 약 15% 이하로 절제)

### 인물 검사
- [ ] 주인공의 행동이 인물 설정에 맞는가
- [ ] 조연에게 존재감이 있는가
- [ ] 악역의 격이 현재 단계와 맞는가

### 5차원 점수 기준

각 차원은 0~100점으로 평가하고, 결과에 따라 정밀 수정 전략을 선택합니다.

### 차원 1: 핵심 일관성
핵심 갈등, 핵심 행동, 인물 동기가 앞뒤로 일치하는지 검사합니다.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 인물 동기가 복선 없이 갑자기 바뀜 | critical | 동기 전환을 촉발한 사건을 보충 |
| 핵심 갈등이 앞뒤로 일치하지 않음 | high | 갈등 설정을 되짚어 수정 |
| 핵심 행동이 인물 성격과 충돌함 | high | 행동을 조정하거나 설명을 보충 |
| 부차적 갈등을 잊음 | medium | 회수하거나 약화 |

### 차원 2: 표면 재작성 정도
문장과 어휘가 충분히 독창적인지, 상투적인 표현을 피했는지 검사합니다.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 원문을 그대로 옮겨 어조가 부자연스러움 | medium | 실제 AI 문체일 때만 고쳐 정상적인 원문은 보존 |
| AI 표지어를 대량 사용 | high | 구체적인 묘사로 교체 |
| 같은 문식이 반복됨 | medium | 표현 방식을 바꿈 |
| 묘사가 지나치게 문학적임(수식어 적층·문어체·비유 연쇄) | medium | 구어체·행동 중심으로 바꿈. 행동화한다고 3~5자 단문을 연속으로 만들지 않으며, 수정 후에도 서술은 쉼표가 있는 긴 문장을 기본으로 함 |

### 차원 3: 형식 일관성
단락이 극적 단위·카메라에 따라 자연스럽게 끊기는지, 주어·인물명 리듬이 자연스러운지, 시작과 끝 형식이 통일되어 있는지 검사합니다.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 글자 수에 맞춰 기계적으로 단락을 자르거나 주어가 과밀함 | medium | 극적 단위에 따라 단락을 재배치. 단락 시작에는 이름을 쓰고, 중간에는 대명사·생략을 사용하며, 핵심 전환에서 다시 이름을 씀 |
| 장 글자 수가 목표에서 벗어남 | **high** | 집필·대개요 수정 시 먼저 세부 개요로 돌아가 계획한 사건 지점을 보충한 뒤 확장. 기존 본문에서 AI 문체만 제거할 때는 새 플롯을 추가하지 않음 |
| 형식이 뒤섞임(대화·묘사 불통일) | low | 형식을 통일 |

### 차원 4: 가독성
장황함, AI 문체, 공허한 요약, 상투적 수사가 있는지 검사합니다.

| AI 문체 특징 | 식별 방법 | 수정 방법 |
|-----------|----------|----------|
| 공허한 요약 | 「他终于明白了」「一切尽在不言中」 | 삭제하고 행동으로 대체 |
| 상투적 수사 | 「命运仿佛在和他开玩笑」 | 삭제하거나 구체적인 묘사로 교체 |
| 비유 적층 | 「像/好像/仿佛/如同」이 연속으로 여러 번 나오고 모든 장면을 비유로 설명 | 서사 기능이 가장 큰 소수의 비유만 남기고 나머지는 행동·물건·소리·결과로 바꿈 |
| 감정 라벨 | 「他感到一阵悲伤」 | 행동 표현으로 바꿈 |
| 공회전하는 심리 묘사 | 내면 독백에 새 정보가 없거나 같은 감정을 반복하거나 독자가 이미 아는 내용을 되풀이함 | 공회전 부분만 압축. 새 정보·결정·감정 전환이 있는 독백은 문장 수만으로 압축하지 않음 |

### 차원 5: 논리 연속성
문장·단락 사이가 매끄러운지, 설정 충돌이 없는지 검사합니다.

| 문제 | 심각도 | 수정 |
|------|--------|------|
| 설정이 앞뒤로 모순됨 | critical | 설정을 찾아 통일 |
| 시간선 오류 | high | 시간선을 표시하고 수정 |
| 인물 정보가 일치하지 않음 | high | 인물 자료 대조표를 작성 |
| 인과 사슬이 끊김 | medium | 연결을 보충 |

### 정밀 수정 전략

5차원 점수 결과에 따라 정밀 수정 전략을 선택합니다.

| 주요 문제 | 전략 | 설명 |
|----------|------|------|
| 핵심 일관성이 낮음 | rewrite | 핵심 갈등을 중심으로 관련 단락을 다시 씀 |
| 글자 수 초과 | compress | 플롯을 추진하지 않는 내용을 줄임 |
| 의미 없는 막힘 | compress | 막힘으로 발생한 변화를 남기고 절차를 압축 |
| AI 문체가 짙음 | de_ai | 금지어를 교체하고 문식을 다시 씀 |
| 작은 문제가 많음 | polish | 언어 세부를 다듬음 |

### 독자 계약과 최종 비축의 양방향 심사

심사는 먼저 “유해하지 않은가”를 묻고, 그다음 “재미있는가”를 묻습니다. **유해하지 않다고 해서 재미있는 것은 아닙니다.** 계약을 깨지 않았다는 것은 지뢰를 밟지 않았다는 뜻일 뿐이며, 감정적 보상이 충분히 강한지도 확인해야 합니다. 위험 표시는 세 단계입니다. 계약 안전(도입 약속과 일치하고 주인공이 핵심 선택권을 보유하며 이익 귀속이 분명함) / 보강 필요(고점을 희석하거나 추진을 앞당길 수 있지만 포석·교환·대가로 복구 가능) / 계약 파괴(핵심 매력을 빼앗거나 무관한 인물이 기대의 소유권을 가져가므로 개요 수정 필요).

- [ ] 독자 계약: 이번 장·이번 권이 도입 약속을 이행하는가, 아니면 핵심 매력을 기관·조연·우연성에 넘기는가? 위험 표시: 계약 안전 / 보강 필요 / 계약 파괴
- [ ] 주인공 대리권: 등장 시간보다 인과권+결산권으로 심사. 핵심 지점에서 네 가지를 확인 — 누가 결정해 일이 발생했는가, 누가 대체 불가능한 선택을 했는가, 누가 핵심 결과를 부담하거나 선택했는가, 핵심 이익·인정·권력은 누구에게 귀속되는가. 조연은 국소 행동을 수행할 수 있지만 조용히 기대의 소유권을 빼앗아서는 안 됨
- [ ] 기대 부채: 약속이 상환되거나 이자를 붙여 연기되었는가, 아니면 설명·절차·설정에 삼켜졌는가
- [ ] 최종 비축: 이 단위가 아직 해금하면 안 되는 최종 비장의 카드(숙적/진실/신분/금손가락 상한)를 사용했는가? 어떤 상승선이 천장에 닿아 뒤에 이어질 발판이 사라졌는가? 두 질문 모두 아니면 통과 — 한 장에서 여러 선이 함께 상승하는 설계는 과속으로 보지 않음
- [ ] 이행 귀속: 기대의 소유권이 약속대로 결산되는가. 자발적 양도는 “장기 순이익이 음수 + 통제권/인과권 하락”이 동시에 나타날 때만 적색 경보. 전략적 양보에서 더 큰 통제권·미래 이익·권력·정보 교환이 보이는가
- [ ] 리듬 연결: 절정·이행 뒤에 짧은 저압과 작지만 보이는 이익·보상을 허용하는가. 기계적으로 즉시 위기를 추가하지 않는가. 새 요소가 작품 전환 부채를 지불하고 기존 약속을 회피하지 않는가
- [ ] 장르 특유의 위험: 이행형 쾌감물·능력 판타지에서 주인공이 반복해서 어리석음이나 피할 수 있는 무능으로 재난을 만들고 타인이 수습하게 하여 인과권과 결산 신뢰를 해치지 않는가
- [ ] 역방향 심사: “안전한 설명”을 삭제하면 감정이 더 강해지는가? 위험한 플롯을 남길 경우 더 강한 기대·대가·쾌감이 생기는가
- [ ] 종합선: 계약·주인공 대리권·기대 부채·최종 비축이 서로 지지하는가. 단순히 “유해하지 않음”에 그치지 않는가

## 3. 단편 전용 검사

### 피폐·쾌감 리듬 검사

단편에 특유한 검사 항목입니다. 피폐한 구간과 쾌감 포인트가 합리적으로 배치되었는지 확인합니다.

```
이상적인 배치: 피폐1 → 피폐2 → 피폐3 → 쾌감1(소) → 피폐4 → 쾌감2(대)
금지 배치: 피폐1 → 피폐2 → 피폐3 → 피폐4 → 피폐5(쾌감 없음, 독자 이탈)
금지 배치: 쾌감1 → 쾌감2 → 쾌감3 → 쾌감4(포석 없음, 쾌감 피로)
```

검사 규칙:

- 300자마다 작은 갈등이 최소 1개 있어야 함
- 피폐 포인트 사이가 전체 분량의 30%를 넘지 않아야 함
- 가장 큰 쾌감 포인트는 전체의 70~85% 지점에 있어야 함
- 결말에는 감정의 착지점이 있어야 함

### 대화 밀도 검사

| 지표 | 합격 기준 | 경고선 |
|------|----------|--------|
| 전체 분량 중 대화 비율 | 45~65% | <30%(너무 건조) 또는 >75%(너무 늘어짐) |
| 장당 대화 수 | 1,000자당 12~18줄 | <8줄(상호작용 부족) 또는 >25줄(파편화) |
| 상처 주는 대화 비율 | 35~45%(피폐물) / 20~30%(쾌감물) | 피폐물 <20%(아픔 부족) / 쾌감물 >40%(지나치게 억압적) |

### 주인공 냉정함 검사(사이다·복수물 전용)

| 검사 항목 | 기준 |
|--------|------|
| 주인공에게 상징적인 냉정한 행동이 있는가? | 반드시 있어야 함(물컵을 들거나, 정장을 정리하거나, 펜을 돌리는 행동 등) |
| 주인공이 감정을 통제하지 못하는 장면이 있는가? | 복수물은 최대 1회이며 앞 30% 안에 있어야 함 |
| 악역이 주인공보다 더 히스테릭한가? | 반드시 그래야 함 — 대비가 쾌감의 원천 |
| 주인공의 대사가 악역보다 짧은가? | 평균 30~50% 짧아야 함 — 짧을수록 힘이 생김 |
| “심문식 대화”가 있는가? | 최소 2곳(주인공의 질문 → 상대의 자백) |

### 증거 사슬 완결성 검사(복수·사이다물 전용)

| 검사 항목 | 기준 |
|--------|------|
| 증거가 장마다 나뉘어 공개되는가? | 최소 3회에 나누어 공개하고 한 번에 모두 주지 않음 |
| 각 증거에 포석이 있는가? | 앞부분에 단서가 심겨 있어야 함 |
| 악역이 매번 우쭐한 뒤 사이다를 맞는가? | 반드시 그래야 함 — 먼저 띄우고 뒤에 꺾음 |
| 최종 증거가 가장 치명적인가? | 마지막 증거가 전체 인식을 바꿔야 함 |
| “시한폭탄” 증거가 있는가? | 주인공이 미리 배치한 증거가 최소 1개 있어야 함 |

### 유해성·몰입·충격·도입·결말·감정·기대감 빠른 검사

> 자세한 유해 문식의 분류·식별·수정 방법은 `anti-ai-writing.md`를 참조합니다.

| 검사 항목 | 기준 |
|--------|------|
| 쾌감물인데 시원하지 않음 | 금손가락의 효과를 분명하게 보여 줘야 함 |
| 억압에 목적이 없음 | 모든 억압은 이후 폭발을 위한 것이어야 함 |
| 악역의 결말이 주인공과 무관함 | 악역의 죽음은 주인공의 행동으로 일어나야 함 |
| 경제·전투력 붕괴 | 설정이 앞뒤로 일치하고 일반인을 기준점으로 삼아야 함 |
| 여주·여조가 갑자기 지능을 잃음 | 인물 설정이 정상적인 범위에서 쓰고, 낡은 공식을 반복하지 않음 |
| 독자의 기대가 오랫동안 충족되지 않음 | 적시에 충족하거나 새 기대를 도입 |
| 주인공의 행동을 이해할 수 없음 | 이해하고 공감할 수 있어야 함 |
| 분위기가 뜬금없는 개그로 깨짐 | 분위기 > 뜬금없는 개그(희극물 제외) |
| 훅이 회수되지 않음 | 훅 미회수 = 용두사미 |
| 충격의 층위 | 점 → 망 → 심층으로 확장하고 단순한 충격만 쓰지 않음 |
| 충격 계단식 상승 | 계단식으로 상승하며 직선적으로만 밀어 올리지 않음 |
| 충격의 범위 | 관계망 전체가 반응해야 함 |
| 앞 50자 안에 갈등·이상이 있음 | 배경 포석만으로 시작하지 않음 |
| 앞 100자 안에 핵심 갈등을 알 수 있음 | 반드시 알 수 있어야 함 |
| 도입 감정 강도 | ≥7(1~10) |
| 결말이 구체적인가 | 행동·대화·장면으로 끝내고 요약·반성을 금지 |
| 결말에 여운이 있는가 | 독자가 계속 읽고 싶어 해야 함 |
| 결말 감정 강도 | 피폐물 ≥8, 쾌감물 ≥7, 치유물 ≥6 |
| 감정이 대등하게 해소되는가 | 피폐가 쌓인 만큼 보상하고, 악역의 결말을 주인공과 연결 |
| 기대 관리 | 장편 2개 뒤 단편 1개 리듬을 유지하고 핵심 매력을 관통시킴 |
