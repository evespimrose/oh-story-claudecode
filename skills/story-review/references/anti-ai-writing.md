## AI 작성 지문 (반드시 피할 것)

### 고빈도 AI 용어

> 완전한 금지어 표는 [banned-words.md](banned-words.md) 참고

**보충 항목** (`banned-words.md` 에서 미커버한 고차원 대체):

| 범주 | 대체 원칙 |
|------|---------|
| 추상 승화어 (운명, 숙명, 정해짐) | 구체적 사건으로 추상 개념 대체 |
| 만능 비유 (밀물처럼, 번개처럼, 마치 봄바람) | 우선 비유를 쓰지 않으며, 필요시 소수의 생활적, 캐릭터화된 비유만 남김 |

### 장말 요약체

**금지** 장 끝에 다음 방식으로 수렴:
- 요약적 감상 ("그는 마침내 깨달았다……")
- 승화식 감탄 ("이 밤은, 정말 아무도 잠들지 못할")
- 철학식 마무리 ("인생이란 이런 것……")
- 복선식 예고 ("그가 모르는 것은, 더 큰 폭풍이 곧 닥친다는 것")

**정확한 방법**: 장말은 동작, 대화 또는 현안으로 수렴하여, 서사 자체가 여운을 만들게 한다.

### 중첩식 묘사 (동일 동작을 쪼개 세 번 쓰기)

**탐지 패턴**: 한 동작/감정을 먼저 발생 쓰고, 다시 인지 디테일 보충, 다시 신체 반응 보충하여 세 단락으로 나눠 쓴다. 독자는 같은 동작이 쪼개져 세 번 반복된 것을 본다.

**전형 특징**:
- 먼저 개괄적 동작 쓰고, 다시 같은 동작의 디테일을 전개하고, 다시 신체 반응 씀: 세 단락이 같은 일을 말함
- "발생층→인지층→반응층" 순서로 단락 분할되어 나타남
- 각 차원이 독립 단락으로 되어 있지, 같은 단락의 연속 본문에 섞여 있지 않음

**잘못된 예시**:
> 임부는 머리를 숙이고, 왼손으로 문서를 누르며, 오른손으로 붓을 잡아 종이에 내려꽂았다.
>
> 팔꿈치부터 손목까지 온몸이 떨렸다.
>
> 붓끝이 종이 위에 잠시 멎었다가, 한 획을 긋고 다시 멎었다. 그 "임" 자의 비뚤림이 삐뚤어졌다.

→ 같은 동작 (손 떨림/글쓰기)을 세 단락으로 나눠 썼으며, 각 단은 같은 순간의 다른 차원임

**정확한 방법**: 발생, 인지, 반응 세 차원을 같은 단락의 연속 본문에 섞어 독자가 하나의 완전한 순간을 읽게 한다:

> 임부는 왼손으로 문서를 누르고, 오른손으로 붓을 잡아 종이에 내려꽂았는데, 붓끝이 종이에 닿자마자 빗나가 팔꿈치부터 손목까지 멈추지 않고 떨려서, 그 한 획이 비스듬히 끌려나갔다.

→ 발생, 인지, 반응이 한 단里에 동시에 나타남

**처리 원칙**: 기능이 있는 감정 디테일을 보존하고, 같은 순간의 중복 묘사를 연속 화면으로 병합한다. 병합 후 현저히 얇아지면 원문에 기능이 있는 정보를 우선 회복하거나, 기존 정보를 더 자연스러운 동작/대화 표현으로 바꿈; 원문에 없는 서사, 설정, 관계 또는 타임라인을 새로 추가하지 않는다.

## 핵심 규칙

> **문장 길이는 규칙 3을 기준으로 한다**: 규칙 1-4와 본 파일 다른 곳의 「짧은 문장 / 짧게 나누기 / 지울 수 있으면 지우기」 발언은 규칙 3과 충돌 시 규칙 3을 따른다.

### 규칙 1: 단락 밀도 진단

단락 장단은 고정된 우열이 없다. 검사 중점은 낭독과 모바일 독서 시 끊김이 있는가:

- 한 단락은 보통 한 동작, 한 정보 변화 또는 한 조의 밀접 연관된 반응만 싣는다.
- 쉼표 열이 너무 길고, 여러 완전 동작이 한 단락에 몰려 있어 읽을 때 숨 가쁘면, 동작 또는 정보 변화 기준으로 나눈다.
- 연속 짧은 단락이 강요처럼 깨지면, 같은 카메라 앵글 내의 인접 문장을 병합하여 화면이 연속되게 한다.

```
과밀: 그는 창밖의 비를 보며, 말로 다 표현할 수 없는 느낌이 가슴에 밀려왔고, 이 세월 걸어온 길과 이미 잊은 많은 일들이 이 순간 몰려왔다.

더 자연스럽게: 그는 창밖의 비를 응시했는데, 비는 오후부터 해 질 녘까지 내렸다.
"아직도 그녀 생각해?" 노인이 물었다.
그는 말이 없었다.
```

### 규칙 2: 동작 + 대화 + 감정 반응

3요소 순환 추진하며, 심리 활동만 단독으로 2단 이상 쓰지 않는다:

```
동작 -> 대화 -> 감정 반응 -> 동작 -> 대화 -> ……
```

감정은 "그는 느꼈다/그는 생각했다"로 쓰지 않고, 신체 반응과 행동으로 표현한다:
- "그는 매우 긴장했다" 쓰지 않음 -> "손바닥에 땀으로 축축해 젓가락을 떨어뜨릴 뻔했다"
- "그녀는 매우 분노했다" 쓰지 않음 -> "그녀는 컵을 바닥에 내던졌는데, 파편이 발등에 튀었음도 허리를 굽혀 줍지 않았다"
- "그는 매우 슬펐다" 쓰지 않음 -> "그는 차 안에서 이십분 앉아있어야 시동을 걸었다"

이상 대체는 핵심 감정 노드에 대한 것; 저강도 경과 감정은 한 번 직서해도 좋다 ("그는 좀 짜증났다")고, 굳이 매번 외현화할 필요 없다.

### 규칙 3: 문장은 얼마나 길어야 하는가 (짧은 문장은 도구이지 기본이 아니다)

서술 (방백)은 기본적으로 **쉼표 긴 문장**으로 쓴다: 한 문장은 쉼표로 2-4개 동작이나 정보를 이은 뒤 마침표를 찍는다; 쉼표 사이는 8-12자, 전 문장은 20-30자. 짧은 문장은 가끔 쓰는 고립된 강조 도구이지, 서술의 기본 작법이 아니다.

| 장면 | 문장 길이 | 예시 (장편 어법 원문) |
|------|------|------|
| 일상 / 추진 / 묘사 (대다수 서술문) | 쉼표 사이 8-12자, 전 문장 20-30자 | 음습하고 축축한 기운이 코앞에 밀려왔고, 몸 아래는 얇은 볏짚이 깔려 축축하게 피부에 달라붙었다. |
| 대화 | 구어체, 장단은 캐릭터에 따름 | "너 미쳤어?""아마도." |

**부적격 (AI 체와 동급)**:
- 쉼표 사이가 모두 ≤5자의 파편으로 이어짐 ("그가 손들고, 문열고, 들어가고, 앉았다" 식)
- 통째로 3-8자 문장이고, 마침표가 강요처럼 촘촘함 (전보체, 패턴 9 참고)
- 일장일단 기계적 교차 (역시 템플릿)

> **베스트셀러 말뭉치 교정** (칠묘 장편 현언/도시/고언/현환/역사 125권×앞 8장 방백 통계): 쉼표 사이 평균 8.8-9.6자; 전 문장 평균 22-24자; 쉼표 긴 문장이 서술문 중 74-80% 차지; ≤5자 짧은 파편은 약 20%이며 대부분 고립된 시간어, 전환, 동작 강조다. 단편 (염언체)은 단락이 더 짧지만 (≤15자 단일 문장 단락이 거의 절반, 장편은 약 2-3成), 문장 내부 리듬은 장편과 같다: **단락은 체재에 따라 짧아지지만, 문장 내부는 깨지지 않는다**.

### 규칙 4: 구어체 표현

- 속어, 욕설 허용 (캐릭터 신분에 부합)
- 대화는 문어체 쓰지 않음 ("나는 이 일이 부적절하다고 생각합니다" -> "별로라고 생각해")
- 서술도 점잔 빼지 않음 ("그의 눈빛이 번뜩였다" -> "그는 눈알을 꼼짝 않고 응시했다")
- 성어보다 구절 우선 ("어쩔 수 없었다" -> "어쩔 수 없지")——대화와 캐릭터 어조에 붙는 서술만 해당; 방백에서 흔히 쓰는 성어 (태연히, 딴 생각 등)는 그대로 둔다.

## Show Don't Tell 원칙

| Tell (고지식) | Show (보여주기) |
|-------------|-------------|
| 그는 소심한 사람이다 | 그는 검사 보고서를 손에 넣고 세 번이나 뒤척여 봤지만, 여전히 열 엄두를 못 냈다 |
| 이 술집은 시끄럽다 | 바텐더가 그의 귓가에 두 번이나 소리쳐야 그가 알아들었다 |
| 그녀는 부유하다 | 그녀는 아무렇게나 신용카드를 탁자에 던졌는데, 카드 번호가 이 식사 열 배나 비쌌다 |
| 두 사람 관계는 나쁘다 | 그는 그녀가 방금 우려낸 찻잔에 담배꽁초를 꽂았고, 그녀는 무표정하게 찻잔을 옆으로 밀었다 |
| 그는 똑똑하다 | 3초. 그는 3초 보고 서류를 덮었다. "3페이지, 2번째 줄." |

**핵심 방법**:
1. 행동으로 형용사를 대체
2. 디테일로 요약을 대체
3. 대화로 방백 설명을 대체
4. 반응으로 감정어를 대체

## 품질 차원 검사

### 1. 핵심 일관성 (가중치 최고)
- 서사가 개요/전문과 일치하는가
- 인물 행동이 인설과 부합하는가
- 설정에前后 모순이 없는가

### 2. 표면 재작성 (AI 지문 방지)
- AI 고빈도 용어 포함 여부 (위 표 참고)
- 장말에 요약/승화 있는지
- 대단 순수 심리 묘사 있는지
- 단락이 연극 단위/카메라로 자연스럽게 끊어졌는가, 기계적 단일 문장 단락이나 짧게 깨서 강요처럼 만들지 않았는가 (웹소설 단락 규칙)

### 3. 형식 일관성
- 대화 형식 통일: 프로젝트/플랫폼 약정대로 같은 인용부호 스타일 유지; 지호 염언 단편은 「」 사용 가능
- 문장 부호 리듬이 어조와 부합: 통째 마침표화 피함; 기능 있는 물음표와 소수의 느낌표 보존; 동작/짧은 문장으로 망설임이나 중단을 표현하고, 줄임표나 대시로 억지로 쉼을 만들지 않음
- 장면 전환에 명확한 표시 있음
- 타임라인이 추적 가능하게 명확함

### 4. 가독성
- 연속 여러 긴 문장이 독서 리듬을 누르고, 동작, 대화 또는 짧은 문장 환기가 부족한지
- 대화가 구어체인지
- 미설명한 희귀어/설정 용어 있는지
- 리듬에 빠름과 느림이 있는지 (한 가지 리듬일 수 없음)

### 5. 논리 연속성
- 캐릭터 동기가 합리적인가
- 사건 인과 사슬이 명확한가
- 타임라인이 맞는가
- 캐릭터의 지식 범위가 합리적인가 ("신의 시점" 열면 안 됨)

## 빠른 자가 검사 구결

```
한 일 한 단락, 카메라는 자연스레 끊긴다.
대화는 사람이 말하는 것처럼.
심정은 심정으로 쓰지 않는다.
끝에 큰 승화 두지 않는다.
겨루기는 줄글로 쓰지 않는다.
일상은 복선 말뚝을 묻는다.
```

> 웹소설 단락 규칙: 연극 단위/카메라/한 일 끝날 때 자연스레 단락 끊기; 짧은 단락은 빨리 읽히고, 긴 단락은 완전한 추리, 분위기와 감정 고리를 싣는다. 기계적 단일 문장 단락이나 통째 같은 길이 피함.

---
> **판타지 고득점 표본 교정**: 판타지 본문은 "모바일 짧은 단락 + 자연 허사 + 장내 동작/대화 추진"에 더 가깝지, 기계적 지표 달성이 아니다. 판타지 고득점 표본 305장 창에 따르면: 단락 중위 약 23.5자, 50-60자 행폭은 평균 5.1%만 차지; 평균 대화 비율 약 20.6%, 대화≥50%는 3/305에 불과, 시작 대화는 59/305; `地/得`은 305/305, `很`은 275/305, `像/好像/仿佛/如同`은 267/305, 등호는 176/305, 줄임표는 281/305. 결론: 이것들은 문맥대로만 복기할 수 있지, 0 용납 하드 금지로 삼을 수 없다.
>
> **반투기 경계**: "반탐지"를 위해 억지로 매 문장 바꾸어 쓰기, `……`를 `........`로 고치기, `地/得`을 전부 `的`로 바꾸기, 모든 등호/「很」/「像」 금지, 억지로 시작 대화하거나 삼번사증으로 장 재배열하지 않는다. AI 풍 제거는 윤문이지 구조 재작성 아님; 사용자가 명시적으로 재작성을 요구하지 않는 한 장 순서, 복선 분포, 대화 비율과 인물 정보 방출 리듬을 변경하지 않는다.

## 10가지 AI 작성 패턴 탐지

### 패턴 1: AI 고빈도어

| 금지 | 대체 |
|------|--------|
| 부지불식간에 | 삭제 |
| 마치/꼭 | 삭제하거나 구체 묘사로 |
| 눈에 들어오다 | 삭제 |
| 마음속으로 생각하다 | 동작으로 사고 보여주기 |
| 낮은 목소리로/담담하게 말하다 | 동작 태그로 바꾸기 |
| 안색이 변하다 | 구체적 표정/동작으로 |
| 입꼬리가 살짝 올라가다 | 그가 웃었다/입꼬리를 살짝 쳐올렸다 |

### 패턴 2: 약화 부사 범람
임계값: 매 1000자당 3개 초과 = AI 서명. 중점 모니터: 살짝, 담담히, 천천히, 가볍게.

### 패턴 3: 의미 팽창
- "의미가 심원하다" -> 구체적 결과 쓰기
- "전례 없다" -> 대비 참조 제시
- "말하자면" -> 삭제

### 패턴 4: 만능 결론
- "미래가 기대된다" -> 미해결된 긴장감으로 끝내기
- "앞길이 창창하다" -> 삭제
- "희망에 차 있다" -> 구체적 다음 동작 쓰기

### 패턴 5: 논문체 단락 구조
소설에 다음 시작 문장이 나옴 = AI 침입:
- "어렵지 않게 알 수 있다""이로부터 알 수 있다""사실상""종합하자면"

### 패턴 6: 문어체 접속사 범람
서술 산문에 빈번 출현: "그리하여""이와 동시에""따라서""그러므로""물론" -> 구어체 대체하거나 직접 삭제.

### 패턴 7: 삼연 병렬병
AI는 일을 "완전"해 보이려고 세 개로 모으는 것을 좋아한다. -> 가장 힘 있는 한 가지만 남기고 삭감.

교차 단락 「A가 아니다. / B도 아니다. / 단지 C일 뿐이다.」는 `formulaic-parallelism`이 advisory로 처리: 이는 정연한 진열일 수도 있고, 변명, 현안 배제 또는 감정 진보를承担할 수도 있다; 강요가 반복되거나 화면을 느리게 할 때만 압축한다. 해당 유형 힌트와 「X가 아니건, 어떻게 X하건」, 동일 동사 「V하지 않 A, V하지 않 B」는 모두 의미 복기만 수행: 대화도 검사하되, 명확한 인물 어조나 임무 기능이 있을 때 보존 가능; 세강 여러 필드가 같은 요구를 반복하는 것에서 오면, 본문은 한 번만 소비하지 항목마다 복술하지 않는다.

### 패턴 8: 설명조 / 신의 시점 / 안배감
가장 눈치채기 어렵지만, 가장 "AI 답"인 부류. 서술자가 캐릭터의 당대를 뛰어넘어 설명, 스포일러, 요약, 정성, 고양을 하여, 독자는 "작가가 현존한다"와 "서사가 짜맞춰졌다"는 냄새를 맡는다. 이것이 바로 "설교감/신감/설명조/기계감/억지감/안배감"의 근원이다.

| 표현 | 예 (삭제/수정) |
|---|---|
| 인과 설명 | 「……이유는……이기 때문이다」「알고 보니……」「이는 곧……을 의미한다」「바로 …… 때문이다」-> 삭제. 인과는 캐릭터 동작, 대화, 반응 속에서 독자가 스스로 조립하게 한다 |
| 신 시점 스포일러 | 「그녀가 모르는 것은」「어찌 알았으랴」「여러 해 후에」「어느새」「마치 예시하는 듯」-> 삭제. 캐릭터가 지금 아는 것만 쓰고, 현안은 독자가 스스로 품게 한다 |
| 독자를 위해 결론/정성 내리기 | 「연기가 정말 대단했구나」「이 연극을 그녀는 한 번 본 적 있다」「그는 이처럼 박정한 사람이다」-> 삭제. 증거 (표정, 동작, 대사)를 내놓고 정성은 독자에게 맡긴다 |
| 캐릭터를 위해 심리 요약 | 「그녀는 깨달았다, 이 모든 것은 운명임을」-> 편견 섞인 스침 생각이나 신체 반응 한 마디로 바꾼다 |
| 요약/동기/평가 고리로 의미를 가득 채우기 | 「그는 마침내 깨달았다」「이는 최선의 선택이었다」「모든 사람이 이 순간을 기억할 것이다」-> 정성적인 말 삭제하고, 캐릭터가 지금 처리해야 할 구체적 결함, 미완료 동작 또는 국소 피드백으로 바꾼다; 평가를 보존한 뒤 억지로 물건/동작을 우겨넣지 않는다 |
| 안배감/억지 복선 | 뒤 글을 위해 억지로 배경 설명, 통째 회상 역순 -> 배경은 캐릭터가 지금 진짜 필요한 대로 스침 생각, 반 말, 물건 조각으로 끄집어내고 집중적으로 설명하지 않는다 |
| 승화식 마무리 | 끝에 대조 고양, 금구 제점 -> 한 동작이나 한 마디 여백으로 막고, "뜻"을 화면 속에 눌러 담는다 |
| 추상 운명/시작 수렴 | 「운명이 마침내 송곳니를 드러냈다」「이미 짜놓은 바둑판」「이 순간 마침내 깨달았다」「그의 반격은 이제 막 시작됐다」-> 캐릭터가 지금 보이는 파일, 동작, 대화 또는 물리적 결과로 바꾼다; `check-ai-patterns.js`가 `abstract-summary-tic`를 보고할 때 우선 처리 |
| 상용구 밀도 과다 | 마치/약간/한 점/깊이 숨 들이켰다/평온无波/指節이 하얗게 질리다 등이 줄줄이 재현 (`cliche-density-tic`) -> 동의어 순환이 아니라, 통째로 캐릭터 지금 증거로 돌아가기: 파일, 동작, 대화, 물리 결과 |
| 비유 밀도 과다 | 처럼/마치/꼭/같다 등 비유 표지가 조각조각 재현 (`metaphor-density-tic`) -> 정보나 감정을 가장 잘 전달하는 한두 개만 남기고 나머지는 구체 동작, 물건, 소리, 결과로 되돌리기; 새 비유로 바꾸지 않는다 |
| 시스템 공고 공문조 과다 | 대괄호 규칙/패널/공고 행里 하드 규칙어가 조각조각 (`system-notice-formality-tic`) -> 캐릭터가 보는 스크린/공고/규칙 담지로 보존; 담지 내부에서만 일부 하드어를 백화화하거나, 캐릭터가当场 알아본 구체 결과를 보충할 뿐, 서술자 설명으로 바꾸지 않는다 |

**더 은밀한 층위 (자가 검사 가장 어렵고, 표지 어구 없음)**——역시 안배감/신감:
- 비판적 부사/보어: 「적절히 우려했다」「딱 알맞게 웃었다」「모자람도 과함도 없다」-> 작가가 독자를 위해 "이건 꾸민 것이다"라고 도장 찍는 중. 그저 동작만 쓰고 (「그녀는 수건을 가렸고, 눈은 움직이지 않았다」), 꾸민 것 아닌 것은 독자가 스스로 판단하게 둔다.
- 스포일러식으로 숨은 뜻을 파헤치기: 「그 희미한 웃음을 그녀는 선명히 보았다」「누구나 봐도 그가 거짓말하는 게 드러났다」-> 숨겨진 것을 캐내는 것. 그대로 두고 파헤치지 말 것.
- 정성 비유/관구구: 「이미 정해진 일을 선고하는 듯했다」「죽은 물건을 보는 듯했다」-> 비유가 캐릭터를 위해 결론 내리는 중. 캐릭터의 지금 강렬한 주관적 느낌이 아니면 삭제; 남기려 해도 그녀의 편견 섞인 순간 느낌일 뿐, 객관적 단언이 아니어야 한다.

자가 검사: 매 문장마다 한 번씩 물어본다——이것은 "캐릭터가 겪고 있는가", 아니면 "작가가 강해/안배하고 있는가"? 작가가 뛰어나와 말하면, 삭제하거나 캐릭터 시점 내의 제시로 바꾼다. 근본 치료법은 깊은 제한 지식 시점을 고정하는 것 (writing-craft.md 「시점 자세: 깊은 제한 지식」 참고)으로, 카메라를 캐릭터 몸 속에 못 박으면 작가가 뛰어나올 자리가 없다.

수정 우선순위: 오염 문장을 먼저 삭제하거나 제자리에서 대체하지, 단락 끝에 "인간味" 꼬리를 덧붙여 보충하지 않는다. 정보를 보충해야 할 때, 원래의 요약/동기/평가 문장을 캐릭터가 지금 부딪힐 수 있는 문제, 수속, 회신, 지불, 문 밖 동태 등 구체 압력으로 바꾼다; 이미 휴대폰/스크린/공고/문패/서식 등 정보가 있으면, 캐릭터가 본 장내 담지로 우선 보존하지 서술자 설명으로 바꾸어 쓰지 않는다. 구체 담지는 서사를 따라가지 고정 리스트를 씌우지 않는다.

**임무 카드는 고정 공식도 아니고, 범용 보충 절차 버튼도 아니다**: 그저 기존 설명을 캐릭터가 지금 처리해야 할 결함으로 눌러 담을 뿐이다. 먼저 원문에 "처리할 일"과 "막힌 점"이 있는지 묻고; 있으면 임무 카드로 압축 가능; 없으면 그저 설명만 삭제하거나 동작/대화로 고칠 뿐, 새 사건 고리를 새로 만들지 않는다. 수정 후 다시 "지워보자" 테스트: 삭제해도 정보, 감정, 관계, 대가 또는 복선에 영향 없으면 압축 또는 삭제.

**하지만 설명조 삭제 ≠ 독자를 어리둥절하게 만드는 것**: 신명사/신설정/신도구가 처음 나올 때, 여전히 독자가 닻을 잡게 해야 한다——캐릭터의 동작 반응, 대화 속 반 말 자연스러운 언급, 또는 장면 내 물리적 결과로 그것이 지금 어떤 작용이나 무게를 가지는지 한 번 끄집어낸다; 통째로 유래 원리를 설명하지도 않고, 그저 정보 영生词만 내던져 독자를 어리둥절하게 만들지도 않는다. 인물 기억, 감정 완충, 인과 계승도 마찬가지: 만약 한 마디가 겉보기엔 설명/평가 같아도 실제로 작은 연속성을承担한다면 (독자가 캐릭터가 왜 얼굴이 달았는지, 왜 멈췄는지, 왜 이 한 마디를 누르지 못하는지 알게 함), 기계적으로 삭제하여 발췌 리스트로 만들지 말 것; 캐릭터 지금의 백화, 동작, 물건 또는 반 마디 생각으로 눌러 담는다. 예: 「蓝晶」처음 나올 때 "이것은 기억을 저장하는 장치다" 라고 쓰지 않지만, 그녀가 蓝晶을 관자놀이에 대자, 다른 사람 기억 조각이 눈앞에서 펑 터진다고 쓸 수 있다——기능이 독자에게 보이고, 전모는 현안으로 남는다. 구분: 닻은 "캐릭터가 지금 부딪힌 지각 가능한 결과/기억 또는 감정 계승" (보존 또는 압축)이고, 설명은 "작가가 뛰어나와 설정 유래/원리를 강해하거나 독자를 위해 결론 내리는 것" (삭제)이다.

### 패턴 9: 과도 압축 (전보체)

AI 풍 삭제하다 지나친 역방향 지문. 매 문장을 모두 최단으로 압축하고, 구조 허사를 싸 쓸어내고, 매 동작마다 「했었다/한 번 했다」식 가벼운 반응을 보충한다. 단일 문장은 보기엔 깨끗하지만, 이어 읽으면 강요 같고 독자의 체감은 "부자연스럽고, 숨이 가쁘다"다. 삭감 목표는 쓸데없는 말 (설명, 물타기, 숫자 채우기)을 지우는 것이지, 중국어의 자연스러운 중복을 지우는 게 아니다.

| 표현 | 수정법 |
|---|---|
| 비첨두 서술문조차 모두 최단 문장으로 압축 | 강조 문장 (동작/감정/현안 첨두)은 짧게 유지; 복선, 경과, 일상 동작은 자연스러운 백화 문장으로 쓰고, 了/的/就/的时候 등 구조 허사를 보존 |
| 「한 번 당겼다/한 번 멎었다/두 번 쳤다/반 바퀴 느슨해졌다」식 미동작 고밀도 재현 (check-ai-patterns.js가 micro-action-tic 보고) | 동작 병합하고 구체 디테일로 바꾸기; 매 동작마다 반응 꼬리를 이을 필요 없다 |
| 강조 부사 (连/才/又/只/全/反而)이 싸 쓸려나감 | 삭제 전 의미 판단: 인설, 대비, 풍자 의미承担하는 건 보존 ("才 이십 삼일"에서 「才」를 삭제하면 인설 강조가 거꾸로 됨) |
| 대화 어기사가 영으로 줄어듦 | 캐릭터 따라 자연스러운 저빈도 의 呢/吧/啊 보존; 역방향으로 마구 더하지도 말 것——인간味는 구조의 자연스러움에서 나오지, 채팅조에서 나오는 게 아니다 |
| 서술에 공문/문언조 잔류 (不得不/须/未/已然/当前) | 백화로 바꾸기 (不能/要/还没/现在). 시스템 공고, 규제 조문, 패널 방송은 냉엄한 기능 보존 가능; 만약 `system-notice-formality-tic` 경보가 울리면, 원래 담지 내에서만 일부 백화화할 뿐, 서술자 설명으로 바꾸지 않는다 |
| 장문에서 짧은 서술 단락이 조각조각 (`overcompressed-prose-tic`) | 모든 짧은 단락을 늘일 필요 없음. 먼저 인공 통독: 강조 짧은 문장, 밀집 카메라가 문맥상顺하면 보존; 그저 강요처럼 깨진 경과 문장만 처리하여, 같은 카메라로 다시 병합하여 독자가 동작, 공간, 인과를 따라 읽게 한다 |
| 따옴표 밖 서술이 저연결 밀도이고 중장 문장 부족 (`low-connective-density-tic`) | 전역으로 「的/了/就」채우지 말 것, 대사/탄막/시스템 방송의 본래 짧음도 처리하지 말 것. 먼저 서술층에서 강요처럼 깨진 곳을 찾아 필요한 연결, 지시와 중장 계승 문장을 회복; 중장 문장 고리가 있는 저기능어 텍스트는 보존 가능 |

자가 검사: 삭제 마치고 이어 한 번 읽어보고, 독감이 강요 같거나 명령문 같으면 삭제를 지나친 것이다——비첨두 문장을 자연스러운 백화로 회복하지, 계속 삭제할 게 아니다.

본 패턴이 제약하는 것은 삭감의 정도이지, 정리 강도를 낮추는 게 아니다: 금지어, 진부한 문식, 고지식 심리는 여전히 그대로 삭제 수정하며, 패턴 1-8과 Gate A-G는 전액 실행; 되메우기는 구조 허사와 연결만 되돌리지, 어떤 템플릿 표현도 보존하거나 회복하지 않는다.

### 패턴 10: 이수 수정 가짜 자연스러움 (기름진 도치 / 감시 카메라 동작 리스트 / 대화 지표화)

일부 "반탐지 프롬프트"는 텍스트를 또 다른 템플릿으로 몰아간다: 돌발성을 높이려고 도치를 남발하고, 진짜 사람 느낌 내려고 기계적으로 말실수와 욕설을 더하고, 모바일 독서를 위해 억지로 매 문장 바꾸어 쓰고, 대화 비율을 채우려고 심리와 서술을 억지로 대사로 고친다. 이것들은 자연스러운 웹소설이 아니라, 이수 흔적이다.

| 표현 | 수정법 |
|---|---|
| 기름진 도치 | 「손에 칼을 들고, 그는 달려들었다」류 수반 동작 전치를 쓰지 않는다. 연속 동일 주어 시, 우선 장내 물건, 소리, 국소 신체 또는 환경 피드백으로 자연스럽게 문두를 바꾼다; 사물 의인화 남발하지 않는다 |
| 감시 카메라식 동작 리스트 | 같은 단락에 연속 "손을 뻗어 집고, 건네받고, 걷어내고, 내려놓고, 몸을 돌리고……" 가 단계표 같다. 시시한 동작을 병합하고, 감정, 서사 또는 공간 기능 있는 동작만 남긴다; 필요 시 캐릭터 망설임, 오판, 타인 반응 또는 환경 피드백으로 완충한다 |
| 고압 장면 잘못된 탈수 | 갈등, 추격, 겨루기는 설명과 논리 풀칠 삭제 가능; 일상, 애매, 복선은 장 전체 탈수하면 안 된다. 지울 것은 쓸데없는 말이지, 「的/了/就/但是」등 자연스러운 연결이 아니다 |
| 글자 빼먹고 단어 누락 | AI 제거 후 동사에 대상이 없고, 동작 지향이 불분명하고, 독자가 누가 누구에게 무엇을 했는지 모르면, 필요한 목적어, 담지물 또는 물리 피드백을 보충해야 한다; 중국어는 생략 가능하지만, 강요처럼 빼먹어 강요 같을 순 없다 |
| 대화 지표화 | 50%-60% 대화 비율을 채우려고 억지로 대사를 확장하지 말 것. 대사는 캐릭터가 진짜 할 말 있고, 지금 반드시 해야 할 때만 늘린다; 긴 대사는 동작을 나눌 수 있고, 설명적 대사는 우선 갈등, 회피 또는 반 말 정보로 압축한다 |
| 경직 형식 투기 | 억지로 매 문장 바꾸어 쓰기, 50-60자 한 줄, 줄임표를 영문 점으로 고치기, `地/得`을 전부 잘못 고치지 않는다. 플랫폼과 프로젝트 기존 형식대로 따를 것 |

`check-ai-patterns.js`의 `action-list-tic`는 감시 동작 리스트만 힌트할 뿐, blocking 아니다. 기능성 겨루기/추격/의식 단계가 동작 고리 자체로 정보를承担한다면, 보존하거나 `[복기 필요]`로 표시 가능. 판타지 고득점 표본에서 해당 유형 적중은 0이므로, "통독 필요"한 스타일 힌트로 쓰기 적합하지, 하드 실패항으로 삼기 적합하지 않다.

#### 도구 힌트 처리

`check-ai-patterns.js`는 로컬 작성 lint; blocking은 확정적 문식/문장 부호 문제로 제한하고, advisory는 완성 임계로 삼지 않는다. 사용자가 다른 도구 리포트를 붙일 때, 본문에 내릴 수 있는 문식, 단락, 어휘 문제만 구체 수정점으로 전환하지, 「0% AI / 100% 진짜 사람」이나 「고정 공식」을 쓰지 않으며, 점수를 둘러싸고 미세 조정을 반복하지도 않는다.

도구 힌트는 독감 규칙보다 높지 않다. 참고 텍스트에 「마치/매우/느꼈다」등 상용구나 고지식 심리가 나와도, 여전히 패턴 1-8대로 청소; 기계적으로 어구를 채우거나, 일부러 오자를 내거나, 소재를 둘러싸고 껍질 씌우지 않는다.

**AI 풍 제거 보충 판단**:
- 우선 처리: 작가의 설명 요약, 의미 꼬리, 서사를 「그는 깨달았다 / 이는 ……을 의미한다 / 진짜 중요한 것은 / 이번 성장」으로 번역하는 것. 우선 삭제하거나, 장내 동작, 대화, 물건 상태, 임무 상태와 캐릭터가当场 처리해야 할 결과로 되돌린다.
- 장내 담지 우선: 원문에 이미 휴대폰, 스크린, 공고, 문패, 서식, 청구서, 물증, 규칙행이 있을 때, 캐릭터가 보는/잘못 읽는/처리하는 텍스트나 물건으로 보존; 같은 정보를 서술자가 규칙을 설명하는 식으로 바꾸어 쓰지 않는다.
- 백화하되 물타기하지 말 것: 정교한 연극 반응 구 (두피가 팽팽해지다, 눈꺼풀이 펄쩍 뛰다, 가슴이 철렁하다, 속이 뒤끓다)를 연속으로 써서 서사 추진을 대체하지 말 것; 평범한 동작/평범한 느낌을 쓸 수 있으면 평범한 동작/평범한 느낌을 쓰고, 자연스러운 「的/了/就/但是/已经/之后/没有」등 연결을 보존한다.
- 소재 문풍 우선: 문풍 대조는 도움 되지만, 반드시 목표 소재/본서 문풍 지문에서 나와야 한다; 반룡조, 구 웹소설조, 1인칭 어조 등을 범소재 만능 수정법으로 삼지 않는다.
- 범용 수정법으로 삼지 말 것: 단순히 제목 더하기, 물건 보충, 동작 꼬리 보충, 문장 늘리기/짧게 압축하기, 대기열/문열/기록체 늘리기는, 구체적인 서사, 시점과 언어 문제 처리의 대체물이 될 수 없다.

#### 개요 문장을 연속 단락으로 쓰기

텍스트에 이미 blocking / 뚜렷한 advisory가 없지만, 여전히 강요처럼 읽힐 때, 오직 깨진 곳만 처리:

1. 논리 보고서처럼 읽히는 단락을 표시: 「그는 안다/그는 깨달는다/이는……을 의미한다/진짜 문제는/반드시/필요하다」등 판단 고리가 연속 출현하되, 지금의 동작, 물건 또는 대화 피드백이 부족하다.
2. 서술자 결론을 실체화: 캐릭터가 지금 만질 수 있고, 듣고, 억지로 처리해야 할 결과로 「그는 깨달았다/이는 ……을 의미한다」를 대체한다. 고정 물건 리스트를 씌우지 말고, 어떤 장면 껍데기를 범용 규칙으로 삼지도 말 것.
3. 오직 깨진 곳에서만 자연스러운 연결과 구조 허사를 회복; 비율 목표를 세우지 말고, 기계적으로 연결을 보충하지 않는다.
4. 시스템 공고, 규제 조문, 패널 방송은 냉엄한 짧은 문장 보존 가능; `system-notice-formality-tic` 경보 시, 원래 담지 내에서만 일부 하드 규칙어를 백화화하거나, 캐릭터가当场 구체 결과를 보게 할 뿐, 서술자 설명으로 바꾸지 않는다.

`overcompressed-prose-tic` / `low-connective-density-tic`의 구체 수정법:

1. 연속 짧은 서술 단락을 동그라미 쳐서, 단단마다 기능을 표기: 폭발/반전/공포 강조, 밀집 카메라는 계속 짧아도 됨; 복선, 공간, 인과, 동작 계승은 같은 카메라로 병합해야 한다. 인공 읽었을 때顺하면, 해당 advisory 때문에 계속 늘일 필요 없다.
2. 병합 시 「동작 순서, 공간 방위, 인과 계승」을 우선 보충, 예를 들어 「고개를 들 때/문 밖에서/이미/여전히/바로/被」처럼 매 문장마다 억지로 「的/了/就」를 우겨넣지 않는다.
3. 병합 후 다시 상용구와 고지식 심리를 삭제: 순조롭게 읽힌다고 AI 체를 회복하는 건 아니니, 「마치/느꼈다/매우/마치」를 조각조각 다시 더해선 안 된다.

복기 처리: 만약 `overcompressed-prose-tic` / `low-connective-density-tic`를 청소한 뒤에도 독감이 여전히 불안정하면, 국소 미세 조정을 멈추고 단락급 재작성 또는 인공 독감 대조로 전환한다.

예시:

```
과도 압축:
임요가 고개를 들었다.
비가림막 밖 가로등이 꺼졌다.
바람도 멎었다.
카운터의 종이컵이 두 번 흔들렸다.

순조롭게 고친 후:
임요가 고개를 들 때, 비가림막 밖 가로등이 한 잔씩 꺼져가고 있었다. 바람이 문득 멎자, 카운터의 종이컵은 제자리에서 가볍게 빙글빙글 돌고 있었다.
```

## 체계적 AI 제거 3단계법

### Pass 1: 범용화 제거 (Strip Generic)
- 추상 감정 요약 문장 -> 삭제하거나 구체 동작으로 대체
- 가짜 깊이 문장 -> 삭제
- 의미 팽창 -> 구체적 영향으로 축소
- 공허한 결론 -> 삭제
- 정연한 대조 문식 -> 흩어서 재작성
- 장식적 형용사 적층 -> 백묘
- 「于是」「然而」「此刻」과용 -> 절반 삭제
- 모든 캐릭터 말투가 똑같이 "고급" -> 어조 구분

**원칙**: 지울 수 있으면 지우고, 지울 수 없으면 구체 디테일로 대체. 이 한 번으로 80% AI 풍을 제거한다.

### Pass 2: 문어화 제거 (Cut Professional Diction)
- 분석적 용어 (「机制」「结构」「逻辑」「体系」가 소설에 출현) -> 일상 표현으로 바꾸기
- 추상 명사 남용 -> 직접 일을 말하기
- 체제 내 용어 (「进一步」「深入」「推进」「落实」) -> 삭제
- 전문 용어 적층 -> 필요한 것만 남기고, 백화로 설명

**예외**: 전문감을 보존해야 하는 장면 (역사 소재 정식 용어, 문학향 의도적 밀도, 희극 과장 수사).

### Pass 3: 자연스러움 회복 (Restore Natural Presence)
- 구체적인 감관 디테일 (냄새, 온도, 촉감)
- 캐릭터 말투 방식의 구분 (사람마다 다른 어조)
- 문두 변화: 연속 3+ 문장이 같은 주어나 같은 품사로 시작하면 시작법을 바꾼다 (동작, 장면, 대화 도입)
- 리듬 변화 (장단 문장 교차): 감정 beat, 동작 추진과 연극 단위에 따라 문단 장단을 자연스럽게 조절; 연속 다단 같은 길이 금하고, 짧게 채우려고 깨서 강요처럼 만들지 않는다. 장단은 무작위가 아니고, 침전처는 느리게 할 수 있으며, 갈등/반전처는 홱 짧게 할 수 있고, 완전한 추리와 감정 고리는 우선 연속성을 유지한다
- 사회적 위치감의 대화 (상급자와 하급자의 말투가 다름)
- 장면 특유의 기억점
- 프로젝트 특유의 언어 습관 (캐릭터의 말버릇)

**원칙**: 적을수록 좋다. 매 단락마다 1-2개 구체 디테일을 더하면 충분하다.

### 업그레이드 전략

| AI 풍 정도 | 전략 |
|----------|------|
| 경도 | Pass 1만 수행 |
| 중도 | Pass 1 + Pass 2 |
| 중도 | 완전 3단계 + 중점 단락 재작성 |

### 자가 검사 리스트
- 대화 자연스러움 검사: 대화가 구어체 표현을 사용하는지, 문어체/정식 어조를 피했는지
- 아무 문장이나 하나 지웠을 때 이해에 영향이 있는가? 없다 = 쓸데없을 가능성
- 다른 캐릭터들이 대화로 구분되는가?
- 이 장면만 갖고 있는 디테일이 하나라도 있는가?

## AI 풍 제거 보충 기법

### Show vs Tell

| 고지 유형 | AI 작법 | 자연 작법 |
|----------|--------|----------|
| 기대감 고지 | "그는 매우 기대했다" | 기대->감정->만족의 고리를 보여주기 |
| 캐릭터 목적 고지 | "그녀는 이혼하고 싶다" | 행동으로 목적 보여주기 |
| 캐릭터 태도 고지 | "그녀는 매우 침착했다" | 대화와 반응으로 체현 |
| 서사 행보 고지 | "다음에 큰 일이 날 것이다" | 복선->반전->연속으로 보여주기 |

### 심리 묘사는 스며들 듯 조용히

- 괄호 붙여서 내심 활동 표기 = 대입감 파괴
- 대단 내면 독백으로 동기 설명 = AI 서명
- 직접 「그녀는 느꼈다」「그녀는 깨달았다」쓰기 = 감정 고지식

**자연 작법**: 심리 활동을 자연스럽게 서사에 녹이고, 행동으로 심리를 암시하고, 침묵/동작/이상 행동으로 내심을 표현한다.

### 대입감 검사
- 주인공 행동이 독자가 이해하고 공감하고 받아들일 수 있는가?
- 악역은 충분히 강한가? (약한 악역 = 독자가 주인공 이겨도 의미 없다 느낌)
- 인설围绕 행동을 썼는가? (행동/언어/사고가 인격围绕 펼쳐짐)
- 독자 기지 정보가 효과적으로 조작되었는가? (정보차가 감정 변동을 만듦)

## 재작성 예시 라이브러리

### 감정 외현 예시

**긴장**
- '그는 약간의 긴장을 느꼈고, 심장이 부지불식간에 빨라졌다'
- 그는 손에 쥔 종이컵을 꽉 쥐어, 물이 약간 쏟아졌다

**분노**
- '분노가 그의 가슴 속에서 타올랐고, 그는 부지불식간에 주먹을 꽉 쥐었다'
- 그는 젓가락을 탁자에 탁 내리쳤고, 그릇 국물이 튀었다

**슬픔**
- '한 점의 슬픔이 가슴에 밀려왔고, 그녀의 눈에는 눈물이 스쳤다'
- 그녀는 고개 숙여 커피를 저었는데, 아주 오랫동안 저었다

**두려움**
- '공포가 순식간에 그를 덮쳤고, 그는 약간의 전율을 느꼈다'
- 그의 등은 벽에 붙은 채, 꼼�짝 못 움직였다

**실망**
- '그녀는 약간의 상실감을 느꼈고, 마음이 무언가에 움켜잡힌 듯했다'
- "아." 그녀는 휴대폰 화면을 껐다

**놀람**
- '그의 동공이 살짝 축소되었는데, 분명 이런 말을 들을 줄 몰랐다'
- 그는 입을 떡 벌렸지만, 아무 말도 나오지 않았다

### 장면 묘사 예시

**AI풍 장면**
- '햇살이 커튼 틈새로 스며들어, 마루에 얼룩덜룩한 그림자를 드리웠다. 공기 중에는 희미한 꽃향이 퍼져 있었고, 마치 세상 전체가 평온하고 상서로운 분위기에 잠긴 듯했다.'
- 오후 세 시, 거실에는 시계 소리만 들렸다.

**AI풍 날씨**
- '하늘은 음산하고 구름이 빽빽하여, 마치 언제라도 쏟아질 듯했다. 매서운 찬바람이 휘몰아치며, 약간의 살을 에는 듯한 한기를 머금었다.'
- 비가 내릴 것 같다. 바람이 밖에 널어둔 옷을 마구 흔들었다.

**AI풍 겨루기**
- '그의 주먹은 마치 질풍노도처럼 맹렬했고, 매 타격마다 의심할 여지 없는 힘이 서려 있었다. 상대의 동공이 살짝 축소되었는데, 분명 이처럼 날렵한 공세를 예상하지 못했다.'
- 그가 한 주먹 쑥 내밀었는데, 상대는 피하지 못해 입꼬리가 터졌다.

### 끝 재작성 예시

**승화식 끝** -> '그는 창가에 서서 먼 곳의 스카이라인을 내다보며, 마침내 삶의 진리를 깨달았다: 때로는, 손을 놓는 것이 최선의 선택이다.' -> 그는 담배꽁초를 꺼서, 방으로 돌아가 잤다.

**요약식 끝** -> '이 순간, 모든 것이 변했다. 그녀는 알았다, 이제부터 그녀의 인생은 새 장을 펼칠 것을.' -> 그녀는 그 문을 닫았다. 뒤돌아보지 않았다.

**감상식 끝** -> '세월은 흐르는 물처럼 조용히 흘러갔다……' -> 이런 단락은 그냥 삭제한다.

### 리듬 조정 예시

> 이하 예시는 비대한 수식, 적층 비유와 추상 요약을 처리하는 것이지 「길면 나누기」가 아니다: 재작성 후 서술은 여전히 쉼표 긴 문장 위주 (규칙 3)이며, 정상적인 쉼표 긴 문장을 짧은 문장 열로 나누지 말 것.

**병렬 문장**
- '그는 그녀의 눈을 보고, 그녀의 입술을 보고, 그녀가 살짝 떨리는 속눈썹을 보며, 가슴속에 말로 다 표현할 수 없는 감정이 밀려왔다.'
- 그는 그녀를 봤고, 그녀는 말이 없었다.

**비대한 긴 문장 수식 제거**
- '그가 마침내 그 무거운 나무문을 밀어 열자, 눈에 들어온 것은 어두컴컴한 방이었고, 공기 중에는 낡은 기운이 퍼져 있었으며, 구석에는 먼지가 쌓인 상자들이 잔뜩 쌓여 있었다.'
- 그가 나무문을 밀어 열자, 방은 어두컴컴했고 구석에는 먼지 쌓인 상자 몇 개가 쌓여 있었다.

**정연한 단락 깨뜨리기**
- '그녀는 봄 꽃을 좋아했고, 여름 햇살을 좋아했고, 가을 낙엽을 좋아했으며, 겨울 눈을 좋아했다. 매 계절마다 저마다 독특한 아름다움이 있었다.'
- 그녀는 봄을 좋아했고, 다른 계절도 그럭저럭이었다.

## 갈등 대화 재작성 예시

### AI식 온화한 대화
- '내 생각엔 네가 이렇게 하는 건 좀 부적절한 것 같아. 내 기분을 좀 생각해줄 수 없니?' -> "네 눈에 나나 있어?"

### AI식 완벽한 설명
- '사실 내가 이렇게 한 데는 이유가 있어, 그때 상황이 매우 복잡했거든……' -> "네가 어쩌라고?" 그녀는 찻잔을 툭 내려놓았다.

### 대화 감정 오급 진보 예시

같은 갈등 장면, 약한 데서 강한 데로:

1. **객관 진술**: "너 내 물건 버렸네."
2. **진술+건의**: "너 내 물건 버렸는데, 다음에 좀 먼저 말해줄 수 없겠니."
3. **주관 비난**: "너 감히 내 물건을 왜 건드려."
4. **비난+명령**: "너가 뭔데 내 물건을 건드려? 꺼져."
5. **비난+PUA**: "내가 너 먹여주고 입혀줬는데, 넌 물건 하나 제대로 못 놔누냐. 넌 평생 이 모양이지, 나 없으면 아무것도 아니야."

### 충격 분층 재작성 예시

**AI식 한 방에 끝내기**: 모든 사람이 충격에 빠져, 자신의 귀를 믿지 못했다.

**자연스러운 분층 충격**:
1. 맞은편 남자의 손이 살짝 떨려, 찻잔 물이 쏟아졌다.
2. 곁에 있는 사람들이 서로 눈치를 봤고, 누군가 한 발 뒤로 물러섰으며, 구석에서는 누군가 휴대폰을 꺼내기 시작했다.
3. 방금까지 잘난 체하던 여자는, 얼굴 웃음이 굳었다. 그녀는 입을 떡 벌렸지만, 한 마디도 나오지 않았다.

### 대입감 수리 예시

**수동적 주인공**: 그녀는 매우 두려워서, 어떡해야 할지 몰라 그저 일이 지나가길 기다렸다.

**능동적 주인공**: 그녀는 문을 잠그고, 휴대폰을 무음으로 바꾼 다음, 녹음을 켰다.

## 품질 검사 리스트

매 장 작성 마친 후, 이 리스트대로 항목별 스캔:

- [ ] **단락 통제**: 단락이 동작/정보 변화 기준으로 끊어졌고, 읽을 때 끊김이 없음
- [ ] **본문에 대시 없음**: 본문 (서술과 대화 포함)에 `——`/`—`/`--` 없음 (마침표, 쉼표, 짧은 문장 또는 동작으로 문장 끊기), 대화 예외 설정하지 않음
- [ ] **AI 고빈도어 스캔**: 不禁/仿佛/映入眼帘/心中暗道/沉声道/嘴角微扬/不由自主/只见 없음
- [ ] **약화 부사 카운트**: 매1000자 「微微/淡淡/缓缓/轻轻」이 3개 초과하지 않음
- [ ] **삼연 병렬 없음**: AI식 "세 개 한 조" 수사 없음
- [ ] **정연 부정 리스트 복기 완료**: 교차 단락 「A가 아니다 / B도 아니다 / 단지 C일 뿐」및 기타 `formulaic-parallelism` advisory를 대사와 함께 항목별 복기 완료; 기능성 수사는 보존 가능
- [ ] **논문체 없음**: 「不难看出/由此可见/事实上/综上所述」없음
- [ ] **문어체 접속사 적층 없음**: 「于是乎/与此同时/从而/因而/诚然」범람 없음
- [ ] **장말 요약 승화 없음**: 동작/대화/현안으로 수렴, 감상/철학/예고 없음
- [ ] **대단 심리 묘사 없음**: 심리 활동이 2단 초과하지 않고, 괄호로 내심 표기 없음
- [ ] **감정은 동작으로 보여주기**: 핵심 감정 노드에 직접 "분노/슬픔/긴장" 쓰지 않고, 신체 반응으로 대체; 저강도 경과 감정은 한 번 직서해도 좋으며 굳이 매번 외현화할 필요 없음
- [ ] **대화 구어체**: 문어조 없고, 다른 캐릭터 어조가 구분됨
- [ ] **문장 부호 평탄화하지 않음**: 질문, 폭발, 망설임을 모두 마침표로 누르지 않음; 또한 무작위로 `？`/`！`를 적층하지 않으며, `……`/`——`로 억지로 쉼을 만들지 않음
- [ ] **Show Don't Tell**: 행동으로 형용사를 대체하고, 디테일로 요약을 대체함
- [ ] **문장 길이 달성**: 서술 기본은 쉼표 긴 문장 (쉼표 사이 8-12자, 전 문장 20-30자, 규칙 3); 짧은 문장은 가끔 쓰는 고립된 강조일 뿐, 다 쓰면 쉼표 긴 문장으로 돌아감; 연속된 ≤5자 파편이 없고, 통째 짧은 문장이 강요처럼 깨지지 않음
- [ ] **detector advisory 항목별 복기**: `micro-action-tic` / `abstract-summary-tic` / `cliche-density-tic` / `metaphor-density-tic` / `reasoning-chain-tic` / `system-notice-formality-tic` / `overcompressed-prose-tic` / `low-connective-density-tic` / `action-list-tic` 적중 시 스크립트가 제시한 수정법대로 처리: 먼저 통독하여 기계적 재현인지 판단한 뒤, 확실한 경우만 수정; 기능성 작법은 보존하거나 `[복기 필요]`로 표시하며, 동의어 순환하거나 기계적으로 물타지하지 않음
- [ ] **하드 지표 투기하지 않음**: 반탐지를 위해 억지로 매 문장 바꾸어 쓰기, 50-60자 한 줄, 대화 50%-60%, 영문 점 줄임표, 또는 `地/得`을 전부 `的`로 바꾸지 않음
- [ ] **임무 카드는 원문 경계에 복종**: 추상 요약을 캐릭터가 일 처리하다 막히는 식으로 바꿀 때, 반드시 원문에 기존한 임무/증거/수속/물건 결함에서 비롯되어야 함; 원문에 없는 사건 고리를 새로 추가하지 않음
- [ ] **AI 제거 3단계법 실행**: 경도는 Pass1만, 중도는 Pass1+2, 중도는 완전 3단계
- [ ] **대화 자연스러움 테스트**: 문어체 흔적 없음 = 통과
