# 일반 웹소설 콘텐츠 심사 Rubric

> 용도: 사용자가 番茄, 起点, 知乎盐言 등 목표 플랫폼을 지정하지 않았을 때 `/story-review`의 기본 소설 콘텐츠 평가 기준으로 사용합니다. 이 기준은 **이야기 텍스트의 품질**을 평가하며 skill/plugin 구현 품질을 평가하지 않습니다.

## 평가 방법

각 항목을 PASS / WARN / FAIL로 표시하고, FAIL/WARN을 통일된 Findings Schema로 변환합니다.

- 주선·인물 동기·세계 규칙·독자 신뢰에 영향을 줌 → S1
- 독자 유지율·리듬·장 효과·인물 신뢰도에 뚜렷한 영향을 줌 → S2
- 국소 품질·형식·어휘·가벼운 리듬 문제 → S3
- 문체 제안 또는 선택적 개선 → S4

## 핵심 차원

| 차원 | PASS | WARN | FAIL |
|---|---|---|---|
| 핵심 매력 | 장이 분명한 매력을 중심으로 추진되고 독자가 계속 읽는 이유를 앎 | 매력은 있으나 표현이 약하거나 보조선에 희석됨 | 이 장이 어떤 매력이나 주선을 위한 것인지 보이지 않음 |
| 갈등 추진 | 이번 장에 분명한 갈등·장애물·선택 또는 대가가 있음 | 갈등이 약하고 추진감이 부족함 | 설명·잡담·요약이 대부분이며 실제 추진이 없음 |
| 임무의 막힘 | 인물이 일을 처리하다 막히고, 그 막힘에서 정보·관계·대가·선택 또는 복선 변화가 발생함 | 막힘은 있으나 변화가 약해 압축 가능 | 막힘이 절차 세부에 불과하고 삭제해도 이야기에 영향이 없음 |
| 감정 곡선 | 포석·고조·해소 또는 반전이 있음 | 감정은 변하지만 지점이 불분명함 | 감정이 평평하거나 갑자기 방향을 틂 |
| 훅과 기대 | 시작 또는 끝에서 최소 한 곳에 기대를 세움 | 훅은 약하지만 후속 문제가 남아 있음 | 미스터리·목표·미완성 기대가 없음 |
| 도입의 신선도(도입부·앞 3장에만 적용) | 구체적인 인물·처지의 진입점이 있고 같은 장르의 기본 공식이 아님 | 훅은 있으나 도입 형태가 동종 장르와 겹침 | 장르 기본 템플릿으로 시작해 동종 작품에 통째로 옮길 수 있음(동질화) |
| 인물 동기 | 행동이 목표·성격·처지·관계 압력과 맞음 | 일부 행동에 포석이 부족함 | 플롯 추진을 위해 인물이 왜곡됨 |
| 대화 품질 | 대사에 속뜻·정보 조절·인물 차이가 있음 | 정보가 쌓이거나 목소리가 다소 비슷함 | 대사가 설명서 같고 모두 같은 말투임 |
| 설정 일관성 | 기존 규칙·시간선·인물 속성을 어기지 않음 | 보충 증거가 필요한 가벼운 모호점이 있음 | 이미 작성된 설정이나 앞의 사실과 충돌함 |
| 문장 자연도 | 구체적이고 감각적이며 행동이 정보를 전달함 | 가끔 상투어나 추상 요약이 나옴 | AI 문체·진부한 표현·요약체가 뚜렷함 |
| 문장 길이 리듬 | 서술은 쉼표가 있는 긴 문장을 기본으로 하고, 짧은 문장은 가끔 고립된 강세로 사용한 뒤 긴 문장으로 돌아감 | 국소적인 파편 문장·전보체 또는 가끔 기계적인 장단 교차가 있음 | 쉼표 사이가 계속 ≤5자이거나 전체가 개요 같은 초단문이며, 심사 과정에서 긴 문장을 잘게 쪼갬 |
| 문장 부호 리듬 | 문장 부호가 어조·인물 목소리·감정 기능과 맞음 | 일부 문장 부호가 단조롭거나 다소 쌓임 | 문장 전체를 마침표로 만들거나 물음표·느낌표를 무작위로 쌓거나 `……`/`——`로 억지로 멈춤을 만듦 |
| 구체 글자 수 표현 검증 | 「这五个字」「短短四字」식 표현의 실제 글자 수가 맞고 서사적 필요도 있음 | 글자 수는 맞지만 「그 몇 글자」가 더 자연스러움 | 글자 수가 실제와 다르거나 산정 기준을 확인할 수 없음 |
| 형식 가독성 | 단락이 극적 단위·카메라에 따라 자연스럽게 끊기고 대화는 독립되며 불필요한 빈 줄이 없고 주어 리듬이 자연스러움 | 일부 단락이 길거나 잘게 끊기며 주어 반복이 다소 많음 | 단락이 뭉치거나 기계적으로 잘리고 대화·서술이 읽기 어렵거나 주어가 과밀함 |
| 플롯 순환 | 목표→장애물→행동→대가/피드백→새 기대의 고리가 분명함 | 순환은 있으나 한 고리가 빠지거나 피드백이 약함 | 목표·장애물·피드백이 없고 독자가 국면 변화를 알 수 없음 |
| 절정 구축 | 에너지 축적→가짜 승리→붕괴→반전/이행이 층위 있게 구성됨 | 폭발점은 있으나 축적 또는 이행이 부족함 | 직선적으로 펼쳐지고 대가·이행·감정 해소가 없음 |
| 관계 진전 | 상호작용의 강도가 관계 단계에 맞고 경계를 넘을 때 포석이 있음 | 일부 추진이 빠르지만 증거를 보충할 수 있음 | 친밀·신뢰·적대가 갑자기 뛰어오름 |
| 복선 상태 | 복선의 심기·상태·회수 경로를 추적할 수 있음 | 복선이 다소 빽빽하거나 성기지만 이해를 방해하지 않음 | 복선이 설정과 충돌하거나 끊기거나 주선 이해를 혼란스럽게 함 |

## 황금 3문

1. **독자는 왜 다음 페이지를 넘기는가?** 답하지 못하면 최소 S2입니다.
2. **이번 장에서 무엇이 바뀌었는가?** 플롯·관계·정보·감정 중 최소 하나가 바뀌어야 하며, 그렇지 않으면 최소 S2입니다.
3. **판단을 뒷받침하는 증거는 무엇인가?** 원문 증거가 없는 finding은 출력하지 않고 “증거 부족”으로 바꿉니다.

## 공개 권장 기준

| 종합 상황 | Verdict |
|---|---|
| S1/S2가 없고 S3는 빠르게 처리 가능 | APPROVE |
| S2가 있거나 S3가 많아 독서에 영향을 줌 | CONCERNS |
| S1이 있거나 핵심 매력·동기·규칙이 붕괴함 | REJECT |

## 출력 요구

- 모든 문제에는 severity, category, location, evidence, issue, fix가 포함되어야 합니다.
- S1/S2를 먼저 열거하고 S3/S4를 뒤에 적습니다.
- 막연한 평가만 하지 않습니다. 각 finding은 다음 수정 라운드를 안내할 수 있어야 합니다.
- `consistency` / `factual` 유형 finding의 fix에는 사실을 통일하는 방향만 쓰고 문학적 창작 조언은 쓰지 않습니다.
