# 상태 추적 프로토콜

> 이 문서는 "이번 섹션 요약"의 추출 로직과 "캐릭터 상태 기록"의 형식을 정의합니다. 집필 skill은 집필 전 준비 단계의 상태 필터링 단계에서 이 파일을 로드합니다.

---

## 이번 섹션 요약

각 장/섹션을 집필하기 전, 로드된 모든 컨텍스트에서 이번 섹션과 관련된 정보만 필터링합니다. 이는 전체 로드로 인해 LLM 컨텍스트가 무관한 정보로 희석되는 것을 방지하기 위함입니다.

### 필터링 로직

컨텍스트에서 세 가지 유형의 정보를 추출합니다:

1. **현재 상태**: 이번 장에 등장하는 캐릭터의 최신 능력, 관계 변화, 대중적 이미지
2. **역사적 인과**: 이번 장의 사건과 직접적으로 관련된 복선의 원인, 과거 사건
3. **세계관 제약**: 이번 장과 관련된 세계관 규칙(능력 체계, 사회 규칙, 지리적 제한)

### 필터링 기준

**"이것을 모르면 이번 장에서 설정 오류가 발생할 수 있는" 정보만 유지합니다.**

구체적인 판단 방법:
- 이번 장의 상세 개요에 특정 캐릭터가 언급됨 → 해당 캐릭터의 현재 상태 유지
- 이번 장에서 복선 회수가 있음 → 복선이 깔린 세부 사항과 이전의 빌드업 유지
- 이번 장이 특정 장소/능력/규칙과 관련됨 → 관련 세계관 제약 유지
- 순수 배경 지식(이번 장의 사건과 인과 관계가 없음) → 삭제

### 출력 형식

필터링 후 간결한 "이번 섹션 요약"을 출력합니다:

```
## 이번 섹션 요약(제{N}장)

### 캐릭터 상태
{캐릭터A}: {최근 변화를 포함한 현재 상태 한 줄 요약}
{캐릭터B}: {현재 상태 한 줄 요약}

### 관련 복선/전사
{복선1}: {설정 세부 사항, {설정 장}}, 이번 장에서 {회수/진행} 필요

### 세계관 제약
{제약1}: {이번 장과 관련된 규칙/설정}
```

**예시(데모 《계정 관리 시켰더니, 고퀄 편집 영상으로 인터넷을 뒤집어 놓으셨다》 제10장):**
```
## 이번 절 속기(제10장)

### 캐릭터 상태
강진: 로켓군 문선대 홍보병, 《제군들이여, 용의 포효를 들어라》가 이미 대박 났으며, 군 홍보 신입에서 군내에서 인정받는 창작자로 거듭나는 중
종가가: 군보 기자, 인터뷰 원고 심의 통과, 강진과 인터뷰 관계에서 안정적인 협력 관계로 전환
주박삼: 문선대 부단장, 강진이 사고를 칠까 걱정하던 단계에서 창작 능력을 인정하는 단계로 전환

### 관련 복선/전사
5일 내 팔로워 100만 달성 미션: 제1장에서 시작, 제10장에서도 아직 미결산. 이번 장에서는 화제성만 높이고 제11장에서 결산
전문 팀의 재촬영: 이번 장에서 고화질 전문 버전의 '영혼 없음'을 통해 강진의 휴대폰 원본이 대체 불가능함을 강조

### 세계관 제약
군 홍보 작품 채택은 조직의 의사결정을 거쳐야 함. 강진은 작품의 파급력으로 인정을 받을 수는 있지만, 군 내부 절차를 건너뛰고 직접 결정할 수는 없음
```

## 캐릭터 상태 기록 형식

> ⚠️ **이 섹션은 장편 집필에만 적용됩니다.** 단편은 일반적으로 별도의 캐릭터 상태 추적이 필요하지 않습니다.

동적 상태는 핵심 캐릭터별로 `추적/캐릭터_상태/{캐릭터명}.md`로 분리하며, `tracking_commit.py`가 트랜잭션 JSON을 바탕으로 전체를 덮어씁니다. 정적인 원본 캐릭터 설정은 여전히 `설정/캐릭터/{캐릭터명}.md`에 위치합니다. 나중에 다시 등장할 주인공, 악역, 핵심 조연에 대해서만 스냅샷을 생성하며, 엑스트라나 일회성 기능 캐릭터의 파일은 생성하지 않습니다.

### 형식

```markdown
# 장천｜현재 상태

- 기준 챕터: 제10장
- 신분: 로켓군 문공단 선전병; 군 홍보 히트 콘텐츠 제작자
- 위치: 로켓군 문공단 고위급 시사회
- 현재 목표: 5일 내 백만 팔로워 미션 완료, 실질적인 파급력이 있는 군 홍보 콘텐츠 지속 제작
- 심신 상태: 전문 팀을 통해 원본의 가치가 역으로 검증됨, 군 내부의 인정이 계속해서 상승 중

## 능력 및 자원
- 전생의 MCN 히트작 운영 경험
- 《중국군혼》 반주
- 마스터급 연출 능력

## 주요 관계
- 종가가가 지속적으로 군보 자원을 제공함
- 주박삼과 장요조는 이미 창작 능력을 명확히 인정함

## 기지 정보
- 《군보》 인터뷰 원고 심사 통과
- 원본 영상은 공식 군 홍보 콘텐츠로 계속 사용될 예정

## 미결 사항
- 5일 내 백만 팔로워 미션이 아직 정산되지 않음
- 종가가가 말한 "절반만 맞혔다"는 부분은 여전히 설명되지 않음
```

### 업데이트 규칙

1. 각 장에서는 신분, 위치, 목표, 심신 상태, 능력 및 자원, 관계, 알려진 정보, 미결 사항 중 실제로 변화가 발생한 내용만 기록합니다.
2. 핵심 재사용 캐릭터에 변화가 발생하면, 동일 트랜잭션의 `character_changes`에 변화를 기록하고 `character_snapshots`에 **현재까지 작성된 마지막 장 기준**의 전체 스냅샷을 제출합니다. 툴은 스냅샷 존재 여부로 핵심/임시 캐릭터를 판단하며, 핵심 캐릭터의 소형 파일을 전체 덮어쓰기하고 이력을 추가하지 않습니다.
3. 이전 장을 수정할 때는 수정된 장부터 마지막으로 작성된 장까지 검토하여 각 차원 및 관계 대상별로 현재 상태를 재계산한 후 전체 스냅샷을 제출합니다. 마지막 단일 차원 변화를 캐릭터의 전체 상태로 간주해서는 안 됩니다.
4. 변화가 없으면 스냅샷을 제출하지 않아도 됩니다. 핵심 캐릭터가 현재 장면에 다시 등장할 때 기존 소형 파일을 직접 읽어오며, 트랜잭션 툴이 필요한 정보를 후속 작성 상태 카드에 반영합니다.
5. 캐릭터 변화 이력은 `장별_기록/제NNN장.md`에 해당하며, 현재 스냅샷은 장별 이력을 중복 저장하지 않습니다.
6. 전체 JSON 필드, 4096바이트 목표 및 8192바이트 하드 제한은 [tracking-transaction.md](tracking-transaction.md)를 참조하세요.
