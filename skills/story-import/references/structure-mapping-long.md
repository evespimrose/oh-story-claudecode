# 구조 마이그레이션 매핑 규칙 (장편)

Phase 3-L 장편 구조 마이그레이션의 상세 매핑 규칙 및 템플릿. `拆文库/{导入书名}/` 분석 결과를 `{导入书名}/` 장편 프로젝트 구조로 변환합니다.

> 단편 마이그레이션 규칙은 `structure-mapping-short.md`를 참고하세요.

> **이름 경계**: `{导入书名}`은 사용자가 직접 작성 중인 소설이고, `{对标书名}`은 별도로 선택한 외부 참고 작품입니다. 두 데이터 소스는 반드시 분리되어야 하며, `{导入书名}`의 분석 결과 또는 `设定/` 폴더를 `对标/`에 작성하는 것은 금지됩니다.

| 拆文库 경로 | 프로젝트 경로 | 변환 방식 |

| — | `추적/역할 상태/{역할명}.md` | `character-state-reverse.md`에서 역추적하여 핵심 역할의 현재 스냅샷 도출 |

| `스토리/산재 플롯.md` | `개요/개요.md` 부록 또는 해당 권 개요 | 관련 권의 개요에 병합 |

## 본문 표준화 규칙

### 명명 형식

소스 파일명 → 표준 형식: `제{0으로 채운 3자리}장_{장명}.md`

| 소스 파일명 | 표준화 후 |
|---------|---------|
| 제1장_초입강호.txt | 제001장_초입강호.md |
| 제1장.md | 제001장_무제.md |
| chapter01.md | 제001장_무제.md |
| 01_각성.md | 제001장_각성.md |

### 장절 구분 인식

원본이 단일 대용량 파일일 때는 다음 구분 기호로 분할합니다(`length-routing.md`의 우선순위 2와 동일한 인식 테이블 재사용):

| 구분 기호 패턴 | 예시 |
|-----------|------|
| `제X장` / `제X장 ` / `제X장：` / `제X장 XXX` | 제1장 초입강호 |
| `Chapter X` | Chapter 1 |
| 순수 숫자 번호 + 제목 | 1. 각성 |

### 콘텐츠 처리

- 원문 내용을 그대로 유지하며 어떠한 수정도 하지 않습니다
- 인코딩을 UTF-8로 통일합니다
- 파일의 머리말과 꼬리말에서 관련 없는 정보를 제거합니다(광고, 선언문 등)

## 관계 파일 변환 규칙

텍스트분해 형식(캐릭터 관계.md) → 프로젝트 형식(설정/관계.md):

```
차문고(拆文库) 형식:
A<->B: 관계 유형 | 감정 | 설명(50-200자) | 변화 궤적

항목 형식:
| 역할 A | 역할 B | 관계 유형 | 감정 성향 | 현재 상태 | 시작 장절 | 변화 지점 |
```

변환 규칙:
- 관계 유형 매핑: 가족→가족애, 연인→사랑, 친구→우정 등
- 감정 성향 직접 재사용: 긍정/부정/중립/복합
- 연변 궤적을 「변화 노드」 열로 추출

## 세계관 동기화 규칙

현재 `story-long-analyze`가 주제화된 디렉토리를 출력했으며, 가져오기 단계에서는 pass-through만 수행하고 더 이상 `세계관.md`를 분석하거나 평탄화하지 않습니다.

| 원본 경로 | 대상 경로 | 현재 규약 |
|---------|---------|---------|
| `拆文库/{导入书名}/设定/世界观/*.md` | `{项目}/设定/世界观/*.md` | 그대로 동기화; `배경설정.md` 필수 존재 |
| `拆文库/{导入书名}/设定/势力/*.md` | `{项目}/设定/势力/*.md` | 독립된 세력 파일 그대로 동기화 |

`력량체계.md`, `지리.md` 또는 소규모 세력 자료가 200자 미만일 때, 업스트림에서 이들을 `배경설정.md`로 통합하므로 이러한 독립 파일은 생략 가능합니다. `배경설정.md`가 없거나 현재 내용이 독립된 력량 체계를 가리키는데 대응하는 파일이 생성되지 않으면, 가져오기를 중단하고 `story-long-analyze` Stage 4를 다시 실행하도록 안내하세요.

## 대강 역추 규칙

### Outline.md（권 수준 구조）와 권 구분 규칙

`story/storyline.md`, `story/*.md` 및 `quick-preview.md`에서 역추적하여 **권 구분은 다음 결정 규칙을 반드시 준수해야 합니다**:

**상황 A: 원문에 명확한 권 경계가 있는 경우**

원문에 명확한 권 수준 표기(예: 「제1권 XXXX」「권1」 등 장절 수준 제목)가 존재함 → 원문의 권 경계에 따라 직접 구분하며, 사용자에게 문의할 필요 없음.

**상황 B: 원문에 명확한 권 경계가 없는 경우**

기계적인 권 분할을 하지 않습니다. 실행 절차:

1. 스토리라인/장면 전환/대규모 시간 도약에 따라 후보 권 경계를 감지합니다 (아래 「후보 경계 감지 참고」 참조);
2. 후보 분할 방안을 사용자에게 표시하며, 형식 예시:

   ```
   후보 권 분할 (참고용, 최종안 아님):
   - 후보 권 1: 제 1-18장 (세계관 구축 + 초기 성장, 장면: 시외 학원)
   - 후보 권2: 제19-45장(주선 갈등 폭발, 장면: 제국 의사당)
   - 후보 권3: 제46-XX장(최종 대결, 장면 전환: 상고 유적)
   위의 스토리 라인/장면 전환 자동 감지 결과이므로, 확인하거나 조정해 주세요.
   ```

3. **사용자가 권 구분 방안을 확인한 후**, `대강/대강.md`의 권 레벨 구조와 해당하는 `대강/권강_제X권.md`를 생성합니다.
4. 사용자가 확인하기 전에는 `대강/대강.md`은 후보 방안만 기록하고, 권 강 정보는 작성하지 않습니다.

> **금지됨**: "권당 기본 20-40장"으로 기계적으로 원문의 권 구분이 없는 책을 자르지 마세요. 후보는 참고용일 뿐 최종 결정은 사용자가 합니다.

### 후보 경계 감지 참고

| 신호 유형 | 예시 | 권 경계 가능성 |
|---------|------|------------|
| 장 연속 + 동일 스토리라인 | 동일 도시/동일 세력 관점 | 동일 권 |
| 주요 장면 전환(새로운 맵/새로운 진영) | 도시 외곽에서 제국 수도로 진입 | 새로운 권 시작점 후보 |
| 대규모 시간 도약(수개월/수년) | 「3년 후…」 | 새로운 권의 시작 후보 |
| 주요 단계 목표 완료 + 새로운 목표 개시 | 단계 boss 격파 → 새로운 위기 발생 | 새로운 권의 시작 후보 |
| 스토리라인 요약에 이미 단계 구분이 있음 | `story/storyline.md` 내부 섹션 | 우선 참고 |

### 권 개요 역추적

#### 목표 형식 템플릿(대강/권개요_제X권.md)

권강은 대강의 전개입니다. 대강은 방향을 결정하고, 권강은 속도를 결정합니다. 본 권의 모든 창작 계획을 포함합니다.

```markdown
# {권명} 권강

## 핵심 정보
- 장 범위: 제{X}-{Y}장
- 글자 수 목표: {W}만 자
- 본 권의 포지셔닝: {포장/전개/절정/전환/마무리}

## 핵심 모순
{한 문장: 본 권이 해결해야 할 문제 또는 달성해야 할 목표}

## 감정 호선
- 템플릿: {V자형/역V자형/W자형/점진형/지연 만족형/급전환형}
- 선택 이유: {소재와 본권의 포지셔닝을 결합}

| 장 | 정서 기조{긴장/가벼움/슬픔/열혈/따뜻함/충격} | 강도{1-10} | 트리거 이벤트 |
|------|-----------------------------------------|-----------|---------|
| 제{N}장 | {기조} | {N} | {이벤트} |

## 권 계약과 엔딩 예비(역추론)
- 권 계약: {본권 스토리에서 독자 기대와 주인공의 하이라이트를 귀납; 증거 부족 시 `[보충 필요]` 작성}
- 본권 주추선: {스토리 포인트에서 귀납하여 본권의 최대 클라이맥스를 담당하는 선}
- 본권 전과: {나머지 부수적으로 실현되는 선; 증거 부족 시 `[보충 필요]` 작성}
- 본권 해금한 종국 마일스톤: `[보충 필요]`
- 본권 금기 사항인 종국 카드: `[보충 필요]`
- 계약 위험: {계약 안전 / 보강 필요 / 계약 파괴; 판단 불가능 시 `[보충 필요]` 작성}
```

#### 필드 매핑
