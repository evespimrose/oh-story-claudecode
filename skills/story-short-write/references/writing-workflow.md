## Phase 2 설계 태스크（프레임워크 확정 후 실행）

### 시작 전 references 먼저 로드（항목별로 체크, 건너뛸 수 없음）

- 소재 톤/기교 정하기 → `genre-styles/{소재}.md` + `short-craft.md` 로드 ✅/❌
- 악역/진실 드러내기 방식 쓰기 → `villain-and-reveal.md` 로드 ✅/❌
- 大纲 쓰기 → 소재 패키지 `genre-styles/{소재}.md`의 리듬 골격 +（마이너 소재）`genre-writing-formulas.md` 속기표 ✅/❌
- 반전 정보차 검증 → `reversal-toolkit.md` 로드 필요 ✅/❌
- 복선 회귀 확인 → 아래 「복선 회귀 체크리스트」 참고 ✅/❌
- 어떤 항목이 적용 안 되면（예: 악역 없음）, 이유를 표기한 후 건너뛸 수 있음

### 설계 단계

1. **신물 / 관통물 설계**（옵션, 1-2개）：소재 패키지 기교库 「신물 플립」 참고（예: 추기장장의 신물 의미 반전）
   - 기입：`- 첫 번째 등장（제X절）：{장면}（{의미}）`를 세 번 반복, 절호 위치 포함
2. **악역 설계**（있는 경우）：villain-and-reveal.md 악역 템플릿 사용
   - 기입：`{정체} + {동기} + {악행 방식} + {치명적 약점} + {응보}`
3. **진실 드러내기 방식 확정**：villain-and-reveal.md 4가지 진실 폭로 메커니즘 중 하나 선택
4. **小节大纲.md 작성**：절당 1행, 형식은 다음과 같음：
   `구조단/오단 기능 | 주사건 | 부사건×3-5 | 감정 | 인물/관계 변화 | 인과/논리 연쇄 | 독자가 새로 알게 된 것 | 마무리承接/갈고리 | 복선/소품 | 동정 | 대화 밀도 | 목표 글자수`
   - `구조단/오단 기능`은 시작/단계설정/격화/반전/마무리（또는 발단/전개/전환/고조/결말）사용. 장편의 내용 요약에 가볍게 대응하되, 장편의 완전한 챕터 블루프린트를 그대로 쓰지는 말 것
   - `인물/관계 변화`는 절 전후 변화를 적음；명시적 변화가 없으면 「명시적 변화 없음, 하지만 관계 압력/오해/거리감 변화는 …」 또는 `[보충 예정]`으로 적을 것
   - `인과/논리 연쇄`는 `원인 → 행동 → 결과 → 후과/새 문제`로 적어, 절이 그저 감정만 쌓는 일이 없도록 할 것
   - `마무리承接/갈고리`는 본절이 다음 절로 어떻게 이어지는지 적음；마지막 절은 결말 지점을 적을 것
   - 부사건은 기능이 명확해야（플롯 추진/반전 단계설정/감정 격상）, 장식적 부사건 금지
   - 부사건이 3개 미만일 때 확장 룰 사용（방해 추가 / 조연 반응 / 이동 중 발견 / 짧은 회상 / 액션 단계；short-craft.md 제10-11절 참고）
   - 부사건은 `->`로 연결, 각 부사건은 구체적인 플롯 포인트 설명 + 기능 태그 포함：
     `구체적으로 무슨 일이 일어났는가{기능 태그}` 예：`청구서에 4800원 추가된 걸 발견{발견}` / `반지를 변기에 내려보냄{갈등}` / `그가 웃었다{격상}`
     기능 태그：`대화` / `갈등` / `복선` / `회상` / `발견` / `격상`
     플롯 포인트 설명은 「누가 무엇을 했는가」까지 구체적으로 적어, `대화`나 `갈등` 같은 태그만 써서는 안 됨
   - 동정 표시：`동` 또는 `정` 또는 `동정`. 이웃한 두 절은 되도록 번갈아 사용；소재상 연속으로 같은 표시가 필요한 경우, 절 내에 감정 변화가 있는지 확인（예: 두 절 모두 「정」이지만, 첫 절은 「의혹→시린 마음」, 두 번째 절은 「심장이 찢어짐→붕괴」처럼 감정 곡선이 계속 상승해야）
   - 대화 밀도：`높음`（3회 이상）/ `중간`（1-2회）/ `없음`（절 전체 무대화）. 되도록 2절 연속으로 `없음`으로 표기하지 말 것；일기 열람, 혼자 발견하는 장면 등은 예외 허용하나, 연속 무대화 구간의 감정은 감각 디테일과 신체 반응을 섞어서 추진할 것
5. **반전 정보차 검증**（outline 작성 후, 집필 전에 반드시 검증）：
   - 답변：독자가 몇 절에서 진실을 알게 되는가？「폭로 절호 ÷ 전체 총 절호」로 위치 백분율 계산
     - < 50% → 지연 폭로, 반전 무효（독자가 진실을 너무 일찍 알아서 이후 충격 부족）
     - 50-60% → 회색 지대, 반전 강도 검토 필요（앞선 오도 단서가 충분한지）
     - > 60% → 반전 위치 적정（독자가 충분히 기다렸다, 충격력 극대화）
   - 체크：독자가 성공적으로 오도되는 가짜 단서가 최소 1개 이상 있는가？（독자가 미리 추측한 후 캐릭터를 기다리는 게 아님）
   - 체크：반전 전에 진실을 가리키는 단서가 ≥3개铺垫되었는가？（단서는 은밀해야, 명시적이면 안 됨）
   - 검증：한 사람（또는 자기 시뮬레이션）이 outline만 보고 반전 전에 진실을 추측할 수 있는가？추측하면 = 실패
6. **복선 회귀 체크리스트**（outline 작성 후, 집필 전 체크）：
   - 결말의 모든 핵심 요소（소품/정보/캐릭터/관계 변화）를 나열할 것
   - 각 결말 요소가 앞글에 ≥1회 이상 복선이 깔렸는가？없으면 = 천강보살, 반드시 복선 보충할 것
   - 관통 소품의 세 번 등장이 완전한가？（첫 등장은 단계설정단, 두 번째 등장은 반전단, 세 번째 등장은 마무리단）
   - 복선 절호와 폭로 절호의 간격이 ≥3절인가？（간격이 너무 짧으면 복선 무효）

### 집필 전 로드（필요에 따라, 동시 ≤3개）

- 필독：`short-format.md`（正文 포맷）+ `short-craft.md`（공용 베이스）
- 필독：`short-deslop.md`（작성 시 AI 풍 자가 검사）
- 소재별 1개 로드：`genre-styles/{소재}.md`（핵심 10소재）또는 `genre-writing-formulas.md`（마이너 소재 속기표）
- 필요에 따라 로드：`villain-and-reveal.md` / `emotional-methods.md`

### 작업 디렉터리 구조

작업 디렉터리 구조는 [Phase 2：구상 핵심 프레임워크](../SKILL.md#phase-2구상-핵심-프레임워크) 참고. 设定.md 내용 구성：핵심 프레임워크 + 인물 설정 + 반전 복선 + 관통 소품（세 번 등장 추적표 포함）+ 악역 설계 + 对标 요약. 小节大纲.md는 절당 1행, 형식은 [설계 태스크（프레임워크 확정 후 실행）](../SKILL.md#설계-태스크프레임워크-확정-후-실행) 제4단 기준으로 함.

### 조작 원칙

- 正文은 직접 파일에 쓰고, 대화에만 출력하지 말 것
- 정밀 보완 시 파일을 읽어 다시 쓰기, 수정 기록은 직접 设定.md의 관통 소품 추적에 반영
- 设定.md에서 관통 소품 추적표 유지：
  `| 소품 | 첫 등장(절호/의미) | 두 번째 등장(절호/의미) | 세 번째 등장(절호/의미) |`

## Phase 4 정밀 수정 및 다듬기

### 정밀 수정 체크리스트

```
## 정밀 수정 체크리스트

### 시작
- [ ] 앞 3문장이 사람을 사로잡는가？
- [ ] 무의미한 배경 설명이 없는가？
- [ ] 오프닝 갈고리가 하나 포함되었는가？

### 감정
- [ ] 감정 곡선에 명확한 방향이 있는가？
- [ ] 반전 전 감정 단계설정이 충분한가？
- [ ] 반전 후의 충격이 충분한가？

### 반전
- [ ] 반전이 예상 밖이었는가？
- [ ] 반전이 이치에 맞는가（돌이켜보면 복선이 있음）？
- [ ] 반전 시기가 적절한가？

### 리듬
- [ ] 늘어지는 부분이 없는가？
- [ ] 모든 문장이 존재 가치가 있는가？
- [ ] 글자수가 목표 범위 내인가？

### 포맷
- [ ] 문단은 짧은 걸 위주로 하되, 길이 번갈아 가며 밀도 변화가 있는가？（전체가 같은 길이가 아님）연속으로 지나치게 긴 대형 문단이 없는가？
- [ ] 문단 사이에는 단일 개행만 있는가？
- [ ] 대화는 독립된 행에 있고, 인용부호 스타일이 프로젝트/플랫폼 약정과 일치하는가？
- [ ] 구두점 리듬이 말투/인물 음색과 맞는가：전체가 마침표화되지도, 랜덤으로 물음표/느낌표를 쌓아놓지도, `……`/`——`로 억지로 쉼을 만들지도 않았는가？
- [ ] 正文（대화 포함）의 `……`、`——`、`—`、`--`가 모두 동작, 짧은 문장, 쉼표 또는 마침표로 바뀌었는가？
- [ ] 「그는 말했다/그녀는 일렀다」가 없는가？

### 갈고리
- [ ] 2-3소절마다 갈고리가 있는가？
- [ ] 장 마지막에 갈고리가 있는가（서스펜스 또는 여운）？

### AI 풍
- [ ] 금지 비유：「운명의 톱니바퀴」「물결처럼 밀려오는」「봄바람인 듯」「심장이 턱 내려앉다」「눈가가 붉어지다」가 없는가？
- [ ] 같은 신체 부위/감정 묘사가 5회를 초과하지 않는가？（통계：손가락/심장/무릎/눈, 초과하면 반드시 교체）
- [ ] 「처럼」 사용 빈도：전체적으로 10곳 미만（「인 듯」「안 닮다」 포함）
- [ ] 완전한 AI 풍 블랙리스트는 short-deslop.md 참고

### 기교
- [ ] 감정 외현：직접적인 감정어 뒤에 장면 속의 구체적인 동작이나 소품이 이어지는가？공허한 감정 요약문（한 스산한 X가 마음에 밀려오다）이 없는가？
- [ ] 신물（사용 시）：의미 반전이 완전한가？（设定.md 추적표 확인）
- [ ] 일동일정：각 절에 동과 정이 있는가？
- [ ] 시작 밀도：앞 100자에 사건 ≥3개 있는가？

### 마무리
- [ ] 결말에 여운이 있는가？
- [ ] 독자가 전달하고 싶을 생각이 드는가？
```

### 구두점 확정성 마무리

정밀 수정 후 `正文.md`에 대해 먼저 `node scripts/check-ai-patterns.js --check --fail-on=blocking 正文.md` 실행. blocking은 먼저 正文를 수정하고 재스캔；advisory는 독감 느낌 제시일 뿐, 확실히 문제인 경우만 수정, 기능적 작성은 `[재확인 필요]`로 표기.
이어서 `node scripts/normalize-punctuation.js 正文.md`（기본 `--quote-mode keep`）실행하여 무기능 생략부호, 대시, 이중 하이픈 및 독립 구분선을 정리；옌옌（盐言）「」는 영향받지 않음.

### 삭감 원칙

1. 플롯을 추진하지 않는 대화 → 삭제
2. 반전을 단계설정하지 않는 묘사 → 삭제
3. 감정을 고조시키지 않는 심리 활동 → 삭제
4. 독자가 추측할 수 있는 내용 → 축약
5. 중복으로 표현된 감정 → 병합

## 자주 나오는 문제와 해결책

| 문제 | 원인 | 해결책 |
|------|------|--------|
| 시작이 사람을 사로잡지 못함 | 배경 단계설정을 함 | 갈등부터 직접 시작 |
| 중간이 늘어짐 | 정보 밀도가 너무 낮음 | 삭감하거나 장면 병합 |
| 반전에 힘이 없음 | 복선이 부족하거나 너무 뚜렷함 | 오도 단서 증가 |
| 결말이 힘이 없음 | 반전 후 너무 길게 끌음 | 반전 후 500자 이내로 마무리 |
| 전체가 평범함 | 감정 곡선이 너무 평탄함 | 감정 낙차 확대 |
| 일기장처럼 느껴짐 | 감정 묘사 부족 | 인물의 내면 감정 추가 |
