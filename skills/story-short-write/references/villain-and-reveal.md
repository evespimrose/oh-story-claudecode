# 악역 시스템 + 진실 폭로 메커니즘

> 악역 설계 템플릿, 진실 드러내기 방식, 응보 설계. Phase 2에서 악역 설계 시 로드.

---

**본 파일의 역할**（다른 내용은 어디서 보는가）：
- 각 소재의 악역 루틴（사정대도 악역, 환생보복 악역 등）은 genre-writing-formulas.md에 있음, 본 파일은 공용 설계 템플릿만 제공
- 본 파일의 악역 인물 설정 템플릿 `{정체}+{동기}+{악행 방식}+{치명적 약점}`은 「설계 청사진」에 중점을 두고, genre-writing-formulas.md의 `{인물 설정}+{동기}+{행동}+{태도}+{피해 정도}`는 「모순 충돌 공식」에 중점을 둠——전자는 Phase 2 설계에, 후자는 Phase 3 집필에 사용

## 1. 악역 설계 템플릿

### 인물 설정 템플릿

다음 템플릿을 작성하여 设定.md에 기입：

```
악역：
- 정체：{주인공과의 관계}
- 동기：{자체적으로 타당한 악행 논리：탐욕/질투/지배욕/보복/자기보호}
- 악행 방식：{구체적인 수단：언어 탄압/경제적 지배/사회적 고립/신체적 상해/법적 모함}
- 치명적 약점：{주인공이 이용할 수 있는 약점：탐욕/오만/비밀/의존/공포}
- 응보：{악행에 대응되는 결말}
```

### 횡포도 점층 계단

악역의 행동은 반드시 단계적으로 증가시켜, 건너뛰거나 중복하지 않아야 함：

| 단계 | 행동 유형 | 예시 |
|------|----------|------|
| 소악（앞부분 1/3） | 언어 탄압, 냉대 폭력 | 「네가 시집온 건 큰 복이야」 |
| 중악（중단） | 경제/사회적 피해 | 통장 몰래 가져가기, 밖에서 평판 깎기, 관계 이간질시키기 |
| 대악（후반） | 신체/법적 피해 | 약 먹이기, 모함하기, 죽음에 이르게 하기, 인신매매 |

### 5가지 악역 유형 속기

| 유형 | 특징 | 대표작 | 치명적 약점 |
|------|------|--------|------------|
| 조종형 | 사랑을 빙자해 모든 것을 통제 | 왕씨（황제 동생） | 통제욕 때문에 행동에 증거가 남음 |
| 탐욕형 | 끝없이 요구함 | 약혼녀 | 욕심이 지나쳐 본색 드러냄 |
| 위장형 | 진짜 정체/목적을 숨김 | 사기꾼（환생한 남동생） | 정체가 조사에 견디지 못함 |
| 횡포형 | 힘 믿고 사람 괴롭히고 제멋대로 | 소낭（황제 동생） | 오만 때문에 뒤 돌아보지 않음 |
| 연약형 | 약한 척 동정 구하고 뒤에서 조종 | 어머니（매부 길 바꿔줌） | 가면이 증거에 깨짐 |

## 2. 진실 폭로 메커니즘

### 4가지 드러내기 방식

#### 증물 폭로

물리적 증거로 일거에 결정짓는다.

조작：단계설정단에 「별로 중요해 보이지 않는 소품/문서」를 심어놓고, 폭로 시 그 의미를 뒤집는다.

```
복선：어머니가 목에 항상 금자물쇠를 차고 있었는데, 언니가 준 거라 했다
폭로：금자물쇠를 열자 안에 「금은동」 세 글자가 새겨져 있었음
결정타：그녀는 이 자물쇠를 한 번도 열어본 적이 없었다
```

#### 증인 폭로

제3자의 시각이 거짓말을 깨부순다.

조작：주변 역할（하인/이웃/동료）을 배치해, 결정적 순간에 주인공이 모르는 정보를 털어놓게 한다.

```
복선：주마마는 언제나 할 말을 다 못 하고 입을 다물곤 했다
폭로：주마마가 임종 때 주인공에게 편지를 한 통 건넸다——선황후의 자백서
결정타：왕씨는 이 편지가 있는 걸 알고 있었기에 줄곧 주마마를 찾고 있었던 거다
```

#### 엿듣기/마주치기

주인공이 숨겨진 정보를 얻는다.

조작：「주인공이 있으면 안 될 장면」을 설계해, 주인공이 무심코 진실을 보거나 듣게 한다.

```
복선：어머니는 전화 올 때마다 발코니로 나갔다
폭로：주인공이 발코니를 지나다가 어머니의 말을 들었다——「그 금자물쇠는 가짜야, 지금까지 모르고 있었을 거야」
결정타：전화 건너편 사람은 매부였다
```

#### 지연식 양파 껍질 벗기기

한 겹 진실이 더 깊은 진실을 이끌어낸다.

조작：층마다 한 절씩 폭로하며, 층마다 윗층보다 더 잔혹하게 한다.

```
1층：남동생의 여자친구는 그녀가 말한 사람이 아니었다
2층：여자친구는 사기꾼이었고, 범죄 기록이 있었다
3층：임신은 가짜였다
4층：남동생은 이미 전화 사기 단지에 속아 넘어갔다
```

### 소재별 폭로 리듬 선택

| 소재 | 추천 방식 | 리듬 |
|------|----------|------|
| 사정/쾌활물 | 증물 폭로 또는 증인 폭로 | 한 번의 대폭로, 깔끔하게 떨어뜨림 |
| 감정/비련 | 엿듣기/마주치기 + 지연식 양파 껍질 | 층층이 폭로하며, 층마다 더 아프게 함 |
| 고대 로맨스/복수 | 증인 폭로 + 증물 폭로 | 먼저 증인으로 복선 깔고 증물로 일거에 결정 |
| 미스터리/추리 | 지연식 양파 껍질 | 전체적으로 층층이 드러내며 마지막 한 조각 퍼즐 |
| 시대물/가족애 | 엿듣기/마주치기 | 뜻밖의 발견, 감정 충격 최대화 |

## 3. 악역 응보 설계

### 규칙

응보는 반드시 악행과 대응되어야 한다. 악행이 무거울수록 응보도 무겁다.

### 대응 원칙

| 악행 | 응보 | 대응 논리 |
|------|------|----------|
| 냉궁에 죽도록 내버려둠 | 스스로 냉궁에 들어감 | 인과 윤회 |
| 통장 몰래 가져가기 | 계좌가 동결되어 한 푼도 못 가짐 | 훔쳐 잃은 건, 자기 것까지 잃는다 |
| 사랑을 빙자해 조종함 | 모든 사람에게 버려짐 | 가짜 사랑 진짜 조종, 결국 아무도 조종할 수 없게 됨 |
| 돈 사기치기 | 더 심한 사람한테 사기 당해 단지에 감 | 사기꾼이 더 고수 사기꾼에게 수확당함 |

### 4가지 응보 모드

| 모드 | 적용 장면 | 조작 |
|------|----------|------|
| 법적 제재 | 현대적 배경, 악행이 법에 저촉됨 | 신고/고소/판결, 짧은 몇 마디로交代 |
| 사회적 죽음 | 위선형/조종형 악역 | 진실 공개, 모든 사람이 본색을 깨닫게 함 |
| 인과 윤회 | 고대 로맨스/복수 소재 | 한 일이 자기 자신에게 돌아옴 |
| 정신 붕괴 | 비련/안타까운 소재 | 악역이 모든 걸 얻었지만 단 하나 소중한 걸 잃은 걸 알게 됨 |

### 응보 강도 보정

- 응보 강도 = 악행 강도 × 1.0-1.2（지나치지도 가볍지도 않게）
- 긴 응보 묘사를 쓰지 말고, 2-3문장으로 넘기며 독자에게 여백을 줄 것
- 응보의 「쾌감」은 대응감에서 오지, 묘사 길이에서 오는 게 아님

## 4. 반전 유효성 자가 검사（Phase 2 사용）

outline 작성 후, 이 자가 검사로 반전이 정말 독자에게 반전으로 다가가는지 확인：

| 체크 항목 | 통과 기준 | 불통과 = 필요한 것 |
|----------|---------|-------------------|
| 독자가 진실을 아는 시기 | >60%는 적정；50-60%는 회색 지대로 반전 강도 검토 필요；<50%는 반전 아님（3단계 기준은 writing-workflow.md「반전 정보차 검증」상세） | 단서 방출 리듬 조정, 진실 폭로 연기 |
| 오도하는 가짜 단서가 있는가 | ≥1개 독자가 믿을 가짜 단서 | 붉은 청어（red herring）또는 선택적 서술 오도 추가 |
| 진실 단서의 은밀도 | 돌이켜보면 찾을 수 있지만 처음 읽을 때는 무시됨 | 단서는 일상 디테일에 숨기고, 강조하는 말투 사용 금지 |
| 캐릭터가 아는 것 vs 독자가 아는 것 | 반전 전에 독자와 캐릭터 중 최소 한쪽은 진실을 모름 | 정보차 만들기：독자가 모름 / 캐릭터가 모름 / 양쪽 다 모름 |

**실패 모드**：「지연 폭로」는 반전이 아님. 독자가 2절에서 진실을 이미 알고 뒤에 10절은 그저 캐릭터를 기다리기만 하는 것 = 지연 폭로로 독자가 심심해진다. 진정한 반전은 밝혀지는 순간에 일어나 독자와 캐릭터가 같이 충격받아야 한다.
