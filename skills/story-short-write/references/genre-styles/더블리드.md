# 소재 스타일 팩: 더블리드 / 숙명의 인연

> 즈후 옌쉬안 특색 대분류. 먼저 `short-craft.md` 공용 베이스를 읽고, 본 팩은 그 위에 해당 소재 전용 조닝을 덮어씌운다.
> 한 줄 포지셔닝: **핵심 인장력은 남녀 삼각이 아니라, 두 남자 사이의 인연과 할퀴며, 숙적 / 지기 / 구원 / 채무 네 가지 선으로 전기를 흘린다; 정서 농도를 한껏 높이되, 형제애, 숙명감, 점유욕의 차원에 둔다.** 독자가 원하는 건 「한쪽은 차갑고 한쪽은 뜨거운 온도차 충돌」+「입으로는 원수지간이라 하고, 아랫쪽은 목숨도 내주는」 어긋난 쾌감이다.

---

## 서술 성격

1인칭이 주류지만, 처참반성의 편향된 피해자와는 다르다: 더블리드의 「나」는 자주 **관계에서 능동적이거나, 강세거나, 점욕하는 쪽**(동생을 곁에 키우는 형, 상대방을 개처럼 갖고 노는 환생자, 냉담하게 계약을 이행하는 계약 남편)이다. 다른 한쪽의 뜨거움과 비굴함은 대화와 동작으로 반사되어 비춰진다.

성격은 **말은 그른데 마음은 맞는 것(口是心非)** 위에 세운다: 생각하는 것과 말하는 게 반대다. 입으로는 까칠하게 굴면서 마음속으로는 챙겨준다. 까칠한 내면 비꼬기(「심주는 초능력 안 써—머리가 나쁜가 보지」)와 냉담한 서술(「그가 죽는 것에 대해 나는 별로 느낌이 없다」)이 둘 다 고빈도로 나온다. 입을 열 때는 동성 간의 인연 호칭 닻을 자주 걸어둔다: 「우리 형」「의붓동생」「원쑤」「숙적」「암위 십칠」.

**양쪽 시점 / 짝사랑 시차 삽입**을 허용한다: 「나」의 서술 사이에, 다른 한쪽의 비밀스러운 헌신(몰래 적은 공책, 체력 고갈시킨 끝에 생긴 우연의 일치, 주지 못한 편지) 한 단락을 끼워넣는다. 독자는 「나」보다 먼저 그가 얼마나 사랑하는지 알게 된다. 이것이 본 소재 주 엔진이며, 전지적 화자가 아니다.

## 시작 파라다임

마찬가지로 먼저 **결과 역순의 황금 소개**(150-300자)를 두지만, 배신 전모를 스포일러하는 게 아니라 **두 사람의 어긋난 관계 카드**를 털어놓는다: 누가 짝사랑하는지, 누가 누구에게 빚진 건지, 누가 누굴 망칠 건지, 처참반성 회한 예고. 본문 제1장에서 이 어긋남을 느리게 재생한다.

| 시작식 | 실제 사례 |
|--------|----------|
| 부고 역순 + 불가사의 | 《흐린 날 즐겁다》 사설옥은 내가 그와 결혼한 지 3년 만에 죽었다. 자살로. |
| 서로 패며 원수 맺기 + 숨은 흐름 묻기 | 《원쑤가 나를 짝사랑하다》 나와 심주는 원쑤였다. 종말 전 맞서고, 뒤엉켜 떨어지지 않았다. |
| 점유 선언(형 / 의붓동생) | 《나와 우리 형》 나는 우리 형이 밉다. 더러운 돈 버느라 그가 몸을 파는 게 밉다. |
| 계약 족쇄로 시작 | 《덫에 빠지다》 심칙, 3년 뒤 가고 싶으면 보내줄게. 근데 3년 뒤에야 알았지, 그는 절대 보내줄 생각이 없었다는 걸. |
| 환생 / 책빠져들기로 죽음의 국면 예지 | 《쌍둥이의 재앙》 태아로 장군집 외아들로 태어났다. 나는 혈육 아닌 그 형이, 미래에 내 한마디에 황성을 도륙할 줄 알았다. |
| 코미디 반전 갈고리 | 《미친 황제와 착한 암위》 황제가 암위를 모집했다. 오십 냥에 밥도 집도 제공. 근데 내가 받은 장비는 투명한 얇은 옷과 수정 가슴 장식. |
| 채무 역순 + 확진 반격 | 《버려진 장난감》 사한주는 사구성에서 가장 오르기 힘든 고봉이었다. 그리고 나는 그의 곁에서 키운 의붓동생이었다. 근데 나는 확진 판정받은 그날, 그의 면전에서 낯선 남자를 데리고 집에 왔다. |

## 갈고리 모티프와 밀도

밀도는 높으나, 상승 라인이 「배신 심화」가 아니라 **두 사람 관계의 걸쇠가 한 겹 한 겹 조여지는 것**: 대치에서 억지로 같이 지내게 되고, 같이 지내다가 서로 빚지게 되고, 빚지다 보니 아무도 못 가게 된다. 마디마다 최소한 한 번의 온도차 충돌이나 한 번의 시차 폭로를 밀고 나가며, 장 끝에는 어긋난 갈고리를 남긴다.

- **짝사랑 시차**(1순위 모티프, 「짝사랑」 공동 출현 576회로 「달콤사랑」 다음으로 많다): 겉으로는 미워하거나 / 싸우거나 / 담담한데, 아래쪽에서는 한쪽이 몰래 사랑하고 있다. 시차가 폭로되는 순간이 가장 큰 쾌점이다.
- **계약 / 빚 / 인연으로 강제로 묶기**: 조수 계약, 차용증, 정략결혼, 암위 계약으로 원래 헤어져야 할 두 사람을 억지로 묶어, 도망칠 수 없는 동거를 만든다.
- **구원과 구원받음**: 한쪽은 구렁텅이(더러운 돈, 자멸, 미친 상태, 종말의 체력 고갈)에 있고, 다른 한쪽이 손을 내밀거나 / 끌어당겨진다. 공동 출현 「구원」 326, 「치유」 310.
- **채무 역전(남편 쫓는 처참반성 변형)**: 한쪽이 다른 한쪽을 도구로 쓰거나 / 무시하거나 / 배신하다가, 버림받은 자가 결연하게 떠나고(아버지 버리고 아이 데리고 / 자산 들고 / 다른 사람과 시집가고), 무시했던 쪽이 비굴하게 회한한다.
- **숙명 예지**: 환생 / 책빠져들기로 그가 미래에 자살하거나 / 흑화하거나 / 자신을 망칠 줄 알고, 주인공이 목숨 걸고 운명을 고친다. 공동 출현 「환생」 68, 「책빠져들기」 113.
- **신분 반전 정면 충돌**: 고봉의 까칠남 × 충성스러운 의붓동생, 황제 × 착한 암위, 장군 × 늑대 새끼 형, 양쪽 다 A급 / 다 강해서 서로 양보 안 한다.
- **증표 / 기록이 무게를 싣는다**: 몰래 적은 공책, 주지 못한 편지, 유일한 합성사진, 희미해진 표식. 말하지 못한 감정을 물건으로 구체화한다.

## 정서 강도와 패턴(강도 8)

처참반성처럼 한쪽으로만 직설적으로 토해내는 게 아니라, **이중 궤도 온도차**: 한 라인은 차갑고, 입은 거칠고, 억누르고, 말은 그른데 마음은 맞고; 다른 한 라인은 뜨겁고, 비굴하고, 집착하고, 내던진다. 두 라인의 온도차가 충돌하며 전기가 흐르는 게 본 소재 정서 엔진이다. BE는 드물다(56편뿐). 주류는 HE / 구원으로 간다(HE 공동 출현 1054). 끝까지 죽이거나 끝장내지 말 것.

- **차가운 라인**: 직접 「느낌 없어 / 상관 안 해 / 그냥 짜증날 뿐」이라고 쓴다. 평할수록 뒤에 오는 아픔이 더 비춰진다. 《흐린 날 즐겁다》 그의 죽음에 대해 나는 별로 느낌이 없다.
- **뜨거운 라인**: 비굴하고, 집착하고, 회한하는 뜨거운 대사를 독립된 문단으로 던진다. 《아이고, 네 손에 넘어갔구나》 형, 내가 잘못했어, 나 버리지 마. 애비는 누구야? 내가 애 아빠 해줄게, 안 될까?
- **삐걱이는 라인**: 오만한 자가 말은 그른데 마음은 맞는다. 생각하는 것과 말하는 게 반대이며, 입으로 더 까칠하게 굴수록 마음속에 챙기는 게 숨어 있다(《원쑤가 나를 짝사랑하다》의 심주가 매번 건드리는 짓).
- **반전의 아픔**: 냉담한 서술과 뜨거운 디테일 한 가지를 나란히 놓아, 평할수록 더 무거운 내용을 받친다. 《흐린 날 즐겁다》 나는 평범한 업무를 처리하듯 그 일을 치렀다. 냉정하게 그의 유골 사진을 고르고, 묏자리를 골랐다.

실제 사례:

- 《원쑤가 나를 짝사랑하다》 심주가 매번 입으로 말하는 우연한 일이, 전부 그가 초능력 체력 고갈시킨 결과라는 걸 아무도 몰랐다.
- 《쌍둥이의 재앙》 그는 혼수상태에서 내 손목을 꽉 움켜쥐고 중얼거렸다: 더… 더 크게 욕해…
- 《그대와 아침을》 그가 나에게 남긴 건, 주지 못한 편지 수없이 장 뿐이었다. 편지 한 장 한 장마다, 그가 한 번도 내 입 밖으로 내지 못한 감정이 빽빽하게 적혀 있었다.

## 대화 스타일과 실제 명대사

비중이 높고, 독립된 문단으로 둔다. 세 종류 대사가 전체를 떠받친다:

**① 입이 거친 / 공격적인 상대 대사(겉으로는 원수지간)**
- 보고 싶었냐? 변태 새끼!
- 걔가 있다고 너는 믿냐? 내가 잘 알지, 하루종일 여자처럼 남자답지도 않고, 남자가 한 번 만지면 울어대잖아.
- 이 멍청아! 총 쏘려면 자세부터 잡아!

**② 비굴 / 집착의 뜨거움(忠犬 / 얀데레 / 회한)**
- 형, 내가 잘못했어, 나 버리지 마. 애비는 누구야? 내가 애 아빠 해줄게, 안 될까?
- 사랑해, 너 없이는 못 살아.
- 자기야, 내 곁에 있어줘. 돈은 얼마든 내줄게, 내가 뭘 입었으면 좋겠다고 하면 뭐든 입어줄게, 네가 밟고 싶은 데가 있으면 다 밟아줄게.
- 더… 더 크게 욕해…

**③ 계약 / 입장 대사(숙명의 족쇄)**
- 심칙, 3년 뒤 가고 싶으면 보내줄게.
- 좋아, 그런데 차용증 써야 해.
- 돈은 얼마든 내줄게. 네가 부르는 대로 다 줄 게.

갈등은 욕설로 승부하는 게 아니라, **온도차 낙차**로 권력과 설렘의 주인이 바뀌는 걸 표시한다: 전반에는 한쪽이 길게 도발하고 다른 쪽은 냉담하게 상대도 안 하고; 후반에는 차갑던 쪽이 무너지고, 딱딱하던 쪽이 비굴해진다. 누가 먼저 고개 숙이느냐에 마음이 드러난다.

| 반전 코미디 갈고리 | 두 「피해자」가 어쩌다 보니 한데 어울리며, 오해를 웃음거리로 삼는다 | 《네 아내가 너 몰래 밖에서 1을 한다고》 먼저 선언하자면 나는 시비 거는 사람 아니다—근데 너는 알고 있나? 네 아내가 너 몰래 밖에서 1을 한다고. |

## 리듬 뼈대

```
황금 소개(결과 역순 + 짝사랑 / 채무 / 숙명의 관계 카드 스포일러)
→ 제1장 서로 패기 / 계약 / 점유 장면을 느리게 재생하며, 적대감을 세우고 + 숨은 흐름을 묻는다
→ 관계 걸쇠가 조여진다(억지로 같이 지냄 / 계약 / 숙명의 족쇄)
→ 온도차가 한 번 한 번 전기를 흘린다(입은 거칠다 vs 뜨겁다, 어긋남에 압력을 더한다)
→ 시차 / 숨은 사정이 폭로된다(공책 / 체력 고갈 / 주지 못한 편지 폭로)
→ 위기 또는 채무 폭발점(목숨 바치기 / 배신 / 무시 / 흑화)
→ 서로에게 달려가기 또는 회한의 처참반성
→ HE로 수렴(숙명 화해 / 구원 완결)
```

매 장 새로운 어긋남이나 새로운 폭로를 하나씩 넣고, 장 끝에는 갈고리를 남겨두고 수렴하지 않는다. 밀도: 온도차 충돌, 시차 폭로, 위기 폭발점에서는 느리게 재생하며 자세히 적고, 같이 지내는 일상은 한 마디로 넘긴다.

## 마무리 파라다임

- **서로에게 달려가기**: 입이 거칠던 쪽이 마침내 인정하고, 차가운 라인이 무너지며, 온도차가 0으로 수렴한다.
- **구원 완결**: 그를(또는 그에게서) 구렁텅이에서 끌어내고, 「서로 빚진 게 없다」에서 「서로 의지한다」로 간다.
- **회한 처참반성(채무 하위 분류)**: 무시했던 쪽이 비굴하게 되찾고, 버림받았던 쪽은 냉담하게 거절하거나 조건부로 돌아선다.
- **숙명 거꾸로 쓰기(환생 / 책빠져들기)**: 전생의 죽음의 국면을 고쳐서, 이번에는 안 가 / 너는 죽지 못해.
- 주류는 HE다. 처참반성처럼 순전히 고통만 주고 떠나지 말 것; 아무리 앞부분이 고통스러워도 화해나 회복을 줘야 한다.

플롯 개요: 《다행히도 우리 언젠가 만나겠지》 기심이 아무 말 없이 떠난 지 3년째, 유일한 합성사진 한 장이 재회를 끌어낸다. ／ 《그대와 아침을》 환생해서 소익이 죽으며 버티던 결말을 거꾸로 고쳐, 사람을 곁에 가두고 말하지 못했던 감정을 보충한다.

## 해당 소재 전용 튜닝(공용 AI 제거 규칙과의 편차)

이것들은 다른 문맥에선 AI 느낌이거나 너무 과하다 싶지만, 본 소재에선 매력 포인트다. **실수로 지우지 마라**:

- **양쪽 시점 / 짝사랑 시차 삽입**: 「나」의 서술 사이에 다른 쪽의 비밀스러운 헌신을 스포일러하는 건, 유지한다. 이것이 공명의 주 엔진이며 전지적 화자가 아니다. 「비밀을 다 까놓고 독자를 낚지 않는」 함부로 쓴 전지적 시점만 지운다.
- **말은 그른데 마음은 맞는 오만한 내면 독백**: 생각하는 것과 말하는 게 반대인 건, 유지한다. 앞뒤가 똑같게 평탄하게 고치지 말 것.
- **비굴 / 집착 / 회한의 뜨거운 대사**: 충성견, 얀데레, 처참반성의 고백은, 유지한다. 「너무 과하다」고 삭제하지 말 것.
- **계약 / 숙명의 미래 예지 스포일러**: 의식적으로 앞으로 「3년 뒤 / 나중에 그는 후회했다 / 미래에 그가 나를 망칠 거야」라고 낚는 건, 유지한다.

여전히 피해야 할 진짜 AI 느낌: 눈앞에 펼쳐지더니, 속으로 생각하길, 낮은 목소리로, 입꼬리가 살짝 올라가더니, 눈빛이 번쩍이더니, 논문 접속사(틀림없이 / 이로써 알 수 있다), 체감 없는 공허한 정서 요약 문장(한 가닥 슬픔이 마음속에 밀려오더니). 말뭉치에도 간혹 「눈앞에 펼쳐지더니」처럼 섞여 들어오는 게 있으니, 그대로 베끼지 말 것.

## 함께 쓰는 구조 공식(길이에 따라 선택)

- **숙적 짝사랑 / 서로 달려가는 타입(8-11장)**: 1-2장 서로 패며 원수 맺기 + 숨은 흐름 묻기 → 3-4장 억지로 같이 지냄 / 계약으로 묶기 → 5-6장 시차 폭로(한쪽 비밀 드러냄) → 7-8장 위기로 목숨 바치기 / 무너지며 고백 → 서로 달려가 HE. 시점은 한쪽이어도 양쪽이어도 OK; 온도차가 엔진이며, 차가운 쪽이 늦게 무너질수록 좋다.
- **구원 / 현대 정서형**: 한쪽이 구렁텅이(더러운 돈 / 계약 / 자멸 / 종말 체력 고갈) → 다른 쪽이 끌어당김 → 전생 / 계약 족쇄가 사람을 가둠 → 족쇄를 깨고 서로 의지하게 간다. 냉담한 서술이 바탕이며, 반전 디테일이 마음을 찌른다.
- **채무로 남편 쫓는 처참반성형**: 한쪽이 무시 / 배신(의붓동생 / 배우자가 도구 취급) → 확진 / 임신 / 마음이 죽음 → 결연하게 떠남(아버지 버리고 아이 데리고 / 자산 들고 / 다른 사람과 시집감) → 무시했던 쪽이 비굴하게 되찾음 → 냉담히 거절하거나 조건부로 돌아섬. 칼날을 정확히 대고, 욕설하지 말 것.
- **고대 권모 양쪽 다 강한 타입**: 제왕장상 / 형제 키우기로, 환생 또는 책빠져들기로 죽음의 국면 예지 → 숙명을 거꾸로 씀 → 가두거나 / 구하거나 / 친해짐 → 강산과 사람 둘 다 갖는다. 권모 라인과 감정 라인이 서로 노름돌이 된다.
