# 소재 스타일 팩: 가택궁투 / 고언 환생

> 판타지 / 칠묘 / 흑암 통속 단편. 먼저 `short-craft.md` 공용 베이스를 읽고, 본 팩은 그 위에 해당 소재 전용 조닝을 덮어씌운다.
> 한 줄 포지셔닝: **주인공(정실 부인 / 진짜 따님 / 적녀 / 가난한 본처)이 시아버님 + 시어머니 시댁 식구 / 부모님과 함께 백월월 / 가짜 따님을 위해 희생당하고, 사정을 들킨 뒤 화합하고 남편 버리고, 몸 가진 채 나가거나 죽음 도망 환생한다; 상대방이 카드를 깔 때는 때가 너무 늦어, 후회하며 발버둥 친다.** 독자가 원하는 건 「속수무책으로 당하는 비참함」+「휴지 한 장 / 환생으로 뒤집는 통쾌함」이다.
>
> 하위 유형: 가택궁투 / 고언 환생 (화합이혼하고 남편 버리기 · 가짜 따님 자리 뺏기 · 백월월 사랑 빼앗기 · 시대극 환생 · 코미디 브레인)

---

## 서술 성격

1인칭 「나」 피해자가 전 과정을 주도하며, 밀착 체감과 심장 박동을 따라간다. 억누르지 않는다. 이중 궤도: 사정 들키기 전에는 억울함을 참으며 가문 체면을 위해 고통을 삼키고; 사정을 들킨 뒤에는 냉정하고 위엄 있으며, 반문반백의 심판 성선으로 바꿔 한 마디에 운명을 정한다. **문백이 섞인 건 본 소재의 간판 성선이다**: 고언 라인은 「시집가서」「여섯 해 동안」「정식으로 팔촌 잡치고」「도복을 찢고 의리를 끊다」「각자 몸 잘 챙기시오」 같은 반문반백 어휘로 궁궐의 질감을 받친다; 시대극 환생 라인은 「사원 기숙사」「가족 주택」「만원户」「디리얀 셔츠」 같은 시대 구어로 바꾼다. 두 라인 모두 구어체로, 여전히 문단 단위로 토로 독백 + 연쇄 반문을 퍼부은다. **앞으로 나아가 「그는 나중에 미쳐서 후회했다」는 처참반성 결말을 스포일러로 사람 낚는 걸 허용하고 권장한다.**

입을 열 때는 점유 / 신분 관계가 담긴 호칭을 쓴다: 「내 시아버님 / 내 남편 / 나의 태자 전하 / 내 남편」. 그리고 하나의 시간 닻(혼인칠년 / 후작 집안으로 돌아온 지 오년 / 여섯 해 동안 과부로 지냄)을 끼워넣는다.

## 시작 파라다임

본문 제1장 앞에 먼저 **시간 닻 + 전체 호 스포일러의 황금 서문**(150-300자)을 한 단락 둔다. 「제 N년 / 제 몇 해째」로 시작해 닻을 내리고, 배신 전모 + 마음의 죽음 + 「그런데 그는 나중에 후회했다 / 천금을 걸고 나를 찾았다」를 한 번에 스포일러해서 오직 독자 낚시만 판다; 본문 제1장에서 서문 사건을 느리게 재생하며, 대화 체감을 채운다. 환생 라인 서문은 먼저 전생의 죽음 법과 범인을 설명한 뒤, 「다시 눈을 뜨면」 중요한 시점으로 돌아간다.

| 시작식 | 실제 사례 |
|--------|----------|
| 시간 닻 + 배신 | 《돈의》 배균주와 혼인한 지 칠년째, 그가 죄인 노예 한 명을 데려왔다. 그의 백월월이었다. |
| 과부 지낸 연수 닻 | 《네 마음이 없으면 나도 그만, 나중에 나한테 빌지 마시오》 숙왕에게 시집간 지 여섯 해, 혼인 당일 그가 갑옷 입고 출정해 나는 여섯 해 동안 과부로 지냈다. |
| 돌아옴 / 대신 시집감 연수 닻 | 《가짜 따님이 내가 몸을 더럽히게 꾸며, 온 식구가 나를 속이고 숨긴 뒤 자업자득》 후작 집안으로 돌아온 지 오년, 가짜 따님 강운운이 태자 침샘에게 대신 시집가려고 내가 몸을 더럽히게 꾸몄다. |
| 첫 문장이 곧 스캔들 폭탄 | 《남편이 하루에 아내 둘을 들였는데, 내가 자발적으로 시집가길 요청했다》 경성 심가에서 스캔들이 터졌다. 차남 심력이 형이 죽은 뒤 과부가 된 형수를 사랑하게 됐다는 것이다. |
| 전체 호 스포일러 + 처참반성 예고 | 《규방 친구와 죽음 도망한 뒤, 문무 장원급제 자가 미쳐버린 일》 문무 장원급제 자가 혼인 당일, 나와 규방 친구는 마음이 죽어 떠났다. 그런데 그들은 천금을 걸고 온 성을 들고, 애원하듯 우리 행방을 찾았다. |
| 환생해 역으로 시집보내기로 시작 | 《밝은 달에 맑은 빛을 뿌리네》 환생한 뒤, 나는 친히 열쇠를 소꿉친구 손에 쥐여주었다. 「집은 네 거야, 내 남편도 네 거야.」 |
| 문백 궁투 역순 | 《잘못된 연꽃은 늦게 필 뿐》 내가 죽은 지 삼년째, 소욱이 승전하여 조정에 돌아왔다. 그는 하늘에 맹세하며, 세상에 내세울 공을 세워, 사랑하는 사람에게 최고의 체면을 주는 혼인 명령을 구하겠다고 맹세했다. 안타깝게도 그는 너무 늦었어. 내 유골은 이미 썩어 없어졌다. |
| 코미디 브레인 반전 갈고리 | 《돼지 키우는 데 실패한 뒤, 나와 원쑤가 어쩌다 애를 낳게 됐다》 어진이 내려졌다——혼인 명령이 아니라, 돼지를 내려주셨다. |

## 갈고리 모티프와 밀도

밀도가 극도로 높다: 서문에 3-5개의 배신 / 꾀임 사건을 욱여넣고, 본문 마디마다 최소한 새로운 심화나 더 독한 대사 한 마디를 넣고, 장 끝에는 반드시 새로운 폭탄을 남긴다. **계단식 배신: 도덕 → 경제 / 신분 → 생명(아이).**

- **백월월 / 가짜 따님 발동 연쇄**(핵심 모티프): 시아버님에게 백월월 / 소꿉친구 / 의붓여동생이 있거나, 집안에 가짜 따님이 들어와서, 결정적인 순간 온 식구가 그녀만 편들고 주인공을 희생시킨다. 그들은 대부분 「여리고 억울한 척」을 부드러운 칼로 쓴다.
- **엿듣기 / 사정 들키기 한 방에 내리꽂기**: 밀림, 절, 찻집에서 시아버님과 백월월 / 가짜 따님의 진심을 마주쳐, 「예전의 맹세가 다 거짓이었다」는 게 모조리 드러나 마음의 죽음 방아쇠가 된다.
- **시댁 식구 / 부모님 공모**: 나쁜 남자 혼자가 아니라, 시어머니 시댁 식구 / 친부모마저 사실을 알고 감싸준다. 「부모님은 자식을 위해 멀리 내다보신단다. 다만 이 아이는 내가 아니었을 뿐」.
- **믿을 수 있는 증표를 칼로 쓰기**: 정식으로 주고받은 비녀 / 옥패 / 동심결 / 향낭을 백월월이 빼앗거나 주인공이 친히 찢어 깨부수며, 의미가 역전된다.
- **숫자 / 연수가 무게를 싣고 다시 초기화**: 혼인 칠년, 과부 오년, 돌아온 지 오년, 정쟁 십년——바친 게 쌓였다가 한 마디로 모두 사라진다.
- **처참반성 미래 예고**: 서문 끝에 스포일러 보상을 한 마디 끼워넣는다(천금 걸고 찾기, 미쳐버리기, 카드 깔 때는 사람이 이미 떠남 / 죽음).

## 정서 강도와 패턴(강도 8)

쾌감과 고통이 함께 가는 이중 궤도: 사정 들키기 전에는 직설적으로 토로 + 사정 들킨 뒤에는 냉정한 심판(무딘 칼이 차가운 칼로 바뀜). 순전히 고통만 주는 환생 가지(옛 정을 베는 이 / 죽음 도망)는 9까지 갈 수 있다.

- 정서에 직접 이름 붙이고 가중한다: 마음이 재처럼 식었다, 칼로 베이는 듯 아프다, 가슴이 찢어질 듯 슬프다, 눈물이 비처럼 쏟아진다, 마음이 바닥까지 가라앉았다——통틀어 고빈도로 직접 쓴다.
- 정서를 직접 적고, 장면 특유의 동작이나 물건을 뒤에 덧붙인다(둘 중 하나만 하는 게 아니라 둘 다).
- 마음이 죽은 뒤 차갑게 반영된다: 심판할 때는 아무런 동요도 없고, 가장 독한 말도 감정을 자극하지 못한다.

실제 사례:

- 《가짜 따님이 내가 몸을 더럽히게 꾸며…》 내 마음속에 순간 칼로 베이는 듯 아픈 생각이 떠올랐다.
- 《가짜 따님이 내가 몸을 더럽히게 꾸며…》 거대한 슬픔이 나를 덮쳤다. 이제 이 일들을 세상에 드러내놓으니, 내 마음도 따라 피를 흘렸다.
- 《규방 친구와 죽음 도망한 뒤…》 분노와 심장 통증이 가슴속에서 뒤끓었다. 나는 코가 찡해지며 옥패를 집어 던져 산산조각 냈다.
- 《충절로 이름난 집안, 내 동생이 악당에게 업신여김을 당했는데》 나와 할머니는 마당에서 꽉 껴안고 눈물을 비처럼 쏟았다. 다리가 부러진 아픔보다 지금 이 찌르는 듯한 슬픔이 훨씬 아팠다.
- 《비녀 부러지면 봄은 오지 않네》 나는 마음이 재처럼 식어, 소회 면전에서 몸을 돌려 호수로 뛰어들었다.
- 《10년 전 그들이 내게…》 그들 눈에 심여의는 금수강산이었다. 그리고 나는, 금수강산에 난 구멍이었을 뿐.

## 대화 스타일과 실제 명대사

비중 45-60%, 구어체, 독하고, 반문반백이며 독립된 문단으로. 세 종류 대사가 전체를 떠받친다:

**① 가해자 / 온 식구의 도덕적 짓밟는 독설(갈고리 본체, 더 당당할수록 좋다)**
- 《10년 전 그들이 내게 여동생 대신 기생집에…》 너는 천 명이 타고 만 명이 건너는 놈인 주제에 감히 심가 정문을 떳떳하게 걸어 들어오려고? 너나 잘할 게 우리 시댁 체면이지!
- 《이후 소씨는 남이 되리라》 거지 주제에 유아의 치마를 더럽히지 말고.
- 《옛 정을 베는 이를 칼로 베고 싶을 뿐》 네 몸이 상해서 아이를 낳지 못한다는데, 그런 천한 년이 네 아이를 낳아준 건 이미 영광이잖아.
- 《공을 세운 내가 아버지安排로下人 방에서 자게 된 일》 네가 밖에서 십년 동안 한 번도 집에 찾아오지 않았으니, 효도를 다한 게 아니지. 좋은 방에 쓸 자격 없어.

**② 백월월 / 가짜 따님의 여린 연약검**
- 《남편이 하루에 아내 둘을 들였다》 언니, 내가 같이 왕부에 시집가는 게 언니한테 억울한 거 알아. 언니 마음속에 화가 있는 거, 내가 알아. 그냥 따뜻한 차 한 잔일 뿐인데, 언니 속이 풀린다면 열 잔이라도 스무 잔이라도 난 기꺼이 마실래.
- 《진북후에게 시집간 뒤…》 아설 언니, 네가 날 안 좋아하는 거 알아. 네가 서언 오빠랑 소꿉친구로 혼약까지 맺었는데, 내는 그저 외롭고 싶지 않아. 내가 이제 갈게. 다시는 너희를 방해하지 않을게.
- 《10년 전 그들이 내게 여동생 대신…》 그래도 언니가 집에 와줘서 다행이야. 예전 일은 난 절대 원망 안 해.

**③ 주인공이 마음 죽은 뒤 냉정한 심판 명대사(반문반백으로 확정 짓기)**
- 《남편이 하루에 아내 둘을 들였다》 묘아 동생을 만나고 싶으면, 그냥 만나고 오시지.
- 《네 마음이 없으면 나도 그만, 나중에 나한테 빌지 마시오》 이 사람은 존귀함을 따르지 않으니, 곤장 스무 대로 본보기를 보이시오.
- 《가짜 따님이 내가 몸을 더럽히게 꾸며…》 나는 아버지 어머니의 친딸이지, 그녀는 아니다. 나는 태자 전하께서 정식으로 팔촌 잡치고 맞아들인 아내지, 그녀는 아니다.
- 《가짜 따님이 내가 몸을 더럽히게 꾸며…》 나는 이제 지쳤다. 너희들과 더 이상 관계 맺고 싶지도 않고, 이제부터 도복을 찢고 의리를 끊으니, 너희들, 각자 몸 잘 챙기시오.
- 《밝은 달에 맑은 빛을 뿌리네》 집은 네 거야, 내 남편도 네 거야.
- 《10년 전 그들이 내게 여동생 대신…》 웃어라. 더 웃어. 오늘이 지나면, 너희들은 더 이상 웃을 수 없을 테니.

갈등은 대화 길이 반전으로 권력이 바뀌는 걸 표시한다: 나쁜 남자 / 온 식구가 전반에 장문으로 깎아내리면, 주인공은 후반에 한 마디로 차갑게 받아친다.

## 리듬 뼈대

```
시간 닻 + 전체 호 스포일러 서문(처참반성 예고 / 전생 죽음 법 포함)
→ 제1장 서문 사건을 다시 쓰고, 대화 체감을 채운다
→ 마디마디 배신 심화(도덕→경제신분→생명) + 백월월의 연약검 누명
→ 엿듣기 / 사정 들키기(부모님 시댁 식구마저 사실 알고 있음)
→ 마음 죽음 정지
→ 믿을 수 있는 증표 찢기 + 냉정한 심판 + 화합이혼 / 몸 가진 채 나감 / 죽음 도망
→ 카드 깔고 강하게 돌아오기 / 환생으로 뒤집기
→ 나쁜 남자 후회 발버둥 / 천금 걸고 찾기(처참반성) + 명대사로 확정 짓기
```

매 장마다 새로운 정보 폭탄을 넣고, 장 끝에는 갈고리를 남겨 정서를 수렴하지 않는다. 밀도: 사정 들키기 / 역관광 치우기 / 증표 찢기 / 카드 깔기 구간은 느리게 재생하며 자세히 적고, 건너뛰는 건 한 마디로 넘긴다. 고언 라인은 한 마디에 2000-4000자, 시대극 / 현대 라인은 1000-2000자.

## 마무리 파라다임

- 처참반성 역전: 주인공이 떠난 뒤 나쁜 남자가 후회하며 / 미쳐버리며 / 천금 걸고 찾지만, 주인공은 더 이상 파문을 일지 않거나 억울함을 뒤집어 되갚아준다.
- 카드 깔고 압도: 모욕당한 사람이 사실은 섭정왕 / 여왕의 측근 / 만원户가 되어, 강하게 돌아와 온 식구를 발아래 깐다.
- 환생해 역으로 시집보내기 / 죽음 도망: 전생에 필사적으로 쟁취한 남편 집을 능동적으로 다시 내주고, 돌아서서 새 삶을 연다.
- 명대사로 확정 짓기: 한 마디 반어 / 심판으로 성격을 규정짓고 마무리하며, 스크린샷 돌아가는 하이라이트로 삼는다.

실제 사례:

- 《돈의》 재회했을 때, 나는 낙타 상단을 이끌고 사막을 건너 서역의 보배를 수없이 가져왔다. 배균주는 억울하고 상처받은 표정으로 말했다: 「돈의, 너 나 이제 버리는 거야?」
- 《비녀 부러지면 봄은 오지 않네》 하지만 평소喜怒를 얼굴에 내지 않던 소장군이, 미친 듯이 나를 껴안고 다시 한 번 쳐다봐 달라고 애걸했다.
- 《상유는 이미 저물었으니, 그대와 길게 이별하리》 동옥아, 정말로 나와 아들을 버리는 거야?
- 《규방 친구와 죽음 도망한 뒤…》 늦게 온 정성은 풀보다도 싸다.
- 《10년 전 그들이 내게…》 그들 눈에 심여의는 금수강산이었다. 그리고 나는, 금수강산에 난 구멍이었을 뿐.

## 해당 소재 전용 튜닝(공용 AI 제거 규칙과의 편차)

이것들은 다른 문맥에선 AI 느낌이지만, 본 소재에선 매력 포인트다. **실수로 지우지 마라**:

- **문백 섞인 어휘**(시집가서 / 여섯 해 / 정식으로 팔촌 잡치고 / 도복을 찢고 의리를 끊다 / 각자 몸 잘 챙기시오 / 존귀함을 따르지 않는다 / 본보기를 보이시오): 고언 궁투의 간판 성선이니 유지한다. 「문어 같다」고 백화로 고치지 말 것, 「번역한 말투 같다」고 지우지 말 것; 시대극 라인은 대응해서 시대 구어(가족 주택 / 디리얀 / 만원户)를 유지한다.
- **직설적 정서 성어**(마음이 재처럼 식었다 / 칼로 베이는 듯 아프다 / 눈물이 비처럼 쏟아진다): 유지한다. 장면 특유의 동작이나 물건 하나만 뒤에 덧붙이면 되고, 순수 동작으로만 바꾸지 말 것.
- **시간 닻 + 전체 호 스포일러 서문 / 처참반성 미래 예고**: 유지한다. 이런 의식적인 미래 스포일러는 「비밀을 다 까놓고 독자를 낚지 않는」 함부로 쓴 전지적 시점만 지운다.
- **믿을 수 있는 증표 찢는 물리적 동작 + 주관적 규정**(내가 친히 수놓은 건, 내가 친히 끝장을 봐야지): 유지한다. 찢기 + 심리적 귀결점이 본 소재 쾌감 본체다.
- **심판 명대사 / 마음 죽음식 장 끝맺음**: 유지한다; 오직 공허한 철학 승화만 지운다.
- **코미디 브레인 하위 유형의 경쾌한 희극 / 인터넷식 익살 성선**: 오직 해당 하위 유형 내에서만 완화를 허용하며, 반전 / 비꼬는 성선을 쓸 수 있다; 주류 궁투 / 환생 라인은 여전히 소박한 중국어를 바탕으로 하며, 현대 인터넷 유머를 섞지 않는다.

여전히 피해야 할 진짜 AI 느낌: 눈앞에 펼쳐지더니, 속으로 생각하길, 낮은 목소리로, 입꼬리가 살짝 올라가더니, 눈빛이 번쩍이더니, 논문 접속사(틀림없이 / 이로써 알 수 있다), 체감 없는 공허한 정서 요약 문장(한 가닥 슬픔이 마음속에 밀려오더니). 문백이 섞였다고 해서 어려운 한자를 마구 쌓아올린 게 아니며, 여전히 소박함을 바탕으로 한다.

> 문장 부호: 본 소재 사례는 의도적으로 원래 모습을 보존했다(`……` / `......` 포함); 본문에 쓸 때는 `short-craft.md` 제8절을 따라 `……` / `——`를 내지 말 것(정지는 짧은 문장 / 동작 / 줄 바꿈으로). 본 팩은 `……` 쓰는 법을 가르치지 않는다.

## 함께 쓰는 구조 공식(길이에 따라 선택)

- **가택궁투 / 고언 역관광형(8-12마디)**: 서문 스포일러 → 1-2마디 백월월 / 가짜 따님 연약검 누명, 온 식구 편들기 → 3-4마디 사정 들키기(부모님 시댁 식구마저 사실 알고 있음) → 마음 죽음 정지 → 5-6마디 증표 찢기 + 화합이혼 / 도복 찢고 의리 끊기 → 7-8마디 카드 깔고 강하게 돌아오기 / 나쁜 남자 후회 거절당하기. 심판 대사는 반문반백이고 한 마디에 피를 보게 한다; 각성은 사정 들킨 그 순간이다.
- **고언 / 시대극 환생형**: 서문에서 먼저 전생의 죽음 법 + 범인을 설명한다(백월월 자리 뺏기 / 가짜 따님이 아이를 죽게 함) → 「다시 눈을 뜨면」 중요한 시점으로 돌아가기 → 전생에 절대 안 할 일을 하기(역으로 남편 집을 백월월에게 선물, 결연히 죽음 도망, 두 집안을 살리는 걸 거절) → 나쁜 남자 / 온 식구가 카드 깔릴 때 후회하며 미쳐버림. 100% 1인칭; 쾌감은 순서대로 풀리고, 환생한 뒤는 한 걸음 한 걸음 꾀를 부리며 더 이상 참지 않는다.
- **코미디 브레인형**: 황당한 설정으로 시작(시스템 결속 / 선제 환생 / 어진이 돼지 하사 / 온 식구가 연극) → 주인공이 흐름을 타고 규칙을 박살낸다 → 경쾌한 희극 리듬 안에서 역관광 / 뒤집기를 완성한다. 정서 강도는 낮출 수 있으며, 반전과 리듬으로 승부하지만 여전히 한 마디 한 번 폭발점은 지킨다.
