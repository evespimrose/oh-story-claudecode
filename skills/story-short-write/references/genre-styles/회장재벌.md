# 소재 스타일 팩: 회장재벌 / 현대 언정 고통

> 판타지 / 칠묘 / 흑암 통속 단편. 먼저 `short-craft.md` 공용 베이스를 읽고, 본 팩은 그 위에 해당 소재 전용 조닝을 덮어씌운다.
> 한 줄 포지셔닝: **재벌집 부인 / 정략결혼 부인이 남편이 「백월월 / 소실」을 위해 단계적으로 배신당하고, 물증이 서서히 드러나 불륜이 확정되며, 한 걸음 한 걸음 괴롭힘을 당해 마음이 죽는다; 주인공이 미쳐 날뛰다가 냉정히 떠나기로 결심하고, 탄막 / 시스템 / 환생 외부 기능으로 「더 이상 충성하지 않아도 되는」 깨어난 이유를 잡고, 마침내 몸 가진 채 나가 + 경제적 반살을 이루고, 나쁜 남자가 후회하며 발버둥 친다.** 독자가 원하는 건 「소중함을 빼앗김」+「도덕적 협박이 한 마디에 꿰뚫림」+「깨어난 뒤의 통쾌함」이다.

「처참반성」과 한 뿌리(백월월 / 엿듣기 / 마음의 죽음 / 처참반성이 모두 공용)이며, 본 팩이 맛을 더하는 지점은: **나쁜 남자의 도덕적 협박 명대사, 물증이 서서히 쌓여 불륜이 확정되는 것, 미쳐 날뛰다 → 냉정 처리하는 마음 죽음 스위치, 외부 기능이 깨어남을 주는 것, 재벌 경제 / 신분 반제**. 이 다섯 가지는 본 소재의 간판이니, 처참반성만 복제하지 말 것.

---

## 서술 성격

1인칭 「나」 재벌집 부인 / 약혼녀가 전 과정을 주도하며, 밀착 체감과 심장 박동을 따라간다. 아프면 아프다고 말한다. 입을 열 때는 점유 호칭을 쓴다: 「내 남편 / 내 시아버님 / 내 약혼자 / 고씨 부인」. 그리고 재벌 설정 닻을 끼워넣는다(그룹, 주주 총회, 정략결혼, 은혜, 경성권, 승계권).

이중 궤도 전환이지만, 본 소재의 전환은 더 「독하다」: 전반에는 억울함을 토로하는 것뿐 아니라 자주 **진짜 미쳐 날뛴다**(대중 앞에서 싸움 걸기, 인터넷으로 맞서 싸우기, 물건 깨부수기); 사정을 들킨 뒤에는 **냉정 처리**로 바꾼다——소리 지르지 않고, 「그래」 하고 대답하고, 구경하며, 장부를 적는다. 냉정 처리 구간은 반어와 비꼬는 말이 대량으로 나온다.

외부 기능이 붙을 때는 **비꼬는 성선**이 하나 더해진다: 탄막 / 시스템 / 머릿속 목소리 / 환생 기억이 말을 끼어들어, 주인공에게 깨어난 판단을 주고 독자에게 쾌감을 준다. 이 성선은 구어체이고 인터넷 느낌이며 짓궂을 수 있는데, 점잖게 바꾸지 말 것.

앞으로 나아가 「처참반성」 결말을 스포일러로 사람 낚는 걸 허용하고 권장한다.

## 시작 파라다임

본문 제1장 앞에 먼저 **결과 역순의 황금 소개**(150-300자)을 한 단락 둔다. 배신 전모 + 마음의 죽음 + 「그런데 그는 나중에 후회했다 / 그가 미쳐버렸다」를 한 번에 스포일러한다; 본문 제1장에서 소개 사건을 느리게 재생하며, 대화 체감을 채운다. 본 소재 소개에는 종종 「외부 기능 / 신분 카드」를 한 겹 더 넣어 갈고리로 삼는다.

| 시작식 | 실제 사례 |
|--------|----------|
| 재난求救에 도덕적 협박 당한 일 | 《문성이 두 마음을 품다》 남편이 내가 그와 비서가 콘서트 보는 걸 방해한다고, 나를 집 안에 가뒀다. 불이 났을 때 내가 그한테求救 전화를 했는데, 돌아온 건 그저 한 마디, 「너 좀 너그럽게 굴지 않을래? 콘서트 표 두 장 가져간 것 가지고.」 |
| 신분 자술 + 은혜로 협박 | 《오년 간의 은혜, 하루 아침에 다 갚았다》 나는 허년안이자, 고택언과 결혼증명서에 적힌 반쪽이다. 그리고 그의 입으로는 은혜를 빌미로 결혼을 낚는 여자라고. |
| 냉전 헤어진 뒤 나쁜 남자가 자신만만하게 통보 | 《마음이 죽어 떠날 준비를 하다, 냉전 남자친구가 나에게 결혼증명서 통보한 일》 헤어진 지 삼년 뒤, 갑자기 친연의 문자를 받았다: 「허쪼쪼, 삼년 지났으니까 이제 화도 풀렸겠지. 오늘 밤 내가 귀국하니까 마중 나와. 네 부모님도 데리고 와. 우리 결혼증명서 상의하는 날짜 잡자.」 |
| 물증으로 시작(알레르기 있는 걸 알면서 꽃다발 선물) | 《발렌타인데이의 두 번째 꽃다발》 발렌타인데이, 남편이 보낸 꽃다발 두 송이를 받았다. 한 송이는 조화, 한 송이는 생화. 근데 그가 내가 비염이 있어서 꽃향기 못 맡는 걸 뻔히 알면서. |
| 환생 / 외부 기능 자술 | 《탄막이 나에게 악녀 따님 되라고 가르쳐 준 뒤, 소꿉친구가 나를 떠나지 못하게 됐다》 한 번 더 살아나니, 내 머리 위에 갑자기 몇 줄의 탄막이 생겼다. 【주치환아, 넌 항상 기억해! 충성견 충성한들 결국엔 가진 게 다 날아간다고!】 |
| 재벌 지분局으로 시작 | 《쌍둥이 설정? 내가 다 가지고 놀다 지쳤다》 내가 위독해지자, 그룹은 즉시 주주 총회를 열고 딸에게 경영권을 넘기려 했다. 남편은 사생아를 데리고 나타나, 당년에 사실은 내가 쌍둥이를 낳았었다고 큰소리쳤다. |

## 갈고리 모티프와 밀도

밀도가 극도로 높다: 소개에 3-5개의 배신 사건을 욱여넣고, 본문 마디마다 최소한 새로운 배신 심화나 더 독한 대사 한 마디를 넣고, 장 끝에는 반드시 새로운 폭탄을 남긴다. **계단식 배신: 도덕 → 경제 → 생명**. 본 소재는 특히 「경제」를 충분히 쌓아올린다(그룹, 지분, 승계권, 몸 가진 채 나가기).

- **도덕적 협박 연쇄**(핵심 모티프): 나쁜 남자가 배신을 「네가 너그러워야 해 / 그녀는 불쌍해 / 네가 그녀한테 빚졌어 / 네가 나한테 고마워해야 해」로 포장한다. 더 당당할수록 더 큰 갈고리다.
- **백월월 / 소실 발동 연쇄**: 남편에게 백월월 / 소꿉친구 / 전우의 딸 / 후배가 있고, 결정적인 순간 그녀를 위해 아내를 희생시킨다; 백월월은 「여리고 억울한 척」을 부드러운 칼로 쓰며, 종종 대중 앞에서 실신하거나 / 피를 보며 반대로 물어뜯는다.
- **물증이 서서히 쌓여 불륜이 확정된다**(본 소재 간판, 한 번에 엿듣는 것과 구별됨): 한 번에 내리꽂지 않고, 물증 한 건 한 건 쌓아간다——조화 / 잔에 비친 모습 / 향수 냄새 / 머리카락 한 올 / 있으면 안 되는 샘플——독자가 주인공과 함께 한 걸음 한 걸음 검증하며, 무딘 칼이 더 아프다.
- **朋友圈 / 대형스크린 글귀를 칼로 쓰기**: 달콤한 글귀 + 증표의 어긋남(주인공이 남편에게 준 시계가 백월월 팔목에 차 있거나 / 두 사람이 콘서트 대형스크린에 오르는 것). 글귀가 더 깊을수록 칼은 더 무디고 더 아프다.
- **재난기求救에 반대로 모욕당한 일**: 불이 나거나 / 뇌일혈이 오거나 / 아버지 상을 당했을 때求救 전화를 하면, 냉담함이나 「내가 회의 중이야」「보호자는 물러가 계세요」로 답변한다.
- **숫자 / 연수 / 은혜가 무게를 싣고 다시 초기화**: 결혼 오년, 사귄 지 팔년, 삼년 계약, 은혜로 협박——바친 게 쌓였다가 한 마디로 모두 사라진다.
- **외부 기능이 깨어난 이유를 준다**: 탄막 / 시스템 / 환생 / 머릿속 목소리가, 주인공에게 「이번엔 충성하지 않아」라는 근거를 주고, 비꼬는 말을 겸한다.
- **처참반성 미래 예고**: 소개 끝이나 남성 시점에서 스포일러 보상을 한 마디 끼워넣는다(「그는 어떤 늦은 밤, 미친 듯이 내 아파트 현관문을 부수고 왔다」).

## 정서 강도와 패턴(강도 9, 두 단: 미쳐 날뛰다 → 냉정 처리)

본 소재 마음 죽음 스위치는 명확히 두 단이 있으며, 강도는 내내 떨어지지 않고 형태만 바꾼다.

- **전단(미쳐 날뛰다 / 토로)**: 정서에 직접 이름 붙이고 가중한다. 눈물이 저절로 나고, 마음이 재처럼 식고, 온몸이 싸늘하다; 대중 앞에서 싸움 걸기, 인터넷으로 맞서 싸우기, 물건 깨부수기를 할 수 있다. 직설적 정서 + 신체 반응**을 중첩한다**(손톱으로 손바닥을 파고든다 / 토할 것만 같다 / 등줄기가 싸늘하다).
- **후단(냉정 처리 / 심판)**: 사정을 들킨 뒤 차갑게 바꾼다. 소리 지르지 않고, 「그래」 하고 대답하고, 구경한다. 정서는 사라지지 않고 「냉열」로 바뀐다——반어, 비꼬는 말, 장부 보기. 마음이 죽은 뒤 차갑게 반영되는 게 제일 아프다: 「이 말들은 더 이상 내 마음에 아무런 파문도 일으키지 않는다」.
- 외부 기능이 주는 깨어남으로, 후단의 차가움이 근거 있고 갑자기 튀어나온 게 아니게 된다.

실제 사례:

- 《문성이 두 마음을 품다》 내 눈물은 저절로 흘러내렸다. 억울해서인지 아파서인지 모르겠다.
- 《백许下 노래가 거품이 되어 사라지다》 내 등줄기는 싸늘해졌다. 손톱으로 손바닥을 파고들며 온몸이 떨리는 걸 억누르고, 비고 없는 전화번호를 걸었다.
- 《오년 간의 은혜, 하루 아침에 다 갚았다》 그날부터, 내 마음은 더 이상 그렇게 아프지 않았다. 하지만 마음속 어딘가가, 완전히 조용해져 버렸다.
- 《남자친구가 PUA 고수다》 나는 처음엔 미쳐 날뛰다가 나중엔 시시콜콜 따지지 않게 됐고, 심지어 그와 다른 여자를 호텔까지 데려다주는 운전을 해주기도 했다.

## 대화 스타일과 실제 명대사

비중 45-60%, 구어체, 독하고, 독립된 문단으로. 네 종류 대사가 전체를 떠받친다(본 소재는 처참반성보다 「외부 기능 비꼬기」 한 종류가 더 많다):

**① 가해자의 도덕적 협박 명대사(갈고리 본체, 더 당당할수록 더 맞다)**
- 너 좀 너그럽게 굴지 않을래? 콘서트 표 두 장 가져간 것 가지고, 꼭 그 어린 애한테 시비 걸어야 돼? 이렇게 서툰 거짓말까지 꾸며내면서. (《문성이 두 마음을 품다》)
- 네가 인터넷에 함부로 글 올리는 거, 그게 사이버 폭력이야. 천천이는 우울증이 있는데, 지금 모든 사람들이 그녀를 소실이라고 욕하고 있잖아. (《문성이 두 마음을 품다》)
- 연기 좀 잘해. 고씨 집안 체면 떨어치지 말고. (《오년 간의 은혜, 하루 아침에 다 갚았다》)
- 허년안, 난 지금 네 감정 처리할 시간 없어. 일 있으면 비서한테 연락해. (《오년 간의 은혜, 하루 아침에 다 갚았다》)
- 너 좀 너그럽게 굴어. 남자란 첩이 둘 셋 있는 게 어디 흔한 일이 아니야. (《마음이 죽어 떠날 준비를 하다》)
- 쪼쪼야, 이제 허씨 집안이 망했으니 해성권에서 누가 너랑 결혼해 주겠어? 넌 나한테 고마워해야 해! (《마음이 죽어 떠날 준비를 하다》)
- 내가 사생아가 있는 건 다 네가 일중독자라서 그래! 넌 가정에 관심도 없고 아내 된 의무도 다하지 않았잖아! 그래서 내가 밖에서 감정 기댈 곳을 찾은 거야! (《쌍둥이 설정? 내가 다 가지고 놀다 지쳤다》)
- 의사로서 난 피해야 해. 보호자는 물러가 계세요. (《의사 남편이 피하느라 수술 안 하는데, 죽는 건 그의 어머니다》)

**② 백월월 / 소실의 여린 연약검**
- 미안해요, 성성 언니. 다 내가 꼭 시오빠한테 콘서트 같이 가자고 졸라서, 심지어 대형스크린에까지 오르고 말았어요. (《문성이 두 마음을 품다》)
- 아빠, 이러면 안 돼요. 차라리 언니가 사장이 되게 하세요…… (《쌍둥이 설정? 내가 다 가지고 놀다 지쳤다》)
- 언니, 아연 오빠를 탓하지 마요. 그 애들 남자애란 게 원래 그렇게 마음이 큰 거잖아요. 아연 오빠는 언니 사랑해요. 난 그저 그가 행복한 것만 보면 돼요! (《마음이 죽어 떠날 준비를 하다》)
- (대중 앞에선 억울한 척, 은밀하게는 도발) 년아, 그 남자들한테 놀아난 거 기분은 어때? (《진짜 따님 마음에 들게 하려고, 내가 야간업소에 보내졌다》)

**③ 주인공이 마음 죽은 뒤 냉정한 심판 / 반어 명대사**
- 진총재님 오해신 거시네요. 제가 보기엔 진총재님께서 좀 우스우실 뿐인데. (《마음이 죽어 떠날 준비를 하다》)
- 이 세상에 누가 없어선 안 되는 사람 없어! 하물며 삼년이 지났는데, 난 벌써 결혼해서 애까지 둘 엄마인데. (《마음이 죽어 떠날 준비를 하다》)
- 당신이 마신 게 식스 월넛이 아니라 식스 핵이 확실해? (《마음이 죽어 떠날 준비를 하다》)
- 내 딸은 하나뿐이에요. (《쌍둥이 설정? 내가 다 가지고 놀다 지쳤다》)
- 당신은 돼지 머리를 가졌거나, 내가 바보라고 생각하는 거지? 매번 산전 검진 B超에는 아이가 하나뿐이라고 나오는데. (《쌍둥이 설정? 내가 다 가지고 놀다 지쳤다》)
- 맘껏 놀아. 근데 사생아는 만들지 마. (《남편이 사기 당해 다 날린 뒤, 내가 그의 모든 걸 가져갔다》)

**④ 외부 기능 비꼬는 성선(탄막 / 시스템 / 심정, 인터넷 느낌, 짓궂어도 됨)**
- 【충성견 충성한들 결국엔 가진 게 다 날아간다고!】【그를 시원하게 욕해줘, 목숨 바쳐가며!】(《탄막이 나에게 악녀 따님 되라고 가르쳐 준 뒤》)
- 이 남자도 너무 자신만만하지 않나? 입이 있으나 마나 하네. (《마음이 죽어 떠날 준비를 하다》 탄막)
- 나쁜 남자와 년아는 제길, 날 괴롭히지 마! (《마음이 죽어 떠날 준비를 하다》 심정)
- 숙주님, 당신이 떠난 뒤로 각본 안에 중요한 여배우가 없어져서 세상이 다 엉망이 됐어요! 주인공단이 눈치채기 전에, 먼저 돌아가서 한 때 메워주세요. (《바람이 멎고 뜻이 이미 평온하다》 시스템)

갈등은 대화 길이 반전으로 권력이 바뀌는 걸 표시한다: 나쁜 남자가 전반에 장문의 도덕적 협박 / 자신만만한 되풀이 말을 하면, 주인공은 후반에 한 마디로 차갑게 받아친다.

## 리듬 뼈대

```
황금 소개(결과 역순 + 외부 기능 / 신분 카드 + 처참반성 예고)
→ 제1장 소개 사건을 다시 쓰고, 도덕적 협박 대화와 체감을 채운다
→ 물증 서서히 쌓기 / 재난기求救가 단계별로 불륜을 확정한다(도덕→경제 심화)
→ 엿듣기 / 물증이 갖춰져, 진실이 전부 드러난다
→ 마음 죽음 정지(스위치가 미쳐 날뛰다에서 냉정 처리로 바뀜)
→ 냉정 처리 심판 + 몸 가진 채 나가기 / 경제 반제 / 신분 밝히기
→ 나쁜 남자가 후회 발버둥(처참반성)
```

매 장마다 새로운 정보 폭탄을 넣고, 장 끝에는 갈고리를 남겨 정서를 수렴하지 않는다. 밀도: 물증 검증 / 도덕적 협박 / 대중 앞 반전 구간은 느리게 재생하며 자세히 적고, 건너뛰는 건 한 마디로 넘긴다.

## 마무리 파라다임

- 처참반성 역전: 주인공이 떠난 뒤 나쁜 남자가 후회하며 / 현관문 부수고 / 미쳐 사람을 찾지만, 주인공은 더 이상 파문을 일지 않거나 냉담히 거절한다.
- 몸 가진 채 나가기 / 경제적 반살: 협의서 잘 써서 건네주고, 그룹을 텅 비워 「负翁」으로 만들고, 지분이나 CEO 신분을 밝혀 압도한다.
- 돌아서서 다른 사람과 시집가기 / 이미 결혼해서 애있는: 나쁜 남자가 자신만만하게 돌아왔다가, 주인공이 벌써 결혼해서 애까지 둔 걸 발견하게 된다.
- 무시로 마무리: 「그래」 하고 대답하고 더 이상 매달리지 않는 게, 복수보다 더 독하다.

실제 사례:

- 《오년 간의 은혜, 하루 아침에 다 갚았다》 내가 이혼 협의서에 서명을 다 하고, 그의 세상에서 조용히 사라질 때까지.
- 《쌍둥이 설정? 내가 다 가지고 놀다 지쳤다》 그룹을 갖고 싶으면 가져라. 어차피 이년 동안 난 자산을 다 옮겨 놨어.
- 《덧없는 꿈에 잠시 기대어》 근데 나중에, 그가 미쳐버렸다고 사람들이 말했다. 남루한 차림으로 거리에 무릎을 꿇고, 내 이름을 소리쳐 부르며.
- 《한 강의 안개가 맑은 날을 비추듯》 근데 나중에, 그가 눈시울 붉히고, 아무리 찾아도 집으로 돌아가는 길을 찾지 못했다고.

## 해당 소재 전용 튜닝(공용 AI 제거 규칙과의 편차)

이것들은 다른 문맥에선 AI 느낌이거나 지울 수 있는 군더더기지만, 본 소재에선 매력 포인트다. **실수로 지우지 마라**:

- **도덕적 협박 명대사**: 당당하고 논리가 더 황당할수록 맞다(「그녀가 우울증이 있으니 너그럽게 굴어」「내가 바람핀 건 네가 일중독자라서 그래」). 순하게 고치지 말고, 독자를 위해 점을 찍어주는 부연 설명을 덧붙이지 말 것——독자는 나쁜 남자가 스스로 말하게 하는 걸 원한다.
- **물증 탐정식 내심 추론 단락**: 사진 확대하기, 브랜드 증정 이벤트 있는지 찾아보기 같은 「내가 혼자 상상한 게 아님을 증명하는」 독백은, 서서히 밀어붙이는 엔진이니啰唆하다고 지우지 말 것; 지우면 칼이 무뎌진다.
- **탄막 / 시스템 / 심정 비꼬는 말**: 인터넷 느낌, 구어체, 짓궂어도 된다(「입이 있으나 마나 하네」「식스 핵이 확실해」). 점잖게 바꾸거나 문어체로 통일하지 말 것.
- **자신만만한 나쁜 남자의 되풀이 말과 반복**(「내가 너만 사랑해. 임영는 날 사랑하지만 난 그녀랑 장가 안 가」라고 되풀이하는 것): 일부러 그런 거다. PUA의 무딘 칼과 주인공의 무력감을 보여주는 거니, 반복되는 군더더기라고 깎아내지 말 것.
- **직설적 정서 성어**(마음이 재처럼 식었다 / 온몸이 싸늘하다): 유지한다. 장면 특유의 동작이나 물건 하나만 뒤에 덧붙이면 되고, 순수 동작으로만 바꾸지 말 것.
- **처참반성 미래 예고 / 결과 역순 소개**: 유지한다. 이런 의식적인 미래 스포일러는 「비밀을 다 까놓고 독자를 낚지 않는」 함부로 쓴 전지적 시점만 지운다.
- **심판 명대사 / 마음 죽음식 장 끝맺음**: 유지한다; 오직 공허한 철학 승화만 지운다.

여전히 피해야 할 진짜 AI 느낌: 눈앞에 펼쳐지더니, 속으로 생각하길, 낮은 목소리로, 입꼬리가 살짝 올라가더니, 눈빛이 번쩍이더니, 논문 접속사(틀림없이 / 이로써 알 수 있다), 체감 없는 공허한 정서 요약 문장(한 가닥 슬픔이 마음속에 밀려오더니).

> 문장 부호: 본 소재 사례는 의도적으로 원래 모습을 보존했다(`……` 포함); 본문에 쓸 때는 `short-craft.md` 제8절을 따라 `……` / `——`를 내지 말 것. 정지, 미처 못 한 말, 끼어들기당함은 반드시 짧은 문장 / 마침표 / 쉼표 / 동작 비트 / 줄 바꿈으로 구현한다. 본 팩은 `……` 쓰는 법을 가르치지 않는다.

## 함께 쓰는 구조 공식(길이에 따라 선택)

- **불륜 확정 / 용서 안 하는 타입(8-11장)**: 1-2장 물증 서서히 쌓기 + 도덕적 협박(꽃 / 잔그림자 / 향수 / 머리카락 한 올 한 건씩 확정) → 3-4장 재난기求救에 모욕당함 + 백월월이 대중 앞에서 반대로 물어뜯기 → 5장 진실이 갖춰지고 마음 죽음 정지 → 6장 스위치를 냉정 처리로 바꾸기 → 7-8장 몸 가진 채 나가기 + 경제 / 신분 반제 → 나쁜 남자 후회 거절당하기. 100% 1인칭; 도덕적 협박 대화는 「당당」하게 욕설이 아니라; 깨어남은 한 순간(사정 들키기)이거나 외부 기능으로 트리거 될 수 있다; 쾌감은 순서대로 풀린다.
- **외부 기능으로 깨어난 타입(탄막 / 시스템 / 환생)**: 먼저 전생의 죽음 법 / 시스템 임무 / 환생 시점을 설명 → 외부 기능이 켜지고 깨어남과 비꼬는 말을 준다 → 능동적으로 「전생에 절대 안 할 일」을 하기(그룹 / 백월월 / 명분을 능동적으로 남에게 주거나, 결연히 차단하고 떠남) → 나쁜 남자가 자신만만하다가 미쳐 후회 발버둥 친다. 외부 기능 성선이 줄곧 비꼬며 독자를 낚는다.
- **재벌 지분 / 신분 반살형**: 시작하자마자 주주 총회 / 정략결혼 / 은혜 협박으로 판세가 굳어짐 → 나쁜 남자가 사생아 / 백월월을 데리고 재산을 빼앗으려 함 → 주인공이 이미 텅 비게 하거나 / 카드를 쥐거나 / 진짜 신분으로 반전 → 대중 앞에서 비장의 카드를 꺼내 한 방에 뒤집기 → 무시하고 떠나기.
